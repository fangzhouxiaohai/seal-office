release: 2.5.0 云空间分享链接、Zotero 百科与移动端图标修复

移动端云盘重命名与移动提示「接口不存在」的根因修复：
Android 的 uni.request 与鸿蒙的 @ohos.net.http 都没有 PATCH 常量，
原生桥接把 PATCH 降级成了 GET，服务端匹配不到路由后返回 404。
现在统一改为 POST + X-Seal-Method-Override，服务端只接受 PATCH 这一种
覆盖值，避免被用来绕过方法限制。标签、团队、设备改名同样受益。

云空间分享链接（与文档共享互不相干的新通道）：
任何拿到链接的人都能在浏览器直接下载，无需注册和登录；可选 1/3/7/30 天
或永久有效期，可选 4–8 位数字访问码。私有文件本来就是客户端加密的，
所以文件密钥、文件名、节点标识全部放在 URL 的 # 片段里，服务器始终拿不到，
整库泄露也无法解密。访问码用 PBKDF2 派生密钥包裹文件密钥，服务端只存
scrypt 摘要并按 IP 限次。桌面、移动端 shim、落地页三处 PBKDF2 参数一致，
由新增的 parity 测试守住。文件进回收站或被彻底删除时链接自动失效。

Zotero 中文社区百科：
社区站点没有 CORS 头，浏览器直连会被拦下，因此由主进程代理，只允许访问
该域名、只允许 GET、只放行 llms.txt 与 .md 原文，不是通用反向代理。
功能并入知识库而非新建模块：Zotero 百科是「按主题组织的 Markdown 文档」，
与知识库的检索、阅读、引用、提问链路同构，单独开模块只会重复实现。
在知识库顶部加了资料源切换，引用后走同一套 AI 身份核验与资料授权。

移动端 UI：
图标库里 89 个移动端图标把品牌紫 #7363DB 写死在 SVG 上，放到品牌色实心
主按钮上几乎不可见，这就是发送按钮像空方块的原因。统一改为 currentColor，
颜色交给容器决定。发送图标原本是 0.8 描边空心细线，15px 下模糊不清，
改成实心纸飞机。文档标题栏的长文字在窄屏收成图标按钮，保留 aria-label。
分享弹窗与 Zotero 页在窄屏改为单列、按钮撑满、触控高度达标。
