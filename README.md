# 海豹办公 Seal Office

海豹办公是面向 Windows 的本地桌面办公软件，提供文字、表格、演示文稿编辑和 PDF 阅读及页面处理。界面参考 WPS 的常见布局与操作习惯，文件格式支持范围见[1.6.3 版 WPS 对标与已知限制](docs/v1.6.3-WPS对标与已知限制.md)。

主进程按文件、Office、PDF、系统四个领域拆分 IPC；渲染层统一通过 `renderer/src/ipc/bridge.ts` 类型安全调用，不再直接裸调窗口接口。

## 主要能力

- 文字编辑器：基础富文本格式、查找替换、页面布局、文档导出；支持部分 docx 内容读写。
- 表格编辑器：多工作表、基础公式、排序、区域选择和边框；支持 xlsx 与 csv 文件导入及 xlsx 导出。
- 演示编辑器：幻灯片和文本框编辑、基础放映；支持部分 pptx 内容读写。
- PDF 工具：本地文件预览、翻页、缩放，以及页面提取、合并、删除、旋转和文档导出。
- 本地文件：最近文档记录、自动备份与恢复、编辑标签关闭前确认和窗口退出提示；部分内容未能导入时提示保真风险。
- 设置页面：左侧导航、主题变量、深色模式适配、关于信息与品牌图标。

## 环境与命令

需要 Node.js 18 及以上、npm 9 及以上、Windows x64 环境。

```powershell
npm install
npm run typecheck
npm run test:run
npm run build
npm run pack
npm run dist
```

开发运行：

```powershell
npm start
```

### v1.6.3（最新）

- 接入 PDF 阅读器：本地 PDF 可从首页打开，在工具页逐页预览、翻页和缩放；页面提取、合并、删除、旋转后可保存为新文件。
- 打通首页打开文件与最近文档的共用流程；csv 文件按行列导入表格，多工作表 xlsx 可逐表载入。
- 完善文档读写保护：对 docx、xlsx 和 pptx 中未导入的对象给出提示，存在保真风险时保护原件并引导另存副本；本地文件写入采用临时文件替换。
- 完善表格数值与公式保存、演示文稿文本框及基础样式往返；Windows 打包目标包含便携版、安装版和解包目录。
- 最近文件重命名会同步磁盘路径，不支持硬链接的磁盘也能使用；置顶文件再次打开或保存后保持置顶。返回首页再打开表格、演示时保留原模型，工具栏打开新文件会新建编辑标签。
- 本地富文本导入经过安全净化，主窗口阻止跳往外部页面；窗口退出时由主进程确认仍打开的编辑标签。
- 首页推荐面板改为真实本机工具入口，侧栏移除虚构的云空间额度与签到状态；模板入口接通现有模板库，设置页明确标注尚未开放的功能。

功能边界与格式风险见[1.6.3 版 WPS 对标与已知限制](docs/v1.6.3-WPS对标与已知限制.md)，界面令牌与修复记录见[界面设计令牌与自检](docs/v1.6.3-界面设计令牌与自检.md)。
