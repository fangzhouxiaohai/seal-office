## Full description

Seal Office is a free and open-source mobile office app for creating, opening, and editing documents, spreadsheets, presentations, and PDFs. It also provides file import and export, slideshow playback, and practical document tools.

Local editing and saving do not require an account. Files are imported through the system file picker and saved in the app's document space. Content is handed to another app only when the user explicitly exports or shares it.

Cloud storage is optional. Users may also configure their own compatible AI model service. The app does not include a model, API key, or usage quota, and all local office features remain available without AI configuration. The app contains no ads or behavioral tracking and does not access location, camera, or contacts.

Highlights:

- Create, edit, format, and export text documents
- Spreadsheet editing, formulas, formatting, and common data tools
- Presentation editing, playback, ink annotations, and export
- PDF reading, generation, and common page operations
- Local file import, save, share, and workspace recovery
- Optional cloud storage and user-configured AI model services
