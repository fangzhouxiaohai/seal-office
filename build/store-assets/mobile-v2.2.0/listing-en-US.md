# Seal Office 2.2.0 Store Listing (English)

## Short description

Local-first mobile office suite

## Full description

Seal Office is a local-first office suite for mobile, desktop and web. It opens, edits, saves and exports documents, spreadsheets, presentations and PDFs.

- Documents: paragraph and font formatting, images, DOCX/PDF/TXT export
- Spreadsheets: worksheets, formulas, cell formats, XLSX export
- Presentations: slide and text editing, full-screen slideshow, PPTX export
- PDF: reading, zoom, extract, merge, delete and rotate pages
- Seal formats: `.sldoc`, `.slxls`, `.slppt` keep the complete editing model; when the font license allows, the fonts used by the document can be embedded
- Fonts: read installed system fonts, import TTF/OTF/TTC fonts without modifying the system font library
- Local first: basic editing and local saving work without an account; cloud storage and the AI assistant are optional
