## 第一章 软件概述

### 1.1 软件简介

海豹办公软件是一款跨平台办公套件，将文字处理、电子表格、演示文稿、脑图与流程图、PDF工具和模板库整合在统一工作区中。软件采用Electron + React技术栈开发，业务代码通过Web技术统一编写，分别打包为Windows桌面版、Linux桌面版、Web浏览器版、Android移动版和HarmonyOS移动版，实现同一套代码多端运行，用户在不同设备上登录同一账号即可访问同一份云端文档。

本软件定位为轻量级、免费、跨平台的日常办公工具，面向个人用户和小型团队。与传统办公套件相比，海豹办公不绑定特定操作系统，不强制订阅付费，文档默认保存在本地，用户可选择是否开启云同步。

### 1.2 主要功能模块

软件启动后进入工作区主界面，左侧为功能导航栏，包含以下八个主要模块：

1. **文字处理**：新建和编辑文本文档，支持段落排版、字体设置、页面布局、图片插入、表格插入、链接插入、引用标注、审阅修订模式，可导入导出DOCX格式，可导出为PDF、TXT、HTML格式。
2. **电子表格**：新建和编辑电子表格，支持公式计算、函数引用、动态数组溢出、多工作表管理、单元格格式设置、行列调整、自动求和、排序筛选，可导入导出XLSX格式。
3. **演示文稿**：新建和编辑幻灯片，内置12套主题摄影模板和300余种风格组合，支持文本框、图片、形状、图表插入，支持幻灯片顺序调整、全屏放映、自定义放映，可导出PPTX格式。
4. **脑图与流程图**：新建脑图项目，支持中心节点、分支节点、子节点的创建和编辑，支持节点重命名、颜色标记、折叠展开，支持流程图模式，可导出JSON和SVG格式。
5. **PDF工具**：打开和阅读PDF文件，支持页面缩略图导航、页码跳转、缩放，支持页面提取、合并多个PDF、删除指定页面、旋转页面。
6. **模板库**：提供各类办公文档模板，包括会议记录、工作计划、报告封面、简历模板等，点击模板即可基于模板新建文档。
7. **云空间**：登录后查看云端文档列表，支持文档重命名、移动、共享链接生成，支持团队空间和多人协同编辑。
8. **设置**：账号管理、界面主题、语言切换、存储路径设置、关于软件信息。

### 1.3 运行环境要求

**PC桌面端硬件要求**：
- CPU：Intel或AMD x86_64处理器，主频2GHz以上
- 内存：4GB以上，推荐8GB
- 硬盘：500MB以上可用磁盘空间
- 显示器：分辨率1280×720以上

**PC桌面端软件要求**：
- Windows 10或Windows 11（64位）
- Ubuntu 22.04 LTS或兼容的Debian系Linux发行版

**Web版要求**：
- Chrome 90以上、Edge 90以上、Firefox 90以上或Safari 14以上现代浏览器
- 网络连接（仅云同步时需要）

**移动端要求**：
- Android：Android 8.0以上系统，屏幕尺寸5英寸以上
- HarmonyOS：HarmonyOS 2.0以上系统

### 1.4 软件特点

- **跨平台**：一套代码同时构建Windows、Linux、Android、HarmonyOS和Web版本，用户无学习成本切换设备。
- **本地优先**：所有文档默认保存在本地，可完全离线使用，不强制联网。
- **开放格式**：支持DOCX、XLSX、PPTX等标准办公格式双向读写，同时提供.sealdoc、.sealsheet、.sealshow三种专属格式保存完整编辑模型。
- **实时协同**：基于Yjs CRDT算法实现多人同时编辑同一文档，自动合并冲突，无需人工解决。
- **轻量免费**：安装包体积小，启动速度快，核心功能免费使用。

## 第二章 安装与启动

### 2.1 Windows桌面版安装

1. 从官方网站下载Windows安装包，文件名为`seal-office-setup-2.1.0.exe`。
2. 双击运行安装程序，系统可能弹出用户账户控制提示，点击"是"继续。
3. 在安装向导中选择安装目录，默认安装在`C:\Program Files\SealOffice`。
4. 点击"安装"按钮，等待安装进度条完成。
5. 安装完成后，勾选"启动海豹办公"，点击"完成"。
6. 桌面会自动生成"海豹办公"快捷方式，以后双击即可启动。

### 2.2 Windows便携版

1. 下载便携包`seal-office-2.1.0-portable.exe`。
2. 将文件解压到任意目录，例如`D:\SealOffice\`。
3. 双击目录中的`海豹办公.exe`即可运行，无需安装。
4. 便携版的所有用户数据、文档、配置都保存在程序所在目录的`data`文件夹中，拷贝整个目录即可迁移到其他电脑。

### 2.3 Linux桌面版安装

1. 下载DEB安装包`seal-office-2.1.0-amd64.deb`。
2. 打开终端，进入下载目录，执行命令：`sudo dpkg -i seal-office-2.1.0-amd64.deb`。
3. 如果提示依赖缺失，执行`sudo apt-get install -f`自动修复依赖。
4. 安装完成后，在应用程序菜单中找到"海豹办公"图标，点击启动；或在终端执行`sealoffice`命令启动。

### 2.4 Web版访问

1. 打开浏览器，访问官方地址：https://seal.xingmasoft.com/office/
2. 首次加载需要几秒钟，请耐心等待。
3. 加载完成后直接进入工作区，无需安装任何插件。
4. 建议将页面添加到浏览器书签，方便以后快速访问。

### 2.5 移动版安装

**Android版**：
1. 将`seal-office-2.1.0-android.apk`传到手机。
2. 在手机设置中允许"安装未知来源应用"。
3. 点击APK文件安装。
4. 安装完成后桌面出现"海豹办公"图标，点击启动。

**HarmonyOS版**：
1. 将`seal-office-2.1.0-harmony.hap`传到设备。
2. 用文件管理器点击HAP文件安装。
3. 安装完成后在应用列表中找到并启动。

### 2.6 首次启动

首次启动软件时，会显示欢迎页面，提示用户选择界面主题（浅色/深色/跟随系统）。选择后进入工作区主界面。如果用户已有账号，可点击左上角头像进入登录页面；未登录状态下可直接使用本地功能，云同步功能需要登录。

## 第三章 文字处理模块

### 3.1 新建文档

1. 在工作区左侧导航栏点击"文字处理"图标。
2. 选择"新建空白文档"，或选择一个模板。
3. 系统打开新的文档编辑窗口，顶部为工具栏，中间为编辑区域，右侧为属性面板。

### 3.2 文本编辑

- **输入文字**：直接在编辑区域点击开始输入，支持中文、英文、数字混合输入。
- **选中文本**：鼠标拖动选中一段文字，或双击选中词语，三击选中整段。
- **复制粘贴**：选中后按Ctrl+C复制，Ctrl+V粘贴，支持从Word、网页等其他地方粘贴内容。
- **撤销重做**：按Ctrl+Z撤销上一步操作，Ctrl+Y重做。
- **查找替换**：按Ctrl+F打开查找框，输入要查找的内容；按Ctrl+H打开替换框，输入查找内容和替换内容。

### 3.3 字体与段落格式

顶部工具栏提供以下格式设置：
- **字体选择**：点击字体下拉框，选择宋体、黑体、微软雅黑、Arial等字体。
- **字号**：点击字号下拉框，选择小初、一号、二号等字号，或输入自定义数字。
- **加粗斜体下划线**：点击B按钮加粗，I按钮斜体，U按钮加下划线。
- **文字颜色**：点击颜色按钮，选择文字颜色。
- **对齐方式**：左对齐、居中对齐、右对齐、两端对齐。
- **行距**：设置单倍行距、1.5倍行距、2倍行距。
- **缩进**：设置首行缩进、左缩进、右缩进。

### 3.4 插入元素

- **插入图片**：点击工具栏"插入"菜单，选择"图片"，从本地选择图片文件插入到文档中。插入后可拖动图片调整大小和位置。
- **插入表格**：点击"插入"菜单，选择"表格"，选择行数和列数，插入表格后可在单元格中输入内容。
- **插入链接**：选中文本，点击"插入链接"，输入网址，文本变为可点击的超链接。
- **插入分页符**：点击"插入"菜单，选择"分页符"，在当前位置强制分页。

### 3.5 审阅修订

1. 点击顶部"审阅"菜单，开启"修订模式"。
2. 此后对文档的所有修改都会被标记：删除的文字加删除线，新增的文字加下划线和颜色。
3. 在右侧审阅面板中可以逐条查看修订，点击"接受"采纳修改，或点击"拒绝"回退修改。
4. 关闭修订模式后，后续修改不再被标记。

### 3.6 保存与导出

- **保存**：按Ctrl+S保存文档，默认保存为.sealdoc格式。
- **另存为**：点击"文件"菜单，选择"另存为"，可选择保存为DOCX、PDF、TXT、HTML格式。
- **打开DOCX**：点击"文件"菜单，选择"打开"，选择本地DOCX文件，系统自动解析并显示内容。

## 第四章 电子表格模块

### 4.1 新建表格

1. 左侧导航栏点击"电子表格"。
2. 选择"新建空白表格"。
3. 编辑区域显示一个默认的工作表，包含A到Z列、1到100行。

### 4.2 单元格操作

- **输入内容**：点击单元格，直接输入文字、数字或公式。按Tab键移动到下一列，按Enter键移动到下一行。
- **选中单元格**：点击选中单个单元格，拖动选中一片区域，点击行号选中整行，点击列号选中整列。
- **复制粘贴**：选中单元格后Ctrl+C复制，选中目标位置Ctrl+V粘贴。
- **删除内容**：选中单元格后按Delete键清除内容。
- **插入行列**：右键点击行号或列号，选择"插入行"或"插入列"。

### 4.3 公式计算

- **基本公式**：在单元格中输入`=SUM(A1:A10)`计算A1到A10的和；输入`=AVERAGE(B1:B5)`计算平均值；输入`=MAX(C1:C20)`找最大值。
- **引用其他单元格**：公式中直接输入单元格地址，如`=A1+B1*2`。
- **动态数组**：在支持动态数组的公式中，结果会自动溢出到相邻单元格，无需手动拖动填充。
- **常用函数**：SUM求和、AVERAGE平均、MAX最大、MIN最小、COUNT计数、IF条件判断、VLOOKUP查找。

### 4.4 工作表管理

- **新建工作表**：点击底部工作表标签旁边的加号，新建一个工作表。
- **切换工作表**：点击底部Sheet1、Sheet2标签切换。
- **重命名工作表**：双击工作表标签，输入新名称。
- **删除工作表**：右键点击工作表标签，选择"删除"。

### 4.5 格式设置

- **数字格式**：选中单元格，右侧属性面板选择货币、百分比、日期、小数位数等格式。
- **边框**：选中区域，点击边框按钮设置单元格边框线。
- **填充颜色**：选中区域，点击填充颜色按钮设置背景色。
- **对齐**：设置水平对齐和垂直对齐方式。

### 4.6 导入导出

- **导入XLSX**：点击"文件"菜单，选择"打开"，选择本地XLSX文件。
- **导出XLSX**：点击"文件"菜单，选择"导出为XLSX"。
- **专属格式**：按Ctrl+S保存为.sealsheet格式，保留完整公式和格式。

## 第五章 演示文稿模块

### 5.1 新建演示

1. 左侧导航栏点击"演示文稿"。
2. 选择"新建空白演示"，或从模板库选择一个主题模板。
3. 左侧显示幻灯片缩略图列表，中间为当前幻灯片编辑区，右侧为属性面板。

### 5.2 幻灯片编辑

- **添加幻灯片**：点击左侧缩略图下方的加号，或按Ctrl+M新建一张幻灯片。
- **删除幻灯片**：右键点击缩略图，选择"删除幻灯片"。
- **调整顺序**：拖动缩略图上下移动改变顺序。
- **复制幻灯片**：右键点击缩略图，选择"复制幻灯片"。

### 5.3 内容编辑

- **文本框**：点击"插入文本框"，在幻灯片上拖动绘制文本框，输入文字。
- **图片**：点击"插入图片"，从本地选择图片插入，拖动调整位置和大小。
- **形状**：点击"插入形状"，选择矩形、圆形、箭头等形状，拖动绘制。
- **模板**：右侧面板可切换主题模板，12套摄影主题自动应用到所有幻灯片。

### 5.4 全屏放映

1. 点击顶部工具栏"放映"按钮，或按F5键从第一张开始全屏放映。
2. 放映时点击鼠标左键或按空格键切换到下一页。
3. 按Esc键退出放映模式。
4. 放映界面左下角有导航按钮，可跳转任意页、黑屏、白屏。

### 5.5 导出

- **导出PPTX**：点击"文件"菜单，选择"导出为PPTX"。
- **保存专属格式**：按Ctrl+S保存为.sealshow格式。

## 第六章 脑图与流程图模块

### 6.1 新建脑图

1. 左侧导航栏点击"脑图"。
2. 选择"新建脑图项目"。
3. 编辑区中心显示一个默认的中心节点。

### 6.2 节点操作

- **添加子节点**：选中节点，按Tab键添加子节点，或点击节点旁边的加号。
- **添加兄弟节点**：选中节点，按Enter键添加同级节点。
- **编辑节点文字**：双击节点进入编辑状态，输入内容后按Enter确认。
- **删除节点**：选中节点，按Delete键删除。
- **折叠展开**：点击节点旁边的小圆点折叠或展开子树。

### 6.3 项目管理

- 每个脑图项目独立保存，左侧项目列表可切换不同项目。
- 每个项目有独立的撤销历史，按Ctrl+Z撤销。
- 右键点击项目可重命名、复制、删除。

### 6.4 导出

- **导出JSON**：将脑图结构导出为JSON文件，可在其他工具中打开。
- **导出SVG**：将脑图渲染为矢量SVG图片。

## 第八章 云同步与账号

### 8.1 注册登录

1. 点击左上角头像图标。
2. 输入手机号码，点击"获取验证码"。
3. 输入收到的6位短信验证码，点击"登录"。
4. 首次登录自动注册账号，无需设置密码。
5. 也可在登录后进入设置，绑定密码，以后用手机号加密码登录。

### 8.2 云空间

登录后点击"云空间"查看所有云端文档。云端文档列表显示文件名、修改时间、大小。点击文件名直接打开编辑，修改后自动保存到云端。

### 8.3 文档共享

1. 打开一个云端文档。
2. 点击右上角"共享"按钮。
3. 选择"生成共享链接"，设置链接有效期和权限（只读/可编辑）。
4. 复制链接发送给其他人，对方打开链接即可查看或编辑文档。

### 8.4 多人协同

多人通过同一链接打开同一文档时，所有人看到相同的内容，任何一人的修改会实时同步到其他人的屏幕上。系统自动合并不同人的编辑，无需手动解决冲突。光标位置显示其他协作者的头像。

### 8.5 账号注销

1. 进入"设置"页面。
2. 点击"账号管理"。
3. 点击"永久注销账号"。
4. 系统要求输入短信验证码确认。
5. 确认后账号立即注销，所有云端文档永久删除，不可恢复。

## 第十章 常见问题

**Q：软件收费吗？**

**Q：没有网络能用吗？**
