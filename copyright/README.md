## 提交前需补充的内容

1. **著作权人信息**：在 `01-登记申请表/登记申请表填写草稿.md` 中填写【待填】项；
2. **身份证明**：将身份证或营业执照扫描件放入 `04-身份证明/`；
3. **用户手册配图**：在用户手册 Markdown 中插入对应截图（截图位于 `E:\seal-office\release\promo\work-2.1.0\`）；
4. **格式转换**：将源程序 txt 和用户手册 md 打印或转换为 PDF；
5. **在线申请表**：登录中国版权保护中心网站 https://register.ccopyright.com.cn 在线填写申请表并打印签字。

## 提交方式

- 线上：在中国版权保护中心网站注册账号，在线填写申请表并上传鉴别材料 PDF；
- 线下：邮寄纸质材料到中国版权保护中心（北京市西城区天桥南大街 37 号）。

## 费用参考

- 软件著作权登记申请费：按件收取（以版权保护中心最新公告为准）；
- 如需加急，可选择加急通道，费用另计。

## 预计周期

- 普通办理：约 30-60 个工作日；
- 加急办理：可缩短至 3-10 个工作日。
