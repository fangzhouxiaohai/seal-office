# 2.6.0 电脑横版介绍视频制作说明

## 交付内容

成片位于 `release/promo/seal-office-2.6.0-pc-intro-1080p.mp4`，画幅为 1920×1080、每秒 30 帧，时长 396.5 秒。相同目录另有字幕、封面、联系表、预览片、验收报告和校验文件。成片 SHA-256 为 `28a17e5fb10d9c958c1f923706e9ded8b8cebde94caa196d7c33d425fab4fe3d`；全部交付物的校验值见 `release/promo/SHA256SUMS.txt`。

本片依照 `docs/promo/pc-current-storyboard.json` 的 34 个步骤，演示皮肤市场、文字文档的超链接、书签和页码域、Zotero 导入与引文、云空间分享链接、电子表格公式与另存、演示模板、助手任务入口、脑图与流程图，以及 PDF 跨页查找、复制、点选定位、添加批注和另存。每段均展示入口、具体操作和可见结果。录制保留鼠标点击圆环、当前目标的紫色光晕与逐字输入。

## 素材来源与边界

- 画面是海豹办公 2.6.0 生产构建的电脑宽屏界面，在隔离的 Electron 窗口中实际操作录制。录制窗口不是已打包安装的桌面程序；成片中已标注这一来源。
- Zotero 段通过本机接口读取单独导入的演示文献，仅筛选这一条资料。云分享段使用本机隔离云服务和演示账号，生成的链接经匿名接口访问检查；未读取或展示用户现有云文件。该临时链接随录制服务结束而失效。
- 文档、工作簿、PDF 和云文件均为隔离演示资料。助手段只输入任务草稿并说明登录要求，不展示虚构的生成结果。录制专用剪贴板桥接只用于验证复制操作，并恢复录制前的系统剪贴板内容。
- 配音采用用户确认的 `zh-CN-XiaoxiaoNeural`，语速 `+5%`、音调 `+4Hz`。配音文本与字幕以当前分镜为准。

## 实测验收

操作记录归档于 `docs/verification/v2.6.0/电脑横版视频操作记录.json`：34 个步骤、236 次操作、31 项功能结果检查，录制错误数为零。`release/promo/verification.json` 记录完整音视频解码、分辨率、帧率、时长、字幕、响度、紫色轮廓和逐字输入画面变化检查；联系表及 Zotero、云分享、PDF 查找与编辑的代表性画面已人工复核。

制作时发现 PDF 编辑另存后仅文件名变化也会重载阅读器，导致旧渲染任务报错。现仅在 PDF 数据变化时重载文档，并在编辑结果更新时独立挂载预览。针对文件名变化和编辑结果的单元测试通过；最终录屏中编辑后的两页正常显示，批注可见，没有预览报错。另已通过网页构建与类型检查。

成片验收后，已清理 `release/promo/` 中旧版 2.4.0 的电脑和安卓视频、字幕、封面、联系表、预览及投稿中间文件，也已删除本次录制中间目录。历史验收资料保留。本次仅交付 2.6.0 电脑横版；正式发行所需的当前版本安卓竖版须另行制作与验收。

## 复现入口

先执行 `npm run web:build`，再执行 `npm run promo:build -- --pc-current`。制作流程会生成隔离资料、配音、操作录像与成片；须在完整解码和代表性画面复核后，将验收报告中的 `visualReview` 标为“通过”，再执行 `node scripts/promo/pc-current-finalize.cjs` 归档操作记录并清理旧素材。
