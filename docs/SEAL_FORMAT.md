# 海豹办公原生文件格式 v1

| 扩展名 | 类型 |
| --- | --- |
| `.sldoc` | 海豹文字文档，兼容旧 `.sealdoc` |
| `.slxls` | 海豹工作簿，兼容旧 `.sealsheet` |
| `.slppt` | 海豹演示文稿，兼容旧 `.sealshow` |
| `.spdf` | 海豹 PDF，内含完整 PDF 字节 |

原生文件用于保存海豹办公的完整编辑状态，并可继续导出 DOCX、XLSX、PPTX、PDF 等通用格式。Windows、Linux、Web、Android、HarmonyOS 共用上述四种后缀和容器协议；不是仅 Windows 支持。已有 `.sealmind`、`.sealflow` 图形项目格式沿用各自的版本协议。旧三种后缀继续读写，新建和转换默认使用短后缀。

## 容器

原生文件是只有三个常规条目的 ZIP 容器：

1. `mimetype` 必须位于第一个本地条目，使用 STORE，不压缩；内容为 `application/vnd.seal-office.document+zip`。
2. `manifest.json` 是 UTF-8 JSON，包含 `format: "seal-office"`、`version: 1`、`encoding: "seal-json-1"`、`type: "word" | "table" | "ppt" | "pdf"`，以及正文条目的相对路径、字节数和 SHA-256。
3. `document.json` 保存编辑模型：文字使用 HTML 与页面设置，保留现有来源包和修订元数据；表格保存完整工作表模型；演示保存完整文稿模型与所引用资源的原始字节；PDF 使用 `PDF数据` 字段存放完整 PDF 的规范 base64 字节。SPDF 重开先还原这些字节，不把原字体、附件、注释、图像或文字重建为简化模型。

`document.json` 的 `{data, special}` 编码以普通 JSON 表达主体，并用路径列表明确保留 `undefined`、非有限数及负零，避免静默转换公式缓存等数据。对象只能是普通数据对象或数组；循环引用与不支持的对象类型会被拒绝。

## 校验与兼容

读取前检查中央目录、本地条目头、条目数量、重复名称、条目范围和压缩方式。拒绝加密 ZIP、额外条目、重叠范围与错误格式标识。文件及声明解压总量限制为 100 MiB，清单不超过 64 KiB；解压过程限制实际输出字节，随后校验 CRC-32、正文长度和 SHA-256。

扩展名与清单类型必须一致。不支持的版本明确报错，不尝试覆盖文件。SHA-256 用于检测损坏，不是数字签名或身份认证。导入的 HTML、页眉和页脚仍需经过现有富文本净化，来源包与嵌入元数据不被当作可执行内容。

原生保存、另存为、关闭前保存、云自动保存及共享/团队实时文档下载共用该编解码器。桌面可在另存为的格式列表中选择；移动端可在“服务 → 海豹专属格式”导出当前已打开文档的副本，或打开现有原生文件继续保存。已有 Office 文件的导入提示随原生文档保留；继续保存完整原生模型不需要经过 Office 转换。导出普通格式仍受原有保真检查保护，原生格式不表示能够重新绘制或编辑所有尚未导入的来源对象。

共享和团队空间传输相同的加密原始文件。文字、表格和演示原生格式可从各自的实时协作模型生成；PDF 使用完整文件同步，不宣称 PDF 对象级实时共同编辑。资料提取、知识库和演示模板等适用入口也识别对应的新格式，SPDF 提取前先解包。

普通文件出现未支持的内容时，打开前列出实际限制，由用户选择“转换为海豹格式”或“取消打开”。转换另存新文件并重新读取保存字节，原件不覆盖；原生容器保存已识别内容及限制记录，不把未识别内容宣称为已恢复。完全无法解码的加密或损坏文件不会创建部分内容编辑页，应先由原软件使用正确密码解密或导出标准格式。

Windows 安装版为四种短后缀注册右键“新建”，模板必须是可解码的有效容器；Linux 文件关联与 Web/移动文件选择器依据同一格式表生成或校验。各端实际编译、包内资源检查和设备验收需要分别记录，不能用浏览器模拟宿主测试代替安卓或鸿蒙真机测试。
