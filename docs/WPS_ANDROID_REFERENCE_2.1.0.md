- 包名：`cn.wps.moffice_eng`，versionName `26.10.0`，versionCode `2000`。
- APK：173,755,553 字节；SHA-256 `7a012aec41dc3ccfd1cb126c194962f3ae160ccc24105372149328203f32dd26`。
- 架构：APK 中原生库为 ARM64；雷电模拟器为 x86_64，实测能够安装和启动该样本。
- REA + ADB 37.0.1：实际设备发现、安装、启动、窗口与截图证据。

- REA 的 Windows 原生提供器明确拒绝 ARM64 ELF；未篡改目标类型或绕过提供器判断。使用同机 Ghidra 12.1.4 直接静态分析提取的 `libfileformat.so`，获得 225 个函数、94 个导出条目和 8 个选定函数的反编译结果。该库属于文件识别/组件分派层，不能等同于完整文字、表格和排版引擎。

## 实际观察与实现对应

| WPS 样本观察 | 海豹办公采用的通用交互 |
| --- | --- |
| 底部为首页、云盘、服务、找模板、我五个页面入口 | 移动工作台采用首页、云盘、服务、模板、我的；每项切换完整页面 |
| 首页内区分本机、最近、共享、星标、标签；导入属于页面动作 | 文档页提供最近、本机、共享、星标、标签，独立“导入文件”按钮 |
| 云盘与服务分别组织内容和工具 | 云盘页提供个人云空间、团队空间、知识库、回收站；服务页按创作、工具、协作、应用设置分组，并可搜索 |
| 我的页面集中账号、云服务、设备、回收站、设置等 | 我的页提供账号安全入口、云空间用量、设备、团队、共享、标签、设置与帮助 |
| 主页方法在本机/最近与漫游页面间切换 | 保留真实页面状态和原有工作区，返回处理先关闭模态层，再处理模块内部层级与页面历史 |
| 原生文件识别库有按格式、扩展名及组件选择的独立入口 | 统一维护文档格式注册表，贯通打开、保存、文件关联和跨端选择器；专属格式有独立标识、版本与完整性检查 |
