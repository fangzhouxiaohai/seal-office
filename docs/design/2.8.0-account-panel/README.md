## 方案对比

| | A 分组卡片（推荐） | B 双栏面板 | C 紧凑单列 |
| --- | --- | --- | --- |
| 结构 | 顶部账号摘要条 → 云空间卡（进度条、剩余、主操作） → 登录密码卡 → 独立危险区 | 宽屏左栏账号与密码、右栏云空间与危险区；620px 以下自动堆叠为单列 | 账号行、容量条、密码表单与注销用细分割线串成一列，留白最少 |
| 主次 | 每张卡只有一个主按钮且靠右；“注销账号”移入淡红虚线危险区，与保存按钮分离 | 同 A；宽屏时保存按钮与注销分处两栏，距离最远 | 保存按钮与再次输入同行；注销为文字链接，权重最弱 |
| 容量 | 进度条 + 已用/总量/百分比/剩余 | 进度条 + 百分比 + 已开通徽标 | 单行容量 + 细进度条 |
| 宽 1024×720 | 单列居中，720px 宽，纵向需滚动 | 一屏放下全部内容，信息密度最高 | 一屏放下，但宽屏下显得空 |
| 窄 568×966 | 单列完整，长内容在正文区滚动 | 与 A 接近（自动堆叠） | 最短，基本无需滚动 |
| 风险 | 内容最长，小窗口滚动最多 | 两栏在 620–900px 之间可能显得拥挤，需要额外断点走查 | 字段标签改为占位符，读屏与长英文文案可读性较弱 |

**建议选 A**：分组最清楚、危险操作隔离最好、对现有组件改动最小，窄屏和宽屏表现一致。若更看重宽屏一屏看全，选 B。

## 共同约束（实现时遵守）

- 间距 4/8/12/16/24/32，字号 12/13/14/16/18，圆角 10 与 14。

- 点击目标不小于 36×36；中英文长文案、200% 缩放与 568 宽窗口不溢出。
