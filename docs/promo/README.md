# 海豹办公宣传视频

基于 Windows 版 1.6.7 制作，包含仓库与下载入口、底部标签切换、文字编辑与保存、表格公式、演示放映、PDF 页面工具、智能助手入口、本地工具、帮助手册和推荐介绍。

## 成片规格

| 项目 | 横版 | 竖版 |
| --- | --- | --- |
| 画幅 | 16:9 | 9:16 |
| 分辨率 | 1920 × 1080 | 1080 × 1920 |
| 时长 | 3 分钟 | 3 分钟 |
| 帧率 | 30 帧/秒 | 30 帧/秒 |
| 视频与音频 | H.264、AAC、MP4 | H.264、AAC、MP4 |

两版使用温柔普通话女声、同步中文字幕和自行合成的低音量伴奏。竖版单独排版，增加操作特写。结尾提供仓库地址及可扫描的二维码。

## 内容依据

- 仓库画面来自实际公开页面，软件画面来自 1.6.7 Windows 成品。
- 操作使用独立演示文件和用户数据目录，没有使用个人文档或模型密钥。
- 智能助手展示配置、文件范围和输入入口，没有接入模型发送请求，也没有模拟回复。
- 讲解明确当前基础办公范围、复杂 Office 对象的兼容边界，以及云端协作和 PDF 正文编辑尚未开放。
- [讲解与分镜](storyboard.json)保存全部配音文本、视觉令牌与镜头顺序；`assets/` 保存仓库截图及录制关键帧。

## 本地输出

成片及附属材料位于 `release/promo/`，作为构建产物不提交入源码仓库：

- 海豹办公-横版宣传片-1080p.mp4
- 海豹办公-竖版宣传片-1080p.mp4
- 海豹办公-宣传片字幕.srt
- 海豹办公-宣传片配音.wav
- 横版与竖版封面，以及成片核验记录

## 制作命令

制作脚本位于 `scripts/promo/`。需要 Windows、Python 3.11 及以上、Node.js 22 及以上，以及系统微软雅黑字体。配音调用在线语音服务；运行时请遵循服务条款。

```powershell
python -m pip install -r scripts/promo/requirements.txt
python scripts/promo/prepare_audio.py
node scripts/promo/record_app.cjs 9346
python scripts/promo/render_video.py --preview
python scripts/promo/render_video.py --mode both
python scripts/promo/verify_video.py
```

录制前，使用独立用户数据目录启动 1.6.7 解包成品，启用仅监听本机的调试端口，并打开演示 DOCX、XLSX、PPTX 和 PDF 文件。窗口需要正常显示。原始帧序列、逐词配音时间记录和编码缓存保存在 `release/promo/work/`，重新生成视频时需要保留这些工作文件。

需要代理时，可给配音脚本传入 `--proxy` 参数。脚本按讲解内容校验配音缓存，不记录访问凭据。发布到视频平台前，可按平台要求选用相应画幅。

## 画面自检与修正

1. 修正品牌标识的透明底，避免黑色边角。
2. 按语义调整横版标题断行，避免孤字落在下一行。
3. 重新选择竖版特写的关键帧与裁切范围，完整展示文字表格和模型配置字段。

交付前检查两版尺寸、180 秒时长、5400 帧、完整音视频解码、字幕时间范围、音频响度和成片二维码。
