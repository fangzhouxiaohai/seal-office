# 海豹办公 2.3.0

**本版重点：修复打印空白、提升 Word/WPS 兼容、全新 Vivid 界面。**

## 更新内容

- **打印不再空白**：以前打印时把 PDF 直接交给隐藏窗口，Electron 只打印 PDF 查看器外层的空页面。现在先用 pdf.js 逐页渲染为图片，再交给系统打印；纵向、横向混排页面保持原始纸张尺寸，页数与预览一致。
- **Office / WPS 兼容**：新建 Word 文档写入 Word 2013+ 兼容设置（`compatibilityMode=15`）和中文主题语言，Word 不再以“兼容模式”打开；打开的旧文件保持原有设置。PPTX、XLSX、DOCX 的文件属性不再出现 “PptxGenJS”“Un-named” 等占位作者，PPTX 文字标记为简体中文。
- **Vivid 界面**：紫罗兰主色与渐变主按钮；侧栏、图标栏、应用中心、新建窗口按入口分色；卡片、胶囊式功能区、弹窗、菜单统一圆润造型；深色模式同步更新。
