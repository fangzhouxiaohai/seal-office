# 海豹办公 2.4.0

**本版重点：皮肤市场、云空间全格式预览、截图直接粘贴。**

## 更新内容

- **皮肤市场**：“云服务”新增皮肤市场，内置海豹紫（默认，与 2.3.0 配色一致）、深海蓝、森林绿、樱花粉、琥珀橙、石墨灰、薄荷青、勃艮第红、星空靛、暖沙米 10 套皮肤，每套都有浅色和深色两组颜色，并通过正文、次要文字与主按钮的对比度校验。可悬停预览、一键应用、导出为开发模板。
- **自制与公开皮肤**：`.sealskin` 皮肤文件导入后只在本机生效；登录并开通云空间后可上传申请公开，管理员在后台“皮肤审核”通过后，所有用户可在“公开皮肤”中安装。皮肤只包含颜色、圆角和可选背景图，不接受脚本、样式代码或外部链接，客户端与服务端使用同一套校验。开发规则见 `docs/皮肤开发规范.md`。
- **云空间全格式预览**：云空间文件菜单新增“预览”。图片、音视频、文本与代码、PDF、Word / Excel / PowerPoint（含旧版 DOC / XLS / PPT）、OFD、EPUB、压缩包、邮件等格式在本机解密后直接预览，文件不发送给任何第三方服务；可编辑格式提供“用海豹办公打开”，不支持或超过 100 MB 的文件给出中文说明并可下载。预览组件资源随安装包本地分发，不访问 CDN。Android / HarmonyOS 受云打包体积上限约束，使用精简预览。
- **截图直接粘贴**：文字、表格、演示中按 Ctrl+V 或右键“粘贴”可直接插入系统截图、QQ / 微信截图和浏览器复制的图片。
- **界面细节**：右键菜单按功能配彩色图标，AI 命令统一为多彩星星图标；云空间各页面首次读取时显示统一的加载状态，不再出现空列表闪烁。

本版未重制介绍视频，沿用 2.3.0 版视频。
