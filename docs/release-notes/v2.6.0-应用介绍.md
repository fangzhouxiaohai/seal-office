# 海豹办公 应用介绍

海豹办公是一款本地优先的跨平台办公工具。文字、表格、演示和 PDF 可以在手机上打开、编辑、保存与导出，并与 Windows、Linux、Web 版互通。基础编辑全部在本机完成，不需要注册账号即可使用；电脑上没处理完的文档，可以直接在手机上接着改，排版与内容保持一致。程序优先保证“打开就有内容、改完能存回去”，遇到超出现有能力的内容时如实说明原因，不用空内容或默认数据掩盖问题。

主要功能：

一、文字文档

支持正文编辑、段落缩进与间距、行距、上下标、软回车等常用排版操作，可插入正文内嵌图片并进行八向尺寸调整、旋转、精确宽高设置、正文移动、像素裁剪、水平与垂直翻转。图片随文档一起保存，重新打开后位置、尺寸与裁剪保持不变；多张图片可分别设置正文移动与段落布局，调整后文字排版随之重排。提供查找替换、标题导航、分页符与邮件合并，页面设置中的常用参数可以往返读写。

标题导航会按文档层级列出全部标题，点击即可跳转到对应位置，长文档不必反复滚动查找。邮件合并可按数据表批量生成多份文档，字段映射关系可预览确认后再批量输出。页面设置支持纸张尺寸、方向、页边距与页眉页脚开关，保存后重新打开仍可读取。

编辑区支持完整的撤销与重做，本地操作逐步可回退。插入功能包含超链接、书签、页码与总页数域：超链接会写入真实的跳转目标，并拒绝脚本类危险地址；书签写入与 DOCX 一致的定位标记；页码插入的是可自动更新的域而不是固定数字，文档增删内容后页码自动重算。文末注释支持脚注与尾注，引用标记与注释内容成对插入，整体作为一次操作记录，可一次性撤销。

文字文档可导出为 DOCX、PDF、HTML 与 TXT，其中 DOCX 会保留正文、基础字符格式、常用段落排版、标题、列表、简单表格、内嵌图片及部分页面设置。打印前可先预览，检查纸张、方向、页边距、图片与页眉页脚，纵横混排的页面保持各自的原始纸张尺寸。

二、电子表格

支持多工作表管理、基础公式计算、排序、筛选、冻结窗格、单元格合并、基础格式设置、批注、数据验证与无密码工作表保护。公式支持常用算术与统计运算、单元格引用与区域引用，修改被引用单元格后结果自动重算，输入错误时在单元格内直接显示原因而不是留空。冻结窗格可固定首行与左侧列，长表格滚动时表头保持可见。单元格内可插入 PNG 与 JPEG 静态图片。CSV 与 TSV 支持按原格式导入与保存，XLSX 支持往返读写，也可在 Windows 上与旧版表格和开放表格格式互转，转换前会提示可能丢失的格式项。数据验证可限定单元格的取值类型与范围，超出范围的输入会被拦下并说明原因。

拖选多个单元格后，编辑区上方会自动浮出操作面板，可直接合并居中、求和、清除内容或套用格式，无需再翻找菜单。表格的右键菜单补齐了调色板、数据操作与智能助手分组，常用操作集中在一次点击之内。表格支持按当前工作表打印，也可整表导出。

三、演示文稿

支持幻灯片增删、复制、排序、隐藏页与逐页备注；对象可多选、拖动、缩放、旋转、组合、调整图层、锁定、对齐分布，并提供标尺与参考线。文本框与原生对象分开选中，组合成员可逐个编辑，锁定对象需先解除锁定才能改动。

可插入的原生对象包括图片、基础图形、两种矢量图标、艺术字、原生表格（行列编辑与合并拆分）、柱状图与折线图与饼图（含数据、系列、图例与数值格式）、流程与层级与循环与脑图四类语义图、公式、附件以及音视频。公式写入原生数学部件，附件保存真实字节并可插入而不执行其中的宏或脚本，语义图与图示部件保留原有结构与几何。

主题方面提供主题悬停预览与确认应用、配色方案、统一字体、单页或整篇背景（纯色、渐变、图片）、16:9 与 4:3 及自定义尺寸与方向，支持本地模板与自定义主题导入导出。母版与版式可多套共存，新建页面时选择目标版式，已有页面的主题配色可一键统一，不需要逐页重新调色。切换与动画提供 15 种切换效果、出现与淡入淡出与进入退出动画、图表分步动画，可设置持续时间、方向与效果选项，支持应用全部、单击与自动换片以及循环放映。

放映支持从头或从当前页开始、跳过隐藏页、按页面稳定标识的自定义放映、放映范围与循环，放映时铺满当前屏幕并自动隐藏助手，退出后恢复原窗口与对话。演讲者视图为独立只读窗口，可查看当前页、下一页、备注与计时并控制翻页。另有窗口阅读视图，便于一边查看一边处理其他内容。

批注功能支持线程化讨论，可记录作者、回复与解决状态，并支持上一条与下一条跳转，批注可随时隐藏而不删除。本机排版检查覆盖八类常见问题，按页给出可定位的提示，点击直接跳到对应对象，便于一次性清理完毕；繁简转换支持词组级切换。文档定稿后可锁定为只读，也可随时解除；两份文稿可比对，逐页显示增删移动以及文本、对象、备注、批注与动画的差异，并可直接定位到有差异的那一页。

音视频对象插入前会先探测本机解码能力，不支持时直接拒绝并说明原因；可设置封面、播放范围、音量、循环与进入页面自动播放。对象动作可打开网页、跳转指定页或结束放映。放映时提供画笔、橡皮、激光笔、黑屏与白屏，便于现场讲解。

导出支持 PNG 与 JPEG 图片（可选分辨率倍数）、PDF（按实际页尺寸、范围与隐藏页选项，并可输出讲义与备注）、扫描件 PDF、图片型 PPTX 与 HTML 预览。演示文稿还可截屏与录屏，录屏支持屏幕或窗口捕获、区域裁剪、暂停与预览，麦克风需单独勾选，录制内容只有保存后才写入本机文件。此外支持从图片识别文字、讲稿生成与讲解音频合成。

四、PDF

支持居中预览、翻页与缩放。页面工具提供提取、合并、删除、旋转与插入空白页，可把多个 PDF 或其中的指定页面重新组合成新文件，也能在窗口中插入新页面。

阅读时可按 Ctrl+F 打开查找栏输入关键词，全部命中同时高亮并显示总条数，按 F3 跳到下一处、Shift+F3 返回上一处，也可点查找栏的上下箭头逐条浏览。跨行与跨栏的文字会被正确拼接，长文档中不会漏掉被切成多段的词，页面旋转后高亮位置依然准确。

文字层支持框选与复制：拖动即可选中任意一段文字，松开后编辑区上方浮出操作面板，可一键复制、翻译、解释、总结或就选中内容向助手提问；右键菜单另提供整页复制与全文复制。复制时保留原始换行与段落顺序，粘贴到其他程序后不需要手工清理多余空白。

编辑模式可直接在页面上点选目标位置来放置内容，支持新增文字、插入图片、添加批注、遮盖敏感内容与覆盖替换原有文字，点选处的坐标自动回填到编辑参数区，无需手工估算位置。文字支持字号与颜色设置，中文字体自动嵌入，输出后在其他阅读器中显示一致。文字文档也可导出为 PDF。

五、文献引文

写作需要引用参考文献时，可直接在文字文档中使用引文功能，无需手工排版书目。内置 GB/T 7714—2015（顺序编码与著者-出版年两种）、APA 第 7 版、IEEE、Nature、Vancouver 共六套学术样式，插入正文引注后自动生成文末参考文献表。

每一条引注可单独指定页码、章节等定位信息，同一处需要引用多篇文献时可合并为一个引注组，序号与排序由样式自动确定。切换样式时已插入的引注与书目整体重排，不需要逐条重做。引文以标准域代码保存，文档在 Word、WPS 等办公软件中打开仍是可刷新的引文域，不是写死的纯文本。增删文献或调整段落顺序后点「刷新全部域」，全篇序号与书目自动重排；不再需要联动时点「取消链接」，即可把引文转为普通文字。文档保存并重新打开后，引文与书目保持不变。

电脑上装有 Zotero 文献管理软件并开启本地接口时，可在「Zotero 文库」页签点「读取文库」直接获取本地文献条目，支持单条加入与一键全部加入。条目会按文献类型映射为通用引文数据，重复文献自动跳过并说明具体原因。

六、智能助手

助手支持按文件隔离的加密持久记忆，可自动压缩长对话摘要，能给出真实的任务计划并先规划后执行。原生工具循环会在结果不符合预期时纠正重试，长回复按批刷新，大文件分页读取，大批修改分页审阅，取消与保存路径绑定贯穿整个任务过程。

内置 DeepSeek、豆包、智谱与 Kimi 服务预设，也支持自定义兼容接口，可实时显示服务商返回的思考与正文，提供六档思考强度并默认高档，生成过程中可随时停止。每个文件拥有独立的对话上下文，切换文件不会串题，历史对话与记忆可分开清理。

助手给出的修改建议不会直接改稿：先列出待改动的段落或对象，按原文逐条校验，你可以逐项确认或全部放弃；应用后仍可撤销，并随文档一起保存。需要联网的能力只有在你主动使用时才会发起请求。

七、云空间与知识库

可选开通云空间用于跨设备同步。账号安全页可查看已授权设备、修改密码与生成恢复密钥；恢复密钥由用户自行保管，所有授权设备与密钥同时丢失后无法找回内容，停用与清空会删除活动数据，备份至多保留七天。云空间提供文件浏览、上传、下载、重命名、移动、标签与版本管理，每账号配额 300 MB，自动保存须先开通云空间再手动开启。标签可以自定义分组，版本历史可回看并回滚到旧版本，误删可从近期备份恢复。在手机上新建或修改的文件会同步到同一账号的桌面端与网页版，反过来也一样。文件菜单提供预览，图片、音视频、文本与代码、PDF、Word、Excel、PowerPoint、OFD、EPUB、压缩包与邮件等格式在本机解密后直接预览，不发送给第三方服务。

翻译与语义校对可针对整段或全文执行，翻译前可指定目标语言，校对会标出可疑表述并给出修改建议，均需用户确认后才写回正文。分享链接是独立于文档共享的免登录下载通道，有效期可选 1、3、7、30 天或不限时间，访问码 4 至 8 位可选。文件本身仍是本机加密后上传，因此链接把文件密钥、文件名与节点标识放在 URL 片段中（浏览器不会把片段发给服务器），落地页在本地完成解密；访问码只用于包裹文件密钥，服务端仅保存校验摘要，无法还原明文内容。

知识库可将自有资料上传后用于检索与问答，支持扫描件识别与来源标注，回答会标明引用到的段落出处，便于核对原文；文献管理相关的社区文档资料也可作为知识源并入，目录、检索、阅读与引用提问复用同一条链路。此外提供演示模板市场，可按类别与风格筛选并直接创建演示文稿。

协作方面，云项目支持邀请成员、分配角色与实时共同编辑，成员改动即时可见，服务端只保存加密内容。共享链接与团队权限分属两套机制：前者面向外部临时取阅，后者面向内部长期维护，避免把内部文件误做成公开下载。团队空间可按成员分配权限，适合小组共同维护资料与文稿。

八、工具工作区

日历支持按月视图查看与编辑日程，可记录标题、时间、地点与备注，同一天多个安排会并排列出而不互相遮盖；数据保存在本机并可导出，删除日程前会二次确认。笔记支持 Markdown 书写与预览，可新建多个笔记本、添加标签、插入图片，并按标题、正文或标签搜索，导入导出可编辑文件。

脑图与流程图提供多种结构与版式，节点可拖动调整、展开收起、设置样式与连线文字，既可保存在本机，也可显式建立加密云项目，通过共享或团队方式共同编辑，支持多人实时协同与版本回退。

设计工具用于制作海报、方图、横幅与信息长图，可从模板开始或使用空白画布，宽度与高度在 200 至 2400 之间任意设定并可一键交换；进入画布后可编辑文字、形状、图片与图层，保存为可继续编辑的文件。

Windows 版另提供 Access 数据库工作区与多表管理，可浏览表结构、查看与编辑记录。常用目录可固定本机常用路径，快速打开其中的文件。

九、文件与工作区

文件页不再使用全局左栏，改为底部固定标签切换文件和返回首页，正文使用完整工作区，屏幕空间利用率更高，手机上尤其明显。顶部区保留文件名与保存状态，未保存时给出明显标识，避免漏存。支持多标签同时打开多份文件，双击关闭标签，关闭前会提示未保存的改动；从系统拖入文件可直接打开，近期打开记录可批量移除。在文字、表格、演示中粘贴可直接插入系统与聊天工具的截图，不需要先另存为文件；打开失败时通过固定弹窗说明具体原因，不用空白页代替错误提示。

关闭时若有未保存内容，会弹窗提供取消、保存后退出与不保存退出三种选择；选择保存后退出时，没有保存路径的文档会先询问位置。文件在应用外被修改或导入不完整时会提示风险并保护来源文件，不会用空白内容掩盖损坏。未保存的工作区会自动备份，异常退出后可静默恢复。

移动端的系统返回键按当前层级逐级退出：有浮层时先关浮层，在多标签中先回文件列表，再回到桌面，不会误把正在编辑的内容丢掉。

十、视图与交互

文字、表格、演示与 PDF 阅读均支持按住 Ctrl（macOS 为 Command）滚动滚轮缩放，也可用状态栏的减号、百分比与加号控制，点百分比回到百分之百。四类文件共用 8.33% 至 6400% 的连续档位，默认打开比例为 150%，可覆盖从全局缩略到逐字校对的全过程。缩放只改变本机查看比例，不写入文档，也不影响打印与导出的页面尺寸。

选中内容后的浮窗按当前情境变化：选中文字时给出字体与段落相关项，选中表格多格时给出合并、求和与数字格式，选中对象时给出图层与对齐。浮窗位置跟随选区，靠近页面边缘时自动翻转到另一侧，不会遮住正在编辑的内容。

在文字里选中一段文字、表格里拖选多格、幻灯片里点选对象、PDF 阅读区选中文字后，编辑区上方会自动浮出操作面板，集中提供复制、剪切、格式刷、字体与段落格式、突出显示、字体颜色、对齐、合并居中、求和、清除内容等操作，并附带润色、扩写、缩写、重写、语气调整、翻译、解释、总结、续写与问答等快捷动作。面板不抢占输入焦点，随滚动或按 Esc 自动收起，助手返回的结果按预览确认后写回。

界面提供深浅色模式切换，固定显示在每个页面的右上角；皮肤市场内置十套皮肤，每套包含浅色与深色两组颜色并做过对比度校验。皮肤文件只包含颜色、圆角与可选背景图，不接受脚本、样式代码或外部链接，导入后仅在本机生效。

十一、新建文件与模板

可从首页直接新建文字、表格、演示、PDF 与设计文件，并提供多套起始模板。Windows 安装版在资源管理器的新建菜单中提供 DOC、DOCX、PPT、PPTX、PDF、XLS、XLSX 七种真实空白模板，由系统菜单直接建出可编辑文件，不依赖本机是否安装其他办公软件；升级保留原有菜单备份，卸载时不会破坏其他程序后来修改的设置。

设置中心可把海豹办公设为常见文档格式的默认打开程序，覆盖包含 CSV、模板与开放文档在内的多种格式。尚未全部关联时会给出一次性确认，确认后进入系统默认程序页面，取消则直接继续使用，两种选择之后都不再重复询问。

十二、语言、快捷键与帮助

界面支持简体中文与 English 两种语言即时切换，无需重启。常用操作提供键盘快捷键：保存为 Ctrl+S，另存为 Ctrl+Shift+S 或 F12，打印预览为 Ctrl+P，撤销重做为 Ctrl+Z 与 Ctrl+Y，全选、查找与替换分别为 Ctrl+A、Ctrl+F 与 Ctrl+H。快捷键按文字、表格、演示、PDF 与放映五个作用域分开配置，可逐个修改或一键恢复默认，冲突时会提示改用其他组合。

内置帮助手册按文件类型分区，可就地查看排版规范、导出说明与兼容边界。程序内的「联系客服」使用固定弹窗展示联系方式，关闭后回到当前页面，不打断正在进行的编辑。

十三、文档转换服务

手机上打开旧版文字、演示与部分开放格式时，使用您自行配置的转换服务完成。配置项只有服务地址与访问令牌，可先执行连通检查并查看服务端返回的输入数量与单文件大小上限，检查不通过会给出具体原因；上传正文前逐次确认服务地址，转换完成后删除服务端临时文件。Windows 版内置离线转换引擎，无需配置即可使用。

十四、格式兼容与平台

格式兼容方面，DOCX 可读写正文、基础字符格式、常用段落排版、标题、列表、简单表格、PNG 与 JPEG 与 GIF 与 BMP 内嵌图片及部分页面设置，图片的内容、顺序、显示尺寸与说明会完整保留，单张限 20 MB、文档图片累计限 100 MB。XLSX 可读写受支持的工作表、基础格式与静态图片。PPTX 可读写文本框、备注、图片、基础图形、矢量图标、艺术字、原生表格、图表与嵌入数据工作簿、语义图与连接线、主题与配色、多母版与版式、页面尺寸与背景、页脚日期页码、切换与对象动画、批注、公式、附件与原生图示部件。PDF 可阅读并处理页面，文字文档可导出 PDF。CSV 可导入表格并另存为 XLSX，HTML、HTM、TXT 与 MD 可打开文字内容。

需要说明的是，旧式 DOC、XLS、PPT 在本机不作正文编辑，需要原格式编辑时可使用其他兼容程序打开；RTF 与 ODF 目前未接入。外部兼容性验证在本机实际安装的办公软件上完成，未在 Microsoft Office 中逐项核验的格式行为，本介绍不作相关声明。遇到无法完整保留的内容，程序会列出实际损失项，建议先另存副本再继续编辑。

平台方面，海豹办公提供 Windows 安装版与便携版、微软商店包、Ubuntu 版、Web 版以及 Android 移动版。各平台共用同一套文档格式与编辑内核，同一份文件可在不同设备之间继续编辑。桌面端侧重批量排版与打印输出，移动端侧重随时查看、快速修改与分享，两端打开同一份文件时显示同一份内容，不会出现两套不一致的版本。

程序启动时会做一次安装完整性检查，发现文件异常会明确列出受影响项并给出修复建议，不会以残缺状态静默运行。设置中心可恢复初始设置、修改新文件提醒方式与本地工作偏好，修改后立即生效。

隐私方面，基础编辑在本机完成，程序内没有使用统计、遥测上报、崩溃转储上传与广告组件。可选登录、云空间与云文档自动保存均由用户主动开启，云空间默认关闭。只有您主动使用助手、翻译、语义校对、语音合成等联网功能时，才会把完成该次请求所需的片段发送到您自己配置的服务地址；密钥、对话与记忆使用系统数据保护能力加密保存在本机用户数据目录。私有云文件、名称与索引在客户端加密后上传，服务器无法直接解密内容。您可随时删除本机用户数据目录以彻底清除本地数据，自己保存的文档不受影响。

总结而言，海豹办公适合需要在本机处理日常文档、又不想被账号与网络绑定的人使用：文字、表格、演示、PDF 四类工作在同一窗口内完成，引用文献、协作分享与智能改写按需开启，不用时不占用带宽也不上传内容。
