# 海豹办公 2.6.0 新版本特性

## 本次更新

1. 新增文献引文功能，写作时可直接插入规范格式的参考文献，无需手工排版书目。打开文字文档编辑区顶部的「引文」入口，可从内置六套学术样式（GB/T 7714—2015 顺序编码与著者-出版年、APA 第 7 版、IEEE、Nature、Vancouver）任选其一，插入正文引注并自动生成文末参考文献表。引文以标准域代码保存，文档在 Word、WPS 中打开仍是可刷新的引文域，不是写死的纯文本；增删文献或调整段落后点「刷新全部域」，全篇序号与书目自动重排，也可随时「取消链接」转为普通文字。

2. 新增与 Zotero 文献管理软件的直连读取，省去逐条录入文献的重复劳动。电脑装有 Zotero 并开启本地接口后，在「Zotero 文库」页签点「读取文库」即可获取本地条目，支持单条「加入」与一键「全部加入」。重复文献自动跳过并说明原因，不会重复写入。

3. 新增 PDF 关键词查找。阅读时按 Ctrl+F 打开查找栏，输入关键词即可跨页检索，全部命中同时高亮并显示总条数；F3 跳到下一处、Shift+F3 返回上一处，也可点查找栏箭头逐条浏览。

4. 新增 PDF 页面编辑模式。打开后可直接在页面上点选目标位置，放置新增文字、插入图片、添加批注、遮盖敏感内容或覆盖替换原有文字，点选处的坐标自动回填到编辑参数区，无需手工估算位置。

5. 新增文字文档的超链接、书签与页码域插入。超链接可给选中文字挂上真实跳转目标，书签写入与 DOCX 一致的定位标记，页码与总页数插入的是可自动更新的域而非固定数字。三者均随文档保存，重新打开后保留。

## 修复与优化

1. 设备兼容性修复：现已解决移动端系统返回键层级判断错误的问题，确保多标签、浮层与工作区切换时按正确层级逐级退出，不再误跳回桌面，各机型表现一致。

2. 功能可用性修复：现已解决文字编辑器多个插入入口只提示「暂不可用」的问题，确保超链接、书签、页码三项核心插入功能真实写入文档并可保存重开。

3. 场景稳定性修复：现已解决表格与演示编辑器存在「功能开发中」无效入口的问题，确保不再有只弹提示、不执行操作的按钮；同时保证引文域在编辑器重新渲染后完整保留，刷新与保存不丢域代码。

4. 服务问题：现已解决后台上传管理页面打开后整页空白的问题，确保页面样式与脚本正常加载，管理功能立即可用。
