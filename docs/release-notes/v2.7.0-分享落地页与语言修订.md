# 2.7.0 分享落地页与界面语言修订

## 现象与定位

用户在 Windows 版生成的 `/share/#/s/...` 链接打开后进入管理后台登录页；“我的分享”提示接口不存在；生成链接后必须再点一次复制；英文界面中的多维表格等页面仍有固定中文控件。对照本地源码和线上状态，匿名下载页 `share/index.html` 未部署到站点，现有站点配置将 `/share/` 回退到管理后台首页，当前运行的后端版本缺少已写入仓库的“我的分享”路由。分享弹窗的复制动作只绑定在按钮上。语言适配表也未覆盖多维表格的固定文案。

## 修订方案与验收

1. 将匿名下载页作为独立静态资源随服务端部署；站点为 `/share/` 设置独立路由，打开链接直接显示文件信息、访问码输入框或下载按钮，不暴露管理后台登录界面。浏览器端在本地解密；公开接口保持匿名可访问，分享管理接口仍要求文件拥有者登录。
2. 服务端部署前核验“我的分享”路由包含在待发布版本，部署后检查当前运行版本及账号隔离测试；不得修改已有用户文件或分享记录。
3. 链接创建成功后立即尝试写入系统剪贴板，成功时明确提示“已生成并复制”；复制失败时保留完整链接和手动复制按钮，并给出中文说明，不误报成功。
4. 补齐截图涉及的多维表格固定文案，并对其他主要入口和页面做英文界面扫描。文件名、用户输入和文档正文不参与翻译。切回中文应恢复原有文案。
5. 客户端、网页、服务端分别通过自动测试和线上匿名访问验证后，再重新生成对应发行包、更新 README 与验收记录。
