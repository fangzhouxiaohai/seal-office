# 2.7.0 界面与稳定性修订

## 分享下载

分享页输入错误访问码后继续显示输入框，允许直接修改和重试。新生成的链接为页面入口增加版本参数，分享凭据仍只放在链接片段内；服务端为分享页面及脚本设置禁止缓存。旧链接仍可使用，浏览器若保留了旧后台页面，需要刷新或清除该站点缓存。具体部署、隔离验证和回滚记录见[分享页修复说明](v2.7.0-分享链接缓存与访问码修复.md)。

## 界面和语言

- 帮助主题、内置知识指南、移动导航、编辑器状态及设置快捷键等固定界面补充英文，搜索和无障碍名称一并更新；用户文件内容、现有文件名和历史助手消息保持原文。
- 新建空白文件时根据当前界面语言选择默认名称；切换语言不会重命名已创建或已打开的文件。
- 移动端云自动保存提示在窄屏下分行排列，状态文案和编辑、阅读视图提示跟随界面语言。
- 模型设置中的保存和清除按钮重新排版，保留清除前确认，按钮颜色跟随当前皮肤。
- 安卓启动页保持单一系统画面，缩小海豹标识并使用等比例名称；安卓 Java 工程固定在仓库根目录 `android-studio/`，旧 HBuilderX 工程继续保留。

## 本轮已完成的验证

- 网页生产构建完成 45 项浏览器功能检查；扩大语言检查覆盖 84 个界面区域，记录到 0 处可见英文界面漏译和 0 个渲染错误。新版网页 `2.7.0-web-20261106-032200` 已部署，公网回归通过。
- 安卓正式包使用原证书签名，在隔离模拟器覆盖安装；30 个工作台资源与本轮安卓构建逐字节一致。模拟器实际系统返回键覆盖五个主导航、文字和 PDF 全屏阅读、演示放映；英文状态和窄屏提示条同样检查。冷启动截图中标识宽 88.3 dp，名称约 70 × 16.3 dp，标识与名称间距 10 dp。
- 鸿蒙使用本机原生编译链生成 HAP 和 App Pack，分别验签；HAP 中 30 个工作台文件和两个包中的原生工作台均与本轮编译资源一致。未在鸿蒙设备安装；上架用 App Pack 仅作本机归档。

## 已知问题和验收边界

Windows 安装版首次切换语言时的闪退已从转储定位到 Chromium 无障碍超链接查询中的致命退出分支。隔离测试的 320 次语言切换未复现，但尚未覆盖转储中同一条无障碍查询路径，不能认定闪退已彻底修复；详见[排查记录](../verification/Windows语言切换闪退排查-20261106.md)。助手请求已携带界面语言，实际回复是否遵循仍取决于所选模型。用户此前截图对应的 PDF 原件尚未提供，无法对该文件的特定页面作原件验收。

安装包的具体构建、签名和设备测试情况以发行验收记录及附件校验结果为准，不将浏览器布局模拟或未完成的内核修复表述为真机验收或已彻底修复。
