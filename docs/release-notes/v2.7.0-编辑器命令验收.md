# 2.7.0 编辑器命令全面验收

## 验收范围

逐一核对文字、表格、演示、PDF 编辑区中对用户可见的顶部功能区、右键菜单和相关弹窗。每个入口至少确认：点击后进入实际命令或完整操作流程；不满足操作前提时给出具体原因；执行后的内容、撤销重做和保存重开符合该命令语义。文件导入、导出与打印另核对真实输出，不把打开弹窗或显示成功提示当作功能完成。

## 排查与实施顺序

1. 从各编辑器的菜单声明、命令派发和测试生成入口清单，检查空回调、固定成功提示、占位内容和未接通的命令。
2. 对确认的故障先补失败测试，再修复命令或入口；无法可靠执行时隐藏或禁用入口，并说明具体原因，避免误导用户。
3. 使用最小内容与包含表格、图片、批注等对象的文档核对修改结果；对有文件输出的命令验证落盘字节及重新打开，不覆盖用户原件。
4. 分别运行编辑器测试、类型检查、构建自检和界面交互检查。真实业务 PDF 的第 3 页问题需取得原件后另行验收。

## 判定口径

“可用”指对应操作实际产生预期结果并通过上述验证；“前提受限”指入口明确禁用或提示真实限制；“未验收”指缺少真实文件、设备或外部服务验证，不写作已修复。最终记录按编辑器列出已检查的入口、发现的问题、修复和剩余限制。
