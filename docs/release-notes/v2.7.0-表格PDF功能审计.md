# 2.7.0 表格与 PDF 功能区审计

## 核查范围

- 表格编辑器七个顶部标签、单元格右键菜单与选区浮窗，逐项核对命令登记、处理函数、数据模型和保存路径。
- PDF 阅读器顶部工具栏、页面右键菜单，以及 PDF 工作台的页面处理与编辑操作。

## 已确认的问题与处理方案

1. 表格“数据透视表”目前只有“后续版本提供”的提示，没有生成、保存和重开能力。发行版先撤下该入口，待完整数据透视模型与持久化实现后再恢复。
2. 表格右键“插入单元格”“删除单元格”实际插入或删除整行，容易误改数据。保留已实现的整行、整列操作，撤下这两个错误标注的重复入口。
3. 表格右键“设置单元格格式”只提示改用顶部功能区。接入真正的格式设置对话框，可设置字体、字号、强调、颜色、对齐、换行和数字格式，并写入选区且可撤销。
4. PDF 页码解析会忽略范围中的坏段或接受零页、负数，可能只处理用户输入的一部分。改为整段校验；任一页码无效时拒绝执行并提示。
5. 表格排序只搬原始文本，导致格式、批注和图片错位。改为搬动完整单元格对象，图片锚点随行移动；选区含合并单元格时拒绝排序并说明原因，避免静默破坏。删除重复项改为真正删除重复行并上移；自动换行可再次点击关闭；单格合并不再虚报成功。
6. 空白表格选区的智能助手右键及浮窗操作原先点击没有反馈。空白选区不显示这些动作，有内容时仍可交给助手。

## 验证结果与边界

- 表格编辑器与 PDF 工作台完整交互测试共 72 项通过；表格命令、格式入口、页码解析等最终针对测试 69 项通过。原生表格格式三轮保存重开与 XLSX 往返测试共 7 项通过。
- PDF 阅读、右键与原生编辑保存重开测试共 25 项通过；主进程 PDF 页面处理和文字写入测试 32 项通过。完整前端构建、全局类型检查和差异格式检查均通过。以上往返测试验证了一组代表性操作；**未逐个对全部 59 个表格按钮、全部 PDF 页面处理组合做独立真实文件保存重开**。排序、删除重复行、右键格式对话框等本次修复有模型和界面测试，尚待补充专门的文件往返用例。
- PDF 截图中出现故障的原件仍未提供，因此不能把该文件第 3 页列为已通过验收。当前版本已有画布自动重试一次和手动重试，具体根因需用原件复现。
- 该审计没有覆盖其他文件类型；Word、PPT 由独立审计处理。
