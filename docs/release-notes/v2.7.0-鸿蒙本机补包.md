# 2.7.0 鸿蒙本机补包记录

本轮先运行 `npm --prefix mobile run build:harmony` 生成当前鸿蒙专用网页资源，再运行 `npm --prefix mobile run check:harmony`，通过 HBuilderX 自带的原生编译器产出最新网页与原生工作台代码。HBuilderX 图形界面已打开，但其命令行持续报告未检测到界面，无法重新运行原生项目生成步骤。因此保留此前由 HBuilderX 生成的 `mobile/unpackage/dist/build/app-harmony/` 工程；运行 `node mobile/scripts/repack-harmony-generated.mjs`，严格核对版本、文件清单和返回键协议，将本轮原生编译器的 55 个文件同步到该工程，并逐字节核对其中 30 个网页资源文件。编译产物或清单不符时脚本停止。

随后使用 DevEco Studio 自带的 Hvigor，以 `release` 产品和模式分别运行 `assembleHap`、`assembleApp`，均成功。独立 HAP 与外层 App Pack 分别通过 `hap-sign-tool verify-app`。HAP 中 29 个网页资源与本轮构建逐字节一致，原生工作台与本轮编译器产物逐字节一致；App Pack 内的工作台与独立 HAP 一致。

正式归档：`release/v2.7.0/seal-office-2.7.0-harmony.hap`，66,316,262 字节，SHA-256 为 `e85ab0e4b49317d7ea5fa462d433dee8445e52f4fdeae4ba9327aa0186527c25`；`release/v2.7.0/seal-office-2.7.0-harmony.app`，42,153,611 字节，SHA-256 为 `423590be9494784fee7e76ce26d5e115cd4b69c9d1b9536c0613843d7d944f9c`。两者均纳入全屏阅读返回与演示放映回退修复。App Pack 仅供上架，不作为直接安装包发布。尚未在真实鸿蒙设备安装测试。
