# 2.7.0 文件兼容、分享管理与界面升级

本版针对用户提供的报表、分享与界面问题。以下说明只描述实现范围；各平台安装包与真实设备验收结果以本版发行验收记录为准。

## 文件打开与原件保护

- 对扩展名为 `.xls`、实际内容为 UTF-8 网页文档的报表，先按内容识别，再提取其中的表格文本。传统二进制 `.xls` 继续走原有兼容转换路径。
- 已用用户补充的审核报表原件验证：685319 字节，实际为带 UTF-8 标记的网页表格；导入为 1 张工作表、1126 行、14 列，读取到 11479 个非空单元格。另用用户补充的区域账号 CSV 验证：20826 字节，165 行、每行 10 列。两份原件均只读核验，未修改。
- 网页表格导入保留文本型编号、前导零、中文、实体字符和合并单元格。只读取表格数据，不运行网页脚本或加载网页外链；超过资源上限、无表格结构或编码错误时给出明确错误。
- 带导入损失警告的文档可以选择查看已识别内容。编辑区持续显示缺失项并处于受保护查看状态；另存到新路径后才可编辑，原件不被直接覆盖。

## 云空间与分享

- “我的云空间”顶部新增“我的分享”，集中列出本人发起的分享链接和指定账号共享，支持分页、筛选、批量取消、删除记录与清理已失效记录。删除分享记录不会删除云文件或历史版本。
- 修复生成分享链接后地址为空或显示 `undefined`：主进程现在保留创建结果中的链接地址，界面在展示前核验地址格式。
- 服务端逐条检查记录归属与当前状态；清理已失效记录时重新判定，防止误删恢复有效的分享。

## 预览、助手与界面

- PDF 单页无法取得画布时更换画布自动重试一次；持续失败时只给该页提供手动重试，其他页面继续可读。
- 修复智能助手因旧页面状态误报“当前文件已关闭”，但随后又把修改应用成功的问题。候选修改先校验，再依据当前文档状态应用一次。
- 文字编辑器六个功能区标签采用首页色调体系；智能助手输出层级、功能区选中态和助手输入框颜色按当前皮肤调整。
- 修复 Zotero 百科“引用并提问”只选中资料却不显示提问区的问题；现在点击后可输入问题、查看引用正文，并在发送前确认资料授权。
- 桌面、Web 和移动共用的输入框焦点样式去除深色粗描边和加粗光晕，改为当前皮肤色细边框；助手输入框聚焦与悬停保持同一效果。
- 移动端返回键先关闭弹窗与全屏阅读或放映层；底部五个主标签实际可见时，单次返回系统桌面。原生层通过本次按键序号核对网页确认，过滤重复回调。

## 移动安装包与功能完整性

- 正式 Android APK 由 `android-studio/` 的 Java 原生工程本机编译和旧版同一证书签名，不再使用 HBuilderX 云打包，因此不受云端 60 MB 源码限制。最终包内 30 项工作台资源合计 59,653,639 字节，完整编辑器、功能依赖和字库均保留。旧 HBuilderX 安卓源码只作历史留档。
- 安卓模拟器验证五个底部主标签在可见时单次返回桌面；文字与 PDF 全屏阅读、演示放映第一次返回均只退出当前界面。Android WebView 拒绝系统全屏时，演示使用固定视口放映层继续播放。启动画面只使用系统页面，留白圆形海豹标识与“海豹办公”名称显示到工作台绘制完成，避免网页再叠加第二张标识；正式包保持旧版签名。
- 后续 Windows 发行只打 NSIS 安装程序与微软商店包，不再生成或上传便携版。
- 网页启动检测改为外部脚本，符合现网安全策略；修订后的网页版本 `2.7.0-web-20261106-032200` 已部署，并完成公网文档、模板、项目等回归。此前 `2.7.0-web-20261106-022151` 保留为历史版本。
- HarmonyOS 沿用本机原生编译链路，HAP 与 App Pack 分别验签；发行页只提供可安装 HAP，App Pack 仅本机上架归档。鸿蒙真机尚未验收。

## 已知边界

- 网页型 `.xls` 的目标是安全读取表格内容和生成可编辑副本，不承诺网页样式、脚本、宏或传统工作簿对象无损导入。
- 用户截图对应的 PDF 原件尚未补充，无法对原件第 3 页逐页预览。现有改动只提供画布获取失败后的容错与单页重试；若设备持续无法分配画布，该页仍可能显示失败。审核报表虽已通过结构导入验收，业务数据逐项准确性仍需用户核对。
- 历史分享链接的密钥只存在原链接片段中；记录页不能从服务器重建完整旧链接。取消分享不能收回他人已下载的副本。
