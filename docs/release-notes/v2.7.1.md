# 2.7.1 文件兼容、Access 改造、版本更新与拍照扫描

本版依据《2.7.1 升级计划》实施。以下只描述实现范围与已验证结果；未经真实设备或真实样本验证的部分在“已知边界”中如实列出。

## 表格兼容（xlsx）

- 颜色：补齐 Excel 标准索引色调色板（含 `indexed="64"` 系统前景色、`65` 系统背景色）、主题色明暗变体（`theme` + `tint`，按 HLS 亮度通道计算，与 Excel 2007 默认主题 35 个色板值比对误差不超过 1）、带透明度的 ARGB 与自动色。边框颜色无论能否解析都不再产生告警；只有未知主题索引等确实无法解析的颜色才提示，并归入“保真风险”。
- 筛选：重写 `autoFilter` 读写，支持多列、多值（含空白）、自定义条件（等于、不等于、大于、小于、开头是、结尾是、包含及“且/或”组合）、绝对引用与非 A1 起始范围，保留排序状态。暂不支持按条件隐藏行的形态（如前 10 项、动态筛选）按原始 XML 原样写回，不再阻断编辑。写入后重新解析自校验。
- 命名区域：区分 `_xlnm.*` 内部保留名与用户定义名；打印区域、打印标题读入并写回，内部名不再报“命名区域未导入”，用户定义名仍如实提示。
- 保存后回读校验：桌面端保存或另存为 `.xlsx` 后，从磁盘重新读取刚写入的文件，与编辑模型逐项比对单元格、公式、合并区域、筛选与颜色。发现差异时列出具体工作表、单元格与差异项，提供“另存为副本”（原件恢复为保存前字节）与“保留本次保存”。超过 1 万行时抽样比对并标注“已抽样校验”。

## Word 目录与交叉引用（docx）

- 放行只需保留缓存结果、不需本程序重算的域：页码类、目录 TOC、PAGEREF、REF、NOTEREF、HYPERLINK（含内部跳转）、SEQ、STYLEREF、日期时间类、文档属性类、TC、XE、INDEX 等。IF、公式域、邮件合并、INCLUDE、DDE、表单域等需重算或引用外部的域仍提示。
- 含域的段落沿用原生结构保留机制，保存时逐字写回原 XML，目录跳转用的 `_Toc` 书签一并保留；修复了重新生成段落的书签编号与保留书签冲突导致目录跳转失效的问题。
- 带自动目录的文档可直接覆盖保存，保存成功后提示一次“目录与交叉引用的页码沿用原文件缓存，修改后请在 Word 或 WPS 中更新域”。

## 导入警告分级与打开时询问

- 警告分为“保真风险”（数据完整，只是部分表现或自动特性不更新，允许覆盖保存）与“内容风险”（确有内容未导入，阻止覆盖原文件）。未登记的新警告默认按内容风险处理。文字、表格、演示三个编辑器、退出前批量保存和智能助手使用同一判据。
- 打开文件时：完全支持或只有保真风险，直接打开无弹窗；有内容风险，弹窗列出具体缺失项，提供“仅查看”与“另存副本并编辑”；关键内容缺失时只提供“仅查看”并说明原因。按路径与文件指纹记住选择，同一文件再开不再弹窗，但编辑区顶部仍持续显示缺失项和“另存副本以便编辑”入口。

## Access 数据库（仅 Windows 桌面）

- 新建后打不开：实测根因是新建时连接串手工拼接，路径含分号或等号时被拆成额外参数；另有默认保存路径只传裸文件名、落到不可写的运行目录，以及创建失败与打开失败共用一条笼统提示。现统一使用连接串构建器，默认路径改为“文档”目录，新建前检测驱动与目录可写性，创建后立即回读结构，错误按驱动未安装、目录不可写、文件损坏、文件已存在、密码错误、结构冲突分类提示。
- 建表改为字段行编辑：字段名即时校验，类型使用中文下拉，长度仅短文本显示，主键与必填用开关；提供人员信息、订单记录、商品明细、日志记录四个模板，创建时间、修改时间、备注一键追加，以及从已有表复制结构。
- 支持新增字段、改名改类型、删除字段与更换主键，均有中文确认说明数据影响；ACE 不允许的操作给出具体原因并保持原结构。
- 常用查询按钮（查全部、按条件筛选、统计行数、最近 100 条），SQL 编辑器默认折叠，提供命令模板插入。录入控件按字段类型渲染。
- Web、Android、HarmonyOS 不显示 Access 入口。

## 版本更新检查与发布后台

- 服务端新增 `releases` 表、匿名限流的 `/v1/updates/latest` 查询接口，以及管理员 `/v1/admin/releases` 增删改查接口；管理后台新增“版本发布”页，开启强制更新与删除需二次确认。
- 设置页新增“关于与更新”：“自动检查更新”开关（默认开启，启动检查一次、运行期间每 4 小时一次）与“当前版本 + 检查更新”按钮。手动检查不受开关影响，四种结果（有新版、已是最新、网络失败、商店版）如实提示。
- 更新卡片：Windows 与 Web 位于左下角从底部滑入，Android 与 HarmonyOS 位于中上部从顶部落下。Windows 安装版下载后核对字节数与 SHA-256，不一致拒绝安装；商店版跳转微软商店；Web 刷新页面；移动端打开下载或商店地址。

## 拍照扫描与单据转表格

- 公共模板层：证件（身份证、营业执照、银行卡）、试卷，以及送货单、磅单、发票、报账单、入库单、小票，字段中英双语；扫描工具箱与单据识别共用。
- 阶段一：拍照或导入、自动找四角与透视校正（支持手动拖动四角）、彩色/灰度/黑白增强、多页合成图片型 PDF，全部在本机处理。
- 阶段二：识别前走资料授权确认，复用现有文字识别通道；提取文字、导出 Word、导出可搜索 PDF，界面提示“识别结果需核对”。
- 阶段三：扫描件库（分组、全部/已导出两视图、排序、批量删除导出与合并 PDF）。
- 单据转表格：必须先选单据类型；按模板解析，异常清单标出字段模糊、数字校验不符（数量×单价、合计、毛重−皮重）与必填缺失，确认后生成新工作表或下载 xlsx；一次最多 100 张。
- 平台分配：Android、HarmonyOS 以拍照为主入口；Windows 只做文件导入与截图粘贴，不做拍照；Web 只做上传处理下载，不做扫描件库。
- 权限与隐私：安卓 Java 宿主声明 `CAMERA` 并按需申请，鸿蒙声明 `ohos.permission.CAMERA`；首次拍照前先显示本应用说明，拒绝后仍可相册导入；`docs/隐私声明.md` 已同步。

## 界面语言

所有新增固定文案（含下拉选项、弹窗按钮、占位符与无障碍名称）均提供中英文；主进程返回的导入告警约 160 个片段补齐英文。`interfaceLanguage.test.tsx` 自动审计零失败。

## 不处理事项

MSIX 直接侧载报 `0x800B010A` 属预期行为：仓库中的 MSIX 是供微软商店代签的上传包。用户请从微软商店安装，或改用 `seal-office-setup-<版本>.exe`。

## 已知边界

- 计划中点名的四个用户样本（`全校.xlsx`、`2__2026111_f716705c.xlsx` 与两个带目录的 docx）未在本机找到，只用按其结构构造的同类文件验证，尚未用原件验收。
- 透视表、宏、外部数据连接、SmartArt、条件格式等对象本版仍不能完整读写，打开时会列出具体缺失项并询问处理方式，不能承诺“所有文件无损”。
- 表格筛选编辑界面仍为单列单值；导入的多列多值条件能正确生效和写回，但在界面里重新筛选会替换原条件。
- 目录页码不在本程序内重算；含域段落整段受保护，目录条目文字不能直接修改。
- 回读校验只接在桌面端表格保存与另存为上；Web、移动端、导出与云端自动保存未接入。万行级文件的耗时未做专项测量。
- 扫描与识别的真实相机、真实识别服务、复杂背景下的找边效果，以及更新卡片在真实安装包与真机上的跳转和安装，均未在真实设备上验证。鸿蒙宿主打开外部链接的能力需真机确认。
- Access 只在已安装 ACE 驱动的本机做了端到端验证，未在无驱动环境或安装版中实测保存对话框路径。
