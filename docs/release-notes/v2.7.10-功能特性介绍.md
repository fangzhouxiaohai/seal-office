# 海豹办公 2.7.10 功能特性介绍

## 一、云空间文件操作立即可见

新建文件夹或上传文件成功后，当前目录会立即刷新并显示最新内容，不需要退出云空间或手动刷新页面。上传过程中保留进度和结果，失败项提供重试入口；重复操作会校验当前目录和文件状态，减少误操作与重复上传。

## 二、界面语言切换更完整

补齐云空间账号安全、自动保存、验证码、日历以及相关操作面板的中英文文案。切换语言后，按钮、字段、状态、错误提示和校验反馈保持一致，已保存的语言选择在重新打开应用后继续生效。用户文档正文、表格内容、演示内容和自定义文件名不会被自动翻译。

## 三、个人空间登录与注销更清晰

重新整理个人空间的登录、账号安全、会话管理和注销区域，按“账号信息、当前会话、安全操作”的顺序组织内容。危险操作使用独立确认步骤，注销结果和失败原因明确显示，操作完成后返回状态稳定，减少误触和找不到入口的情况。

## 四、长内容弹窗适配窄屏

统一检查长文本、错误详情、验证码说明、账号安全和发布信息等弹窗。内容超出窗口高度时，正文区域可以独立滚动，底部的关闭、取消、确认和提交按钮始终可见可操作；窄窗口和手机宽度下，标题、字段、按钮和错误信息会按可读顺序换行，不再被屏幕边界截断。

## 五、桌面与移动端同步更新

本版共享渲染层同步更新到 Windows、Ubuntu、macOS、Web、Android 和 HarmonyOS。Android 正式 APK 使用原有发布证书，HarmonyOS 同时生成已签名 HAP 和用于 AppGallery 上架的 App Pack。各平台版本统一为 2.7.10，移动构建号为 20710。

## 六、升级与发布附件

Windows 提供 NSIS 安装程序和 Microsoft Store MSIX，Ubuntu 提供 DEB，macOS 提供 Apple 芯片版与 Intel 版 DMG，另有 Web ZIP、Android APK 和 HarmonyOS HAP。所有公开安装包均有 SHA-256 校验值。HarmonyOS App Pack 仅用于 AppGallery 上架，不作为终端下载附件分发。

升级前建议保存正在编辑的文档。安装完成后检查云空间同步状态、最近文件列表和个人空间登录状态，确认本机与云端内容一致。
