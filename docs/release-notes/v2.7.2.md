# 海豹办公 2.7.2

本版围绕简洁模式、默认缩放与后台版本发布升级；移动构建号为 20702，应用身份与原签名保持不变。

## 编辑与查看

- 设置新增“简洁模式”，默认开启。文件工作区收起顶部标题及常驻同步提示，功能区按钮保留图标、中文悬停提示和辅助名称，隐藏按钮文字及底部分组名称。首页、设置入口和必要操作继续可用。
- 简洁模式只影响显示，云自动保存继续运行；保存失败、冲突等需要处理的状态仍会显示。
- 新打开的文字、表格、演示、PDF 与 OFD 默认按 100% 查看。设置新增“默认放大至 150%”，默认关闭，开启后作用于后续打开的文件。
- 当前文件手动调整的比例不会被设置切换或返回设置页覆盖。查看比例不改变正文、导出或打印尺寸；表格原有文件视图信息继续保留。

## 后台版本发布与更新检查

- 修复服务器仍运行旧版后台导致“版本管理”入口缺失、匿名更新查询被登录校验拦截的问题，补齐部署清单与后台构建校验。
- 版本页主要显示发布列表，点击“发布版本”后在大弹窗填写说明及分别上传附件；后台采用深色顶栏与侧栏、浅色内容区和紧凑表格。
- 同一版本支持 Windows 安装程序、微软商店、Ubuntu、macOS、Android、HarmonyOS 与 Web 分别上传，平台均可选，可只发布部分平台。
- macOS 使用独立更新通道及 `seal-office-2.7.2-macos.dmg` 命名，上传时校验 DMG 格式，客户端打开对应下载地址；没有真实安装包时不创建该平台发布记录。
- 上传完成后由服务器计算大小与 SHA-256，核验平台、版本、文件名及包格式；批量发布全部校验通过后统一写入，避免部分成功。
- 安装包只在发布后提供公开下载，下架后停止该附件的匿名下载；支持安装包的大文件上传和范围下载。
- 更新检查按实际平台查询，异常提示区分服务未部署、连接失败等情况；微软商店版本继续进入既有商店页面。
- 从本版开始，打包与验收完成后直接上传后台发布更新，再核验旧版发现新包、新版显示已是最新版本及公开下载字节一致性。

## 安装包与发布流程

- 安卓正式包由根目录 `android-studio/` 的 Java 工程本机编译，默认打包入口统一到该工程，发布前验证原证书、应用身份、构建号和内置资源。
- 鸿蒙本机重打包同步原生版本与网页资源，HAP 和 App Pack 分别签名、分别验签。App Pack 仅保留作 AppGallery 上架，不上传仓库发行页。
- Windows 交付安装程序和微软商店 MSIX，继续保留中文程序名“海豹办公”；发行文件统一使用 `seal-office` 前缀。
- 安装包和 Web 发布到 GitHub 与 GitCode 的本版发行页，校验值以 `SHA256SUMS.txt` 为准。发布流程与验证记录见 `docs/verification/v2.7.2-release.md`。

## 平台说明

- 本轮新增 macOS 发布与客户端更新能力；当前 Windows 构建环境尚未生成及签名 DMG，因此本版不创建没有真实安装包的 macOS 发布记录。
- 微软商店 MSIX 是商店上传包，商店审核和分发由微软处理；不能把本地生成或后台登记等同于商店审核通过。
- 鸿蒙当前使用 Release Profile，HAP 需通过 AppGallery 正式或测试渠道安装；直接通过 hdc 安装还需要包含设备 UDID 的调试 Profile。
- Ubuntu 22.04、24.04 已分别完成 77 项安装运行验收；正式 DEB 使用这份已验证产物。当前没有已连接的鸿蒙设备，浏览器与签名检查不代表真机安装；iOS 本轮未生成 IPA。
- 第三方 Office 文件的既有格式兼容范围不变；本轮升级不代表已经覆盖所有复杂版式、宏、外部连接或图表对象。
