# 海豹办公 2.7.3 功能特性介绍

## 一、把编辑区让给正文

这版最直接的变化是纵向空间。简洁模式改为默认关闭；开启后不再单独占一行放“返回首页”和“设置中心”，两个入口并进功能区标签行，与“开始、插入、页面布局、引用、审阅、视图”排在同一行。打开 PDF 时，无论是否开启简洁模式，都不再显示这两个按钮，PDF 顶部保持干净。功能区底部的分组名称行，以及桌面端编辑器的品牌顶栏整行删除；云同步、全局设置、帮助手册、语言、主题五个图标移到标签行右端，功能不变，位置更省地方。设置中心与帮助手册仍保留原有顶栏，触屏和窄屏下标签行右侧的图标也保持足够大的点击区域。页面真正多出来的高度，全部还给正文。

## 二、云文档自动保存更可信

开启云端自动保存后，每次保存按“生成文件字节、写回本机原文件、再加密上传云端”的顺序执行。本机文件写回失败、被占用，或已被其他程序修改时，立即停止这次上传并给出中文原因，不会出现云端比本机新的情况。写回成功、且内容没有再次变化时，标签上的未保存标记同步清除；写回过程中若又修改了内容，标记会继续保留，不会把新改动误判为已保存。云端文件被删除、本地仍在编辑时，系统会自动清理失效的云记录并按新文件重新上传，不再一直提示“上传失败：云文件不存在或已删除”。尚未保存过的新文档只上传云端快照，共享与协作绑定的文件继续走整文件同步，不额外生成个人副本。状态条与设置说明同步改成“先保存本机文件再加密同步”，一眼能看懂先后顺序。

## 三、Word 转 PDF 更清晰

导出的 HTML 与 PDF 补上了与编辑区一致的正文样式：字体、14 像素字号、1.75 行距、段落后 10 像素、A4 版心与 20 毫米、18 毫米页边距、图片与表格自适应版心、分页符强制换页。此前导出内容没有基础样式，打印窗口会退回浏览器默认字体，整页文字又密又虚；现在打印前会等待字体与全部图片就绪，再按 CSS 纸张排版，不再把整页缩放塞进纸张。实测导出结果为矢量文字、内嵌微软雅黑子集字体、页面内零位图；系统打印的页面栅格化分辨率也从 200 DPI 提升到 300 DPI，放大查看不再发虚。

## 四、多端同一份交付

Windows 提供安装程序与微软商店 MSIX，Ubuntu 提供 DEB，另有 Web 包、Android 正式签名 APK、HarmonyOS 已签名 HAP，以及 macOS arm64 的 DMG。各端版本号、构建号与内置工作台资源保持一致，安装包校验值集中记录在 SHA256SUMS 里，便于核对与回滚；安卓包沿用原证书，可覆盖安装并保留旧版本地数据。macOS 包采用临时签名、未经苹果公证，首次打开需要在“系统设置 → 隐私与安全性”里允许运行；鸿蒙 HAP 使用发布证书，需通过应用市场正式或测试渠道安装。

## 五、升级提示

同版本重装不会触发客户端自动更新，需要手动安装本次安装包；后台更新记录仍为首轮版本，如果希望已经安装 2.7.3 的电脑自动收到后续修复，请使用更高的版本号发布。安装前建议保存正在编辑的文档，安装完成后检查云同步状态与最近文件列表，确认本机文件与云端内容一致；遇到文件被其他程序占用导致同步暂停时，按状态条提示关闭占用程序后点“立即同步”即可重试。
