# 海豹办公 2.7.3

本版继续压缩编辑区上方的固定条带，修正简洁模式的布局与默认值，并优化 Word 转 PDF 的清晰度和云文档自动保存的写盘顺序；移动构建号为 20703，应用身份与原签名保持不变。

## 界面与显示

- 简洁模式改为**默认关闭**。设置中心与帮助手册的说明同步更新；旧版本已保存的显示记录在升级后一次性迁移为关闭，并保留“默认放大至 150%”的原选择，迁移后再次手动开启不会被重置。
- 简洁模式原先在顶部独占一行的“返回首页”“设置中心”导航行已彻底删除，两个按钮并入功能区标签行右侧，与“开始 / 插入 / 页面布局 / 引用 / 审阅 / 视图”同一行，编辑区上方不再多出一行。
- 打开 PDF 文件时，无论是否开启简洁模式都不显示这些顶部按钮：PDF 没有功能区标签行，桌面端也不再为它渲染独立顶栏。
- 功能区底部的分组名称行在文字、表格、演示三端、桌面与移动端、普通与简洁模式下均已删除；桌面端编辑器的品牌顶栏整行删除，云同步、全局设置、帮助手册、语言与主题五个图标迁入功能区标签行右侧。
- 首页顶栏、设置中心与帮助手册的桌面顶栏保持原样；触屏或窄屏下标签行右侧图标保持不小于 44px 的点击区域，云自动保存的失败与冲突提示继续显示。

## 云文档自动保存

- 开启云文档自动保存后，每次快照按“生成文件字节 → 写回本机原文件 → 加密上传云端”的顺序执行，本机文件不再落后于云端。
- 写回本机时校验原文件指纹：文件被其他程序修改、被占用或写入失败时立即停止本次上传，并显示具体中文原因；写回成功后更新文档指纹，后续手动保存不会误报“文件已被其他程序修改”。
- 尚未保存过的新文档没有本机路径，只上传云端快照；共享或协作绑定的文件继续走整文件共享同步，不额外上传个人副本。

## Word 转 PDF 清晰度

- 导出的 HTML / PDF 补齐与编辑区一致的正文基础样式：字体栈、14px 字号、1.75 行距、段落后 10px、A4 纸张与 20mm / 18mm 页边距、图片与表格自适应版心、分页符强制换页。此前导出内容没有任何基础样式，打印窗口会退回浏览器默认字体，整页文字又密又虚。
- 打印固定 `scale: 1` 并保留 `preferCSSPageSize`，按 CSS 的 A4 版心排版，不再整页缩放；页边距统一由 `@page` 声明，移除会被忽略且可能与 CSS 叠加的数值边距。
- 渲染等待由固定 600ms 改为等待字体与全部图片就绪并连续两帧绘制后立即打印（最多 10 秒），避免字体未就绪时打印出回退字形；打印窗口改为隐藏状态持续绘制并关闭后台节流。
- 系统打印的逐页栅格化分辨率由 200 DPI 提升到 300 DPI，超长文档由 150 DPI 提升到 200 DPI。
- 实测：用正式导出链路生成 A4 PDF，页面 595×842pt、0 张位图、内嵌 Microsoft YaHei 子集字体（CIDFontType2 / Type0），正文版心 174×257mm，文字为矢量。

## 安装包与发布流程

- Windows 交付安装程序与微软商店 MSIX，Ubuntu 交付 DEB，另有 Web ZIP、Android APK 与 HarmonyOS HAP；发行文件继续使用 `seal-office` 前缀，程序界面与快捷方式仍是中文名“海豹办公”。
- 安卓正式包由 `android-studio/` Java 工程本机编译并核对旧证书指纹，鸿蒙 HAP 由本机重新签名并单独验签；两者发布前都校验版本、构建号与内置工作台资源。
- 校验值以 `release/v2.7.3/SHA256SUMS.txt` 为准，验证记录见 `docs/verification/v2.7.3-release.md`。
