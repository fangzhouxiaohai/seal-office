# 海豹办公 2.7.4

本版修复超大扫描页 PDF 打开空白的问题，并把非 PDF 编辑器的云同步提示并入功能区标签行；移动构建号为 20704，应用身份与原签名保持不变。

## PDF 阅读

- 修复把整页做成一张超高位图的 PDF 打开后显示空白的问题。这类文件的单页图片常达 3000×38000 像素，超过 Chromium 的位图单边上限，pdf.js 解码失败后页面只剩白色背景。
- 现在打开前会先判断页面尺寸，仅在单页面积超过 3000 万点或单边超过 16000 点时，把超大位图按整数因子等比缩小（最长边 8192 像素）后重新写回 PDF，再交给阅读器渲染。页面大小、内容位置与绘制矩阵都不变。
- 常规 PDF 不触发优化，打开速度与之前一致；环境不支持压缩流接口时跳过优化并按原文件显示，不会把文件打开失败。
- 实测示例文件：优化约 1.9 秒，位图 3117×38572 缩到 623×7714，文件由 2.35 MB 降到 0.39 MB，Chromium 中约 1.4 秒渲染出内容。

## 界面与云同步

- 文字、表格、演示编辑器的顶部不再有整行云同步提示条，改为功能区标签行右侧的圆角长方形状态徽标，显示“云端已保存”“正在同步”“待同步”“同步失败”等简短状态。
- 开启云端保存后本来就是自动保存并同步，因此徽标不再附带“立即同步”按钮；同步失败时徽标变红，点击即可重试，完整原因显示在悬浮提示中。
- 打开 PDF 的界面保持原来的整行提示条与“立即同步”按钮；移动端同样保留整行提示，不受影响。
- 简洁模式下徽标与“返回首页”“设置中心”并排显示在标签行，不会额外占一行。

## 安装包与发布

- Windows 交付安装程序与微软商店 MSIX，Ubuntu 交付 DEB，另有 Web ZIP、Android 正式签名 APK、HarmonyOS 已签名 HAP 与 macOS arm64 DMG。
- 本次修复位于共享渲染层，桌面端、网页版与移动端同时更新；各端版本号与构建号一致，校验值见 `release/v2.7.4/SHA256SUMS.txt`。
