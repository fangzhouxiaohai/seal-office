# 海豹办公 2.7.5

本版修正底部“更新”按钮突出状态栏的样式问题，并让更新检查在系统代理与系统证书环境下也能正常连接；移动构建号为 20705。

## 界面

- 首页右下角的“更新”按钮收进底部状态栏内：按钮高度 22px、圆角胶囊形、字号 12px，与“海豹办公 v2.7.3”版本号并排，不再探出状态栏覆盖版本信息。
- 移动端更新入口保持原位置与尺寸。

## 更新检查

- 主进程改用 Electron 的 `net.fetch` 请求更新服务，沿用 Windows 系统代理与系统证书库；此前使用 Node 的 `fetch`，在开启系统代理或企业根证书的电脑上会连不上更新服务，而云同步等浏览器侧请求仍然正常。
- 首次连接失败后等待 600ms 重试一次，仍失败才提示“无法连接更新服务”；用户取消时不重试。
- 更新包下载复用同一请求实现，代理环境下同样可用。
- 已经安装旧版且在线更新失败的电脑，需要手动安装本次安装包一次，之后可正常收到后续更新提示。

## 安卓更新交互

- 安卓端不再显示浮动的“更新”按钮。发现新版本时弹出说明弹窗（标题为“发现新版本 {版本号}”，可展开更新说明），提供“稍后”“更新”两个选择。
- 点击“更新”后关闭说明弹窗并立即打开下载进度弹窗，下载完成后由原生宿主直接拉起系统安装程序，不再出现应用内的“更新已下载/稍后安装”二次确认；缺少“安装未知应用”权限或安装失败时才显示原因与重试。
- 系统安装器自身的确认属于 Android 系统行为，定制系统可能不同，应用不再叠加确认层。桌面端保留右下角更新入口，鸿蒙继续通过应用市场更新。

## 安装包与发布

- Windows 交付安装程序与微软商店 MSIX，Ubuntu 交付 DEB，另有 Web ZIP、Android 正式签名 APK、HarmonyOS 已签名 HAP 与 macOS arm64 DMG。
- 校验值见 `release/v2.7.5/SHA256SUMS.txt`；macOS DMG 仍为临时签名、未公证，首次打开需要在“系统设置 → 隐私与安全性”里允许运行。

## 平台说明

- 微软商店 MSIX 是商店上传包，审核与分发由微软处理。
- 鸿蒙 HAP 使用发布证书，需通过应用市场正式或测试渠道安装。
- 第三方 Office 文件的既有格式兼容范围不变。
