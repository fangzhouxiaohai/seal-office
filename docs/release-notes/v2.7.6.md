# 海豹办公 2.7.6

本版解决超大扫描页 PDF 放大后看不清的问题：提高位图缩放上限与超大页面的渲染画布上限；移动构建号为 20706。

## PDF 阅读

- 2.7.5 解决了这类 PDF 打开空白，但把整页位图缩小到最长边 8192 像素，只剩原分辨率五分之一，放大后文字无法辨认。
- 现在位图最长边上限提高到 30000（Safari 为 16000），该类文件只缩小 2 倍，保留原分辨率的一半；示例文件由 3117×38572 变为 1558×19286。
- 超大页面的渲染画布上限由 1600 万像素提高到 3200 万（移动端 2400 万），175% 缩放时可按 1:1 渲染，不会再被压缩后再拉伸。
- 优化结果按文件指纹缓存，同一文件再次打开不重复解码；常规 PDF 不受影响。

## 安装包与发布

- Windows 交付安装程序与微软商店 MSIX，Ubuntu 交付 DEB，另有 Web ZIP、Android 正式签名 APK、HarmonyOS 已签名 HAP 与 macOS arm64 DMG。
- 校验值见 `release/v2.7.6/SHA256SUMS.txt`；macOS DMG 仍为临时签名、未公证，首次打开需要在“系统设置 → 隐私与安全性”里允许运行。
