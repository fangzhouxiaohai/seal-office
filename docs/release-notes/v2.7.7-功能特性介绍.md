# 海豹办公 2.7.7 功能特性介绍

## 一、PDF 工作台：查看、编辑、复制

本版把 PDF 阅读拆成三种模式：拖拽查看用于放大后按住页面移动，只读可复制允许选字复制，编辑模式提供添加文字、替换可见文字、批注、插图和遮盖。模式按标签保存，切换时保留页码、缩放和阅读位置，并取消尚未完成的框选；单纯浏览不产生待保存修改。滚轮、触控板和双指缩放继续可用，整页可见时页面保持原位。无文字层的页面会提示为扫描图像，受权限限制的文件继续遵守原有复制限制。

## 二、PDF 按内容转换

新增转换为 Word、Excel、文本和图片，支持全部页、当前页或指定页范围，转换前说明扫描页与复杂版式的处理方式，转换后标出需要复核的页码。文字型报告按阅读顺序生成段落；表格按行列生成真实单元格，金额保留数值、前导零保留文本，并支持先预览再选择表格或页范围；文本按页提取正文，图片按页导出，多页自动打包。转换使用文档快照另存，取消或失败时原 PDF 保持不变。

## 三、第三方 Office 文件更能打开

带图表的 XLSX 不再整份打不开：图表未导入时保留表格数据、公式和列宽并给出警告。python-pptx 默认模板中重复的母版占位符会规范化为唯一标识，演示文稿可正常打开并保留页面与文字；矩形、圆角矩形、椭圆、线条等基础形状支持导入，尽量还原位置、尺寸、旋转、填充、边框和形状内文字。WPS 生成文档的导入与另存继续改进。保存时只写回已经导入的对象，不把缺失内容当成完整内容写回；单个对象不支持时只提示未导入，不再让整份文件失败。

## 四、打开失败时看得懂

打开失败弹窗显示文件名、格式、失败阶段和可读原因，而不是只有底层异常。技术详情可展开、可复制，也能直接打开文件所在文件夹；文件被移动或删除时说明原因，并提供明确的重试入口。诊断日志写入本机目录，只保留最近若干条，不包含文档正文、账号或密钥。原始文件保持不变，不用空白内容掩盖失败。

## 五、数据库与 Windows 更新

新增 Access 数据库入口，可新建 ACCDB、打开现有 MDB/ACCDB，维护表结构、记录并执行常用查询。Windows 更新入口收敛为右下角小进度圈与小安装按钮：下载过程不再弹大窗口或后台下载条，下载完成只显示“安装”；点击安装直接启动已校验的新版安装程序，确认启动成功后再退出，不再只关闭程序；下次启动只显示小安装按钮，不自动安装、不弹大面板、不遗留错误提示。安装失败会回到可重试状态并说明原因，运行期间仍每四小时检查一次更新。

## 六、多端同一份交付

Windows 提供安装程序与微软商店 MSIX，Ubuntu 提供 DEB，另有 Web 包、Android 正式签名 APK，以及 HarmonyOS 已签名 HAP 与 App Pack；macOS 提供 Apple 芯片版与 Intel 版。版本统一为 2.7.7，移动构建号 20707，校验值集中在 SHA256SUMS.txt。安卓包沿用原证书，可覆盖安装并保留旧数据；鸿蒙 HAP 需通过应用市场正式或测试渠道安装；macOS 为临时签名、未经公证，首次打开需要在“隐私与安全性”里允许运行。升级前建议保存正在编辑的文档，安装完成后检查云同步状态和最近文件，确认本机与云端一致。
