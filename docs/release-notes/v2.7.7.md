# 海豹办公 2.7.7

本版集中完善 PDF 工作台、第三方 Office 文件导入与打开失败的提示，并补齐 Access 数据库入口。移动构建号为 20707。

## PDF 工作台

- 新增拖拽查看、编辑、只读可复制三种模式，可按标签独立切换，切换时保留当前页、缩放和阅读位置。
- 只读可复制模式下可拖选文字并复制，不提供编辑工具；没有文字层的页面明确提示为扫描图像。
- 新增 PDF 转换为 Word、Excel、文本和图片，可按全部页、当前页或指定页范围导出；转换前说明扫描页与复杂版式的处理方式，转换后标出需要复核的页码。

## 文档导入与保存

- 带图表的第三方 XLSX 打开时，图表未导入会保留表格数据、公式和列宽，并给出具体警告，不再整份文件打不开。
- 演示文稿支持矩形、圆角矩形、椭圆、线条等基础形状导入；形状或图片属性不完整时，警告定位到页与对象。
- 改进 WPS 生成文档和新旧 Office 文件的导入与另存，保存后重新打开内容保持一致；原始文件不被修改。

## 打开失败提示

- 打开失败弹窗显示文件名、格式、失败阶段和可读原因，并提供技术详情、复制详情与“打开所在文件夹”入口。
- 不使用空白内容或默认数据掩盖失败，用户可判断是哪个文件、哪一步出了问题。

## 数据库

- 补齐 Access 数据库入口，可新建 ACCDB、打开现有 MDB/ACCDB，浏览与维护表结构和记录，并执行常用查询。

## 安装包与发布

- Windows 交付安装程序与微软商店 MSIX，Ubuntu 交付 DEB，另有 Web ZIP、Android 正式签名 APK 与 HarmonyOS 已签名 HAP；macOS 由官网按芯片版本提供。
- 校验值见 `release/v2.7.7/SHA256SUMS.txt`。

## 平台说明

- 微软商店 MSIX 是商店上传包，审核与分发由微软处理。
- 鸿蒙 HAP 使用发布证书，需通过应用市场正式或测试渠道安装。
- 第三方 Office 文件的既有格式兼容范围不变。
