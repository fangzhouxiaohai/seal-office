# 海豹办公 2.7.8

- 修正部分演示文稿末页的底色图形遮住正文的问题。打开、仅查看和另存时均可查看完整的兼容性提示。
- 手机版增加拍照取景、连续扫描、相册导入与审阅，首页和服务页可直达图片、PDF、录音转文字与二维 CAD 工具。首次使用相机时先说明用途。
- 管理后台登录页和登录后的页面底部均可查阅网站备案号。
- 11 月 22 日修订了 Windows 普通安装版、Ubuntu 和 macOS 的程序内更新。使用 2.7.7 时如果点击“更新”出现 `path is not defined`，或已安装首发的 2.7.8 桌面包，请保存文档、退出程序，从官网下载对应的 2.7.8 修订包并覆盖安装一次。后续版本可在程序内下载并校验。[官网下载](https://seal.xingmasoft.com/#downloads)
- 改善演示文稿中的图片和文字混合图层读取，保留图片比例锁定、替代文字和对象标识。改善表格对部分 Excel 表样式与文本条件格式的兼容性。
- 导入和保存提示限制最大高度，详情可在弹窗内滚动。受保护文稿顶部显示简短提示，兼容性说明可按需打开。
- 已启用的云空间在登录后自动解锁。升级时，已解锁的旧客户端可迁移原有密钥，其他旧客户端在首次解锁时迁移。迁移完成后可通过短信验证恢复访问，已有云文件继续使用原密钥解密。未迁移的旧云文件仍需要原解锁密钥或一台已解锁的设备。
- 鸿蒙 HAP 使用正式发布配置，安装请使用 AppGallery 或其测试渠道。微软商店 MSIX 用于商店提交。
- macOS 支持 Apple 芯片和 Intel 处理器，请按芯片下载对应 DMG。两款安装包采用临时签名，尚未通过 Apple 公证。
