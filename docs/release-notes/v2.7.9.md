# 海豹办公 2.7.9

- 表格现在可直接打开扩展名为 CSV 的 XLSX 工作簿，以及网页表格格式的 XLS 报表。编辑后默认另存为 XLSX，保留来源文件。
- 表格工具栏显示选区字体、字号。空白表格默认显示字体菜单首项和 10 磅，字体颜色和填充颜色支持自定义 RGB 色值。
- 手机上进入扫描取景页会自动请求相机权限，允许后即可取景。扫描识别与单据转表格支持 PDF 选页导入，行业模板可按关键词搜索。
- 日历支持中国大陆节日、年度放假调休及常见国际节日，月份可用箭头切换。新增日程可选择和试听三种提示音，提醒方式取决于设备通知权限。
- 打开超过 5 MB 的文件时，界面显示后台读取进度，支持取消后重新打开。
