海豹办公 2.8.0 正式发布。本次更新围绕更新体验、云空间效率与界面一致性展开，覆盖 Windows、Linux、安卓、鸿蒙与网页版。

一、更新体验
Windows 端改为启动完整安装向导，安装程序等待主程序退出后接管安装，失败时直接打开安装包所在目录并保留安装日志。Linux 端确认更新后改为浏览器下载 DEB 安装包，不再在应用内下载。鸿蒙应用市场更新失败时自动回退到官网下载区。各平台都会在界面写明当前更新方式，避免误以为功能异常。

二、云空间
新增云盘拖放移动与批量移动：鼠标拖动、触屏长按、悬停进入文件夹、拖到边缘自动滚动、按 Esc 取消，多选后可一次移动到目标目录，失败项逐条说明原因。文件列表新增大小列并支持按大小排序，文件夹大小递归汇总；网格视图悬停即显示名称、大小、创建与修改时间。账号与云空间面板按分组卡片重新组织，账号摘要、空间用量、账号安全与独立危险区的分区更清晰，业务流程与校验保持不变。

三、预览与打印
修复部分 DOCX 预览因缺少命名空间引起的 XML 报错，修复 MySQL 保留字导致的预览与历史版本下载失败。预览页底部接管打印与导出：PDF 直接送系统打印，其他格式按当前渲染结果打印，第三方预览器自带的下载与打印按钮不再干扰操作。

四、界面与多语言
全部弹窗限定在程序可视区域内，标题与底部操作固定、正文滚动，小窗口与手机窄屏下关闭和提交始终可达。界面文案台账与扫描守卫上线，应用页完成首批迁移，英文模式下不再残留中文，本轮新增的预览、拖放与更新提示均已补齐英文。

五、管理后台
管理后台新增管理员本人修改密码，保留当前会话并撤销其他会话，包含 15 分钟内 5 次尝试上限与不含密码的审计记录。

升级建议：升级前保存正在编辑的文档；安卓与鸿蒙安装包沿用原证书，可覆盖安装并保留本地数据；鸿蒙上架包需经应用市场正式或测试渠道安装。
