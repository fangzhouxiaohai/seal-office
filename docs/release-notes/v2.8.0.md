# 海豹办公 2.8.0

- Windows 更新改为启动完整安装向导：交接进程等待主程序退出后无参数启动安装程序，失败时打开安装包所在目录并记录安装日志。
- Linux 更新确认后改为浏览器下载 DEB 安装包，鸿蒙应用市场更新失败时回退官网下载区，界面写明各平台更新方式。
- 全部弹窗约束在程序可视区域内，标题与底部操作固定、正文滚动，小窗口与手机窄屏下关闭与提交始终可达。
- 修复云空间预览部分 DOCX 因缺少命名空间导致的 XML 报错，全实体 MySQL 保留字统一转义，修复历史版本下载返回 500。
- 预览工具栏接管打印与导出 HTML：PDF 原件直送系统打印，其他格式打印当前渲染结果，隐藏第三方自带下载与打印按钮。
- 新增云盘拖放移动与批量移动：鼠标拖动、触屏长按、悬停进入文件夹、边缘滚动与 Esc 取消，失败项逐条说明原因。
- 云空间列表新增文件与文件夹大小列并支持按大小排序，文件夹递归汇总；网格视图悬停显示名称、大小、创建与修改时间。
- 账号与云空间面板按分组卡片改版：账号摘要、云空间用量、账号安全与独立危险区分区更清晰，业务流程、接口与校验不变。
- 管理后台新增管理员本人修改密码，保留当前会话并撤销其他会话，含 15 分钟 5 次限流与不含密码的审计记录。
- 界面语言台账与扫描守卫上线，应用页首批迁移为显式文案键，英文模式下应用页无中文残留。
- macOS 提供 Apple 芯片和 Intel 芯片独立安装包，应用内更新使用通用安装包。本次 macOS 安装包采用临时签名，尚未通过 Apple 公证。部分旧格式转换和原生 PDF 导出仍依赖系统已有的 LibreOffice。
- Web 版可直接访问 [海豹办公 Web](https://seal.xingmasoft.com/office/)，由服务器统一更新。
