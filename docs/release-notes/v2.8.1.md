# 海豹办公 2.8.1

- 云空间拖放移动重做：拖动卡片改用窗口级浮层，不再撑出横向和纵向滚动条；长目录靠近文件区上下沿自动滚动并按最终位置投放，空文件夹可直接接收，多选整组一次提交，按 Esc、窗口失焦或触摸被系统中断时取消且不提交。
- 脑图、流程图项目卡与多维表格记录行、字段条、页脚改用图标按钮，补齐重命名、同步到云端、恢复、永久删除等矢量图标，读屏名称写明动作与对象，触屏点击区不小于 44 像素。
- 界面语言继续迁移：脑图与流程图项目库整页支持中英文，数量与项目名作为参数传入；演讲者窗口标题、显示器名称和安卓故障页随产品语言显示。
- 安卓宿主把状态栏、导航栏与软键盘区域让出 WebView，弹窗统一按可用高度计算，账号与云空间等弹窗的标题、关闭按钮和底部操作在安卓 15 边到边模式下完整可见。
- 表格编辑器“开始”标签的字号与字体颜色改为单行显示，窗口变窄时由功能区横向滚动承载，不再压缩换行。
- macOS 提供 Apple 芯片和 Intel 芯片独立安装包，应用内更新使用通用安装包。本次 macOS 安装包采用临时签名，尚未通过 Apple 公证。
- 部分旧格式转换和原生 PDF 导出仍依赖系统已有的 LibreOffice，与 2.8.0 相同；界面中英文切换尚未覆盖全部页面，本轮完成项目库与原生入口。
- Web 版可直接访问 [海豹办公 Web](https://seal.xingmasoft.com/office/)，由服务器统一更新。
