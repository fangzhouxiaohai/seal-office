# Windows 新建菜单与默认程序实现计划

## 需求与设计

安装版自动提供 DOC、DOCX、PPT、PPTX、PDF、XLS、XLSX 七种新建菜单，使用真实格式的空白模板。默认程序按钮注册软件实际可读写的 DOCX、XLSX、PPTX、PDF，直接进入 Windows 为海豹办公提供的专属关联页面；现代 Windows 的受保护默认关联由系统确认。

首次安装创建安装标识，升级沿用标识，卸载移除。首次启动读取标识并核验实际默认程序，用应用统一确认弹窗询问；无论确认或取消，后续启动不再弹出。便携版不自动触发安装提示。

新建菜单原注册值完整备份，升级不重复备份，卸载仅恢复仍属于本软件的菜单，保留安装后其他程序写入的设置。旧式格式模板不代表本软件新增旧式编辑器；保留电脑已有兼容程序的打开方式。

## 设计令牌与自检目标

沿用设置页现有 `--brand`、`--text-1`、`--text-2`、`--border`、背景、控件圆角与间距变量。按钮仍位于设置行右侧，增加执行中和禁用状态。首次提示沿用统一确认弹窗，只有一个主确认按钮；描述使用支持格式和系统确认要求，避免说明拥挤。自检设置行标题与动作一致、执行中避免重复触发、窄窗口说明换行与弹窗按钮可达。
