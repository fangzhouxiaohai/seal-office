# 文件类型图标实现计划

**目标：** Windows 关联文件按文字、表格、演示、PDF 显示不同图标，与应用内类型标识一致。

**架构：** 共享声明式图形与色彩设计，Electron 生成多尺寸资源；关联服务校验外置图标，便携版复制到持久路径，再交给现有 PowerShell 注册链路。

**技术栈：** React、SVG、Electron、Node.js、PowerShell、NSIS。

## 任务与文件

- [x] `renderer/src/components/fileIconDesign.json`、`FileTypeIcon.tsx`：集中图形与颜色，接入 `Icon.tsx` 和现有文件入口。
- [x] `build/make-file-icons.cjs`：读取设计，输出 `build/file-icons/*.svg`、`*.png` 与 `main/windows/file-icons/*.ico`；运行 `node_modules/electron/dist/electron.exe build/make-file-icons.cjs`。
- [x] `main/windows/fileIcons.js`：外置资源逐字节核验，便携版持久复制；测试覆盖删除临时资源后图标仍存在、中文空格、篡改及缺失资源失败。
- [x] `defaultApps.js`、`shellIntegration.ps1`、`build/installer.nsh`、`package.json`：传递图标路径、注册类别图标并打包资源，版本更新为 1.7.2。
- [x] `scripts/verify-shell-integration.ps1`：隔离注册表验证七种类型、升级更新及原生图标读取；`verify-windows-release.cjs`：验证真实成品资源与便携持久路径。
