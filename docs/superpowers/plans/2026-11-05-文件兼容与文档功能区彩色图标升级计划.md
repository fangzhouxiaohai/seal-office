# 文件兼容、云分享管理与文档功能区彩色图标升级计划

> 本文件是下一版的设计与实施计划，供审阅后执行。2026 年 11 月 5 日补入“我的分享”与 PDF 第 3 页预览失败需求。当前只完成样例、截图与源码核对、方案和效果示意；尚未修改应用、运行文件转换或发布安装包。

**目标：** 让以旧版表格扩展名交付的网页报表可以安全查看和另存；让含导入损失的文件先看到已识别内容，同时保护原件；修复截图中的 PDF 逐页预览失败；在“我的云空间”集中管理本人发起的全部分享记录；把文字编辑器顶部功能区图标调整为与首页一致的高饱和度彩色体系。

**基线：** 当前 `package.json` 为 2.6.0。下一次发行沿用仓库发布规则确定版本号，本计划不调整版本、应用身份或签名。工作区已有其他未提交修改，实施前须先核对并保留。

**架构：** 文件内容识别在读取边界完成，再按真实类型进入现有解析器；网页表格使用隔离解析和工作表模型，不将来源网页直接注入编辑界面。导入损失由打开状态与保存保护共同约束。PDF 先取得真实文件复现和逐页诊断证据，再针对画布创建失败修复。分享记录在客户端合并两条现有分享通道，由服务端校验本人权限、状态和批量操作；删除记录不删除原文件。图标由文字功能区命令语义映射到首页现有色调，不改变编辑命令。

**技术栈：** Electron 主进程、React、TypeScript、现有表格模型、PDF 阅读器、云服务与功能区组件、Vitest、主进程及服务端测试。

## 三、文件打开与保存设计

### 3.1 按真实内容分流

1. 在主进程读取边界核对文件大小、扩展名与有限前缀字节。传统复合文档签名的 `.xls` 仍走现有兼容转换；确认 UTF-8 或可无损识别编码、具有网页文档结构和实际 `<table>` 的 `.xls` 标为“网页表格型旧版报表”；其余内容继续给出具体中文错误。不能只搜索 `<table>` 字符串就判定成功。
2. 网页报表只在隔离的解析文档中提取表、行、单元格文本及有限的合并单元格信息，不执行脚本、不加载外链、不显示原始网页。限制输入字节、表格数量、单元格数量和展开后的模型大小；超限时明确报原因，不返回空白表格。
3. 样例中每个数据单元格标有 `mso-number-format:\@`，表示来源刻意按文本保存。导入时应保留前导零、长编号、日期字符串、空字段、中文和实体转义；有明确数字类型的其他样例按真实类型处理。来源包含不支持的样式、公式或对象时列出具体损失，不以“导入成功”掩盖。
4. 打开入口包括首页打开、最近文档、文件拖入和资源管理器关联；它们共用同一识别结果。浏览器、移动端若使用不同读取边界，实施时按同一验收矩阵适配，不能仅在首页按钮生效。

### 3.2 有损文件的受保护查看

1. 将警告分为“可查看但保存可能丢失”和“未得到可用正文或数据”。前者允许选择“查看已识别内容”，进入明确标注来源风险的受保护状态；后者保持阻断并说明未识别部分。命名区域未导入和边框样式未导入属于前者，但必须持续展示缺失内容清单，不表示原貌完整。
2. 受保护查看状态不允许原路径写回。用户要编辑时选择另存为 `.slxls` 或 `.xlsx` 副本，再在副本中编辑；副本必须使用不同路径。取消、解析失败、另存失败均不创建误导性的已完成编辑状态，也不改原件。
3. 网页表格型 `.xls` 采用同样的来源保护。入口文案明确说明“文件实际为网页表格，已按表格内容读取；原始文件保持不变”。原始扩展名仅作来源信息，不把新副本伪称为原格式无损写回。
4. 预览页和错误弹窗使用具体中文文案，区分“格式不匹配”“文件损坏或加密”“仅部分内容可查看”“转换超时”，同时给出可执行的下一步。失败时禁止用空表格、默认数据或成功提示遮盖异常。

### 3.3 验收样例与数据保护

仓库测试使用不含业务信息的最小合成文件：带编码标记的网页表格、前导零与长编号、实体字符和中文、合并单元格、真实二进制 `.xls`、非表格网页、脚本与外链、损坏文件、超限文件以及含命名区域和非细实线边框的 `.xlsx`。真实审核报表只作为本机手工验收输入，记录散列值和行列核对结果，不提交其正文、截图中的业务明细或转换副本。验收前后核对原件散列值一致。

## 四、我的分享：统一记录与批量管理

### 4.1 入口与列表

1. 在“我的云空间”顶部“新建文件夹”右侧增加“我的分享”按钮。点击进入独立记录视图，返回后恢复原文件夹、搜索和选择状态；未登录或云空间未解锁时沿用现有开通、解锁流程。回收站页面不显示该入口。
2. 列出当前账号**发起的**两种分享：任何持链接者可下载的“分享链接”，以及指定接收账号的“共享文档”。“共享给我的”继续保留在现有共享文档页面，不纳入可撤销的“我的分享”。列表按创建时间倒序，支持按类型、有效状态和文件名筛选；展示来源文件名、类型、接收方式、权限、创建时间、到期时间、下载次数（仅分享链接）和当前状态。接收账号仅显示服务端已脱敏号码；不显示访问码、文件密钥、链接凭证或加密载荷。
3. “所有记录”包含有效、已到期、已撤销和来源文件已移除的记录。现有分享链接接口最多返回 500 条，新版必须提供可继续加载的分页，不能把截断结果标作全部。文件名仅由已解锁客户端关联本人的云文件元数据补全；来源已移除时显示“来源文件已移除”，不伪造名称。旧链接的完整地址含客户端独有的密钥片段，服务端无法重建，因此列表不承诺再次复制旧链接。

### 4.2 操作语义与服务端边界

| 操作 | 可选记录 | 执行结果 |
| --- | --- | --- |
| 取消分享 | 本人发起且当前仍有效的记录 | 立即撤销访问授权，保留记录供核对；已被他人下载的本机副本无法收回。 |
| 删除记录 | 本人发起的任意状态记录 | 若仍有效，服务端在同一事务中先撤销再删记录；只删除分享记录，不删除云文件、历史版本、回收站文件或他人已有副本。保留必要审计记录。 |
| 清理已失效 | 服务端判定已到期、已撤销或来源文件已移除的本人记录 | 预览可清理数量并确认后批量删除；提交瞬间重新判定，状态恢复有效的记录不能误删。 |

列表允许逐项勾选和“全选当前筛选页”，明确显示选择数量；批量取消与批量删除分开确认，清理已失效提供独立按钮。服务端按账号校验每个标识的归属和类型，并对大批量分段处理、返回成功数与逐项失败原因；客户端只移除真正成功的项目，失败项保留选中以便重试。重复提交、部分成功、网络中断与其他设备同时撤销时不得显示虚假的“全部成功”。

计划新增统一分页查询与批量操作接口，例如 `/v1/my-shares` 查询和 `/v1/my-shares/batch` 操作；内部复用现有两张分享表及撤销规则。查询只返回管理所需元数据，状态以服务端时间及来源文件状态计算。保留现有单项分享接口与“共享文档”页面入口，避免旧客户端失效；新接口必须做所有权校验、审计和跨账号越权测试。

## 五、PDF 第 3 页画布失败排查与修复

截图显示 PDF 已进入阅读器，但第 3 页创建画布失败。现有 `PdfPageCanvas` 在取得页面和尺寸后调用画布的二维绘图环境；页面节点缺失或绘图环境返回空值都会产生同一错误。**目前无法凭截图确定根因或对应哪一份文件。**本机同一批接收目录下有 `自治区健康科普资源库系统开发计划.pdf` 与 `自治区健康科普资源库系统开发计划(1).pdf` 两份候选；只读检查均为 12 页、未加密的 PDF 1.4，散列值分别为 `0DE94C05DB0BF12CE110C0071229657EB5964397A8D71D68E9A43D5A20AB2F56` 与 `383FE1703AC1C89C0623146BD5D02CE44AF796856A73387810ECDC3F5259B2F6`。未运行应用预览，未确认两份中的哪一份触发截图故障。

1. 开发时先用上述两份候选分别复现，确认截图对应的文件；在隔离副本上记录文件散列、页数和第 3 页尺寸。分别在桌面版、浏览器和受影响设备核对首次打开、滚动到第 3 页、缩放、切换标签、重新打开。只记录页码、画布尺寸、像素比、渲染并发、节点是否存在及绘图环境是否可用，不记录文档正文。
2. 用诊断结果区分节点生命周期、画布上下文申请失败、页面尺寸异常和单页资源过载。修复只针对确认的原因：必要时限制并发和像素预算、避免已卸载页面继续申请画布，或在上下文不可用时给该页明确的重试入口。不能用空白页、低清伪图或吞错弹窗冒充成功。
3. 单页失败时保留其他已成功页面和原始 PDF 字节，错误提示定位到页码；重试只针对失败页，并限制重复次数。无法恢复时允许用户继续查看其他页或下载原件，不得使整个阅读器卡死。
4. 测试覆盖第 3 页失败、`getContext` 返回空值、切换文档时页面卸载、连续多页与高缩放；用两份候选逐页打开、滚动、缩放、关闭重开，并做相关编辑保存回归。若两份均不能复现，需取得截图对应的确切文件与环境记录，不能把截图案例标为已修复。

## 六、文字功能区彩色图标设计

以下配图是**色彩意向示意**，由现状截图生成，文字局部可能有图像生成误差；按钮名称、位置与最终验收均以现有程序界面和上方原始截图为准，不把示意图当作已实现效果。

![文字功能区彩色图标意向示意](assets/2026-11-05/文档功能区彩色图标示意.png)

| 功能语义 | 建议主色 | 表现规则 |
| --- | --- | --- |
| 打开、保存、导出 | 打开琥珀色 `#E09B06`；保存蓝色 `#2F7CF6`；导出紫色 `#9B4FE8` | 大按钮图形保持原形，配约 13% 同色浅底；同类导出保持同色系。 |
| 剪贴板、插入 | 蓝色 `#2F7CF6`、青色 `#0FA69A` | 粘贴、剪切、复制等按动作分色；不将所有小按钮做成大色块。 |
| 字体与段落 | 紫色 `#9B4FE8`、青绿色 `#0FA69A` | 颜色选择类控件显示当前所选颜色，语义主色仅用于图标轮廓；文字和字号仍保持易读。 |
| 样式、视图、审阅 | 蓝色 `#2F7CF6`、青色 `#0B9FE0`、橙色 `#F2711C` | 同一命令在不同标签保持同一颜色；禁用态回落中性灰。 |
| 删除或高风险动作 | 红色 `#EF4056` | 仅用于真正具有删除或危险语义的命令，不把普通操作标成警告。 |

配色源于 `renderer/src/styles/flatDesktop.css` 的首页色调。文字功能区六个标签均按命令标识映射颜色；共享按钮组件需有明确的文字编辑器作用域，防止表格与演示功能区意外变色。浅色、深色、悬停、按下、激活、禁用、键盘焦点和高对比度场景都须逐态检查；保留图标轮廓与中文名称双重识别，不以颜色作为唯一含义。小图标尺寸仍为现有 16 像素，大图标仍为 20 像素，现有横向滚动、分组线和编辑区选区保持逻辑不能受影响。

## 九、完成判据与边界

1. 用户提供的网页表格型 `.xls` 可查看全部 11 列、1,120 行数据；前导零、长编号、中文及空值无静默变化；原件字节和散列值不变；另存副本重新打开后抽查首、中、尾记录一致。
2. 截图所示“命名区域未导入、部分边框样式未导入”不再使已识别内容完全不可见；风险提示具体、持续可查，原件不能被有损结果覆盖。损坏、加密、无表格结构与超限文件仍明确拒绝。
3. “我的云空间”顶部出现“我的分享”；本人发起的分享链接与指定账号共享可完整分页列出、筛选和批量勾选。取消分享即时撤权且留记录，删除和清理仅移除分享记录；跨账号操作被拒绝，原云文件、历史版本和其他有效分享保持不变。
4. 截图对应 PDF 的第 3 页能够在受影响环境真实显示，关闭重开及缩放后仍可查看；若某页确实无法渲染，其他页保持可用并准确提示页码。两份候选均不能确认故障时，不得宣布这项真实案例已通过。
5. 文字功能区六个标签采用首页同一色彩体系，按钮名称、顺序、功能、快捷键和选区行为不变；禁用态、深色主题、键盘焦点及常见缩放下均可辨识。
6. 目标测试、完整测试、类型检查和构建命令均通过，留存真实文件打开、PDF 逐页、分享撤权与副本往返记录，再宣称升级完成。当前计划阶段不具备上述完成证据。

网页报表型 `.xls` 的目标是安全读取表格内容和生成可编辑副本，不承诺网页样式、脚本或旧版工作簿全部对象无损转换。示意图用于确认配色方向，不代表应用已经改版。
