# 管理后台重做与鸿蒙审核排查计划

## 目标与边界

- 以用户提供的 `tpadmin-master` 中 ThinkPHP 8、Vue 3 与 TDesign 工程为基础，重做海豹办公管理后台，保留运行概览、账号与用量、三类审核、操作记录、文档转换和版本管理等既有能力。
- 保留现有云服务的客户端接口、账号、版本及存量业务数据；新管理后端若需独立配置或存储，必须与现有业务存储隔离，不对现有数据库执行初始化或覆盖。
- 保留版本发布大弹窗及各平台选择、附件上传校验、macOS 更新支持和现有权限控制。新后台不能出现演示账号、演示数据、默认弱密码或暴露不必要的框架管理接口。
- 确认鸿蒙发行包实际相机权限与华为隐私托管的结构化声明，提供有证据的操作步骤；未经用户明确要求不代为提交审核或改变现有隐私协议。
- 修复各端更新卡片对 Markdown 的显示；兼容旧客户端对 2.7.2 更新说明的读取。应用版本保持 2.7.2，不改动原发行标签；已经安装同版本的客户端不会因同版本替换自动提示更新。

## 执行与验收

1. 检查框架许可证、仓库原有状态、构建依赖和生产运行条件；保留用户提供的原始仓库及未提交内容。
2. 先梳理现有接口、认证、业务菜单和发布流程，设计兼容方案并编写回归测试，再实现迁移。
3. 运行类型检查、构建和后端自动化测试；在隔离数据与模拟服务中验证登录、错误处理、各业务页面、文件上传、发布以及窄屏交互。
4. 部署前进行生产配置检查，准备可验证的部署产物和回滚方案，确保客户端接口与存量数据不变；部署后验证公网登录、各页面、无权限访问和更新接口。
5. 记录实际测试、尚未覆盖的部分与部署结果，更新 README，审查提交内容和凭据后同步仓库。
6. 先测试标题、列表、标点、纯文本及不可信内容，再构建各平台修复成品，校验原身份和签名；同版本发布必须核验附件绑定、摘要和旧记录兼容，保留原发行包及历史证据。

## 更新下载与安装流程

- 点击立即更新后，窗口中央展示实际下载进度，可选择后台下载或取消；后台下载时在右下角显示真实进度，校验完成后显示更新按钮。
- 取消须中止下载并清除本次待安装状态；下载完成的有效安装包跨启动保存，下次启动拉起系统安装流程；持有待安装包时跳过运行期间的四小时自动检查。
- Windows 在应用进程结束后启动安装程序；其他平台按系统允许的方式交由用户完成安装，不能把不可用的系统安装接口伪装成成功。
- 先覆盖状态切换、取消竞态、下载失败、摘要校验、重启恢复与定时检查，再验证各平台构建、签名及实际可运行范围。已有候选包生成于本需求之前，不能作为最终发行包。

## 后台界面修正

- 对照用户提供的框架原始仪表盘和布局，采用其浅色侧栏、绿色主题、图标、顶部面包屑、多标签和仪表盘卡片结构；页面只呈现现有接口返回的真实数据。
- 在隔离数据中验证页面、导航、弹窗、窄屏及交互，实测生产资源版本及页面后再部署更新。
- 所有后台页面及权限管理界面适配浅色和暗色主题，覆盖筛选标签、表格、表单、弹窗、状态及禁用态，使用主题变量并在真实浏览器逐页验证可读性。

## 用户与权限管理

- 原“账号与用量”重命名为“用户管理”，保留现有账号和用量数据及其操作。
- 增加管理员管理、角色管理、菜单管理，使用实际持久化和服务端鉴权，管理员仅可执行已授权的操作；菜单隐藏不能替代接口权限校验。
- 先核对现有管理登录与用户提供框架的账户、菜单、角色模型，设计兼容和隔离方案；不得初始化、覆盖或删除原有业务数据，也不得创建默认弱口令。
- 先测试身份认证、角色和菜单授权、越权拒绝、变更后会话权限、现有管理员兼容与错误处理，再完成页面、部署、生产只读验证及回滚准备。
