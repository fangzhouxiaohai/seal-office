# WPS 首页 UI 设计规格

- 日期：2026-09-22
- 范围：仿 WPS 桌面端「首页/启动页」界面
- 状态：已获用户批准

## 一、目标与范围

### 目标

将现有最简骨架界面（蓝色顶栏 + 三条模块列表 + 文本占位区）替换为可辨识的 WPS 新版首页，
使用户打开应用即看到与 WPS 365 一致的启动页观感。

### 本轮范围

1. 首页全部视觉还原：顶栏、左侧导航、新建四宫格、最近文档网格与列表、空状态、底部状态栏。
2. 交互：导航切换、新建跳转、文档选中与打开、星标切换、视图与排序切换。
3. 现有 `components/` 下空文件、`routes.tsx`、`store.ts` 全部落地实现。

### 本轮不做

1. 不修改主进程与 preload 脚本（`contextIsolation` 安全问题另案处理）。
2. 不接入真实文件系统数据，最近文档使用工程内静态示例数据。
3. 不实现文档、表格、演示的真实编辑能力，编辑器页为占位页。
4. 不落地深色主题，仅预留设计令牌便于后续扩展。

## 二、视觉规范

### 配色令牌

写入 `renderer/src/styles.css` 的 `:root`，全部为浅色基调。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--brand` | `#2B6CF6` | 主色、选中态、主按钮 |
| `--brand-hover` | `#1E5AE0` | 主色悬停态 |
| `--brand-soft` | `#EBF1FE` | 选中项浅蓝底 |
| `--bg-app` | `#F5F7FA` | 主内容区背景 |
| `--bg-card` | `#FFFFFF` | 卡片、顶栏、左侧导航背景 |
| `--bg-hover` | `#F2F5FA` | 悬停背景 |
| `--border` | `#E8EBF0` | 卡片与区块分隔边框 |
| `--border-subtle` | `#F0F2F5` | 区块内部细线 |
| `--text-1` | `#1A1D24` | 标题文字 |
| `--text-2` | `#5C6472` | 正文文字 |
| `--text-3` | `#8A92A6` | 辅助信息 |
| `--star` | `#F5A623` | 星标 |
| `--danger` | `#E34D59` | 危险语义、PDF 图标 |
| `--success` | `#00A870` | 成功语义、表格图标 |
| `--warning` | `#ED7B2F` | 警告语义、演示图标 |

### 文档类型图标配色

| 类型 | 颜色 |
| --- | --- |
| 文字 | `#2B6CF6` |
| 表格 | `#00A870` |
| 演示 | `#ED7B2F` |
| PDF | `#E34D59` |

### 字体、尺寸与形状

- 字体族：`"Microsoft YaHei", "PingFang SC", Arial, sans-serif`。
- 字号：12（角标）、13（辅助信息）、14（正文）、16（区块标题）。
- 数字使用 `font-variant-numeric: tabular-nums`，保证对齐。
- 间距阶梯：4 / 8 / 12 / 16 / 24 / 32 像素。
- 圆角：卡片 8px，按钮与输入框 6px，标签 4px。
- 阴影：常态不使用阴影，仅以 1px 边框界定层次；卡片悬停使用
  `0 4px 16px rgba(31, 41, 55, 0.10)`。

### 图标方案

不引入第三方图标库，自建 `Icon.tsx` 内联 SVG 图标集：

- 线性图标统一 1.6px 描边、圆角端点，尺寸 16px 与 20px 两档。
- 文档类型图标为单色填充图标，颜色由所属类型决定。
- 全站图标只此一套，不混用其它风格。

## 三、布局结构

Electron 主进程当前使用系统默认边框窗口，因此顶栏不包含最小化、最大化、关闭按钮。

### 顶栏（高 48px，白底，底部 1px `--border` 分隔）

- 左：WPS 圆形标识（28px）、「WPS Office」文字、分隔竖线、当前页名。
- 中：搜索框，宽 320px，含放大镜图标与占位文字「搜索文件、模板」。
- 右：设置图标按钮、帮助图标按钮、32px 圆形头像（显示用户名「演示用户」的首字）。

### 左侧导航（宽 200px，白底，右侧 1px `--border` 分隔，纵向可滚动）

按四组渲染，每组之间以 8px 间距与细线分隔：

1. 首页、最近、星标、共享
2. 我的云文档、团队文档
3. PDF 工具、脑图、流程图
4. 设置、帮助与反馈

选中项样式：`--brand-soft` 背景、`--brand` 文字色、左侧 3px 主色指示条、圆角 6px。
悬停项样式：`--bg-hover` 背景。

各导航项的确定行为：

| 导航项 | 行为 |
| --- | --- |
| 首页 | 显示全部最近文档 |
| 最近 | 显示全部最近文档，区块标题改为「最近」 |
| 星标 | 仅显示已星标文档 |
| 共享 | 仅显示已共享文档 |
| 我的云文档、团队文档 | 提示「云文档功能开发中」，不切换内容 |
| PDF 工具、脑图、流程图 | 提示「该功能开发中」，不切换内容 |
| 设置、帮助与反馈 | 提示「该功能开发中」，不切换内容 |

未实现项一律使用 Ant Design `message` 输出中文提示，不伪造页面、不使用默认数据填充。

### 主内容区（`--bg-app` 背景，内边距 24px，纵向滚动）

**新建区块**

- 区块标题「新建」，16px、字重 600。
- 四宫格卡片，横向等分四列，最小宽度 168px，高 104px，白底、8px 圆角、1px `--border` 边框。
- 卡片内容：36px 彩色文档图标 + 14px 名称，垂直居中排列。
- 悬停：边框转主色浅色、上移 1px、阴影加深。

**最近文档区块**

- 标题行：左侧「最近文档」标题；右侧依次为网格/列表视图切换按钮组、排序下拉、查看全部链接。
- 网格视图：按主内容区可用宽度自适应列数，宽度不小于 1600px 时为 5 列，
  不小于 1240px 时为 4 列，其余为 3 列；卡片含缩略图区与信息区。
  - 缩略图区：`#F7F9FC` 背景、居中文档类型图标、左上角类型角标。
  - 信息区：文件名（单行省略，悬停显示完整名称）、「修改时间 · 大小」、右上角星标。
  - 悬停：右上角出现三点更多按钮。
- 列表视图：表头为「名称 / 类型 / 修改时间 / 大小 / 操作」，下方为数据行。
- 排序选项：修改时间、名称、大小。
- 查看全部：将左侧导航切换为「最近」，展示全部文档。

**空状态**

筛选结果为空时渲染居中空状态：图标 + 「暂无最近文档」+ 「新建文档」主按钮，不留空白区域。

### 底部状态栏（高 28px，白底，顶部 1px 分隔）

左侧显示文档总数与星标数，右侧显示版本号。

### 编辑器视图

点击新建卡片或双击文档卡片后进入编辑器视图，与首页视图的差异如下：

- 顶栏中部的搜索框替换为当前文档名，顶栏当前页名替换为模块名（文档、表格、演示）。
- 左侧导航替换为编辑器导航：顶部为「返回首页」按钮，下方为模块名与占位菜单项。
- 主内容区渲染对应模块占位页，显示模块名称与「编辑功能开发中」，并提供返回首页按钮。

应用仅存在首页视图与编辑器视图两种布局，由 `store` 中的当前模块决定，不引入路由库。

## 四、文件结构

```
renderer/src/
├── main.tsx                 入口（本轮不修改）
├── App.tsx                  应用外壳：装配顶栏、导航、主区，按模块分发页面
├── styles.css               全局样式与设计令牌
├── routes.tsx               模块注册表：导航项、页面组件、文档类型映射
├── store.ts                 React Context：当前模块、视图模式、文档列表、星标切换
├── components/
│   ├── TitleBar.tsx         顶栏
│   ├── Sidebar.tsx          左侧导航
│   ├── NewDocGrid.tsx       新建四宫格
│   ├── RecentDocs.tsx       最近文档标题行、视图容器、空状态装配
│   ├── DocCard.tsx          文档卡片（网格视图）
│   ├── DocRow.tsx           文档行（列表视图）
│   ├── EmptyState.tsx       通用空状态
│   ├── Footer.tsx           底部状态栏
│   ├── ErrorBoundary.tsx    渲染异常中文兜底
│   └── Icon.tsx             内联 SVG 图标集
├── pages/
│   ├── HomePage.tsx         首页
│   ├── WordPage.tsx         文档编辑占位
│   ├── TablePage.tsx        表格编辑占位
│   └── PptPage.tsx          演示编辑占位
└── mock/
    └── recentDocs.ts        静态示例数据与筛选、排序纯函数
```

约束：

- `routes.tsx` 是模块映射的唯一事实源，导航项与页面组件映射均从此导出，
  禁止在其它文件重复硬编码模块清单。
- 每个文件职责单一，`App.tsx` 只负责装配，不承载业务渲染逻辑。

## 五、数据模型

文档条目字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 唯一标识 |
| `name` | string | 文件名 |
| `type` | `'word' \| 'table' \| 'ppt' \| 'pdf'` | 文档类型 |
| `size` | number | 字节数 |
| `updatedAt` | string | 修改时间，`YYYY-MM-DD HH:mm` |
| `starred` | boolean | 是否星标 |
| `shared` | boolean | 是否共享 |

静态示例数据共 12 条，覆盖四种类型，文件名与时间均为真实感中文内容。

纯函数：

- `filterDocs(docs, navKey)`：按导航项筛选（最近=全部，星标=星标项，共享=共享项）。
- `sortDocs(docs, sortKey)`：按修改时间倒序、名称升序、大小降序排序。
- `formatSize(bytes)`：输出中文可读大小，如「1.2 MB」。
- `formatTime(value)`：输出中文相对时间，如「今天 14:32」「昨天」「3 天前」。

## 六、交互行为

| 场景 | 行为 |
| --- | --- |
| 左侧导航单击 | 切换选中项；首页容器内按导航项切换文档筛选 |
| 新建卡片单击 | 文字、表格、演示跳转对应模块页 |
| PDF 工具单击 | 弹出中文提示「PDF 编辑功能开发中」，不跳转、不伪造页面 |
| 文档卡片单击 | 选中该文档，主色描边加浅蓝底 |
| 文档卡片双击 | 打开对应模块页 |
| 星标单击 | 切换星标状态，阻止事件冒泡，不触发选中 |
| 视图切换 | 网格与列表之间切换，状态保存在会话内 |
| 排序切换 | 修改时间、名称、大小三选一 |
| 空筛选结果 | 渲染空状态，提供「新建文档」按钮 |
| 模块占位页 | 显示模块名称与「编辑功能开发中」，提供返回首页按钮 |

异常处理约定：

- 不支持的操作用 Ant Design `message` 输出具象中文提示。
- 组件渲染异常由 `ErrorBoundary` 捕获，展示中文错误说明与「重试」按钮，
  禁止出现静默空白窗口。
- 任何异常均不得以默认数据掩盖。

## 七、测试策略

新增开发依赖：`vitest@^0.34`、`@testing-library/react@^14`、
`@testing-library/jest-dom@^6`、`jsdom@^22`，均与当前 Vite 4、React 18 版本兼容，
依赖源使用已可达的 npmmirror。

遵循测试先行：先编写失败测试，再编写实现代码使其通过。

测试覆盖范围：

1. `mock/recentDocs` 纯函数：筛选、排序、大小格式化、时间中文格式化。
2. `routes` 模块映射：每个导航项均存在对应页面组件，每种文档类型均有目标模块。
3. `store` 状态行为：星标切换、视图切换、模块切换。
4. `HomePage` 关键渲染：存在「新建」「最近文档」文本、四张新建卡片、空数据时出现空状态。
5. `Sidebar` 交互：点击导航项触发模块切换。

视觉表现无法由断言覆盖，采用构建校验、运行截图核对与逐项点击验证。

## 八、验证方式

1. `npm run test:run` 全部通过。
2. `npm run build` 构建成功，无编译错误。
3. `npm start` 启动应用，截取窗口图像核对布局、配色与图标。
4. 按交互清单逐项点击验证：导航切换、新建跳转、PDF 提示、文档选中与打开、
   星标切换、视图切换、排序切换、空状态展示、占位页返回首页。

以实测输出作为完成依据，不以推断结论替代验证。
