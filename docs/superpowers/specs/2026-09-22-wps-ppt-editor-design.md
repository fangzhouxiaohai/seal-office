# WPS 演示文稿编辑器设计规格

- 日期：2026-09-22
- 范围：仿 WPS 演示（Presentation）的编辑器界面与编辑能力
- 状态：设计已定，随实现推进

## 一、目标与范围

### 目标

实现演示文稿编辑器：左侧幻灯片缩略图、中部画布、Ribbon 八标签与底部状态栏，
并提供真实可用的幻灯片与文本框编辑能力。

### 本轮完整实现

新建与删除幻灯片、切换与复制幻灯片、文本框的新增与编辑、文字与段落格式、
幻灯片版式与背景色、导出为 HTML 预览页、撤销重做、状态栏统计。

### 本轮按钮就位、点击给出中文提示

切换动画、自定义动画、幻灯片放映、排练计时、母版视图、SmartArt、表格、
图表、音频与视频、批注、比较与合并。

### 本轮不做

1. 不实现真实的播放引擎与动画时间轴。
2. 不导出 pptx（需引入文件格式库）。
3. 不修改首页、文字编辑器与表格编辑器的既有交互。

## 二、界面结构

| 区域 | 尺寸 | 内容 |
| --- | --- | --- |
| 顶栏 | 48px | 复用现有 `TitleBar` |
| 文档标签栏 | 32px | 复用现有 `DocumentTabs` |
| Ribbon 标签行 | 36px | 开始、插入、设计、切换、动画、幻灯片放映、审阅、视图 |
| Ribbon 功能区 | 96px | 复用 `ribbon/RibbonPanel`，传入演示标签声明 |
| 主区左侧 | 176px | 幻灯片缩略图列表，可滚动，支持选中、复制与删除 |
| 主区中部 | 自适应 | 画布：按 16:9 比例渲染当前幻灯片，文本框可拖动与编辑 |
| 状态栏 | 28px | 幻灯片序号、幻灯片总数、缩放控制 |

画布基准尺寸 960×540（16:9），按缩放比例等比缩放。

## 四、数据模型

```ts
export interface 文本框 {
  id: string
  x: number
  y: number
  width: number
  height: number
  text: string
  字号: number
  加粗: boolean
  斜体: boolean
  下划线: boolean
  颜色: string
  对齐: 'left' | 'center' | 'right'
}

export type 版式类型 = '标题幻灯片' | '标题和内容' | '空白'

export interface 幻灯片 {
  id: string
  title: string
  版式: 版式类型
  背景色: string
  文本框列表: 文本框[]
}

export interface 演示文稿 {
  id: string
  name: string
  幻灯片列表: 幻灯片[]
  当前索引: number
}
```

版式决定初始文本框：标题幻灯片只有标题框；标题和内容为标题框加内容框；空白无文本框。

## 五、交互行为

| 场景 | 行为 |
| --- | --- |
| 点击缩略图 | 切换当前幻灯片 |
| 新建幻灯片 | 在当前幻灯片之后插入，并切换过去 |
| 删除幻灯片 | 至少保留一张，否则给出中文提示 |
| 复制幻灯片 | 在当前幻灯片之后插入副本 |
| 双击画布文本框 | 进入文本编辑，失焦或回车确认 |
| 拖动文本框 | 按住拖动改变位置，限制在画布范围内 |
| 字体与段落命令 | 作用于当前选中的文本框 |
| 版式命令 | 重置当前幻灯片版式与文本框 |
| 背景色命令 | 改变当前幻灯片背景 |
| 撤销重做 | 每次结构或内容变更前记录快照，上限 100 条 |
| 导出为网页 | 生成含全部幻灯片的 HTML 预览页 |

异常一律通过中文提示呈现。

## 六、文件结构


复用：`editor/history.ts`（`HistoryStack<演示文稿>`）、`editor/ribbon/*`、
`editor/exportDoc.ts` 的下载函数、`components/Icon.tsx`。

## 七、测试策略

纯函数用单元测试覆盖：幻灯片增删改与复制、当前索引边界、版式对应的初始文本框、
文本框增删改、画布边界约束。

组件用 Testing Library 覆盖：缩略图渲染与选中、点击切换、画布文本框渲染、
双击进入编辑、状态栏统计。

拖动、缩放等真实交互在运行窗口中用 CDP 验证。

## 八、验证方式

1. `npm run test:run` 全部通过。
2. `npm run typecheck` 退出码 0。
3. `npm run build` 构建成功。
4. 运行窗口逐项点击验证并截图，存于 `docs/screenshots/ppt/`。
5. `npm run dist` 重新打包并运行打包版确认无回归。

## 九、实现顺序

1. 数据模型与纯函数（测试先行）

3. 缩略图列表与画布组件
4. 容器装配、路由接入与样式
5. 导出、撤销重做等数据操作
6. 全量验证、打包与文档更新
