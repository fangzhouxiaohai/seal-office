# WPS 表格编辑器设计规格

- 日期：2026-09-22
- 范围：仿 WPS 表格（Spreadsheets）的编辑器界面与数据能力
- 状态：设计待实现，供后续会话按实现计划执行

## 一、目标与范围

### 目标

在已有的仿 WPS 首页与文字编辑器之上，实现表格编辑器：还原列标行号网格、名称框与公式栏、
底部工作表标签，并提供真实可用的单元格编辑与基础公式计算能力。

### 本轮完整实现

单元格编辑与选区、行列操作、字体与对齐格式、数字格式、边框与填充、合并单元格、
基础公式函数、排序与筛选、自动求和、撤销重做、多工作表、导出为 CSV 与 HTML。

### 本轮按钮就位、点击给出中文提示

数据透视表、图表、迷你图、条件格式、数据验证、模拟分析、宏、外部数据连接、
SmartArt、公式审核中的追踪引用、共享工作簿。

### 本轮不做

1. 不实现超大表格虚拟滚动，默认网格 100 行 26 列（A 至 Z），共 2600 个单元格，
   一次性渲染在可接受范围内。
2. 不实现数组公式与跨工作表引用。
3. 不导出 xlsx（需引入文件格式库，另案评估）。
4. 不修改文字编辑器与首页既有交互。

## 二、界面结构

| 区域 | 高度 | 内容 |
| --- | --- | --- |
| 顶栏 | 48px | 复用现有 `TitleBar` |
| 文档标签栏 | 32px | 复用现有 `DocumentTabs` |
| Ribbon 标签行 | 36px | 开始、插入、页面布局、公式、数据、审阅、视图 |
| Ribbon 功能区 | 96px | 复用 `ribbon/RibbonPanel`，按表格的命令声明渲染 |
| 名称框与公式栏 | 28px | 左侧名称框显示当前地址或选区的区域地址，右侧公式栏显示并编辑内容 |
| 列标行号区 | 24px | 左侧行号列固定宽 46px，顶部列标 A 至 Z |
| 单元格网格 | 自适应 | 单元格默认宽 88px、高 24px，支持列宽行高调整 |
| 工作表标签栏 | 28px | 工作表标签的切换、重命名与新建 |
| 状态栏 | 28px | 选区统计（计数、求和、平均值）、缩放与视图模式 |

网格采用「左上角全选按钮 + 列标行 + 行号列 + 内容区」的四宫格结构，
内容区可横向与纵向滚动，列标与行号随内容区滚动同步。

## 四、数据模型

### 单元格与工作表

```ts
export interface CellFormat {
  字体?: string
  字号?: number
  加粗?: boolean
  斜体?: boolean
  下划线?: boolean
  '字体颜色'?: string
  填充颜色?: string
  水平对齐?: 'left' | 'center' | 'right'
  垂直对齐?: 'top' | 'middle' | 'bottom'
  自动换行?: boolean
  数字格式?: '常规' | '数值' | '货币' | '百分比' | '千位分隔'
  小数位?: number
  边框?: { 上?: boolean; 下?: boolean; 左?: boolean; 右?: boolean }
}

export interface SheetCell {
  /** 用户输入的原始值，公式以 = 开头 */
  原始值: string
  /** 计算或格式化后的展示值 */
  显示值: string
  格式: CellFormat
}

export interface Sheet {
  id: string
  name: string
  /** 键为地址，例如 A1；未出现的地址视为空单元格 */
  单元格: Record<string, SheetCell>
  行数: number
  列数: number
  /** 各列宽度，单位为像素 */
  列宽: number[]
  /** 各行高度，单位为像素 */
  行高: number[]
}

export interface Selection {
  /** 锚点地址与焦点地址共同决定选区范围 */
  锚点: string
  焦点: string
}
```

默认工作表 100 行、26 列，列宽 88px，行高 24px。

### 历史栈泛型化

现有 `editor/history.ts` 的快照类型固定为 `{ html, selection }`，表格需要承载工作表快照。
实现时把 `HistoryStack` 泛型化为 `HistoryStack<T>` 并保留默认类型参数，
使文字编辑器现有代码无需改动，表格侧使用 `HistoryStack<工作表快照>`。

### 合并单元格

`Sheet` 增加 `合并区域: string[]`，存放区域地址。合并后仅左上角单元格保留内容，
其余单元格不参与渲染与选区命中；对已合并区域再次执行合并命令即取消合并。

### 筛选行为

筛选以选区首行作为表头、首列作为筛选依据。执行筛选命令后弹出中文选项面板，
列出该列的去重值，勾选后隐藏不含选中值的行；清除筛选恢复全部行。
筛选只影响显示，不修改数据。

### CSV 导出规则

逐行拼接，字段间以逗号分隔。字段包含逗号、双引号或换行时用双引号包裹，
字段内的双引号写成两个双引号。导出内容取自各单元格的显示值，
含公式的单元格导出计算结果而非公式原文。

### 地址与区域

- `地址(行, 列)`：列序号转字母、行序号加一，例如 `(0, 0)` 得 `A1`。
- `解析地址(地址)`：`A1` 得 `{ 行: 0, 列: 0 }`。
- `区域地址(选区)`：单格返回 `A1`，多格返回 `A1:C3`。
- `展开区域(区域文本)`：`A1:C3` 得全部地址列表。

## 五、公式引擎

### 支持范围

- 以 `=` 开头视为公式。
- 运算：加、减、乘、除、乘方、括号、百分比。
- 引用：单元格 `A1`、区域 `A1:B5`。
- 比较：`=`、`<>`、`>`、`<`、`>=`、`<=`。
- 函数：`SUM`、`AVERAGE`、`MAX`、`MIN`、`COUNT`、`COUNTA`、`IF`、`ROUND`、`ABS`、`CONCAT`。

### 求值规则

1. `求值公式(公式文本, 取值函数)`：由外部提供 `取值函数(地址) => number | string`，
   使引擎与表格状态解耦，便于单元测试。
2. 区域引用展开为取值列表后交给函数。
3. 除数为零、函数名未知、参数个数错误、循环引用一律返回 `#错误` 并在单元格标记，
   不使用默认值掩盖。
4. 引用空单元格按 0 参与数值运算、按空串参与文本运算。
5. 循环引用检测：求值过程中记录正在求值的地址栈，重复出现即判定为循环引用。

### 重算策略

任一单元格编辑后，对整个工作表重新求值。单元格数量为 2600，重算耗时在可接受范围内，
不引入依赖图。

## 六、交互行为

| 场景 | 行为 |
| --- | --- |
| 单击单元格 | 选中该单元格，名称框显示地址，公式栏显示原始值 |
| 拖动或按住 Shift 单击 | 扩展选区，名称框显示区域地址，状态栏统计选区 |
| 方向键 | 移动选区，边界处不越界 |
| 直接输入字符 | 进入编辑态并把字符写入公式栏，回车确认后写入单元格 |
| 双击单元格 | 进入编辑态，公式栏显示原始值 |
| F2 或点击公式栏 | 同上 |
| Esc | 放弃编辑，恢复原值 |
| 回车 | 确认编辑，选区内向下移动一格 |
| 删除键 | 清空选中单元格的内容，保留格式 |
| 列标单击 | 选中整列 |
| 行号单击 | 选中整行 |
| 全选按钮单击 | 选中全部单元格 |
| 列宽拖动 | 调整列宽，最小 40px |
| 单元格格式命令 | 应用于选区全部单元格 |
| 合并后居中 | 合并选区并居中；再次点击取消合并 |
| 自动求和 | 在选区下方或右侧写入 `=SUM(区域)` |
| 升序与降序 | 按选区首列排序，排序前记录历史 |
| 筛选 | 在选区的首行下方隐藏不匹配行 |
| 工作表标签 | 切换、双击重命名、新建、删除（至少保留一个） |
| 撤销与重做 | 每次编辑与格式操作前记录快照，上限 100 条 |

异常一律通过中文提示呈现，不以默认数据掩盖。

## 八、测试策略

纯函数用单元测试覆盖：地址与区域换算、数字格式化、选区统计、公式求值
（四则运算、引用、区域引用、全部函数、错误分支、循环引用）。

组件用 Testing Library 覆盖：名称框与公式栏联动、单元格选中与编辑、选区扩展、
工作表标签切换与重命名、状态栏统计、Ribbon 标签切换与命令派发。

网格的真实交互在运行窗口中用 CDP 验证：输入公式后显示计算结果、
求和、排序、合并居中、撤销重做、导出、多工作表切换。
