# WPS 文字文档编辑器设计规格

- 日期：2026-09-22
- 范围：仿 WPS 文字（Writer）的文档编辑器界面与编辑能力
- 状态：已获用户批准

## 一、目标与范围

### 目标

在已完成的仿 WPS 首页之上，实现打开文档后的文字编辑器：完整还原 Ribbon 六标签界面，
并提供真实可用的基础编辑能力。

### 本轮完整实现

字体、段落、样式库、剪贴板、撤销重做、查找替换、字数统计、插入表格、图片、形状、文本框、
页眉页脚、页码、日期、符号、超链接、书签、分栏、水印、页面边框、纸张方向与大小、页边距、
拼写检查、简繁转换、视图模式、显示比例、标尺与网格线。

### 本轮按钮就位、点击给出中文提示

图表、公式、SmartArt、邮件合并、目录与题注、批注与修订、文档比较、域与文档部件、翻译。

说明：翻译需要外部接口，本轮无可用服务，归入未实现。拼写检查实现为基础检查——
检测连续重复字符（如「的的」）与中文全角标点误用为半角的情形，命中时给出中文提示并定位，
不依赖外部词典，属于真实可用的检查而非占位。

### 本轮不做

1. 不导出 PDF（需主进程 `printToPDF`，受 `preload` 安全问题阻塞，另案处理）。
2. 不引入 docx 生成库。
3. 不实现真实文件读写，文档内容保存在内存。
4. 不引入 ProseMirror、Slate 等编辑框架。
5. 不修改首页既有交互。

## 四、核心架构
### 命令注册表

Ribbon 按钮不直接操作 DOM，一律派发命令，行为集中在 `editor/commands.ts`。

```ts
export interface CommandContext {
  /** 编辑区根元素 */
  root: HTMLElement
  /** 历史栈，供命令在执行前后记录快照 */
  history: HistoryStack
  /** 请求重新渲染，用于刷新按钮激活态与状态栏 */
  refresh: () => void
  /** 输出中文提示 */
  notify: (文本: string) => void
  /** 缩放比例与视图状态 */
  view: ViewState
  /** 更新视图状态 */
  setView: (部分: Partial<ViewState>) => void
}

export interface EditorCommand {
  id: string
  label: string
  run: (上下文: CommandContext) => void
  /** 未实现或当前不可用时返回 false */
  enabled?: (上下文: CommandContext) => boolean
  /** 处于激活态时返回 true，例如光标在加粗文本内 */
  active?: (上下文: CommandContext) => boolean
}
```

命令 id 采用 `模块.动作` 命名，如 `font.bold`、`para.alignCenter`、`edit.find`。

未实现的命令统一由 `未实现命令` 工厂生成，其 `run` 只调用 `notify('该功能开发中')`，
避免在六个标签页中重复写提示逻辑。

### 编辑区

- 使用 `contentEditable` 容器，初始内容为空白段落。
- 输入后触发内容快照记录（防抖 300 毫秒）。
- 粘贴时拦截默认行为，仅插入纯文本，避免带入外部样式破坏版式。
- 纸张由外层容器承载阴影与背景，编辑区只负责文本内容。

### 撤销重做

`history.ts` 维护快照栈：

- 快照结构：`{ html: string, selection: SavedSelection | null }`。
- 栈上限 100 条，超出时丢弃最早的一条。
- 记录时机：格式化命令执行前、输入停止 300 毫秒后、结构性操作（插入表格、分页符）执行前。
- `undo()` 与 `redo()` 各维护独立指针，新操作发生后清空重做分支。

### 字数统计

`wordCount.ts` 导出 `countWords(文本: string)`：

- 中文字符（含中日韩统一表意文字）按字计数。
- 连续的西文字母与数字按一个词计数。
- 标点与空白不计入。
- 返回 `{ 字符数: number, 词数: number, 段落数: number }`，其中字符数不含空白。

### 查找替换

`FindReplacePanel.tsx` 为编辑区上方浮层，字段：查找内容、替换为、区分大小写、全字匹配。

- 查找：从当前光标处向后循环查找，命中项以高亮标记包裹并滚动到可见区域。
- 替换：替换当前命中项。
- 全部替换：替换全部命中项，并提示替换处数。
- 查找无结果时提示「未找到匹配内容」，不使用默认值填充。

### 导出

`exportDoc.ts`：

- `导出为Html(标题, 正文Html)`：拼装含中文 `meta` 的完整 HTML 文档。
- `导出为文本(正文Html)`：去除标签并保留段落换行。

下载通过创建 `Blob` 与临时 `a[download]` 触发，文件名取自当前文档名（扩展名相应替换）。

### 多文档标签

`store` 扩展为管理 `documents: EditorDocument[]` 与 `activeDocumentId`：

```ts
export interface EditorDocument {
  id: string
  name: string
  html: string
  /** 该文档独立的撤销重做栈，不与其它文档共享 */
  history: HistoryStack
}
```

标签栏展示全部文档，支持点击切换与关闭；关闭最后一个标签时回到首页。

## 六、测试策略

contentEditable 的选区与 `execCommand` 在 jsdom 中不可靠，因此把可测逻辑全部提取为纯函数，
用单元测试覆盖；编辑区真实行为在运行窗口中用 CDP 验证。

单元与组件测试范围：

1. `wordCount`：纯中文、纯英文、中英混排、含标点与换行、空串。
2. `history`：入栈、撤销、重做、栈上限、新操作清空重做分支。
3. `commands`：命令注册表完整性（每个 Ribbon 按钮引用的命令 id 均已注册）、未实现命令的提示行为。
4. `exportDoc`：HTML 输出含标题与中文 meta、文本输出去除标签并保留段落。
5. `Ribbon`：标签切换、按钮点击派发对应命令。
6. `FindReplacePanel`：输入校验、无结果提示、替换计数。
7. `EditorStatusBar`：页码、字数与缩放展示。
8. `DocumentTabs`：切换与关闭标签。

运行窗口验证：六个标签页逐一展开截图、加粗与对齐等格式操作生效、
查找替换定位命中、撤销重做可回退与恢复、字数随输入变化、导出触发下载。
