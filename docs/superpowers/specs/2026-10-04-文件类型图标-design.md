# 文件类型图标设计

## 目标与范围

为文字、表格、演示、PDF 提供不同的 Windows 文件图标，并使首页、最近文件与底部标签使用相同图形。应用自身的蓝色海豹品牌图标保留。DOC 与 DOCX、XLS 与 XLSX、PPT 与 PPTX 分别共用对应类别图标。

## 设计令牌

- 画布：64 × 64；页面留白 8，页面圆角 4；折角、线宽与内容位置统一。
- 颜色：文字 `#2B6CF6`、表格 `#15845B`、演示 `#C86220`、PDF `#C73F4C`；标记白色，折角使用白色透明叠加。
- 形状：文字行、表格网格、带播放标记的投影屏、PDF 曲线；依靠颜色与形状同时区分。
- 不增加字体、阴影或动画；保留原有按钮的交互与布局。
- 图形与颜色集中存放在一个设计文件，前端与生成器共同读取；界面颜色通过 CSS 变量引用。
- Windows 图标包含 16、20、24、32、40、48、64、128、256 像素；小图不放难以辨认的文字。

## 链路

1. 使用项目已有 Electron 的 SVG 渲染能力生成透明 PNG 和多帧 ICO，不增加图片转换依赖。
2. 原始图标随应用完整性清单打包，外置副本供 Windows 读取。注册前逐字节核验，缺失或修改明确报错。
3. 安装器传递固定资源路径，各类别的 ProgID 使用相应 ICO。升级重新注册包括旧式新建类别的图标，并通知 Windows 刷新关联。
4. 便携版手动注册时先复制到本机持久数据目录，确保程序退出、临时解包目录移除后图标依然存在。
5. 卸载沿用现有菜单备份恢复机制，只删除海豹办公自己的 ProgID；保留其他应用关联。不修改 Windows 的受保护默认应用选择。

## 验收

验证资源一致性、便携持久路径、损坏错误、包含中文和空格的路径、七种类别注册、升级更新、原关联保留、卸载恢复。通过 Windows 原生图标提取确认资源可读，检查各帧尺寸并人工审阅大小图、浅深背景。执行类型检查、回归测试、Windows 编译与两种成品的真实启动验收，最后更新 README、帮助、提交及发布。
