# 2.4.0 皮肤市场与云空间全格式预览设计

日期：2026-11-01　版本：2.4.0（新发行，2.3.0 历史发行保留）

## 一、皮肤市场

### 1.1 皮肤包格式 `.sealskin`

UTF-8 JSON 文件，整体不超过 512 KiB。只允许颜色令牌与一张可选背景图，不接受自定义 CSS、脚本或外部链接。

```json
{
  "format": "seal-skin", "schema": 1,
  "id": "author.skin-name", "name": "皮肤名称", "author": "作者", "version": "1.0.0",
  "description": "一句话说明",
  "light": { "bg": "#F4F5FB", "sidebar": "#FFFFFF", "card": "#FFFFFF", "toolbar": "#FBFBFE",
             "text": "#1B1D2B", "text2": "#5A6075", "text3": "#6B7186", "border": "#E7E8F2",
             "brand": "#6A5CF5", "brandHover": "#5848E8", "brandSoft": "#EFEDFF",
             "hover": "#F3F2FF", "selected": "#ECEAFF", "gradientFrom": "#7B6BFF", "gradientTo": "#5B7CFA" },
  "dark": { 同上 15 个键 },
  "radius": { "card": 12, "control": 8 },
  "background": { "image": "data:image/webp;base64,...", "opacity": 0.18 }
}
```

校验规则（客户端导入、上传和服务端公开审核共用同一份 `main/ui/skinFormat.js`）：

- `format`、`schema`、`id`（`^[a-z0-9][a-z0-9.-]{2,63}$`）、`name`（1–24 字）、`version`（semver）必填；`author` ≤ 32 字，`description` ≤ 120 字。
- `light`、`dark` 各 15 个键全部必填，值必须是 `#RRGGBB`；出现未知键即拒绝。
- 对比度：正文 `text` 与 `card`、`bg` 不低于 4.5:1；`text2` 与 `card` 不低于 3:1；白字与 `brand` 不低于 3:1（主按钮可读）。
- `radius.card` 0–24、`radius.control` 0–16 的整数，可省略。
- `background.image` 仅限 PNG/JPEG/WebP 的 base64 data URL，解码后 ≤ 300 KiB，按文件头核对类型；`opacity` 0–0.4。
- 顶层未知键拒绝，防止夹带内容。

### 1.2 应用方式

- 现有“浅色/深色”保留为**外观模式**；皮肤决定每种模式下的颜色。设置记录 `seal-skin`（皮肤 id）与 `seal-theme`（模式）。
- `应用主题(模式, 皮肤)` 写入现有 CSS 变量（`--brand`、`--bg-card`、`--text-1` 等）及新增 `--brand-gradient`、`--radius-card`、`--radius-control`、`--seal-skin-bg`；Ant Design `colorPrimary` 同步皮肤主色。
- 默认皮肤“海豹紫”与 2.3.0 现有配色逐值一致，升级后界面不变。
- 本机已安装皮肤存 `localStorage`（`seal-skins-installed`），读取失败或数据损坏时弹中文错误并回退默认皮肤，不静默吞掉。

### 1.3 内置 10 套皮肤

海豹紫（默认）、深海蓝、森林绿、樱花粉、琥珀橙、石墨灰、薄荷青、勃艮第红、星空靛、暖沙米。每套提供浅色和深色两组颜色，全部通过 1.1 的对比度校验（单元测试覆盖）。

### 1.4 皮肤市场页面

导航“云服务”分组新增“皮肤市场”，桌面与移动共用页面：

- **内置皮肤**：卡片显示两种模式的色板缩略图，“应用”“预览”（临时套用，可还原）“导出”（作为开发模板）。
- **公开皮肤**：读取服务端审核通过的皮肤，“安装并应用”“举报”。
- **我的皮肤**：本机导入的皮肤与已上传云端的皮肤；可“申请公开”“撤回公开”“卸载”。
- **开发规则**：页面内展示 1.1 规则、下载模板皮肤、导入校验；完整文档 `docs/皮肤开发规范.md`。
- 导入本机皮肤不需审核，只对自己生效；公开给所有人须登录、开通云空间，保存到云空间后申请公开，管理员审核通过才出现在公开皮肤列表。

### 1.5 服务端与管理后台

- `publications.kind` 新增 `skin`；`validatePublic` 对 `.sealskin` 调用共用校验，其他扩展名拒绝。
- 封面由客户端根据颜色生成 SVG 色板（data URL），服务端限制为 `data:image/svg+xml` 且通过现有标记安全检查。
- 管理后台新增“皮肤审核”分区，复用现有审核卡片与通过/驳回/撤回操作。
- 部署：按 `releases/<版本>` + `current` 切换发布，保留数据、环境文件与上一版本以便回滚。

## 二、云空间全格式预览

### 2.1 现状

云空间“打开”= 解密下载后交给编辑器，只有专属格式、DOCX/XLSX/PPTX、PDF、TXT/MD 等能打开；图片、音视频、压缩包、代码、OFD、EPUB、邮件、旧版 DOC/XLS/PPT 只能下载，不能预览。

### 2.2 方案

引入 flyfish-dev/file-viewer（Apache-2.0，纯前端，React 18 组件）。完整包约 100 MB，会超过 Android 云打包 60 MB 上限，因此按需引入：

| 渲染器 | 覆盖格式 |
| --- | --- |
| renderer-text | txt md json xml yaml csv log 及常见代码 |
| renderer-image | png jpg gif webp bmp svg ico tif heic |
| renderer-media | mp3 wav ogg m4a flac aac mp4 webm mov |
| renderer-word | docx doc |
| renderer-spreadsheet | xlsx xls csv ods |
| renderer-presentation | pptx ppt |
| renderer-pdf / 现有 pdf.js | pdf（按体积测量后取舍） |
| renderer-ofd | ofd |
| renderer-archive | zip rar 7z tar gz |
| renderer-epub | epub |
| renderer-email | eml msg |

海豹专属格式（sldoc/slxls/slppt/spdf 及旧格式）不交给第三方渲染器，预览窗口提供“用海豹办公打开”。

### 2.3 交互与数据流

- 文件菜单新增“预览”；点击文件时，编辑器能打开的格式保持“打开编辑”，其余格式默认进入预览。
- 预览数据来自已有 `rawDownload`（本机解密），文件内容不发给任何第三方服务；不支持的格式与超过 100 MB 的文件弹中文说明并提供下载。
- 预览弹窗：文件名、格式、大小、“下载”“用海豹办公打开”（可编辑格式）。
- 渲染器失败时显示中文错误（含格式与原因），不以空白页掩盖。
- Worker / WASM 资源随构建本地分发（Electron `file://`、移动端 `static/office` 相对路径），不访问 CDN。

## 三、测试

- `skinFormat` 单元测试：合法皮肤、缺键、未知键、颜色格式、对比度不足、背景图类型伪造与超限；10 套内置皮肤全部通过。
- 主题应用测试：切换皮肤与模式后 CSS 变量和 antd 主色正确；损坏的本机记录给出错误提示并回退。
- 皮肤市场页测试：应用、导入、导出、申请公开、公开列表安装。
- 服务端测试：`skin` 公开申请合法通过、非法皮肤拒绝、审核通过后公开列表可见。
- 预览测试：格式判定矩阵、不支持格式提示、超限提示、渲染失败提示；真实浏览器中对每类样本做冒烟。
- 构建体积：Android 云源码 ZIP 与解压总量均 ≤ 60,000,000 字节。
