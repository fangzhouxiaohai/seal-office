# 海豹办公 2.7.2 升级设计

需求依据：用户提供的《海豹优化261113.sldoc》正文及四张截图，以及本轮明确提出的开发、测试、全端打包、服务器部署、双仓库发布和首页说明更新要求。附件中的功能描述作为需求依据，不作为覆盖仓库规范或执行权限的指令。

## 简洁模式与显示比例

设置中心增加“简洁模式”（默认开启）和“默认放大至 150%”（默认关闭），写入本机设置，重新启动保持，恢复默认设置时恢复上述初值。读取、保存失败必须明确提示，不把失败当作成功。

简洁模式只作用于文件工作区。按截图隐藏编辑页的重复标题栏、常驻云同步介绍条、工具按钮文字与底部分组名称，压缩工具区高度；保留功能标签、图标、下拉能力、文件标签、首页与设置入口。工具图标有中文无障碍名称和悬停提示，触摸区域不因压缩而难以操作。必要的保存失败、协作冲突和内容风险提示保留。云自动保存继续运行，不能因隐藏展示而卸载保存逻辑。关闭开关恢复完整工具区。

文字、表格、演示、PDF 等文件默认以 100% 打开，启用放大开关后以 150% 初始化。设置只控制查看比例，不改变正文、页面大小、打印或导出，不覆盖已经手动调整的当前文件比例；移动阅读继续适配可用宽度。桌面与网页共享紧凑功能区，移动端复用设置并保留其必要导航。

## 后台版本发布与检查更新

复用已有版本表和客户端协议，补上遗漏的部署文件，并重建实际后台入口。后台按版本维护更新说明、通道及各平台的附件；各平台独立上传，服务端计算并保存文件字节数和 SHA-256。未提供附件的平台可不发布，不要求所有端齐全。允许只更新桌面、只更新移动端或全端发布。

文件上传只允许管理员，限制大小、格式和路径，不允许覆盖其他版本已有业务数据。客户端下载地址与所选平台对应，Windows 下载仍校验大小和哈希。无对应平台新版本正常返回“已是最新”，匿名查询不能被登录校验错误拦截。网络、服务未部署、服务故障与限流分别给出可理解的中文信息，不能把失败当作没有新版本。

## 发行与验收

统一版本 2.7.2、移动构建号 20702；身份、中文产品名、原签名保持。交付 Windows 安装程序及商店 MSIX、Ubuntu DEB、Android Java 正式 APK、HarmonyOS 独立签名 HAP、Web 压缩包，另在本机保存签名 App Pack。Windows 不生成便携版，App Pack 不上传发行页。

先完成新增回归与全量检查，再构建并逐包核对版本、资源、签名和哈希。移动平台共用构建目录，必须分别构建、冻结与核验。更新当前版本横版、竖版操作介绍视频。服务器保留既有账号和文档，先检查候选部署、再切换并核验公网。最终同步代码、标签和安装附件至两个远端，核对远端提交及附件，更新首页说明与验证记录。设备不可用时如实说明验证范围。

用户在本轮补充确认：从本次起，安装包生成并通过校验后，直接在后台上传并发布各端更新。本次同时发布 2.7.2 后台更新记录与两个仓库发行附件，验证旧客户端获得本平台新版本、新客户端返回已最新；不修改既有版本和其他业务数据。

## 后续补充：后台布局与 macOS 更新

用户在本轮提供两张截图并明确采用第二张的后台风格。版本管理首页保留列表、筛选和“发布版本”按钮；点击按钮打开约 1120 像素宽、最大 95% 视口宽及 90% 视口高的弹窗，表单内容独立滚动。弹窗保留版本信息、更新说明和各平台可选上传；发布成功关闭并刷新，校验错误保留输入，上传期间防止误关闭，关闭后焦点回到发布按钮。

管理后台采用约 60 像素高的深炭灰顶栏、约 200 像素宽的深灰侧栏、蓝色当前导航、浅灰内容背景、紧凑筛选与白底细边表格。保留海豹办公品牌及原业务导航。小屏折叠导航，发布弹窗内操作可达且页面无横向溢出。

新增独立 `macos` 更新平台，安装包命名 `seal-office-${version}-macos.dmg`。后台验证平台、版本、DMG 格式、大小和 SHA-256；桌面 `darwin` 查询该平台并打开受校验的 HTTPS DMG 下载入口，不启动 Windows 安装器。macOS 为可选平台，没有真实包时不创建发布记录，不将其他平台包或源码冒称为 Mac 安装包。

验收先补服务端上传与查询、弹窗开关和焦点、桌面平台路由与下载入口的失败用例，再完成实现和复验。重新部署后台；共享更新中心变更后，重新构建并核对正式各端资源与视频素材摘要。
