# 海豹办公 v1.2.0 构建修复记录

## 问题现象

执行 `npm run dist` 打包命令时，electron-builder 在 `@electron/rebuild` 阶段报错：

```
read ECONNRESET failedTask=build stackTrace=RequestError: read ECONNRESET
at ClientRequest.<anonymous> (node_modules\got\dist\source\core\index.js:970:111)
```

## 根因分析

1. **项目无原生依赖**：项目所有依赖（antd、react、docx、exceljs 等）均为纯 JavaScript 模块，无需 node-gyp 重建
2. **默认重建行为**：electron-builder 默认执行 `@electron/rebuild` 步骤，尝试从 npm 下载重建工具
3. **网络异常**：
   - 首次错误：下载过程连接中断（ECONNRESET）
   - 二次尝试：DNS 被劫持到 Twitter IP（199.59.148.9:443），导致连接被拒绝（ECONNREFUSED）

## 修复方案

在 `package.json` 的 electron-builder 配置中新增 `npmRebuild: false`：

```json
"build": {
  "npmRebuild": false,
  ...
}
```

同时配置环境变量使用国内镜像：
- `ELECTRON_MIRROR`: https://npmmirror.com/mirrors/electron/
- `npm_config_registry`: https://registry.npmmirror.com

## 修复效果

打包成功生成以下产物：
- `release/SealOffice 1.2.0.exe`（便携式版本）
- `release/SealOffice Setup 1.2.0.exe`（NSIS 安装包）
- `release/SealOffice Setup 1.2.0.exe.blockmap`（增量更新块映射）
- `release/win-unpacked/`（免打包目录）
