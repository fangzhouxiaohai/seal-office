# 海豹办公 v1.3.0 功能更新记录

## 更新内容

### 一、修复文件打开问题

**问题现象**：打开 docx、xlsx、pptx 等常规办公格式文件时无法正常解析，反而打开了 HTML 和 JSON 格式。

**根因分析**：
- `fileChannel.js` 的 `readFile` 函数将 docx/xlsx/pptx 作为二进制文件处理，返回 base64 编码内容
- `commands.ts` 的打开命令没有根据文件扩展名路由到对应的解析器，直接将 base64 内容当作普通文本显示

**修复方案**：
- `commands.ts`：打开文件时检测文件扩展名，docx 文件通过 `office.readDocx` 解析为 HTML，xlsx 文件通过 `office.readXlsx` 解析为 HTML 表格
- `pptxCodec.js`：`读取pptx` 函数返回值从 `{ 幻灯片, 警告 }` 改为 `{ 演示文稿, 警告 }`，返回格式兼容 deck.ts 模型
- `PptEditor.tsx`：打开文件时区分 pptx 和 json 格式，pptx 通过主进程解析后设为演示文稿模型

### 二、新增 PPT 文字选中修改颜色功能

**问题现象**：编辑 PPT 时无法选中部分文字来修改颜色、加粗等格式，只能对整个文本框统一设置样式。

**根因分析**：
- `SlideCanvas.tsx` 中文本框以纯文本渲染，不支持内部文本选择和独立格式化
- `pptCommands.ts` 的格式化命令只对文本框整体生效

**修复方案**：
- `deck.ts`：新增 `文本片段` 接口和 `片段列表` 字段，支持文本级富文本渲染。新增 `文本转片段`、`片段转文本`、`检测选中片段`、`应用格式到选中片段` 等辅助函数
- `pptCommands.ts`：重写 `text.bold`、`text.italic`、`text.underline`、`text.color` 命令，使其作用于选中的文本片段而非整个文本框。新增 `演示命令上下文.选中起始` 和 `选中结束` 字段
- `SlideCanvas.tsx`：支持片段列表渲染，每个字符独立为 span 元素并可设置不同样式。新增 `on文本选择` 回调用于检测鼠标选区
- `PptEditor.tsx`：新增选中起始/结束状态，传递 `on文本选择` 回调给 SlideCanvas，更新激活态检测逻辑以反映选中片段格式
