# v1.5.0 功能链路全面修复

本提交针对 v1.5.0 全链路审查发现的缺陷逐项修复，覆盖主进程保存/编解码链路、表格粘贴与导出、演示文稿命令与坐标换算、公式惰性求值、PDF 合并入口，并同步更新测试与文档。目标：所有功能链路合理、正确、可用，测试全量通过，打包成品推送仓库。

## 一、主进程保存 / 编解码链路（严重，会导致文件损坏或数据丢失）

### 严重-1：fileChannel.js 二进制保存逻辑损坏所有 docx/xlsx/pptx/PDF 文件
- 文件：`main/ipc/fileChannel.js`（原 L44）
- 根因：渲染层二进制保存传入 `Uint8Array`；Electron IPC 结构化克隆后主进程收到的是 `Uint8Array`，而 `Buffer.isBuffer(uint8array) === false`，落入 `Buffer.from(String(内容 ?? ''), ...)`，把字节变成逗号分隔的数值串按 utf8 写入，任何二进制文件都损坏。
- 修复：抽出导出函数 `内容转缓冲(内容, 格式)`：`Buffer` 直接返回；`Uint8Array` 用 `Buffer.from(内容.buffer, 内容.byteOffset, 内容.byteLength)`；格式为二进制且为合法 base64 时 `Buffer.from(文本, 'base64')`；否则 utf8。`module.exports` 同时导出 `内容转缓冲` 与 `文本扩展名`。
- 新增 `main/ipc/fileChannel.test.js`（5 项）覆盖三种类型输入。

### 严重-2：PptEditor.tsx 未对 base64 解码直接保存，pptx 损坏
- 根因：`office.writePptx` 返回 `数据` 为 base64 字符串，PptEditor 直接当二进制传给 `saveToFile`。
- 修复：由 `fileChannel.js` 的 `内容转缓冲` 自动识别合法 base64 并解码，PptEditor 无需再改（保持其 `{ 幻灯片 }` 契约）。

### 严重-3：writeXlsx 模型契约不匹配，保存 .xlsx 为空表
- 根因：渲染层 `htmlToXlsxModel` 返回 `{ 工作表: [{ 名称, 数据 }] }`，主进程 `xlsxCodec.js` 只读 `模型.行` → 空数组 → 空工作簿。
- 修复：`main/office/xlsxCodec.js` 写入时同时兼容 `模型.工作表[0].数据`（取每单元首段文字文本）与旧 `模型.行`。新增契约测试。

### 严重-4：writePptx 模型契约不匹配（编辑器另存路径），保存 .pptx 为空演示文稿
- 根因：`htmlToPptxModel` 返回 `{ 幻灯片列表 }`，`pptxCodec.js` 只读 `模型.幻灯片`。
- 修复：`main/office/pptxCodec.js` 写入时同时接受 `模型.幻灯片列表`（提取标题+内容文字）与 `模型.幻灯片`（文本字段）。新增契约测试。

## 二、表格编辑器

### 严重：SheetEditor Ctrl+V 异步粘贴失效
- 文件：`renderer/src/sheet/SheetEditor.tsx`（约 L360-376）
- 根因：`navigator.clipboard?.readText().then(系统值 => 粘贴值 = 系统值)` 是异步，但写入单元格在 `.then` 外同步执行 → 系统剪贴板内容永远粘贴不上，仅本地缓存生效。
- 修复：定义 `执行粘贴(粘贴值)`，有 `readText` 时在回调内写单元格（成功用系统值、失败用本地值），无接口时直接执行本地粘贴。

### 中等：表格缺 xlsx 导出链路（宣称支持 .xlsx 但无入口）
- 文件：`renderer/src/sheet/sheetExport.ts`、`SheetEditor.tsx`、`ribbonSpecs.ts`
- 修复：`sheetExport.ts` 新增 `导出为Xlsx(工作表)` 返回 `{ 工作表: [{ 名称, 数据 }] }`（用有效范围显示值，公式导计算结果）；并修正 `生成表格文件名` 对带点扩展名的拼接。`SheetEditor.tsx` 新增 `file.exportXlsx` 分支：模型 → `writeXlsx` → `showSaveDialog` → `saveToFile(...,'二进制')`。`ribbonSpecs.ts` 导出组新增 `file.exportXlsx` 大按钮。新增 `sheetExport.test.ts` 相关测试。

## 三、演示文稿编辑器

### 严重：PPT 重复命令 id 覆盖导致整框样式失效
- 文件：`renderer/src/ppt/pptCommands.ts`
- 根因：命令表用 `reduce` 后注册覆盖先注册；`text.bold/italic/underline/color` 整框命令被同 id 片段格式化命令覆盖 → 选中框无文本选区点加粗报"请先选中要修改的文字"。
- 修复：新增 `应用整框样式` 用 `更新文本框` 应用样式并清空片段列表；四个片段命令在无选区时回退为整框样式；删除被覆盖的死注册。

### 严重：SlideCanvas 文本选择坐标换算错误
- 文件：`renderer/src/ppt/SlideCanvas.tsx`（处理文本框鼠标移动，约 L86-95）
- 根因：用 `事件.clientX / 比例` 当画布坐标，未减画布 `getBoundingClientRect` 偏移、忽略 `transform: scale` 中心原点。
- 修复：取画布 `getBoundingClientRect`，`逻辑x = (clientX - rect.left) / 比例`，`相对x = (逻辑x - 框.x) / 框.width`。

## 四、公式惰性求值

- 文件：`renderer/src/sheet/formula.ts`、`formula.test.ts`
- 根因：IF 函数非惰性，求函数提前对所有参数求值，含错误分支时整体报错。
- 修复：新增 `求函数IF()`：`切分顶层参数()` 取三个区间，仅对 `条件为真 ? 真分支 : 假分支` 所在区间求值。新增惰性 IF 与嵌套 IF 测试。

## 五、PDF 合并入口启用 + 版本号修正

- 文件：`renderer/src/pdf/PdfWorkbench.tsx`
- 修复：state 由单 `源文件` 改 `文件列表`（多 base64）；Upload 多选；命令下拉去除 `filter(键 !== 'merge')`；`执行()` 对 merge 用整个文件列表（需≥2 个）且不要求页码。主进程 `pdfChannel.pdf.merge` 已接收列表并合并，链路正确。
- 文件：`renderer/src/ipc/bridge.ts`：`getAppInfo` 兜底版本 `1.2.0` → `1.5.0`（与 package.json 一致）。
