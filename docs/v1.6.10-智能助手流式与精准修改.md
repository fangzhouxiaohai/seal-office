# 1.6.10 智能助手流式与精准修改

## 需求与根因

旧版请求使用一次性响应，只读取 `message.content`，未接收流式思考与正文。Word 上下文将所有段落拼成一个字符串，但修改预览仅在单个文字节点内查找；跨加粗或颜色片段的原文因此失配。旧协议也没有段落排版指令，无法完成“重新排版”。

本版将模型连接、事件桥接、正文解析和文件候选作为一条链路更新，所有实际写入仍需在应用内预览并确认。

## 模型服务与思考强度

| 预设 | 接口 | 初始模型 | 思考参数 |
| --- | --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/chat/completions` | `deepseek-flash` | 开启思考，默认 `high` |
| 豆包 | `https://ark.cn-beijing.volces.com/api/v3/chat/completions` | 填写账号已开通的模型或推理接入点 | 开启思考，强度由模型控制 |
| 智谱 | `https://open.bigmodel.cn/api/paas/v4/chat/completions` | `glm-5.3` | 开启思考，默认 `high` |
| Kimi | `https://api.moonshot.cn/v1/chat/completions` | `kimi-k3` | `reasoning_effort`，默认 `high` |

六档为低、中、高、极高、最高、极致（`ultra`）。DeepSeek、智谱、Kimi 当前预设的三档映射如下：

| 界面选择 | 实际参数 |
| --- | --- |
| 低 | `low` |
| 中、高、极高 | `high` |
| 最高、极致 | `max` |

界面解释实际映射。自定义服务可选择模型默认、三档、标准四档、扩展六档、仅开启思考或令牌预算模式；只向模型发送所选模式的参数，不在参数被拒绝后悄悄重发或伪称已启用。

DeepSeek 的初始界面已填写地址与模型，用户只需填写自己的 API 密钥并保存。模型权限、余额及调用额度由服务商提供。更换服务商或接口地址不沿用旧密钥，访问密钥加密落盘且不回显。旧配置迁移为自定义服务，并保持模型默认参数模式。

## 流式对话与取消

- 按 SSE 事件边界解析，支持网络分帧、跨字节中文、换行和服务商心跳。兼容返回普通 JSON 的聊天接口。
- 分别读取服务商的 `reasoning_content` 或字符串 `reasoning`，以及 `content`。不编造思考；未返回时显示连接、等待或输出阶段。
- 逐步解码顶层“回复”字符串，隐藏原始 JSON 修改协议。思考内容可展开，正文与任务状态分开显示。
- 执行指示器和输出光标提供状态反馈，系统要求减少动态效果时停止动画。
- 点击停止会中断实际请求，保留已收到的内容并停止创建本次修改候选；窗口销毁或渲染进程退出也中断请求。
- 请求标识与发送者隔离，其他窗口不能取消本窗口任务。换标签后任务、回复及候选仍归属原文件；后台任务显示文件名并提供停止入口。
- 响应最多 1 MB；收到完成标识后主动释放连接。空回复、流中断、长度截断、鉴权失败、超时或不支持参数均通过自定义弹窗说明原因。

## 准确修改当前文件

Word 上下文包含段落标识、完整原文、类型、必要格式与图片数量。段落与列表、表格以及混合容器中的文字分别定位，不把不同段落拼成一段。

支持同段落跨格式片段的精确替换，新文字沿用起始片段的样式，保留邻近文字、标签和图片。重复原文用段落标识消除歧义；无标识且不唯一时拒绝修改。段内换行不允许用跨行字符串替换，应分别修改每行以保留结构。

新增段落排版：标题级别、对齐、字号（磅）、字体、六位颜色、加粗、行距、段前段后距和首行缩进。只有明确列出的字段和范围可执行，不能运行模型返回的任意 HTML、脚本或磁盘命令。

表格继续按工作表、地址和原值校验；工作表保护仍会阻止应用。演示按页码及文本框标识修改，支持跨富文本片段改写，并保留未修改片段的样式。所有候选按发送时快照生成，确认前再次比较文件内容；已变化时拒绝应用。预览失败也保留用户问题与收到的回复，已有候选不会被失败请求清除。

## 界面自检

| 发现的问题 | 已采用的修正 |
| --- | --- |
| 思考、正文和执行状态容易占用相同视觉权重 | 思考使用可展开的辅助区；正文为主内容；执行状态采用短文字与指示器 |
| 长思考内容会挤占输入区并推动正文 | 思考区域限制高度并独立滚动，用户上滚阅读时停止自动跟随 |
| 配置表单首次使用需填写过多字段 | 预设自动填写服务、地址及模型，默认只展示密钥与强度；完整地址和参数放入高级设置 |
| 展开设置时聊天区仍占空间，密钥被挤入较小滚动区；助手遮罩挡住文件 | 配置展开时集中展示设置，保存入口保持可见；助手移除背景遮罩，继续操作文件时仍执行内容冲突校验 |

沿用现有品牌色、字体、间距、圆角及明暗主题变量，控件使用统一组件的键盘焦点、禁用及下拉行为。
