# 1.6.3 版 WPS 对标与已知限制

本文按当前源码描述海豹办公 1.6.3 版已经接通的功能和使用边界。WPS 是界面与操作习惯的参照；本文不表示两者功能或文件格式完全兼容。

## 已实现的能力

| 范围 | 当前可用能力 |
| --- | --- |
| 首页与文件 | 新建和打开本地文件；最近文档在本机持久化，可搜索、筛选、置顶、移除、重命名及定位文件；支持自动备份与恢复，关闭仍有编辑标签的窗口时会提示。外部富文本导入经过安全净化。 |
| 文字 | 基础富文本、标题、列表、表格、查找替换和部分页面布局；可读写部分 docx 内容，并可导出网页、纯文本和 PDF。 |
| 表格 | 多工作表、区域拖选、基础格式与边框、排序、自动求和和部分常用公式；可导入 csv，读写 xlsx 的单元格数据与基础公式。复杂内容导入时提示风险，保存时保护原件。 |
| 演示 | 幻灯片与文本框编辑、位置和基础文字样式保存、从头或当前页放映；可读写部分 pptx 内容。 |
| PDF | 打开本地 PDF，逐页预览、翻页和缩放；可提取、合并、删除、旋转页面并保存处理结果。 |
| Windows 版本 | 构建配置包含 64 位便携版、安装版和解包目录；实际交付结果以本轮打包和启动检查为准。 |

源码依据：`renderer/src/fileOpen.ts`、`renderer/src/store.ts`、`renderer/src/editor/DocEditor.tsx`、`renderer/src/sheet/SheetEditor.tsx`、`renderer/src/ppt/PptEditor.tsx`、`renderer/src/pdf/PdfWorkbench.tsx`、`renderer/src/pdf/PdfViewer.tsx`、`main/ipc/fileChannel.js`、`main/main.js` 与 `package.json`。

## 与 WPS 的主要差距

| 范围 | 当前限制与使用建议 |
| --- | --- |
| 文字格式保真 | docx 导入器主要处理正文、基础文字格式、列表与表格。图片、图形、媒体、页眉页脚、脚注尾注、批注和修订等对象不能完整导入；页面布局也不具备完整分页排版能力。对提示存在未导入内容的文件，请另存副本，保留原件。 |
| 表格格式保真 | xlsx 读写以单元格内容和基础公式为主，未完整保留复杂格式、图表、数据透视表及全部公式语法。检测到未导入内容时会提示并阻止直接覆盖原件；另存副本后仍需核对。纯数字文本在导出时可能被识别为数值，带前导零的编号应核对导出结果。 |
| 演示格式保真 | pptx 导入主要处理含文字的形状和部分基础样式；图片、装饰图形、图表、表格、媒体、动画、切换效果及母版图形不能完整导入。打开时若出现未导入内容提示，应另存副本并检查结果。 |
| PDF 阅读与编辑 | 当前阅读器一次显示一页，提供基础翻页和缩放；页面工具仅覆盖提取、合并、删除和旋转。批注、表单、文字修改、目录导航及文字识别尚未提供。 |
| 在线与协作 | 登录、云文档、云同步、共享协作、企业服务等能力尚未接入，文档保存在本机。部分设置项明确标注暂未开放。 |
| 数据恢复 | 自动备份和关闭提示提供基础保护；窗口退出提示按仍打开的编辑标签计数，尚无 WPS 式完整版本历史、云端恢复与多人编辑冲突处理。 |

格式边界依据：`main/office/docxReader.js`、`main/office/docxWriter.js`、`main/office/xlsxCodec.js`、`main/office/pptxCodec.js`、`renderer/src/sheet/formula.ts`、`renderer/src/pdf/PdfViewer.tsx`、`main/ipc/pdfChannel.js` 与 `renderer/src/pages/SettingsPage.tsx`。导入文件的保真风险由文字、表格和演示编辑器向用户显示。

## Windows 交付核对

本轮在 Windows x64 环境运行 `npm run typecheck`、`npm run test:run` 和 `npm run dist`，分别通过类型检查、渲染层 768 项测试、主进程 149 项测试及打包。产物为 `release/SealOffice 1.6.3.exe`、`release/SealOffice Setup 1.6.3.exe` 和 `release/win-unpacked/`。解包版与便携版均已实际启动，核对首页、版本号、预加载桥接和本机文件读取。PDF 阅读器在 Electron 环境下另已完成工作线程加载及单页解析预检；安装向导与各类真实 Office 文件的完整人工验收未在本轮执行。

两份安装介质目前没有代码签名证书，Windows 可能提示文件来源；该提示不表示本轮构建失败。
