# 1.6.3 版 WPS 对标与已知限制

海豹办公以 WPS 常见的工作区和操作方式为参考，提供本机文字、表格、演示和 PDF 工作流程。下表仅列出当前源码已接通的能力；两款软件的功能范围、排版引擎和文件格式兼容程度并不相同。

## 当前可用能力

| 范围 | 已接通的操作 |
| --- | --- |
| 工作区与文件 | 首页和打开的文件共用窗口底部标签；本机文件打开、保存与另存为后，标签同步文件名及保存状态。最近文件可搜索、筛选、置顶、移除、重命名和定位。关闭前刷新并等待本机工作区备份；备份或状态检查失败时默认保留窗口，用户可在风险弹窗中明确选择退出。损坏备份可重试恢复，或先移到独立文件再继续。保存和重命名时核对打开文件的内容指纹，避免静默覆盖应用外的修改；另存为还会检查其他标签的路径占用。模板库可新建文字、表格和演示文件。 |
| 文字 | 正文、基础字符与段落格式、标题导航、列表、简单表格、查找替换、分页符及邮件合并。页面设置中的常见纸张、方向、边距、分栏、边框、底色和文字方向可写入 DOCX；自定义纸张与边距按原数值保留。支持导出 HTML、TXT 和 PDF；TXT、MD 与普通 JSON 打开后可保留原有的 CRLF、CR、LF 及混合换行。 |
| 表格 | 多工作表、单元格编辑、基础公式与格式、合并、行列尺寸、排序、筛选、冻结、页面布局预览、批注、数据验证和无密码的本机工作表保护。首页与表格功能区均可导入 CSV，前导零及以等号开头的原始文本不会被擅自计算；CSV 来源保存时须选择 XLSX。旧版工作表 JSON 可从公共打开入口识别并重新进入表格。可插入、显示、删除 PNG 和 JPEG 图片，并随受支持的 XLSX 数据、基础样式与设置一起读写。拼写检查覆盖重复虚词及中文语境下的半角标点。 |
| 演示 | 幻灯片和文本框编辑、浏览排序、逐页备注、基础放映，以及受支持的淡入淡出和推进切换效果；上述备注与切换效果可随 PPTX 保存和重新打开。 |
| PDF | 单页居中阅读、翻页、缩放及右侧可折叠的页面工具；可提取、合并、删除和旋转页面，结果保存为 PDF。 |
| 智能助手 | 在 Windows 桌面版配置兼容聊天补全接口的模型服务，支持对当前文字、表格或演示文件提问。模型返回的受支持修改先显示位置与前后内容，经用户确认后应用到编辑区，再由用户保存。 |
| 其他本机功能 | 本机日历可编辑日程并导出日历文件；脑图与流程图支持节点、连线、可编辑数据导入导出和图形导出。设置中心提供主题、工作区恢复、双击关闭标签、新文件提醒、翻译服务、模型服务、安装完整性检查和 Windows 默认应用设置入口。 |
| Windows 安装 | `package.json` 配置了 Windows x64 便携版、安装版和解包目录；安装版注册 DOCX、XLSX、PPTX、PDF 文件类型，默认程序仍由 Windows 系统设置选择。 |

源码依据包括 `renderer/src/store.ts`、`renderer/src/fileOpen.ts`、`renderer/src/editor/DocEditor.tsx`、`renderer/src/sheet/SheetEditor.tsx`、`renderer/src/ppt/PptEditor.tsx`、`renderer/src/pdf/PdfWorkbench.tsx`、`renderer/src/assistant/`、`renderer/src/localTools/`、`renderer/src/pages/SettingsPage.tsx`、`main/office/`、`main/ai/assistant.js` 与 `package.json`。

## 文件格式与功能边界

| 范围 | 当前限制与建议 |
| --- | --- |
| DOCX | 读取器以正文、基础文字格式、标题、列表、简单表格和单一页面设置为主。图片、图形、媒体、页眉页脚、脚注尾注、批注、修订、超链接目标、复杂段落格式和合并单元格等无法完整往返；多分节及精确分页排版也未覆盖。水印不能可靠写入 DOCX，操作时会提示。遇到保真警告应另存副本；编辑区中无法写回的对象会在保存前提示。 |
| TXT、MD、普通 JSON | 保留打开时已识别的换行标记；若将所有原段落删除后重新输入，来源换行标记随段落一起删除，新文本按默认换行保存。 |
| XLSX | PNG 和 JPEG 静态图片限单张 5 MB、工作簿累计 20 MB，并限当前网格可显示范围；图片超链接、旋转、裁剪和复杂锚点属性不能保证往返。主题色、复杂字体与边框、条件格式、原生图表、其他绘图对象、数据透视表、结构化表格、外部连接、命名区域、部分工作表视图、部分数据类型与公式语法也不保证往返。数据验证只覆盖列表与整数或小数范围；本机工作表保护不设密码，外部受保护工作表按只读处理。检测到未导入内容时，程序提示风险并阻止覆盖来源文件，另存副本后仍应检查结果。 |
| PPTX | 可读写以文字为主的幻灯片、基础样式、备注和少量切换效果；图片、装饰图形、图表、表格、媒体、复杂动画、母版图形及其他切换效果不能保证往返。无法可靠写入的动画会提示，保存为副本后仍应与来源文件比较。 |
| PDF | 阅读器一次显示一页，页面处理仅包含提取、合并、删除和旋转。批注、表单填写、正文编辑、目录导航及文字识别未提供。 |
| 智能助手 | 不内置模型，也不保证任意自然语言请求都能转为编辑。当前只接受文字替换、单元格写入和演示文本替换三类结构化修改；接口须兼容聊天补全响应。发送消息时会把当前文件的名称和处理所需内容交给所配置的服务，文件过大或回复格式不符时会提示失败。 |
| 在线与协作 | 登录、云文档、云同步、共享协作及企业服务需要服务器，当前没有接入。文档、日程和图形工具数据保存在本机。 |
| 数据恢复 | 自动备份、工作区恢复和关闭提示用于降低误操作风险；尚无完整版本历史、云端恢复或多人冲突处理。 |
| 并发保存 | 打开文件的内容指纹可识别保存前的应用外修改，保存对话框选择已有文件时也会核对选择时的版本。普通文件系统不提供跨进程的原子“比较并替换”，最后一次比较与替换之间仍有极短的竞态窗口；保留重要文件的独立备份。 |

导入警告和原件保护依据 `main/office/docxReader.js`、`main/office/docxWriter.js`、`main/office/xlsxCodec.js`、`main/office/pptxCodec.js` 与各编辑器的保存链路。提示意味着部分内容可能无法写回，应保留原文件，并检查另存副本。
