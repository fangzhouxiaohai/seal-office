# 1.6.3 版界面设计令牌与自检

## 设计令牌

首页沿用项目已有的蓝色主色和浅色工作台。界面变量集中在 `renderer/src/styles.css`，切换主题时由 `renderer/src/styles/themes.ts` 更新颜色。

| 用途 | 令牌 | 浅色值 |
| --- | --- | --- |
| 背景与面板 | `--bg-app`、`--bg-card` | `#f5f7fa`、`#ffffff` |
| 主要与次要文字 | `--text-1`、`--text-2`、`--text-3` | `#1a1d24`、`#5c6472`、`#667085` |
| 主色与边界 | `--brand`、`--border` | `#2b6cf6`、`#e8ebf0` |
| 星标 | `--star` | 浅色 `#9b6100`，深色 `#f5b84b` |
| 间距刻度 | `--space-1` 至 `--space-8` | 4、8、12、16、24、32 像素 |
| 圆角 | `--radius-control`、`--radius-card` | 6、8 像素 |
| 字体与阴影 | `--font-body`、`--font-heading`、`--shadow-card` | 沿用项目字体与单层卡片阴影 |

## 界面自检评审

1. 修复前，首页新增区域混用了未定义的颜色变量和写死的浅色回退值，深色主题下次要文字及背景可能失去层级。现统一引用现有令牌，并将浅色弱化文字调整到与白色背景对比度约 4.97:1、与工作台背景约 4.64:1。
2. 修复前，侧栏展示虚构的云空间额度、企业版入口与未接通的拖入文件提示，形成误导和拥挤。现改为简短的本地存储说明，保留文件操作为页面主视觉重点。
3. 修复前，首页搜索框样式重复定义，部分新导航按钮缺少键盘焦点与禁用状态。现删除重复规则，补齐可见焦点和禁用反馈。
4. 修复前，推荐区的微小状态标记采用对比度不足的独立红色。现改用项目主色，使强调色保持一致。
5. 修复前，内容区缩窄时文档卡片仍按三列排列，极窄窗口又隐藏了所有新建入口。现让首页主内容区参与容器查询，并在 480 像素以下保留横向新建、打开和最近导航。星标令牌也按深浅主题分别调整，提高可辨性。

布局在 480、768、1024、1280 像素断点收缩侧栏和右侧推荐区。修复后的完整界面源码见 `renderer/src/components/HomeSidebar.tsx`、`renderer/src/pages/HomePage.tsx` 与 `renderer/src/styles.css`。
