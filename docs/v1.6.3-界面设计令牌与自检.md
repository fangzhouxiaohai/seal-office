# 1.6.3 版界面设计令牌与自检

## 设计令牌

首页沿用项目已有的蓝色主色和浅色工作台。界面变量集中在 `renderer/src/styles.css`，切换主题时由 `renderer/src/styles/themes.ts` 更新颜色。

| 用途 | 令牌 | 浅色值 |
| --- | --- | --- |
| 背景与面板 | `--bg-app`、`--bg-card` | `#f5f7fa`、`#ffffff` |
| 主要与次要文字 | `--text-1`、`--text-2`、`--text-3` | `#1a1d24`、`#5c6472`、`#667085` |
| 主色与边界 | `--brand`、`--border` | `#2b6cf6`、`#e8ebf0` |
| 星标 | `--star` | 浅色 `#9b6100`，深色 `#f5b84b` |
| 间距刻度 | `--space-1` 至 `--space-8` | 4、8、12、16、24、32 像素 |
| 圆角 | `--radius-control`、`--radius-card` | 6、8 像素 |
| 字体与阴影 | `--font-body`、`--font-heading`、`--shadow-card` | 沿用项目字体与单层卡片阴影 |

## 界面自检评审

1. 修复前，首页新增区域混用了未定义的颜色变量和写死的浅色回退值，深色主题下次要文字及背景可能失去层级。现统一引用现有令牌，并将浅色弱化文字调整到与白色背景对比度约 4.97:1、与工作台背景约 4.64:1。
2. 修复前，侧栏展示虚构的云空间额度、企业版入口与未接通的拖入文件提示，形成误导和拥挤。现改为简短的本地存储说明，保留文件操作为页面主视觉重点。
3. 修复前，首页搜索框样式重复定义，部分新导航按钮缺少键盘焦点与禁用状态。现删除重复规则，补齐可见焦点和禁用反馈。
4. 修复前，推荐区的微小状态标记采用对比度不足的独立红色。现改用项目主色，使强调色保持一致。
5. 修复前，内容区缩窄时文档卡片仍按三列排列，极窄窗口又隐藏了所有新建入口。现让首页主内容区参与容器查询，并在 480 像素以下保留横向新建、打开和最近导航。星标令牌也按深浅主题分别调整，提高可辨性。

布局在 480、768、1024、1280 像素断点收缩侧栏和右侧推荐区。修复后的完整界面源码见 `renderer/src/components/HomeSidebar.tsx`、`renderer/src/pages/HomePage.tsx` 与 `renderer/src/styles.css`。

## 帮助手册设计令牌与自检

手册继续使用 `--bg-card`、`--text-1`、`--text-2`、`--brand`、`--brand-soft`、`--border`、`--space-1` 至 `--space-6` 和 `--radius-control`。主题目录与文章共用现有字号和字体；文章标题是阅读区的唯一视觉重点。

1. 新增本地工具主题后，窄屏目录原先隐藏分类名称，用户难以辨认主题归属。现保留分类名称，并让目录横向滚动。
2. 搜索框和目录按钮的点击高度偏小，触控时容易误触。现把搜索框提高到 44 像素、目录按钮提高到 40 像素。
3. 文章原先可延伸到 720 像素，正文单行过长。现将阅读宽度限制为 640 像素，并让目录滚动条预留空间，避免滚动时文字跳动。

修复后的完整手册代码位于 `renderer/src/components/HelpManual.tsx` 和 `renderer/src/components/helpManual.css`。

## 文字导航窗格设计令牌与自检

导航窗格复用 `--bg-card`、`--text-1`、`--text-2`、`--brand`、`--border`、`--space-2`、`--space-3`、`--space-4`、`--space-6`、`--radius-control` 与 `--shadow-card`；面板宽度为 240 像素。文档纸张保持主要视觉焦点。小于 768 像素时窗格叠放于纸张左侧，避免压缩正文。

【界面自检评审】

1. 初稿的层级缩进表达式需要浏览器支持长度乘法，旧版内核可能忽略。现改用现有间距令牌组合，并限制深层标题的缩进。
2. 初稿的关闭按钮点击区域偏小。现设置 44 乘 36 像素的最小区域，并加入圆角、悬停及可见焦点。
3. 初稿的窄屏并排布局会挤压文档纸张。现改为左侧叠放，面板最大宽度为视口的 78%，同时保持正文区域独立滚动。

修复后的完整代码位于 `renderer/src/editor/NavigationPane.tsx`、`renderer/src/editor/DocEditor.tsx` 与 `renderer/src/styles.css`。

## 全局弹窗与窄屏复核

继续使用 `--bg-card`、`--text-1`、`--text-2`、`--brand`、`--border`、`--space-2` 至 `--space-6` 和 `--radius-control`。危险操作与错误说明统一使用当前主题下的应用弹窗；列表行以文件名为主要焦点，操作图标保持次级权重。

【界面自检评审】

1. 最近文档列表原先把时间、大小及操作列固定并排，在狭窄内容区会裁掉操作。现于内容区不超过 560 像素时收起时间和大小，保留文件名与操作。
2. PDF 工具展开时侧栏曾被挤到表单无法填写的宽度。现于窄容器改为叠放式可折叠面板，正文仍保有独立阅读宽度。
3. PDF 阅读控制组原先禁止收缩与换行，在窄容器中溢出。现于小于 480 像素时允许换行，并保留可见焦点与足够点击区域。
4. 状态层、主题设置、翻译和默认应用操作曾使用脱离主题容器的静态弹窗。现由应用上下文提供弹窗实例，跟随深浅主题；错误仍显示具体原因。

本轮未取得可用的真实界面截图；上述复核基于组件结构、样式断点、类型检查及交互测试，不能替代人工视觉验收。
