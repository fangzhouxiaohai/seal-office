# 1.6.9 文件工作区与全屏放映

## 问题与原因

四类文件页面一直由应用外壳挂载全局侧栏。文字、表格和演示侧栏仅用于返回首页及显示当前模块；PDF 也重复显示首页导航，占用阅读空间。底部已有固定首页标签，可以承担返回入口。

原放映视图只是程序页面中的固定定位层，未调用系统全屏接口；原生标题栏和任务栏仍占用电脑屏幕，智能助手也没有接收放映状态。

## 修改

- 文字、表格、演示和 PDF 文件页移除全局左侧导航，正文使用完整工作区；通过固定底部首页标签返回。
- 首页导航和设置导航继续承担各自的任务；文字大纲、幻灯片缩略图及 PDF 内部工具保持可用。
- Windows 桌面版通过原生窗口接口进入整屏放映，独立放映层挂载到页面根部；幻灯片等比缩放并居中，避免文字变形。
- 放映时隐藏编辑界面、底部标签、智能助手入口和已打开的对话面板。退出恢复面板及输入内容，不清空会话。
- F5 从头播放，Shift+F5 从当前页播放；功能区入口共用同一流程。点击、方向键、PageUp/PageDown、空格和 Home/End 操作放映，Esc 或最后一页继续前进结束。
- 退出、文档切换、视图卸载和系统主动结束全屏都释放放映状态。原窗口已全屏时保留原模式；会话标识和窗口队列避免旧视图的异步退出影响新放映。
- 放映键盘事件不传给隐藏编辑器，避免误触保存、增删页及标签切换。系统全屏错误通过统一弹窗展示原因。
- 修复只浏览或放映翻页就出现未保存标记：工作区的当前页码不再参与文稿内容比较，实际文本、备注和页面修改继续触发保存保护。

## 设计令牌

沿用既有品牌色、文字色、字体、6 像素控件圆角及 4 像素间距刻度。独立 `--presentation-bg` 管理放映背景，`--presentation-caption` 管理页码颜色；页码使用既有 16 像素横向和 12 像素纵向间距。放映画布尺寸属于文稿坐标，不作为界面间距令牌。

## 界面自检评审

1. 全局左栏与底部首页标签重复，压缩正文。移除四类文件页左栏，保持底部入口一致。
2. 程序内覆盖层无法隐藏原生标题栏及任务栏，画布没有使用整块屏幕。接入真实窗口全屏，独立挂载放映层并按实际视口缩放。
3. 右下角助手入口及已打开的抽屉会打断内容焦点。放映状态统一控制可见性，并保存对话与输入状态。
4. 全屏期间隐藏编辑器仍监听快捷键，可能引起误操作。放映层在捕获阶段处理键盘输入，退出后恢复原焦点。

## 验证记录

回归覆盖四类工作区、底部首页切换、全屏转换、原状态恢复、异步重挂载、系统退出、全屏错误、放映快捷键、助手输入保留，以及浏览页码与文稿内容的保存状态区分。

类型检查、生产构建、渲染层 1080 项、主进程 299 项、打包清单 2 项，共 1381 项测试通过。首次全量测试有一项真实 DOCX 重开用例触发 20 秒超时；原断言未修改，单独复核和后续完整测试均通过。

## Windows 成品核验

安装版与便携版均已构建。解包版和便携版分别执行 14 项真实成品核验：打开 DOCX、XLSX、PPTX 和 PDF，检查正文工作区左边界为 0 且宽度等于窗口视口；验证底部首页入口和静默打开。

全屏核验没有模拟屏幕视口。原生窗口的全屏状态为真，窗口与当前显示器范围都为 `(0, 0, 1920, 1080)`；放映容器实际尺寸同为 1920×1080，画布按 16:9 比例居中。编辑器隐藏，助手入口不存在，已打开的助手面板不可见。

两份成品验证了 F5、Shift+F5、功能区从头开始、Esc、末页前进结束、系统主动退出全屏，以及普通窗口、最大化窗口、原窗口已全屏的恢复流程。退出后助手面板及输入保留，翻页不生成未保存标记，程序正常退出。安装目录 36 个文件的完整性校验全部匹配。

验收只替代原生文件选择器返回的路径，使用实际文件读取、格式解析、渲染、系统全屏和关闭核验通道。未执行安装向导；安装版完成构建及文件校验。当前实机为单显示器环境。
