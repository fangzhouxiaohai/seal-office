# 1.7.1 Windows 新建菜单与默认程序

## 交付行为

安装版自动注册资源管理器“新建”菜单的 DOC、DOCX、PPT、PPTX、PDF、XLS、XLSX。七种文件使用真实空白模板，保存在安装目录的 `resources/shell-new/`，不使用改扩展名或零字节文件冒充格式。

DOC、XLS、PPT 由维护者在本机 Microsoft Office 中新建并保存为真实二进制格式，模板静态入库；用户安装和普通构建无需安装 Microsoft Office。维护者需要重新生成旧式模板时使用 PowerShell 7 和本机 Office，运行 `scripts/generate-legacy-shell-new.ps1`；现代模板由 `scripts/generate-shell-new.cjs` 生成。

当前海豹办公的编辑器仍只支持现代格式和已说明的内容范围。DOC、XLS、PPT 需要已有兼容程序编辑，不能将七种新建菜单理解为新增七种完整格式编辑器。默认程序能力只注册 DOCX、XLSX、PPTX、PDF。

## 首次启动

| 情况 | 实际动作 |
| --- | --- |
| 安装后第一次启动，四种格式尚未全部默认 | 显示统一自定义确认弹窗 |
| 点击“设为默认程序” | 注册可用关联，进入海豹办公的系统默认程序页面 |
| 点击“暂不设置”或关闭询问 | 继续使用，不执行关联设置 |
| 已全部默认 | 静默继续 |
| 后续启动或正常升级 | 不再主动询问 |
| 卸载后重新安装 | 新安装标识重新检查一次 |
| 开发版、未安装便携版、不同路径副本 | 不触发安装后询问 |

首次领取检查时将安装标识原子保存到本机 `userData/default-app-prompt.json`，默认状态核验失败也不会在后续启动重复核验同一标识。核验异常使用统一错误弹窗显示真实原因。设置中心始终保留“设为默认程序”按钮，由用户后续自行决定。

Windows 10／11 的默认程序关联受系统保护。软件不伪造 `UserChoice`，不把打开设置页面宣称为已完成全部关联。使用官方入口 `ms-settings:defaultapps?registeredAppUser=SealOffice`；专属页面需要 Windows 11 的相关系统更新，Windows 10 的实际展示由系统版本决定。

参考：[启动 Windows 设置](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-settings)、[启动默认应用设置](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-default-apps-settings)。

## 安装、升级与卸载

安装脚本备份原 `ShellNew` 的值、类型、二进制内容、未展开环境变量及子键。升级保持安装标识和原始备份；原菜单已经被其他程序改变时保存新的原状态。卸载仅恢复仍与本软件注册快照匹配的菜单，保留其他软件后来写入的菜单。

当前用户安装与全用户安装分别使用对应注册表范围。保留已有扩展名的打开类型，通过 `OpenWithProgids`、应用能力及注册应用列表提供可选关联。安装和卸载结束刷新资源管理器关联。注册脚本错误会显示实际原因。

外置系统注册组件随安装包提供；运行前与应用内原脚本逐字节核对，组件缺失或修改时明确失败。PowerShell 以独立参数、隐藏窗口和超时执行，不拼接用户输入命令。

便携版手动设置默认程序时读取启动器提供的 `PORTABLE_EXECUTABLE_FILE`，关联到下载的原始 EXE；普通安装版使用当前可执行文件。便携路径无效时明确失败，不退回会在退出后消失的临时解包目录。

## 设计令牌

沿用项目原有办公风格，使用现有 CSS 变量和统一弹窗主题，无新增零散颜色。

| 类别 | 令牌与使用 |
| --- | --- |
| 品牌与文本 | `--brand`、`--text-1`、`--text-2`，只突出主确认按钮 |
| 背景与边界 | `--bg-app`、`--bg-card`、`--border`，跟随深浅主题 |
| 间距 | `--space-1/2/3/4/6/8`，对应 4／8／12／16／24／32 像素 |
| 圆角与层级 | `--radius-control` 6 像素、`--radius-card` 8 像素，沿用统一弹窗阴影 |
| 字体 | `--font-heading`、`--font-body`，正文常规字重，标题及主按钮强调 |
| 交互 | 沿用悬停、焦点和禁用状态；执行中显示加载，禁止重复提交或取消 |

## UI 自检评审

1. 旧按钮“打开系统设置”没有说明文件关联动作。已改成“设为默认程序”，同一设置行说明支持格式和系统确认步骤。
2. 首次提醒缺少与其他业务弹窗一致的布局。已使用统一受控弹窗，清晰分隔标题、两段说明和按钮，默认不因点击遮罩关闭，关闭后销毁内容。
3. 执行中没有稳定反馈，可能重复点击。已增加加载与禁用状态，首次弹窗执行期间禁止取消，设置按钮防止重复提交。

成品截图核对：弹窗只有一个主视觉操作；标题、正文和按钮区域间距统一；设置说明可自然换行；截图滚动到文件关联行后展示实际按钮。严格模式重挂载只领取一次请求，避免安装记录已消费而提示漏显示。
