# 1.7.3 右键新建与空白文件修复

## 问题与证据

本次反馈中的 DOCX 是零字节文件；PPTX 是包含合法演示清单、但没有幻灯片的零页演示；XLSX 包含三张空表和普通默认视图。它们与海豹办公安装包自带模板不同。

旧实现只写入扩展名下的 `ShellNew`，漏掉已有办公软件在扩展名子 ProgID 下的创建指令。本机旧文字子类型仍使用 `NullFile`，表格和演示子类型使用其他软件模板；同时，当前用户注册优先于机器安装注册。新建菜单和受保护的默认打开程序因此采用了不同配置。

之前的成品检查通过复制模板来验证解析和保存，没有验证资源管理器真正执行新建。本次增加独立的实际右键新建验收脚本，逐类检查生成文件的长度和 SHA-256，再将这些文件用于成品打开与保存重开验收。

## 修复内容

- 新建注册覆盖扩展名、海豹办公子类型及已有子类型；全用户安装同时处理当前用户的旧菜单覆盖。
- 每个修改位置分别保存原配置和安装后的配置；升级保留最初备份，卸载仅恢复仍属于海豹办公的配置，保留其他程序后来修改的菜单。
- 注册明确使用 64 位视图；安装查询兼容旧 32 位安装状态，机器安装升级迁移旧状态并保留原安装标识。
- 用户安装升级为全用户安装时迁移新旧菜单备份、安装标识及程序创建的默认类型，移交同路径应用登记；卸载也清理安装后手动设置默认程序产生的用户登记，保留不同程序路径和其他软件后来修改的配置。
- 普通默认表格视图不再误报。拆分、非默认缩放、隐藏网格、从右到左等未支持设置仍提示导入风险。
- 有效零页演示按真实空列表打开；手动新增幻灯片后可保存，显式零页保存重开仍为零页，备份恢复保留模型和保存状态。
- 演示清单截断、幻灯片引用缺失、幻灯片部件损坏仍报错。缺失保存模型不生成默认内容。
- 使用严格 XML 解析验证唯一根节点、闭合标签及完整清单；损坏文件不能伪装成零页演示。零页演示通过菜单或放映快捷键时使用统一弹窗说明需要先添加幻灯片，不进入全屏或导致界面崩溃。
- 零字节办公文件通过统一错误弹窗说明缺少文档结构与处理方法，保留原文件。

## Windows 菜单缓存

实际调查中，修正注册表后，已运行的资源管理器仍使用缓存中的旧创建方式；新启动的系统菜单组件已读取新配置。刷新资源管理器后，七类实际新建文件均与有效模板一致。

安装和手动注册会发送关联更新通知及系统设置变化通知。某些 Windows 会话仍需要重启资源管理器或注销后更新菜单；程序不会静默终止用户的资源管理器。操作前应结束文件复制、移动等任务。升级软件不会把既有零字节文件自动改写为新文档。

## 支持范围

DOCX、XLSX、PPTX 可使用当前编辑器支持的内容与格式进行读写；PDF 使用当前阅读和页面工具。DOC、XLS、PPT 新建模板是真实旧式二进制文件，仍需已有兼容程序打开，未冒充现代格式或注册为海豹办公可编辑格式。默认程序的 `UserChoice` 不被强制修改。

## 可重复验收

命令执行前按项目约定把临时目录和开发缓存设到 E 盘。

```powershell
npm run typecheck
npm run test:run
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\verify-shell-integration.ps1
powershell -NoProfile -STA -ExecutionPolicy Bypass -File scripts\verify-explorer-new.ps1 -Templates "安装目录\resources\shell-new" -Report E:\Temp\seal-explorer-new-proof.json
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\verify-windows-release.ps1 -ShellFilesManifest E:\Temp\seal-explorer-new-proof.json
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\verify-windows-release.ps1 -InstalledExecutable "安装目录\SealOffice.exe" -ShellFilesManifest E:\Temp\seal-explorer-new-proof.json
```

资源管理器验收会打开 E 盘下的专用测试文件夹并调用实际右键菜单，生成七类测试文件；不修改真实用户文档。完整结果见同目录的版本验收记录。

成品验收在实际新建的 DOCX、XLSX 和 PPTX 中输入内容、保存、关闭和重开，核验内容及保存状态；另行检查合法零页演示的放映提示、新增幻灯片及保存重开。便携版应重新生成一份实际新建清单，避免把上一轮已编辑的文件当作空白模板。
