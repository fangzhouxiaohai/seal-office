# 1.8.0 演示能力升级

> 版本号 `1.8.0` 已随本次发布生效（`package.json` 与发布页一致）。附件的文件名、大小与 SHA-256 见文末「附件」。

## 背景与范围

本版本按[演示功能升级开发计划](superpowers/plans/2026-10-04-演示功能升级开发计划.md)的六批任务推进，围绕演示文稿补齐插入、设计、切换、放映、审阅、视图、工具与智能服务能力。文字、表格与 PDF 维持原有行为；新增能力全部落在演示模块与共用服务中。

外部兼容性一律以本机唯一可用的外部办公软件 **WPS Office**（12.0 / Build 12.1.0.26895，兼容接口自报名称为 Microsoft PowerPoint）为准。**本机未安装 Microsoft PowerPoint，所有涉及 PowerPoint 的行为均未核验，本文不作相关声明。**

## 新增能力

### 模型、画布与原生对象（批次甲、乙）

- 文稿模型引入模型版本、稳定页面与对象标识、资源指纹索引与内容快照；旧文稿与旧备份按真实原因迁移，缺失资源、循环分组、重复引用与非法对象拒绝加载，不用空白页替代损坏内容。
- 统一渲染层供编辑区、缩略预览、放映与导出共用；多选、拖动、缩放、旋转、组合、图层、锁定、对齐分布、标尺、参考线与吸附。
- 原生对象：图片（PNG/JPEG，裁剪与旋转）、基础图形、矢量图标、艺术字、原生表格（行列编辑与合并拆分）、柱状/折线/饼图（含嵌入数据工作簿）、语义图与连接线（流程/层级/循环/脑图）。

### 设计、母版与页面（批次丙）

- 主题配色与字体、主题色引用、显式颜色与黑色标题保留；主题悬停预览不修改文稿，确认后统一应用。
- 多母版与版式、占位符继承与单页覆盖、解除与恢复继承；页面尺寸 16:9 / 4:3 / 自定义与方向，可选择缩放内容或保留对象坐标。
- 背景支持纯色、渐变与图片（单页或整篇）；页脚、日期与页码；本地模板与自定义主题（`.sealtheme.json`）导入导出。

### 播放、切换与动画（批次丙、丁）

- 播放控制器统一处理可见页序列、单击与自动换片、循环、暂停与后台、快速翻页取消旧计时、末页结束与媒体停止。
- 15 种切换（含溶解、涟漪、新闻快报、轮辐、百叶窗、梳理与平滑）与出现、淡入、淡出、进入、退出、图表分步动画；持续时间、方向、效果选项与应用全部。

### 放映（批次丙）

- 整屏放映保留助手隐藏与退出恢复；自定义放映按页面稳定标识保存多组顺序，删除页面自动修复引用。
- 独立只读演讲者窗口（当前页、下一页、备注、计时与控制）、窗口阅读视图、放映范围与循环设置、隐藏页标记。

### 审阅（批次丙）

- 批注线程（作者、回复、解决、上一条/下一条、显示开关）、八类本机排版检查、词组级繁简转换与差异预览。
- 文档定稿（可恢复的只读标记）与两份文稿比对（页面增删移动与文本、对象、位置、样式、备注、批注、动画差异）。

### 媒体、动作与本地交付（批次丁）

- 音视频插入前探测解码能力，支持封面、播放范围、音量、循环与进入页面自动播放；切换音效随换片播放并同步停止。
- 打开网页、跳转页面与结束放映动作（协议白名单）；放映画笔、橡皮、激光笔、黑屏与白屏，临时笔迹由用户明确选择是否保留。
- 导出图片（PNG/JPEG）、PDF（按实际页尺寸，含范围、隐藏页、讲义与备注）、扫描件 PDF、图片型 PPTX 与 HTML 预览；截屏、屏幕录制（WebM）与图片转文字。

### 智能服务（批次戊）

- 统一的模型服务配置：内置 DeepSeek、豆包、智谱、Kimi 与自定义服务，密钥只写入系统安全存储（旧翻译配置在写入并读回校验成功后才清除明文）；翻译、语义校对、讲稿与生成复用同一文本链路，识别与语音单独核验能力。
- 翻译按对象标识分批发送并接收结构化译文，先预览差异再替换或生成双语副本；语义校对逐条确认；讲稿生成与讲解音频在面板内试听。
- 文稿生成先展示提纲再生成可编辑页面，支持 DOCX/TXT/MD 与提纲导入（图片与表格登记为「遗漏」并保留来源信息）；封面与单页生成共用同一协议；智能美化由模型给出结构化布局建议再经布局引擎校验；智能图形与思维导图生成结构化节点并落地为**可编辑对象**；本地素材库支持分类、检索、导入、预览、插入与删除，删除图库条目不影响文稿已引用的资源。

### 讲义、多窗口与批量工具（批次己）

- 讲义母版（每页 1/2/3/4/6/9 张、页眉页脚、日期与页码）与备注母版排版，接入真实讲义/备注 PDF 输出（本机成图核验：讲义 2 页、备注 3 页，均 960×540）。
- 文稿会话按版本串行提交，新窗口共享同一文稿；远端修改作为新基线载入并并入本地撤销栈；关闭最后一个视图才提示保存。
- 批量工具（资源检查、PDF 导出、转图片 PPT、统一主题与字体）逐文件独立结果、失败不撤销其他成功输出、支持取消；便捷工具提供页面合并与拆分、资源提取与图片压缩（压缩未变小时明确拒绝替换）。

## 支持范围与外部兼容

逐项范围与限制见 [README 演示文稿能力与兼容范围](../README.md#演示文稿能力与兼容范围)。要点：

- 原生部件经 WPS 另存后保留：主题配色与页面尺寸、多母版与版式、图片位置尺寸与裁剪、原生表格合并、图表与嵌入工作簿、公式、附件、批注正文作者时间、溶解/涟漪/新闻快报/轮辐/百叶窗/梳理六种切换、自定义放映。
- **不能跨软件播放**：平滑切换（`p14:morph`）与动态图表的构建清单在外部软件另存后丢失。
- **只在本机**：批注的回复、解决状态与对象锚点；母版与版式的继承标记；本机高级切换为近似呈现。
- **本版本不提供文档密码加密**，文档定稿只是可恢复的只读标记。

## 已知限制与未交付项

1. **文档加密不予交付**：没有经验证的 ECMA-376 打开密码组件，且本机未安装 Microsoft PowerPoint，无法完成计划要求的 WPS 与 PowerPoint 双向验证。
2. **未使用真实 AI 密钥做端到端验收**：翻译、语义校对与讲稿链路以可注入假服务完成验收，真实模型效果需用户配置密钥后自测；缺少可用视觉模型时不提供识别入口。
3. **智能能力未用真实密钥验收**：翻译、语义校对、讲稿、文稿生成、智能美化、智能图形与素材语义检索均以可注入假服务完成链路验收，真实模型效果需用户配置密钥后自测；图片转文字需要支持图像输入的模型，本机已配置模型拒绝图像输入，界面显示真实错误而不返回空文本。
4. **讲义与多窗口的边界**：讲义母版在 WPS 另存后会丢失，不能宣称跨软件保留（本机保存重开可保留）；讲义与备注 PDF 只做本机成图与独立解析核验，未用外部办公软件打开；真实双窗口已验证同步与撤销，但双屏、拔屏与分辨率变化仍以可注入回归覆盖（本机只有一台显示器）。
5. **界面验收**：新面板已完成静态样式审查与部分真实窗口验收，尚未完成全部新面板在 480 / 768 / 1024 / 1280 像素下的真实视觉实测。
6. **媒体**：只交付 WebM 录制；媒体播放参数的原生计时行为未在 PowerPoint 核验；媒体播放使用 data URL，单项上限 50 MB。
7. **对象能力边界**：表格与图表不支持旋转；艺术字无阴影；公式为受限语法；原生 SmartArt 只保留部件与几何，不提供节点级编辑；附件保存真实字节但不执行宏。

## 可重复验收

构建与验收命令（临时目录与缓存按项目约定放在 E 盘）：

```powershell
npm run typecheck
npm run test:run
npm run build
node node_modules/electron-builder/cli.js --win --config.directories.output=release/v1.8.0
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\verify-windows-release.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\verify-windows-release.ps1 -Portable
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\verify-windows-release.ps1 -InstalledExecutable "安装目录\SealOffice.exe"
```

真实文件核验：用真实 PPTX 样例完成两轮保存重开，独立解压核对部件与关系，并用本机唯一可用的外部办公软件 WPS Office 打开核验；录制、导出与讲义产物的页数、尺寸与页数逐一核对。详细证据按任务存放在开发证据目录中，逐项命令与退出码记录在验收记录文件内。

### 本版修复的关闭回归

开发过程中合并任务 13（讲义母版、多窗口会话与批量工具）后出现「关闭最后一个窗口后进程驻留」：窗口销毁后再访问 `webContents` 会抛「对象已被销毁」，该异常发生在退出链路上（`app.exit(0)` 也无法结束进程）。已在 `main/main.js` 中把关闭收尾抽为容错的 `清理已关闭窗口` 并补回归；修复后解包版连续两次关闭窗口均在 2 秒内退出、残留进程 0，三个成品形态（解包版/便携版/安装版）的 `first`、`repeat` 与 `confirm` 阶段全部通过。
