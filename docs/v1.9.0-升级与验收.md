# 海豹办公 1.9.0 升级与验收

日期：2026-10-09。版本包含本地办公增强、加密云空间、演示模板市场和知识库。此报告区分已验证功能与仍需外部条件的验收项。

## 已实现

- 文字、表格、演示、PDF 打开默认 400%，工具栏与状态栏显示当前百分比；文字高倍率缩放保留完整可滚动范围，演示大画布采用安全居中。
- 首页新建采用居中弹窗；文字、表格、演示和 PDF 使用海豹办公原创专属图标，关联资源含九档尺寸。界面使用自己的品牌文案。
- 保留本地打印、打印预览、PDF 文字复制、文字/图片/批注编辑及页面处理。修复页脚打印定位额外生成一页的问题。PDF 编辑取消另存时保留修改，关闭与重启备份包含编辑后的字节。
- 自动保存保留 TXT/MD 换行、JSON 原始内容、HTML 页眉页脚、DOCX 排版、XLSX 表格模型及 PPTX 原生对象；不支持完整写回时明确拒绝。保存后退出按正确格式写入，不把 DOCX 字节写到 TXT/JSON 扩展名下。
- 演示市场 300 套内置模板，由 30 个主题与 10 种原创视觉方案组成，每套九页，含可编辑文字、图形、图表和表格。提供分类、搜索、收藏、多页预览、创建副本、上传封面与自定义名称、替换版本、审核公开与撤回。
- 三个演示工具：资料生成并确认可编辑提纲、美化前后预览、图片或扫描 PDF 转可编辑对象。沿用当前 AI 配置，处理资料先取得单次授权。
- 知识库包含六份原创入门指南；支持知识库目录、最多 10 MiB 的 DOCX/XLSX/PPTX/PDF/TXT/MD、自定义名称与封面、公开审核/撤回、内容检索、来源引用与原文跳转、扫描件识别授权。账号退出或切换后清除私有阅读状态，并拒绝迟到请求重新展示旧资料。
- 云空间与自动保存默认关闭，用户分别主动开启；自动保存依赖已开通并解锁的云空间。300 MB = 300,000,000 字节，文件、版本、回收站和公开副本均计费。支持目录、重命名、移动、复制、历史版本、回收站、恢复与清空停用。
- 私有文件、名称、目录和索引在客户端认证加密后上传；恢复密钥由用户保管，服务端不具备私有正文解密能力。公开副本与在线 AI 处理单独授权。
- 加密待同步队列先落盘，分块续传、重启恢复、断网重试、版本冲突副本、退出前最新快照同步。关闭自动保存或云空间后服务端拒绝自动上传；恢复密钥确认前限制退出及切换服务器。
- 手机验证码服务接入阿里云，服务端具备用途、过期、一次性使用、错误次数及发送限流。短信凭据、SSH 凭据和管理密码不进入源码或安装包。

## 生产部署

管理后台：[海豹办公云端管理](https://seal.xingmasoft.com)。API 地址为该域名的 `/api`。管理员凭据单独保存在本机忽略目录，不在此报告公布。

后台使用用户指定的 Panshi Vue/Naive UI 工程与应用上下文，固定上游提交，保留许可证。业务连接海豹办公 Node API；未部署上游 Java 业务服务，具体来源见 `server/admin/PROVENANCE.md`。

宝塔项目目录 `/www/wwwroot/seal.xingmasoft.com` 使用版本目录与 `current` 链接，上一版本保留可回滚。API 非 root 运行，Nginx 反代、HTTPS 免费证书、每日备份、每小时容量/证书/服务检查和每日专属证书续签任务均已部署。备份最长保留七天；公开撤回立即清除在线公开文件及索引。

实际验证 HTTPS 能力接口、管理员登录/退出、300 MB 配额、磁盘余量保护、服务与三个定时任务。生产备份 SQLite 完整性检查通过；目前生产库没有用户文件。含账号、文件历史、密钥封装和密文的恢复解密另在隔离环境验证。

- 桌面端全量 Vitest、主进程全量 Vitest、打包清单测试、TypeScript 检查及 Vite 构建。
- 云服务十项集成测试使用真实客户端加密与临时短信替身，覆盖两账号权限、双设备冲突、断网/重启/续传、并发最新快照、配额、公开撤权、清空停用和备份恢复。测试替身未部署生产。
- 各模板分类抽样创建、编辑、写出真实 PPTX 并重新读取，检查原生图表、表格及标题；全部 300 套检查九页、有效坐标及有效主题背景。
- 已用当前配置的真实 AI 验证知识问答有效引用、提纲与页面生成、图像识别后的原生演示对象、扫描文字识别。不代表所有提供商或复杂扫描样本均可无误识别。

- NSIS 安装包及嵌套应用归档完整性检查通过，归档中的 `app.asar` 与验证过的成品一致。使用隔离的注册表测试位置验证关联安装、资源路径及卸载清理；未替代真实用户安装向导或修改其默认打开程序。
- 最终便携包使用全新隔离用户目录独立启动成功，首页与 1.9.0 版本显示正常，初始云文档自动保存处于关闭状态。

## 尚需完成的外部验收

1. **真实短信收取。** 签名和模板已在服务端配置，模板及签名审核状态已查询；运营商报备仍在处理中。尚未收到测试手机号，不能将手机实机收码、登录和清空空间二次短信确认标为通过。
2. **旧式 DOC/XLS/PPT 转换。** 当前生产主机未部署隔离转换引擎，系统不满足当前受维护转换环境要求。现代 Office 格式已实现；旧式二进制格式需额外转换环境后完成验收，不宣称任意文件类型均可解析或编辑。
3. **用户原始兼容性样本。** 用户提供的 `新疆车用燃气有限公司 企业简介.docx` 在当前可访问路径不存在。已验证生成样本的图片与页眉页脚，尚不能替代该原件的兼容性复测。复杂对象仍保留真实兼容性提示，不能通过隐藏警告宣称导入完整。
4. **发行签名与纸面打印。** Windows 包当前无发布者签名；未发送实际纸面打印任务。预览 PDF 与编辑功能已测，真实打印机、纸张和驱动需对应设备验收。MSIX 商店身份未提供，本次交付 NSIS 安装包及便携包。

以上外部项未通过前，本版在线功能按预发布状态交付。测试报告提供覆盖证据，不构成没有任何缺陷的保证。
