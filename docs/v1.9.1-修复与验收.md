# 海豹办公 1.9.1 修复与验收

日期：2026-10-09。Windows x64 安装包与便携包；云端后台已更新。

## 本次更新

- 演示市场 300 套模板按六类主题配上原创透明插图：工作汇报、商业计划、教育培训、产品技术、人事行政、行业专题。封面标题与配图分别布局，图片真实写入演示资源，创建、保存、导出和重开均保留。
- 修复模板指标、对比建议、实施路径的背景遮住文字：改用同时承载文字和背景的原生表格卡片，内容可编辑并能保存重开。
- 演示创作三个入口使用橙、紫、青配色和对应图标；刷新、上传、收藏、新建、推荐、模板库、云空间及知识卡片采用统一动作配色。编辑工具图标按用途区分颜色，浅色与深色主题均适配。文档纸张及打印颜色不受界面配色影响。
- 改进市场窄屏排布，320px 不再横向溢出，窄屏刷新、上传和收藏点击区域至少 44px。
- DOCX、XLSX、PPTX、PDF 新开文件默认缩放改为 **125%**；显示实时百分比，支持继续缩放和适应页宽。
- 启动默认程序检查只查询状态；主动设置时注册应用，再通过 Windows 默认应用页面确认。移除启动时修改受保护用户选择的流程，错误提示不再显示整段命令。程序不会宣称系统未确认的关联已生效。
- 账号与云空间弹窗移除接口地址和连接服务编辑入口，普通客户端不能调用服务器地址修改操作，云状态 IPC 不返回地址。
- 管理后台重新设计登录页、侧栏、概览、账号列表、模板与知识审核卡片；保留真实数据与审核流程，增加加载、空白与错误状态。修复平板登录页溢出、小屏卡片布局、手机按钮区域及迟到详情跨页弹窗。
- 默认程序及缩放帮助文案与当前行为同步。
