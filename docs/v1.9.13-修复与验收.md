# 海豹办公 1.9.13：PDF 连续阅读与手机打印预览

## 本版改动

- PDF 改为连续纵向排页，滚动时自动更新当前页；可输入页码跳转。只渲染视口附近的页面，手机窄屏默认适配页宽。
- 手机端的文字打印预览按页生成 PDF，显示页数进度；失败或超时会显示错误并提供重试。打印使用预览时生成的同一份 PDF。
- DOCX 导入增加常见 VML 文字水印与图片水印的显示；移动端加入内置中文字体回退。水印也会进入打印预览。

## 成品与验收

- Windows x64：便携版、NSIS 安装版、MSIX 均以 1.9.13 构建。未安装目录的应用通过三次隔离启动验收；MSIX 清单中的包身份、发布者、版本、x64 架构与 BlockMap 均已核对，ZIP 内容通过 CRC 校验。MSIX 未签名，供微软商店签名后分发。
- Android：使用用户提供的 HBuilderX 云打包 APK，未重新签名或修改。验包确认包名 `com.sealoffice.mobile`、版本名 1.9.13、版本码 10913、最低 Android 9、目标 Android 16、ARM 32/64 位、v3 签名和原生库 16 KiB 对齐；内置办公脚本哈希与本项目当前构建相同。包内 `build-info.json` 仍记录资源构建时的 1.9.12 版本号，不影响安装包的 1.9.13 版本及脚本内容。
- Ubuntu amd64：DEB 在 GitHub Actions 的 Ubuntu 22.04 构建，安装后的应用分别在 Ubuntu 22.04 与 24.04 环境完成验收，报告与 DEB 校验值匹配。
- 在浏览器中用合成的 8 页文字内容验证手机打印预览可生成 8 页，并检查了首末页的中文和水印。PDF 阅读、DOCX 水印读取与打印预览的自动测试通过。

## 当前边界

- 未取得用户截图中的原始 DOCX，因此无法证明该文件的专用字体和水印完全一致；没有 iOS、鸿蒙或多品牌安卓真机的本版验收结果。
- 打印预览生成的 PDF 以逐页图像保存，适合预览与打印，但其中的文字不可选取。缺失字体会回退到内置中文字体，字形不保证与原字体相同。
- 含水印 DOCX 可预览和打印，当前 DOCX 写入器仍不能把水印写回文件；保存会明确阻止，避免覆盖原件造成水印丢失。
