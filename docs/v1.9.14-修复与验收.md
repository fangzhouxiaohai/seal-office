# 海豹办公 1.9.14：PDF 连续滚动阅读修复

## 本版改动

- PDF 阅读改为与常见办公软件一致的连续纵向排页：在同一个阅读区内使用鼠标滚轮、触控板或触屏持续向下查看后续页面，不再要求逐页点击“下一页”。
- 保留上一页、下一页和输入页码跳转；跳转动作会滚动到目标页，滚动阅读时页码指示同步更新。
- 普通短文档打开后渲染全部页面，保证前后页连续可见；长文档保留全部页面占位，只渲染阅读区附近的画布，兼顾连续阅读和内存占用。
- PDF 主工作区只保留一个稳定的纵向滚动容器，消除外层页面与阅读器同时滚动造成的“看起来仍是单页”问题。桌面版与 Android 内置编辑器使用同一套修复后的阅读器代码。

## 当前边界

- 本机 HBuilderX 的用户配置目录重定向当前无法被 CLI 访问，因此本次自动流程只完成 Android 安装包内编辑器资源构建，没有把资源误报为 APK。Android 云 APK 需要在可连接 HBuilderX 的环境中重新提交并完成签名、版本、双 ABI、16 KiB 对齐和包内编辑器哈希核验后再发布。
- Windows MSIX 为商店上传包，未做本地商店签名；应由 Microsoft Store 签名后分发。
- 解包版第三阶段的既有 PPTX“插入文本框后保存重开”自动核验连续三次未找到插入文字；相同检查在便携版通过。该检查与本次 PDF 改动无关，但本记录不将解包版完整三阶段验收标记为通过。
