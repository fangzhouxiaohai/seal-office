## 审核问题对照

下表的“验证”区分生产网页流程、原生接口模拟与真实系统操作。浏览器回归不是 HarmonyOS 真机验收。

| 审核项 | 本轮改动 | 已验证范围与边界 |
| --- | --- | --- |
| 系统侧滑返回无响应 | 原生页拦截默认 Back，由网页先关闭弹窗/面板，再处理子目录和页面历史；只有首页确认备份后才通知宿主返回桌面 | 生产页面层级回归及宿主方法测试；需真机侧滑复测 |
| 1. 另存为提示成功但没有文件 | 鸿蒙使用 DocumentViewPicker 保存位置，向目标文件描述符复制真实文件，写入完成才返回成功；取消不清除未保存状态 | 原生方法覆盖等待、成功、取消和写入失败；UI 覆盖取消后再保存 DOCX；系统选择器需真机复测 |
| 2. 打印预览一直加载 | 映射 CSS 字体到实际嵌入的包内字体，改用可捕获错误的 PDF 流；生成超时返回错误而非永久等待 | 混合字体、中文、编号、注释文档实际生成预览并渲染；确认打印发送独立 print 动作，鸿蒙调用系统打印 API |
| 3. PDF 导出失败 | 修复默认导出文件名仍为 `.docx`；确保 `.pdf` 后缀与真实 PDF 字节一致 | 实际点击“导出为 PDF”，检查文件头并自动打开生成文件 |
| 4. 双击文字页面错误 | 子资源报错不得直接移除正常工作台；入口错误先请求页面存活确认 | 双击事件后编辑器保留；图片错误、误报入口错误、健康响应与无响应分支测试；长按选区仍需真机确认 |
| 5. 复制后无法粘贴 | 触摸按下前保存最新选区，复制快照使用后释放；原生写入剪贴板；读取受限时可在用户粘贴框中长按粘贴 | 实际复制后移动光标再粘贴，正文增加；不申请高敏感 READ_PASTEBOARD 权限 |
| 6. 字体不变化 | 提供实际随包加载的思源黑体、思源宋体，修正资源路径与触摸选区 | 实际加载两种字体、画布字形像素不同，选中文字获得指定字体 |
| 7. 中文编号仍为数字 | 对已有列表切换 marker 样式而非再次切换列表开关；DOCX 编号映射保留中文/字母类型 | 页面 computedStyle 为 cjk-ideographic；DOCX 使用 chineseCounting，保存读回保持样式 |
| 8. 表格图表仅提示后续提供 | 增加范围校验、柱形/折线/饼图预览，按真实两列数据生成 PNG 图表图片 | 生产 UI 插入后 XLSX 中有真实 PNG；当前不是 Excel 原生可编辑图表，界面已明确标注 |

| 10. 脚注/尾注不可用 | 引用与注释正文原子插入，保存真实 footnotes.xml / endnotes.xml 及关系，而非只插入普通上标 | UI 插入与取消、OOXML 检查、读回无警告；外部 LibreOffice 打开另存后仍有两类引用与正文 |
| 11–13. 开启云端能力、设置账号云空间、我的云空间登录入口无法打开 | 保持已有页内登录弹窗；错误处理不再因子资源错误移除工作台；返回优先关闭登录 | file:// 生产页面实际点击登录与云空间入口，Logo 解码、关闭与返回通过；不代替真实账号登录/短信或服务端联调 |

| 16. PDF 工具添加文件读取失败 | 统一带点扩展名，PDF 校验兼容两种扩展名约定；鸿蒙由原生选择器分块传回文件字节，避免网页访问外部文件 URI | 模拟原生选择器导入真实 PDF 并渲染中文；数量/总大小/残缺数据/取消保护 |

## 重新打包与真机复测

1. 已在 HBuilderX 重新生成正式包，并核对包内资源哈希及 UTS 外壳。复测或上架请取 `release/v1.9.15-review-fix-20261016/` 中的新产物，不要再取旧 App Pack。
2. 新 `.app` 内模块声明了 INTERNET 和 PRINT 权限，且包含打印权限说明；系统打印服务仍需目标设备可用。
3. 安装新包，检查文件选择器可选本地与文档提供方 PDF；另存为选择明确目录，回到系统文件管理器找到文件并重开。分别测试取消、只读位置、同名覆盖和存储空间不足。
4. 创建带中文、两种包内字体、列表、脚注/尾注的文档，检查字体、复制粘贴、编号、行号；导出 PDF 后实际打开，并调起系统打印预览。普通 PDF 会保留可检索文字；当前移动 PDF 不是 Word 排版引擎，不能承诺完整复制 Word 分页、脚注页底布局或行号打印。
5. 从编辑器进入设置、云空间、登录与功能面板，逐层侧滑返回。首页返回桌面后重新进入，确认未保存工作区仍能恢复；键盘弹出、横竖屏及快速连续返回另测。
6. 分别在审核涉及的 HarmonyOS 6.1/API 23–24、HarmonyOS 7/API 26 设备上复测。当前 `hdc list targets` 没有连接设备，因此这些系统级操作与兼容性不能标记为真机通过。
