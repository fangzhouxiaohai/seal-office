# 海豹办公 1.9.2 智能助手升级与验收

日期：2026-10-09。Windows x64 安装包与便携包。

## 本次升级

- 智能助手可生成含实际正文的文字文件、包含多工作表及公式的表格文件、包含可编辑标题与要点的演示文件。先校验并显示候选，用户确认后创建到编辑区，通过现有保存流程写入文件；不把候选或未保存草稿报告为磁盘文件已保存。
- 新建演示按实际文字框的字体、行高和内边距适配长标题及要点字号；在可读字号下仍放不下时，返回明确拆页要求，保留完整内容，不生成被裁剪的候选。
- 增加文字段落插入、演示原生表格单元格修改、页面切换及对象动画。修改依据当前任务的原始快照校验，保留单元格样式，拒绝锁定对象、被合并覆盖的单元格及无效动画引用。
- 多消息按提交顺序排队，绑定提交时的文件，执行时读取该文件最新内容。上一项候选未确认时等待，文件已关闭时报告错误；支持暂停、继续、移除和失败重试。生成期间仍能编辑下一条消息，完成或报错不会覆盖已有草稿。
- 队列提供带图标的“引导”按钮，同一文件的补充要求可送入正在运行的任务，在工具步骤完成后合并处理。不会取消当前请求或重复运行已引导需求；收尾阶段拒绝的引导仍保留为普通排队任务。需要修订已提出的候选时，可完整替换候选，避免重复创建同名文件。主任务失败时保留补充需求供重试。
- 增加入场、任务进度及输出光标动画，支持系统减少动画偏好。小窗口将消息、候选及队列放在可滚动工作区，输入和发送区保持可见；移动窗口操作按钮至少 44px。
- 上下文估算达到配置窗口的 **80%** 时自动压缩。保留最近需求、工具调用与结果配对、当前计划、待确认候选和完整显示对话。压缩由当前已配置的 AI 服务生成摘要，不切换用户服务。
- 内置五家服务商的十个模型选项，对应模型容量与思考参数；选择模型同步容量。自定义模型未填容量时默认 **131,072 tokens（128K）**，明确设置的容量保留。容量为配置和保守估算，不是服务商实时计费 token 统计。
- 后台管理员密码按本次要求更新，生产 HTTPS 登录及退出验证通过。凭据不写入报告、仓库和客户端包。

## 操作方式

发送消息后，可继续输入并加入队列。急需补充同一文件的当前工作时，点击该排队项的“引导”；该需求被接受后与主任务共同处理，其他文件的需求按队列等待。

| 命令 | 操作 |
| --- | --- |
| `/compact` | 手动压缩当前会话，按队列执行，不打断正在处理的任务 |
| `/pause` | 暂停后续排队任务，当前任务继续 |
| `/resume` | 继续后续队列 |
| `/stop` | 停止当前生成并暂停后续队列 |
| `/new` | 空闲时清空当前会话并开始新对话 |
| `/help` | 查看本地命令说明 |

新文件和修改都需要审阅并应用；应用后仍需按实际保存操作落盘。已提交会话、摘要和待确认候选继续使用本机加密记忆；尚未执行的队列仅保存在当前窗口内，不保证退出后恢复。智能助手当前的受控修改工具覆盖文字、表格和演示，PDF 正文编辑使用独立 PDF 编辑入口。
