# 海豹办公 1.9.6 修复与验收

## 本次修复

1. 修复首次通过选区浮窗或右键菜单调用 AI 时，已保存配置尚未读完就误报“请先配置模型服务”的问题。四类文件共用初始化流程，等待模型配置和当前文件的历史会话，配置读取失败保留实际原因和重试入口。
2. 空闲时首条消息直接执行，不出现在任务队列中。执行中的补充需求进入队列；待确认的文件修改保持原候选，后续需求等待确认。停止、暂停、重试、移除和不中断当前任务的补充引导继续可用。
3. 工具执行过程按操作逐行显示开始、完成、失败或停止状态。相同调用更新原行，失败原因和读取结果可以展开查看，思考内容与最终回复独立展示。执行记录保存到原有本机加密会话记忆，重新打开后可恢复。
4. 强化原生工具模式的复杂任务规划指令，任务计划默认折叠，并放在对话滚动区上方。读取、修改工具可以通过步骤标识绑定计划，按实际结果更新步骤：多批读取保留执行中状态，读完后完成；候选验证成功后等待用户确认，用户应用后才完成。模型不能提前把待确认步骤改成完成，后续未执行步骤保持待执行。
5. PDF 快捷总结、解释、翻译和问答与当前 PDF 文件会话关联，处理消息中引用的选中文字，避免误用此前的文字文件。未打开实际 PDF 的工具页面继续作为一般对话。PDF 快捷助手没有新增对 PDF 原文的直接修改能力。
6. 模型设置变更使缓存失效，晚到的旧配置不会覆盖新配置；首条消息使用已保存的思考强度和上下文窗口。保留 1.9.5 的 DOCX 保存重开格式修复与默认 125% 阅读缩放。
