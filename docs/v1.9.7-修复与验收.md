# 海豹办公 1.9.7 修复与验收

## 本次修复与体验改进

1. 格式操作和插入内容恢复选区时使用不滚动的焦点恢复方式，选中文字改字体、字号、加粗和对齐时保持阅读位置。
2. 选区浮窗在操作功能区、其他面板或输入框时收起；外部鼠标释放和选区变化不再把浮窗重新打开。浮窗位置限制在编辑内容区域内，避免遮挡功能区，下拉菜单长列表可滚动。文字、表格、演示共用浮窗关闭规则。
3. 文字字号采用精确磅值，避免原生七档字号使“小一、五号、初号”等变成错误大小；增大和缩小按相邻实际字号变化，光标后输入与格式刷同样使用精确字号。功能区反映当前字体、字号与加粗等状态，缺省动态值保留原菜单标签。
4. 文字格式命令与键盘快捷键统一进入历史记录；记录新操作前保存待提交输入，重复快照不会吞掉重做分支。页眉、页脚与页面设置加入历史，撤销到原始无页面设置的文档可正确清除修改状态。
5. 识别当前正文、页眉或页脚编辑区域，格式命令、段落样式、格式刷和插入操作作用到所在区域；切换文档清理过期选区。输入字号状态随正文、页眉页脚的鼠标与导航操作重置。
6. 文档保护启用后，修改命令和浮窗操作显示禁用状态及原因，快捷键也受保护检查约束。
7. 云空间、知识库和演示模板的上传入口使用真正的按钮，支持键盘 Enter/空格、忙碌禁用；知识上传在未开通或未解锁时先进入账号引导。云文件、知识和模板搜索显示明确“搜索”按钮，模板翻页有可辨识名称。
8. 新建目录、重命名空名称有明确反馈并保留弹窗；请求失败保留输入，支持重试；提交期间显示加载状态并阻止重复提交。修复校验拒绝产生未处理 Promise 错误的问题。
9. Windows 成品验收脚本使用不含空格的当前安装包文件名。

保留前版的 125% 默认阅读缩放、模板配图、AI 首次调用初始化、队列与引导、逐行执行记录、折叠任务计划和 DOCX 保存重开修复。
