# 海豹办公 2.0.0：第三轮兼容与共同编辑

本轮继续使用原有界面、应用身份和 2.0.0 版本号。最终构建与完整回归的可追溯记录汇总在 `verification/v2.0.0-third-pass/verification.json`；该文件只在本轮完整运行、成品核验和部署验收完成后生成。前两轮报告保留其当时结果，不作为本轮整套通过的替代证据。

## 动态数组与 WPS 往返

二维数组求值、锚点与派生单元格分离，支持溢出引用、跨表依赖、范围扩张与收缩，以及占用、合并、边界冲突的 `#SPILL!`。派生单元格不能单独修改，协作数据只传来源公式和原始单元格，接收端重新计算。保存时写入数组范围、缓存、XLDAPR 元数据和锚点 `cm`，避免仅显示旧缓存。

本机 WPS ET 的独立 COM 计算使用合成文件、独立工作簿和只读输入，不操作用户工作簿。33 组样本比较覆盖基本动态函数、数组运算、错误、Unicode、空白引用和跨表 `A1#`。实际观察到扩展 URI 中 GUID 的大小写会影响 WPS 另存时是否保留动态数组标记；仅修改为原生小写后，33 个锚点标记均得以保留。只改关系 ID、计算版本或计算功能声明的对照不能解决该问题，否定结果也保留。

另存后再次在 WPS 修改 `SEQUENCE(4,2,20)`，跨表 `TRANSPOSE(A1#)` 自动扩张为两行四列；随后通过本项目导入、重算、编辑、保存、重开验证。WPS 与 Excel 对 Unicode 计数及空白引用存在实测差异，因此提供随文件保存的公式兼容模式，并识别 WPS 自身的来源属性。不能仅凭 `Application=Microsoft Excel` 判断来源。

没有收到原先第三方遇到问题的 WPS 云导出原文件；这些测试证明所列合成样本和实际 WPS 往返行为，不代表所有云导出文件已经验证。

## 修订、分页与复杂对象

修订保存作者、时间、标识、插入、删除、移动及原生格式历史；原始正文、最终正文和全部标记视图切换不改写历史数据。新输入、输入法提交、删除、跨段替换、段落拆分与合并可以记录修订，接受或拒绝后保存为原生 DOCX 内容。

来源 DOCX 通过源包与稳定块标识保留分节、页眉页脚、脚注、复杂表格和绘图关系。普通正文仍可编辑；当前编辑器不能表达的复杂原生对象使用受保护块保留，不把它们降级成可编辑的普通文本。源包合并拒绝活动对象、宏、越界关系和超过限制的压缩包。

页数根据实际浏览器测量计算，覆盖显式分页、奇偶分节、连续分节、分栏、孤行寡行、段前段后、与下段同页、合并表格行和重复标题。编辑 HTML 中不插入保存污染用的分页占位符。普通文字、图片和注释保留原有离线 PDF 转换路径；复杂来源文档在转换前明确选择原生排版，预览、打印、导出及另存 PDF 使用同一当前模型快照；原生转换失败不降级冒充成功。原生排版显式保留奇偶分节产生的空白页。

独立渲染校验使用原始与编辑后保存的两份合成 DOCX：每份五个物理页面，共十页，检查横竖混排、双栏、首/偶/默认页眉、脚注、图片像素、自动空白页及最终页码，并实际查看渲染图。浏览器编辑排版和原生 PDF 排版仍不能据此宣称所有字体、浮动对象、公式、域和表格均达到 WPS 的逐像素一致性。

## 快捷键与移动端

已实现的文字、表格、演示命令通过静态命令目录进入现有快捷键设置，可搜索、录制、清除、冲突检查和恢复默认。含参数的命令打开现有功能菜单；不会通过快捷键绕过参数选择。表格导航、扩选、区域跳转、溢出保护，以及演示对象复制、组合、层级、微移和放映控制使用上下文分派。输入法、普通文本输入、弹窗和局部输入框优先保留其正确行为。

放映使用独立作用域，重绑定后工具提示同步更新。演示快捷复制根据对象选择状态复制对象或页面，功能区的“复制幻灯片”始终保持页面语义。命令目录覆盖当前实现的通用命令，不把未实现的命令提示登记成可执行功能。

手机与平板的 Word 阅读增加全屏、横向滑动翻页和双指缩放；屏幕页按当前视口重排，工具栏明确标为“阅读页（按屏重排）”，与原生纸张页码分开。PDF 使用真实文档页面横向分页、双指缩放和全屏，原有连续阅读模式仍可通过图标切换，移除截图中的“连续滚动”可见文字。退出阅读恢复原文、格式和编辑位置。原生全屏被宿主拒绝时使用视口全屏；设备级行为仍需最终云包真机验证。

桌面、Web 与移动 WebView 共用相同文档逻辑。生产浏览器验收另外操作真实动态数组、未失焦 Ctrl+S、数据验证、兼容模式、修订历史和窄屏面板；Android 与 HarmonyOS 分别重新编译 UTS 并生成独立云打包快照。云打包、签名和真机安装升级由用户继续完成。

## 共同编辑与发布边界

共同编辑采用加密 CRDT 更新、断线持久队列、重新连接合并、局部撤销及服务端权限校验。文字按富文本结构与字符合并，表格按来源单元格与字段合并，演示按页面和对象字段合并。保存与下载还需要把当前合并状态重新物化为对应 OOXML 文档；初始文件二进制不能被误当成最新编辑结果。

实际多账号测试使用隔离的本地服务和合成用户。生产验收不注册账号、不发送短信、不邀请真实成员。Linux 在当前 Windows 主机交叉构建并检查归档和可执行文件结构，不代替 Linux 安装和 GUI 运行；Windows 成品另外进行隔离配置的实际启动检查。全部测试通过表示本轮记录的检查范围通过，不是所有 WPS 功能和所有文档的兼容保证。

## 新建应用服务与模板

首页新建面板补入多维表格、思维导图、流程图、设计、知识库和笔记六个实际功能入口，沿用现有蓝色和紧凑界面。移动菜单共 22 个可用入口，依赖桌面数据库的 Access 继续按能力隐藏。另修复手机演示画布在纵向布局中被换列到屏幕外的问题，真实生产构建在 360/390/820px 检查画布边界。

多维表格支持多数据表、六种字段、必填校验、表格/看板/表单视图、排序搜索筛选、批量删除和 JSON/CSV/XLSX 导出。笔记支持 Markdown、笔记本、标签、置顶、回收站、本机图片、自动保存、Markdown 与备份导入导出；存储失败保留草稿，损坏存储可先导出原文再恢复备份。设计提供六类原创尺寸和内容布局，并进入现有演示画布编辑、另存真实 PPTX；画布既有图片/PDF导出继续使用。以上新工具当前为本机数据，尚未把多维表格、笔记与导图扩展为实时共同编辑。

思维导图和流程图增加节点形状、配色、备注、连线标签、自动布局、撤销重做、键盘分支操作、缩放后拖动与双指缩放。JSON/SVG 导出和导入保留结构；转演示生成可编辑形状与原生连接器，页面备注保留可读的节点说明；完整图数据保留在 JSON/SVG 元数据中。

模板库新增年度计划、营销、科技、财务、品牌活动和学术六套完整演示，与原有六套共 12 套、108 页，补充原创本地配图、可编辑图表、流程、表格和页码。预览与创建使用同一文稿模型，配图随 PPTX 保存。市场原有 300 个主题/风格组合保留；颜色组合不另宣称为 300 套全新内容故事。未复制 WPS 专属模板、品牌素材或会员资源。
