# 海豹办公 2.0.0 二轮升级记录

本文件记录第一轮 2.0.0 之后继续实施的功能及其验证边界。第一轮机器结果保存在 `docs/verification/v2.0.0-first-pass/`；二轮证据位于 `docs/verification/v2.0.0-second-pass/`。不能用第一轮包的哈希或测试数量代表二轮成品。

Web 公开入口为 **[海豹办公网页版](https://seal.xingmasoft.com/office/)**。已发布版本 `2.0.0-web-20261018-165357`，使用独立 `webcurrent` 指针；既有根路径管理后台及后端发布指针保持原值。30 个静态文件经本地、服务器与公网逐字节 SHA-256 核对，严格 CSP 下的公网浏览器 8 组功能验收通过，详情见 [Web 部署机器报告](verification/v2.0.0-second-pass/web-deployment.json)。

## 文档与表格

- XLSX 增加 XLDAPR 动态数组元数据：按 workbook 的 sheetMetadata 关系定位部件、解析一基单元格元数据索引及类型索引、保留动态数组标记、公式、数组范围和类型化缓存，导出重建关系、内容类型与元数据。支持别名命名空间、Strict URI 及不同部件目录。富值、未知扩展、无效索引继续报告未导入内容。保留标记并不等于本机已经实现所有动态数组函数的溢出计算。
- 插入、删除行列同步调整同表、跨表 A1 引用、绝对/混合引用、矩形及整行列范围；删除独立引用写出 `#REF!`，范围删除收缩。引用调整跳过文本常量、结构化引用、外部工作簿与三维引用；后三类尚未提供本地重定向或完整求值。源公式及数组范围随结构同步，工作簿更新后临时事件被消费，重复重算不再次平移，撤销快照保留原表达式。
- 未支持公式仍保留源表达式和可用缓存；缓存可能过期的提示继续保留，没有缓存则显示待计算。用户未提供发生公式丢失的原文件，因此回归样本不能被描述为已经复现该文件的具体故障。
- 本地显式注册 245 个公式函数，补充查找、统计、数学、文本、日期与财务函数；保持惰性条件分支和输入规模限制。函数名被注册不代表其每种参数、数组行为或错误细节均与 Excel/WPS 等价，逐项边界见 `renderer/src/sheet/formulaSupport.md`。
- 1900 / 1904 日期系统按工作簿保存并独立参与计算，兼容合法 `date1904="1"` 与 `date1904="true"`；保留序列 0、59、60、61、时间小数及原始数字格式代码。日期、前导零、科学计数和分数显示使用 SSF，混合日期基准工作表导出时拒绝静默转换。
- 新建或编辑的未来函数使用公开规范的存储前缀，未修改的来源公式保留其拼写。实际主进程 XLSX 写出后交由 LibreOffice 强制重算的 230 行独立对照中，228 行一致、2 行有记录的 Calc 差异、0 个未解释差异；1904 样本及跨引擎导入后修改再导出各 33/33 通过。日期和公式样本的验证不等于覆盖全部函数参数空间。
- DOCX 修复脚注/尾注部件的绝对关系路径，支持单引号 `instr` 简单域；未知域保留结果预览并报告保真边界。移动修订按接受后的目标文本导入，避免同时显示来源和目标；历史属性修订不再污染当前字体、段落、节与表格属性。完整历史修订回写仍未实现，保留来源文件保护。

动态数组按公开格式规范独立实现：[Microsoft XLDAPR 元数据扩展](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-xlsx/3dd44d53-847b-402f-a8c7-41a85024caf7)、[动态数组属性](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-xlsx/d1ef676d-d970-4ddd-b642-62f5e0c291e0)、[Office 单元格 cm 的一基索引约定](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oe376/b3e61d30-f15f-4712-9252-50883cbf0f8c)。

## 演示模板

现有商务演示、教育培训、产品介绍、项目汇报、季度总结和创业路演六套模板均扩展为九页，包含完整示例叙事、原创内嵌摄影、可编辑图表、流程、行动表格和页码。模板库卡片、详情与实际创建使用相同页面模型；图片资源恢复成功后才创建文稿。配图由内建 imagegen 生成，完整提示词、尺寸、哈希与来源说明保存在 `renderer/src/assets/presentation-templates/`，没有从 WPS 提取第三方模板图片。

模板测试 18 项通过；六个真实 PPTX 经编码、重读和生产渲染，共 54 页，检查结果没有正文溢出、缺失图片、浏览器错误或外部图片请求。桌面与 390px 手机在 file、HTTP 两种协议均验证卡片、详情和选择。原始机器结果与布局结果见二轮证据目录；这不是所有第三方办公软件及所有系统字体环境的逐页认证。

## 原生分析依据

使用用户指定 REA MCP 与本地 Ghidra 12.1.4/JDK 21 工具链，只读分析已安装 WPS 12.1.0.26895。原始二进制、第三方资源及反编译文本留在 `.upgrade-private/`，产品包不含这些材料。可复用工具安装脚本校验官方发布包 SHA-256，分析会话使用项目专用环境，不修改全局 Java 或其他客户端配置。

xlsxrw、wppcore、wpsio、wpscore、etcore 五个部件均已完成默认完整自动分析，并沿具体交叉引用检查函数。大型 wpscore、etcore 初次导入在 20 分钟绝对期限超时；保留错误后以项目专用 60 分钟期限重试，分别完成 144,808 / 162,539 个函数的工具分析。所有会话均关闭，原始文件没有修改。证据身份、哈希、观察及限制见 [原生证据清单](verification/v2.0.0-second-pass/wps-native.json) 和 [文字引擎观察](v2.0.0-WPS文字引擎观察.md)。

xlsxrw 的动态数组元数据写出路径与公开 XLDAPR 规范一致，指导补齐标准格式处理；前缀只确认参与特定名称筛选路径。wppcore 已追踪版式/主题/切换/动画序列的序列化。etcore 确认公式优化结果将来源表达式、优化表达式、范围、耗时、首格值及动态数组标志分开组织；这是结果展示路径，不是公式求值器。其日期命令注册回调尚未恢复成可解释过程，不能据此宣称已还原日期算法。wpscore 确认独立的修订域显示过滤与恢复路径；转置前的影响确认路径不能被当作接受修订算法。

静态自动分析、字符串或函数数量不证明已经运行所有 WPS 命令，也不证明达到其全部排版、字体、宏、外部数据、动态图表、公式及云功能的行为一致性。本次独立实现通用行为和公开文档格式，不复用 WPS 原生实现、图标或私有云接口。
