使用用户指定的 [REA MCP](https://github.com/morluto/rea)，连接版本为 6.5.0，本机 WPS 位于 `C:\Users\A\AppData\Local\Kingsoft\WPS Office\12.1.0.26895\office6`。

- REA 分别检查了 `wps.exe`、`et.exe`、`wpp.exe` 的静态 PE 资源、文件大小与 SHA-256。对应 Evidence ID 及限制保存在 [wps-analysis.json](verification/v2.0.0/wps-analysis.json)。资源表检查不能证明原生引擎的执行行为。

- 一份资源的属性包含未转义的 `<` 等字面量，脚本只在分析内存中修复后解析，并单独记录修复数量；原文件与归档哈希均保留。原始第三方资源仅位于 `.upgrade-private/wps-analysis-v1.9.16/`，不会进入产品包。
- 最终资源归档的 REA inventory Evidence 为 `ev_be757f12b9ff1b36c341c8c8d5614dbc1915997e93fdd8cf1d0cc66373509c59`，包内文件图没有完整性矛盾；这只证明已选择资源的静态清单。
- 首轮时 Ghidra / IDA 未配置，Hopper 不支持此 Windows 主机。二轮已补齐项目专用 Ghidra/JDK 并开展原生函数追踪，具体证据和限制见二轮记录。没有复用 WPS 私有云接口、许可逻辑、程序代码或图标。

## 公式和文件格式

用户无法提供发生问题的 WPS 云导出文件。本次结论来自代码追踪与人工构造的标准 OOXML 回归文件，不能宣称已复现该文件的具体故障。

原有导入链路在打开 XLSX 后立即重算所有单元格。本地公式分析器不支持的语法可能把文件中的正常缓存显示改成错误。2.0.0 将公式表达式、类型化来源缓存、本地计算结果和计算状态分别保存；无法本地计算时继续显示来源缓存，明确标记可能过期。没有缓存则显示 `#待计算`，保存时不伪造结果。

覆盖的回归包括：

- `$A$1` 与混合引用、含空格或转义引号的工作表名称、跨表引用及循环依赖。
- 常见 `_xlfn.` 前缀、科学计数、百分比、字符串连接与惰性 `IFERROR`。
- 共享公式从属节点先于主节点；展开引用时保留文本常量 `"A1"`、绝对引用与结构化引用。
- 缓存 `0`、`false`、空字符串及 Excel 错误值保留类型；不能用旧缓存掩盖本地实际算出的错误。
- 数组公式保留表达式、数组范围与缓存，导出标记 `fullCalcOnLoad`；依赖来源缓存的本地公式也显示状态。
- XLSX Strict / Transitional 命名空间、不同前缀和关系 URI；DOCX / PPTX 也新增按命名空间规范化的兼容层，正文中的类似前缀文本不被替换。
- 工作簿重算无结果变化时保留对象引用，避免影响既有撤销与重做历史。

## 快捷键和阅读

设置中心提供 87 个已实现通用命令的配置入口：文字 35、表格 17、演示 21、PDF 14，共 100 个默认键位。可以搜索、录制、禁用、恢复单项或全部默认键位；同一文档类型的冲突会阻止应用。修改后菜单显示实际键位，旧默认键不会继续触发文档格式命令。输入法、普通输入框、弹窗和 AltGraph 保留各自操作优先级。

依据 WPS 提示对齐了当前项目已支持的字号、查找、保存、格式、放映、分页与 PDF 导航等命令；额外兼容常用 Office 别名。PDF 增加适应整页、实际大小和适应页宽的实际行为。这里的 87 个命令不等于全部 WPS 上下文快捷键。

成品验收发现并修复了演示文本框编辑中直接 `Ctrl+S` / `Ctrl+Shift+S` 写出旧模型的问题。保存和另存为直接取得包含当前文字草稿的快照，再用于编码、资源收集和已保存基线；无需先失去焦点。已有字符片段同步更新，未修改文字的格式继续保留，Unicode 文本通过实际编码重读验证。另补表格单元格输入和验证列表的输入法确认保护，避免 Enter 在候选转换完成前提交。

移动端导入文字文档后默认进入阅读模式，新建文档默认编辑；阅读模式保留选择复制、目录和查找，关闭正文、页眉页脚、图片及格式修改，支持 16–32 阅读字号和窄屏重排。阅读偏好不写入正文 HTML、纸张、分栏或导出格式，切回编辑恢复原文档排版。外接键盘可用可配置的 `Ctrl+Alt+R` 切换。

## 验证与交付

最终验证报告存放在 `docs/verification/v2.0.0/`，安装文件集中到 `release/v2.0.0/`。Windows 使用包内代码检查与隔离用户目录运行；Linux 在本机交叉构建并检查包结构、版本、依赖、资源和校验值，没有可用 Linux 运行环境时不会宣称通过安装或界面验收。
