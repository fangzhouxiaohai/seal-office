# 2.0.0 发行包命名

按用户最新要求，安装包与分发归档使用英文文件名。程序界面、Windows 主程序与桌面快捷方式继续显示“海豹办公”；应用 ID、版本、安装目录及签名不因文件名变更调整。Linux 原有 `sealoffice` 启动命令保留。微软商店清单保留已注册显示名 `seal-office`。

| 类型 | 本版发行文件名 |
| --- | --- |
| Windows NSIS 安装包 | `seal-office-setup-2.0.0.exe` |
| Windows 便携包 | `seal-office-2.0.0-portable.exe` |
| Microsoft Store x64 上传包 | `seal-office-2.0.0-microsoft-store-x64.msix` |
| Ubuntu amd64 | `seal-office-2.0.0-amd64.deb` |
| Web 静态归档 | `seal-office-2.0.0-web.zip` |
| Android 云包本地归档 | `seal-office-2.0.0-android.apk` |
| HarmonyOS entry HAP 本地归档 | `seal-office-2.0.0-harmony.hap` |
| HarmonyOS 正式 App Pack 发行封装 | `seal-office-2.0.0-harmony.app.zip`，内为同名 `.app` |

2026-10-19 用户提供的是已签名 App Pack，其内层 HAP 没有独立签名，因此本次发布 `.app.zip`，不发布独立 `.hap`。详见 [实际移动成品验收](v2.0.0-发布与移动成品.md)。

后续版本读取 `build/artifact-names.json` 中的同一模板。Electron 构建、Windows 上生成 DEB、Ubuntu 工作流、包下载、验证、发布和 Web 部署归档均使用这组规则。Web 部署的 ZIP 存放在 `.upgrade-private/web-deployment/<release-id>/`，不同部署分别保留，文件名由版本决定；部署 tar、后台指针及服务端路径不因此改名。

Android / HarmonyOS 云服务的默认下载名不由本仓库控制。下载后回原项目运行：

```powershell
npm --prefix mobile run check:apk -- "APK绝对路径" --require-current --archive "E:\seal-office\release\v2.0.0"
npm --prefix mobile run check:hap -- "HAP绝对路径" --archive "E:\seal-office\release\v2.0.0"
```

归档保留原下载文件，按二进制复制并复核 SHA-256；同名但内容不同的文件拒绝覆盖，不解包重打或重新签名。APK 归档要求 Android SDK 校验应用身份、版本、正式签名、资源及现有发行配置。HAP 检查 entry 模块、身份、版本、ZIP CRC 及当前鸿蒙云打包快照的内置编辑器；其签名与设备安装需要使用官方工具独立完成，报告明确记录尚未验证。这些检查在云包尚未提供时不会生成 APK / HAP。

本次配置与脚本验证不等于正式包验收。正式重新构建、安装或浏览器验收由第四轮发行流程完成。历史报告、归档、哈希清单及前三轮 finalizer 保留原文件名和原结论，不回写为新发行结果。

本次规则与测试证据见 `docs/verification/v2.0.0-fourth-pass/package-naming.json`。
