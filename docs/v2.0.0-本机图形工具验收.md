# 2.0.0 本机脑图与流程图验收

本轮增强现有 `DiagramPage`、`diagramData` 和 `diagramPresentation`，沿用本机工作台的颜色、按钮和布局。新增样式独立放在 `diagramEnhancements.css`；没有修改共享导航、App 入口、正式 static/dist 或移动生成资源，也没有使用 WPS 私有图片、模板或反编译实现。

## 实际可用功能

- 脑图和流程图各自具有独立项目列表，支持新建、打开、返回列表、重命名、复制、名称搜索和按修改时间/创建时间/名称排序。删除先进入回收站，可以恢复；永久删除必须再次确认。
- 每个项目独立保存图内容、创建/修改时间和撤销历史。编辑支持撤销、重做、Ctrl/Cmd+Z、Ctrl/Cmd+Y、Ctrl/Cmd+Shift+Z；最多保留100个完整快照，较大的图按单项目2 MiB预算保留最新完整历史。切换项目和关闭重开仍能分别撤销。拖动结束后一次保存和记录，取消拖动恢复原位置。
- 树布局采用有界的广度遍历生成森林，再按子树安排位置；流程布局按广度层级排列。循环、多父边和断开组件不会导致无限遍历，原有节点、连线、标签和备注均保留。
- 画布支持1%–250%缩放、适配全部节点、Ctrl/Cmd+滚轮缩放、双指缩放、背景拖动平移。节点拖动按当前缩放转换屏幕位移与模型坐标，鼠标及触摸均使用 Pointer Events 与指针捕获。
- 节点支持矩形、圆角矩形、椭圆和菱形，以及海蓝、青绿、暖橙、紫色配色。节点备注在检查器编辑并显示提示；连线标签在检查器和画布中可见。
- 在选中节点上 Tab 新增分支；脑图 Enter 新增同级，流程图 Enter 新增后续步骤；Delete/Backspace 经确认删除，删除可撤销；F2进入文字编辑；方向键移动10单位、Shift+方向键移动50单位。Shift+Tab 保持原生离开画布的焦点操作。
- 新建、导入、删除和普通编辑实际写入本机存储，节点文字和备注输入自动保存，输入法组合完成后提交。存储失败不会显示成功：有效编辑及其历史仍保留为未保存草稿，尽量备份到会话存储，支持重试、导出和另存新项目。若项目和会话存储均不可写，会明确提示当前仅为内存草稿并阻止无提示关闭，不能保证操作系统强制终止后的恢复。

图形最多100节点、300连线，坐标上限30000；导入文件最多2 MiB。节点文字200字符、备注2000字符、线标签200字符。非法颜色、形状、端点和新字段均明确拒绝，不能因校验时丢弃未知内容而假称完整导入。

## 多项目存储与迁移

每个项目以单独的 `seal-diagram-project-v2:mindmap:{id}` / `seal-diagram-project-v2:flow:{id}` 记录原子写入，不通过重写整个项目列表保存一张图。记录包含 `schema/id/type/title/created/updated/revision/graph/history/trashedAt`。复制创建新身份和独立撤销历史，回收站保留正文与原撤销栈。列表默认不自动打开某项目。

本机 WPS 对照证据由 REA/Ghidra 对 `kpromeprocesson.dll`（SHA-256 `15eb6cee24aeaa405e280a1a7be8eb4e20a2a188a1e0a050be2a44d76284c88c`）做静态分析取得：`0x10016b70` 读取名称/分类等参数并构造独立文件创建请求；`0x1002a770` 按文件身份重命名；`0x1000ad30` 区分打开、导入和新建；`0x1002e590` 构造删除确认及可从回收站恢复的提示。安全摘要、各函数 evidence ID 和限制在 [本机图形工具原生观察](verification/v2.0.0-fourth-pass/wps-diagram-native.json)。这能支持“应以独立项目管理多张图”的判断，不能证明已操作 WPS 列表界面或完整复刻其云权限；本轮没有向厂商服务发送请求，也没有把第三方代码/资源放入产品。

原来的 `seal-local-mindmap-v1` / `seal-local-flow-v1` 首次读取时迁移为「我的脑图」/「我的流程图」。先在原键追加 `:backup-v2` 写入精确备份，再创建项目，最后写独立迁移完成标记；原键永不改写。任一步失败都显示错误并保留来源，重试不会把旧内容重放到已编辑的新项目上；永久删除迁移项目之前必须确保迁移标记已完成，避免下次旧图复活。损坏的旧数据不会被新建项目覆盖。

保存会比较项目基准版本，拒绝用陈旧窗口内容覆盖已经发现的新版本，冲突草稿仍可导出或复制；这不是云端实时协作，也不宣称 localStorage 提供跨进程事务锁。成功重试在项目记录保存草稿回执，即使会话草稿清理被浏览器拒绝，也不会在下次重载时用旧草稿替代已提交正文。浏览器禁止访问 Storage 属性本身时同样显示可恢复错误，不使组件初始化崩溃。项目容量受所在浏览器/应用本机存储配额限制，JSON/SVG备份仍是跨设备或清理应用数据前的持久备份方式。

## 可编辑数据与真实导出

JSON保留完整节点属性和连线拓扑，并兼容原有仅含文字和坐标的数据。SVG输出真实矢量图形、转义后的文字/标签、完整标题与备注，以及已校验的可编辑图形元数据。本项目输出的SVG可通过“导入数据”再次打开；外部SVG若无该元数据会明确报告不可编辑，不能把空白画布当作成功导入。SVG源中的脚本、foreignObject、DTD和实体被拒绝，原始图形代码不会插入产品DOM。

“转为演示”生成实际可编辑的原生PPT图形、连接到节点的原生连接器、独立可编辑的线标签和语义组合，按比例适配960×540画布。节点备注以“节点名称＋备注”的可读形式写入演讲备注，不向用户备注面板倾倒内部JSON。连接拓扑、形状、配色、文字和备注经过真实PPTX两轮保存/读取验证。

PPT中的线标签是独立图形文字对象；本轮没有实现任意PPT修改自动反向同步回原图。完整源图可编辑备份使用JSON或本项目SVG。长节点标题在画布/SVG中可换行并以省略标记控制显示，完整文本仍保留在编辑数据、SVG标题和PPT对象中。自动布局提供通用层级排列，不宣称覆盖全部专业流程规范、自动正交避障、BPMN或WPS专用图示模板。
