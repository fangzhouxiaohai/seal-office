# 2.0.0 模板扩展验收

新增六套完整演示：年度计划、市场营销、科技方案、财务经营、品牌活动、学术答辩。每套九页，具有各自的业务问题、指标、原生图表数据、四步流程、行动表格、风险与结束行动；全部十二套主题演示共 108 页。另增加研究计划、用户访谈提纲、活动执行方案三个文字模板，以及费用报销明细、渠道投放复盘、研究记录表三个表格模板。渠道投放和费用明细的公式经过真实 XLSX 往返验证。

现有市场的 300 套风格组合全部保留，新增十二套主题摄影模板作为独立内容入口，市场共 312 项。数量没有把六套新叙事的换色重复计算为新内容。模板库与市场均增加用途、推荐和名称/描述搜索，内置内容可离线使用。封面与实际创建的文稿使用同一模型；真实使用前恢复原始图片字节。云收藏、本人上传和公开市场流程沿用现有 UI。

三张新图片 research.png、finance.png、event.png 使用内建 imagegen 工具原创生成，无外部输入照片、商标或 WPS 素材。完整指令在 renderer/src/assets/presentation-templates/prompts-expanded.json；原始尺寸和 SHA-256 在 metadata.json。三张新增图片共 5,963,204 字节。六张模板图片合计 12,512,444 字节。本轮保留当前离线内联机制，图片增加了 JavaScript 初次下载、解析与内存占用；没有把生产独立验收包体积掩盖为零成本。后续可单独设计可缓存资源拆分与离线预取。

验证记录：

- 五个完整测试文件共 32 项通过，日志 .tmp-template-expansion-final-tests.log。覆盖十二套真实 PPTX 读写、原生图表/流程修改后再次读写、封面同源、模板搜索/推荐/失败反馈、市场实际应用与原 HomePage 创建。
- root 与 mobile typecheck 均退出 0。
- 独立生产构建仅写 .upgrade-private/template-expansion-verification/dist，未写正式 dist 或 mobile/unpackage。
- 真实 Electron 在 file 与 HTTP 两种入口运行：十二个 PPTX 读回后逐页渲染共 108 页，21 个桌面/平板/手机布局记录，四次真实模板创建。原始图片经过 SHA-256 核对和浏览器 decode；零正文溢出、零缺图、零外链、零浏览器错误。
- 严格验收显式加载实际 App 的 styles.css、cloud/drive.css、cloud/cloud.css 与移动 mobile.css，补齐 AppProvider 需要的资源 read/restore/sync/release/export 边界。每次截图拒绝错误弹窗，等待可见对话框动画完成；市场实际 grid 样式、封面宽高和摄影 img 都有断言。手机九页预览具有内部滚动，使用按钮保留在视口。
- 公开机器报告 docs/verification/v2.0.0-third-pass/template-expansion.json，含 unexpectedDialogsChecked:true、unexpectedDialogs:[]、每页文本几何、每张图解码状态、市场网格/卡片尺寸、移动预览滚动/按钮几何、PPTX SHA-256、资产指纹及独立生产 JS 的 SHA-256。

