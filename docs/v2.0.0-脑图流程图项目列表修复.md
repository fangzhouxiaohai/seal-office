# 2.0.0 脑图、流程图项目列表修复

本轮修复了脑图与流程图各自只有一张固定画布的问题。版本继续使用 2.0.0，保留现有界面风格。

脑图和流程图现在先进入各自的项目列表。可以连续新建多个项目，按名称搜索，按最近修改、创建时间或名称排序；每个项目有独立名称、缩略图、节点、连线、备注和撤销历史。支持重命名、复制、移入回收站、恢复，以及确认后的永久删除。在编辑器中返回列表或新建另一个项目，不会覆盖原项目。

旧版保存在当前设备上的单张脑图、流程图会分别迁移为“我的脑图”“我的流程图”。迁移前保留原始备份，原 v1 存储键不回写；迁移标记成功提交后才视为完成，后续删除迁移项目不会再次生成旧图。存储损坏、空间不足或其他窗口修改同一项目时会提示问题，保留可恢复草稿并提供备份入口。

原有节点和连线编辑、自动布局、备注、配色、快捷键、鼠标拖拽、双指缩放、JSON/SVG 导入导出及转为可编辑演示功能继续保留。项目列表适配手机、平板和桌面宽度；项目数据仍存放在当前设备或当前浏览器，跨设备转移可使用导出文件。

本轮对本机 WPS 图形插件进行了真实 REA/Ghidra 静态分析，确认独立文件创建、打开/导入、按文件 ID 重命名、删除确认及回收站提示的路径。方法、函数地址、工具 Evidence ID 和无法运行 Windows 界面采集的限制详见 [原生分析记录](verification/v2.0.0-fourth-pass/WPS脑图与流程图原生分析.md)。分析结果用于理解通用行为，实现代码由本项目独立编写。
