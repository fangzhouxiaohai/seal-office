# 海豹办公 2.2.2 表格兼容与性能修复

本次版本为 **2.2.2**，移动构建号为 **20202**。本文件记录问题依据、修复与实际验收结果；平台成品和部署状态按下表分别记录。

## 问题依据

本机只读样例是标准压缩工作簿，文件 17,527 字节，主表实际范围为 39 行、18 列，包含 621 个单元格记录、48 个合并区域。整列默认格式覆盖到第 16,384 列，导入层将列宽键计入数据边界，误生成 44 行、16,384 列的模型；每次交互遍历 720,896 格，合并查询又逐格展开合并区域，保存为旧专属格式后仍携带膨胀范围。

来源工作表使用 70% 视图缩放，旧界面重置为 150%；来源含缩小字体填充设置，旧实现仅报告不支持。以上结构信息来自本机核查，不包含姓名、工资、账户等业务内容。用户原件只供本机只读验收，编辑、保存和重开均使用隔离副本；原件不得提交仓库、上传外部服务或用作宣传素材。

## 改动边界

- 将真实编辑范围与整列默认布局分离，用紧凑区间保存整列宽度和默认格式；真实单元格、合并、验证和图片继续决定有效范围，不能通过固定截断列数丢弃远端内容。
- 保存时只为实际存在的单元格创建记录，旧版大范围模型的空白占位不再写成百万级空值；整列默认格式仍由紧凑区间保留。
- 网格按可见范围渲染，合并查询按边界索引处理；旧版大范围专属文件保留数据，兼顾视口外合并锚点、冻结、编辑、筛选和键盘导航。
- 还原来源视图缩放、字号单位和缩小字体设置；对实际仍不支持或损坏的内容继续给出明确中文提示，不清空警告掩盖损失。
- 补齐字体命令的快捷键目录、字体选择器触发标识和字体目录静态候选，修复字体快捷键无法打开菜单、字体下拉为空的问题。
- 桌面、服务端及移动版本同步；应用身份、签名、中文显示名与英文发行命名规则沿用。
- 当版教程分镜更新至 2.2.2；教程收尾的标题与发行链接改为读取当前版本，历史稿件与历史验收报告保留原记录。

## 智能助手界面更新

本版同时整理智能助手对话面板：标题栏改为品牌标识加图标操作，会话正文直接排版，代码块保留独立复制面板；输入区合并为单一圆角卡片，保留“修改需确认/只读问答”状态、停止生成和发送，桌面与移动、浅色与深色同步。设计审计在 1280 和 390 像素两个视口均为零违规，交互回归 8 组通过。见[助手界面验收](verification/v2.2.2/助手界面验收.md)。参考图仅用于信息层级和输入区结构，不复制其品牌、文案或配色。

## 构建与归档入口

完整规范见[打包规范](打包规范.md)。打包前由主流程执行 `npm run release:prepare`，只清理已确认属于本项目的旧生成产物，保留历史报告、远端历史附件、签名与用户原始文件。本机正式交付集中在 `release/v2.2.2/`，视频在 `release/promo/`。

```powershell
npm run typecheck
npm run test:run
npm --prefix server test
npm --prefix mobile test
npm --prefix mobile run typecheck
npm --prefix mobile run check
python -X utf8 scripts/promo/tutorial-finalize.test.py
npm run release:prepare
npm run dist:windows:all
npm run dist:ubuntu
npm run web:build
```

Web 使用 `scripts/deploy-web.py` 的标准 `preflight → prepare → plan → stage → retain-sessions → publish` 流程，发行标识采用 `2.2.2-web-YYYYMMDD-HHMMSS`。`stage` 必须传入冻结资源的实际摘要和更新后的生产浏览器报告；不能跳过验收直接发布。脚本在本机私有部署目录中按当前版本生成 Web ZIP；主流程需将已验收 ZIP 按原字节归档到 `release/v2.2.2/`，记录摘要后再列入公开附件。部署须核验后端与匿名访问边界，结果由主流程补录。

Android 与 HarmonyOS 必须分别完成以下顺序，前一平台冻结归档后才开始后一平台，不能混用最后一次构建的资源：

```powershell
npm --prefix mobile run build:android
npm --prefix mobile run check:android
# 完成 Android 当前生产资源浏览器验收后再冻结。
node mobile/scripts/snapshot.mjs android
node mobile/scripts/archive-source.mjs android

npm --prefix mobile run build:harmony
npm --prefix mobile run check:harmony
# 完成 HarmonyOS 当前生产资源浏览器验收后再冻结。
node mobile/scripts/snapshot.mjs harmony
node mobile/scripts/archive-source.mjs harmony
```

Android 源码 ZIP 和干净解压项目总量均不得超过 **60,000,000 字节**；本次资源和代码变化后必须重新统计，不能沿用旧版本体积。云源码只代表可提交云打包的项目，不代表已生成 APK、HAP 或 App Pack。

## 当版操作视频

当前分镜为 `docs/promo/current-storyboard.json`，入口 `npm run promo:build` 依次执行配音、实际操作录制与渲染。沿用已确认音色 `zh-CN-XiaoxiaoNeural`、语速 `+5%`、音调 `+4Hz`，禁止更换声音或把原样音业务内容用于宣传。实际演示继续使用隔离资料，不能把用户原件送入录制环境。

主流程在当版 Android 冻结资源验收后，以 `SEAL_PROMO_ANDROID_ROOT` 指向其 `static/office` 的绝对路径。录制真实点击、逐字输入和执行结果，显示点击圆环及紫色目标轮廓。移动浏览器素材如实标注，不能称作 APK 真机录像。完整解码、1920×1080 与 1080×1920 画幅、音轨、字幕、时长和代表帧均完成复核后，才执行 `python scripts/promo/tutorial-finalize.py --record-visual-review --clean` 并填写本版视频结果。
