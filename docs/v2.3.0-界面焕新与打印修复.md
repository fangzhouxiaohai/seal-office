# 海豹办公 2.3.0 界面焕新与打印修复

本次版本为 **2.3.0**，移动构建号 **20300**。本文件记录问题依据、改动范围与实际验收结果；未实测的项目单独注明，不以源码修改代表验收通过。

## 一、打印出来是空白

### 原因

所有编辑器的打印都先在主进程生成一份 PDF 预览，确认打印时再把这份 PDF 交给 `main/printDocument.js`：写入临时 `document.pdf`，用隐藏的 `BrowserWindow`（`plugins: true`）加载，然后调用 `webContents.print()`。

Electron 里 PDF 由内置查看器渲染，它运行在独立的插件框架中；`webContents.print()` 只打印外层文档，外层是空页面，所以打印机收到的是空白页，Windows 打印对话框也显示“没有可用的预览”。这是 Electron 的已知行为（参考 [electron/electron#8351](https://github.com/electron/electron/issues/8351)）。

### 修复

- 新增 `renderer/src/components/printPages.ts`：确认打印时，用渲染层已经在用的 pdf.js 把预览 PDF 逐页画到画布上（默认 200 DPI，超过 80 页降到 150 DPI，单页像素上限 2400 万），生成每页一张图片的打印 HTML。每种纸张尺寸各有一个具名 `@page`，纵向、横向混排的 PDF 也保持各自的原始尺寸，页边距为 0，避免二次缩放。
- `PrintPreview` 改为把这份 HTML 交给系统打印，并在底部显示“正在准备第 N / M 页”进度。
- `printDocument.js` 打印 HTML 前等待字体和所有页面图片解码完成并多等两帧；隐藏窗口启用 `paintWhenInitiallyHidden`、关闭后台节流，打印选项改为 `margins: none`。
- 预览与打印仍使用同一份 PDF 数据，文字、表格、演示和 PDF 工具的打印都走这条链路。

### 测试

- `printPages.test.ts`：混排纸张生成正确的具名 `@page`、每页一张图、标题转义。
- `PrintPreview.test.tsx`：打印时交给主进程的是图片 HTML（`html` 格式），不再是原始 PDF。
- `printDocument.test.js`：临时文件清理、取消与无效输入的处理保持不变。

## 二、Office / WPS 格式兼容

依据 ECMA-376（OOXML）与 Microsoft 的实现说明逐项核对了新建文件的包结构，修复以下会被 Word / PowerPoint / Excel 或 WPS 识别出来的问题：

| 格式 | 问题 | 修复 |
| --- | --- | --- |
| DOCX | 新建文档的 `settings.xml` 兼容模式不是 15，Word 2013 及以后的版本会以“兼容模式”打开并停用新版排版 | 新增 `main/office/docxCompat.js`：新建文档强制 `compatibilityMode=15`，并补齐 `overrideTableStyleFontSizeAndJustification`、`enableOpenTypeFeatures`、`doNotFlipMirrorIndents`、`differentiateMultirowTableHeaders` 等 Word 2013+ 默认兼容项；按 CT_Settings 的元素顺序插入，保证通过架构校验 |
| DOCX | 缺少 `themeFontLang` 的东亚语言，WPS 与 Word 对中文的默认东亚字体、断行判断不一致 | 补 `w:themeFontLang w:val="en-US" w:eastAsia="zh-CN"`，同时补齐 `decimalSymbol` / `listSeparator` |
| DOCX | 打开的原文件如果是旧版兼容模式，强制提升会改变原有排版 | 只处理新建文档；打开的原文件继续保留自身 `settings.xml` |
| DOCX | 文件信息里的作者显示为 docx 库默认的 “Un-named” | 新建文档作者、最后修改者写为“海豹办公”；打开的原文件保留原有文档属性 |
| PPTX | pptxgenjs 默认把作者、公司、标题写成 “PptxGenJS” | 写入“海豹办公”和文稿标题 |
| PPTX | 文本运行语言为默认 `en-US`，PowerPoint 校对与 WPS 东亚断行按英文处理中文 | 文本运行标记为 `zh-CN` |
| XLSX | 工作簿创建者、修改时间为空 | 写入创建者、最后修改者与时间；继续保留 `fullCalcOnLoad`、1904 日期系统等既有兼容处理 |

已有的格式兼容能力（DOCX 源包合并保真、修订与批注、XLSX 公式与日期系统、PPTX 母版/动画/备注等）这次没有改动，相关 115 个主进程测试文件全部通过。

## 三、界面焕新（Vivid 设计语言）

参考多色彩分组、圆润组件的工作台风格，重做了应用外壳与控件。文档纸张、幻灯片对象、表格单元格与打印输出不受影响。

- **主色**：品牌色由蓝色改为紫罗兰色 `#6A5CF5`，主按钮使用渐变与柔和投影；深色模式同步换成深靛蓝底色。主题令牌同步更新到 `themes.ts` 与 Ant Design 主题（圆角 10/16、弹窗圆角 20、阴影、字体栈）。
- **色调体系**：新增 `navTones.ts`，每个入口固定一种颜色（最近/紫、星标/琥珀、共享/天蓝、知识库/青、回收站/石板灰……）。最左图标栏、首页侧栏、应用中心和新建对话框的图标放在同色系圆角底块里，选中时变为渐变实色。
- **卡片**：文档卡片、应用入口、新建选项、推荐卡片统一 16–18px 圆角、细边框与层次阴影，悬停时轻微上浮；应用入口右上角加同色光晕。
- **Ribbon**：标签改为胶囊式，当前标签为深色实心胶囊；功能区收进圆角卡片，分组用虚线分隔；溢出时只显示细滚动条。
- **其他**：顶栏半透明毛玻璃、搜索框胶囊化、文档标签圆角、下拉菜单/弹窗/提示统一圆角和投影、滚动条变细、遮罩加模糊。
- 图标栏标签固定单行，“智能助手”“团队空间”等不再折行。

新样式写在 `renderer/src/styles/flatDesktop.css`（沿用原文件名，桌面、Web 与移动端共用入口），以浏览器实际渲染截图核对了首页、应用中心、新建对话框、文字/表格/演示编辑器和深色模式。
