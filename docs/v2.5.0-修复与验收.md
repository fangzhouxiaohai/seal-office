# 海豹办公 2.5.0

**本版重点：云空间分享链接、Zotero 百科接入、移动端「接口不存在」修复。**

## 更新内容

- **云空间分享链接**：新增独立于「文档共享」的免登录下载通道。任何拿到链接的人都能在浏览器里直接下载，不需要注册或登录海豹办公。有效期可选 1、3、7、30 天或永久；访问码 4 至 8 位、可选，只用于包裹文件密钥。文件仍是在本机加密后才上传，因此链接把文件密钥、文件名与节点标识放在 URL 片段里（浏览器不会把片段发给服务器），落地页用 WebCrypto 在本地解密；服务端只存访问码的校验摘要，无法还原明文，也解不开文件。文件移入回收站后链接立即失效。

- **Zotero 百科**：将 Zotero 中文社区的开源中文文档并入知识库，作为第二个资料源，不新建模块。复用知识库原有的「检索、阅读、引用、提问」链路：按标题或关键词检索，直接阅读原文，也可以引用段落向助手提问。主进程代理只放行该站点的 `llms.txt` 与 Markdown 原文，其余地址一律拒绝。

- **移动端「接口不存在」修复**：鸿蒙与安卓云盘中重命名文件、移动到文件夹会弹出「接口不存在」，实际什么都没改。根因不在服务端缺接口——`@ohos.net.http` 与 `uni.request` 都没有 PATCH 常量，请求被降级成 GET 后匹配不到路由。受影响的还有标签改名、团队改名、成员改角色、设备改名。现改为 `POST` 加 `X-Seal-Method-Override: PATCH`，服务端只接受 PATCH 这一个覆盖值，避免退化成任意方法隧道。

- **移动端图标与排版**：修正图标库中 89 个移动端图标把品牌色硬编码在描边上、放到实心主按钮上几乎不可见的问题，统一改为 `currentColor`。发送按钮换成单路径实心图标；标题栏的长文字按钮改为带可访问名称的纯图标按钮。

- **README 截图更新**：功能介绍截图全部换成 2.5.0 实际界面，共 12 张，覆盖首页、四类编辑器、分享链接、知识库与 Zotero 百科、设置中心及深色主题。
