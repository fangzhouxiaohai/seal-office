## 一、P0 功能正确性

### P0-1 移动端返回键层级判断

**问题**：`mobile/pages/workspace/workspace.uvue` 的 `onBackPress()` 依据 `errorText` 与 `workspaceReady` 判断，而用户要求的是「底部 tab 可见 → 回桌面；二级页面不显示 tab → 返回上一页」。

**处置**：新增 `renderer/src/navigation/backLevel.ts`，把「底部 tab 是否可见」做成纯函数。判定同时检查 `display`、`visibility`、`getClientRects()`，因此键盘弹出导致标签栏隐藏时也判为不可见。

网页层在 `state` 消息中新增 `backToDesktop` 字段下传；`mobile/pages/workspace/workspace.uvue` 改为只读取该字段，原生层不再自行猜测层级：

- 加载失败 → 直接回桌面
- `workspaceReady && backToDesktop` → 回桌面
- 其余情况 → 派发 `seal-native-back`

**验证**：`renderer/src/navigation/backLevel.test.ts` 9 项、`mobile/tests/native-workspace.test.mjs` 5 项通过。

**未验证**：Android / HarmonyOS 真机物理返回键（需真机）。

### P0-2 Word 编辑器「暂不可用」提示

**问题**：`renderer/src/editor/DocEditor.tsx` 残留 `提示不可用插入项` 调用，书签与 `default` 分支以弹窗告警收场。

**处置**：

- 超链接改为真实实现：空地址中止；拒绝 `javascript:`、`vbscript:`、`data:` 协议；显示文字全部 HTML 转义。
- 书签改为真实实现：写入与 DOCX 读写路径一致的零宽标记；空名称、超长、重名分别给出中文原因。
- `default` 分支改为明确的「尚未接入」提示。
- 删除 `提示不可用插入项` 函数。

相关实现集中在 `renderer/src/editor/inserts.ts`（`insertHyperlink`、`insertBookmark`、`insertField`）。

**验证**：`renderer/src/editor/linkAndBookmark.test.ts` 9 项通过。

## 五、防复发记录：云空间不可用

**根因**：宝塔面板建站时对站点根目录执行 `chown -R www:www`，把 `data/` 与 `seal.sqlite` 属主一并改成 `www:www`。而服务以 `User=seal-cloud` 运行，对数据库失去写权限。

读操作在进程启动时已加载进内存，因此 `capabilities` 等只读接口仍返回 200，掩盖了故障；一旦写操作（列目录更新访问时间、创建分享链接、重命名、移动）就失败，前端统一显示「服务暂时不可用」。

**修复**：

```
chown -R seal-cloud:seal-cloud data
chmod 700 data
find data -type f -exec chmod 600 {} \;
find data -mindepth 1 -type d -exec chmod 700 {} \;
chown -R seal-cloud:seal-cloud account-erasure
```

**风险提示**：宝塔每次建站或修改站点设置都会重跑 `chown -R www:www`。`data/` 放在站点根目录下会持续被波及。建议移出站点根（如 `/www/seal-cloud-data/`）并同步 systemd unit 的 `ReadWriteDirectories`，但涉及数据迁移，需明确授权后执行。
