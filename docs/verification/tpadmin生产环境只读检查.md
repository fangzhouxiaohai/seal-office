# 管理后台迁移前生产环境只读检查

2026 年 11 月 14 日补充：后台已迁移至独立 PHP 服务与 Vue 3 管理界面，并根据原框架重新调整为浅色侧栏、绿色主题和仪表盘式首页。生产登录、菜单和真实概览接口已验证；完整功能仍以本轮后续验收记录为准。本文件以下为迁移前检查记录。

本次只读取服务器进程、PHP-FPM 池及站点 Nginx 扩展中的非敏感字段，没有修改配置、进程或业务数据。

- 运行中的 PHP 8.2 FPM 主配置为 `/www/server/php/82/etc/php-fpm.conf`，监听 `/tmp/php-cgi-82.sock`，进程及 socket 用户组为 `www:www`，socket 模式为 `0666`。
- 主池 `request_terminate_timeout = 100` 秒；本次 PHP 适配层真实转换测试上游超时为 200 秒，直接复用此池会使长任务过早中止。可通过独立 FPM 池或独立实例使用专用套接字和覆盖完整业务时长的终止设置，再按实际业务进行验证；不能为此擅自修改共享池影响其他站点。
- 站点扩展目录中当前没有 `/seal-admin/` 路由。既有扩展包含 `/api/v1/admin/release-assets`、`/api/v1/release-assets/`、`/office/`、`/api/`、分享页和后台静态资源路由；新增路由不得改变这些地址的既有含义。
- 新候选已使用独立 Nginx、PHP 8.2 FPM、Unix 套接字与回环模拟上游进行隔离验证，结果和被验证的源码摘要见 [隔离验收](tpadmin-fpm隔离验收.json)。该结果不代表生产配置已部署或通过生产验收。
