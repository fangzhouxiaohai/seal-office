# 管理后台迁移验收清单

本文根据既有海豹办公管理后台、服务端和部署配置整理，供新后台开发、隔离验证及上线检查使用。未标记的项目不代表已经通过。

## 原有功能基线

| 区域 | 应保留的能力 |
| --- | --- |
| 登录与会话 | 管理员密码登录；错误与限流提示；八小时会话有效期；退出或接口返回 401 后清除本地令牌、审核内容和敏感状态；未登录不能读取或调用管理接口 |
| 运行概览 | 账号数量、空间用量、待审核数、服务器剩余空间和进程内存、上传数量与配额、短信配置及发送量；失败时显示实际错误 |
| 账号与用量 | 手机号脱敏、账号启停状态、用量、注册和最后操作时间；搜索、排序及分页，不暴露私有文件正文 |
| 三类公开内容审核 | 演示模板、知识内容、皮肤分别查看；标题及状态筛选、公开内容预览和原文件下载；通过、拒绝与撤回动作及对应状态约束；异步结果不串入已关闭或已切换的审核弹窗 |
| 操作记录 | 账号脱敏、操作名称与详情中文展示、关键字和动作筛选、分页；明确只显示最近 200 条 |
| 文档转换 | 状态、启停、并发数、测试、最近任务和筛选；令牌创建或重置前确认，只显示一次，关闭或离开后清除；连接失败或登录过期不得显示成功 |
| 版本管理 | 分组列表、状态统计、版本及平台筛选；大弹窗按需发布 Windows 安装版、商店版、macOS、Ubuntu、Web、Android、HarmonyOS；版本号、文件名和附件摘要校验；强制更新二次确认；各平台上架、下架、删除确认和批量发布的原子性 |

## 隔离验证

- 使用隔离服务和新建测试数据，不修改生产账号、已有审核、历史发布或原始附件。分别验证有效、错误、过期及伪造管理员令牌；直接访问管理接口也必须由现有业务服务执行授权检查，不能只依靠前端路由或页面隐藏按钮。
- 逐页验证列表、搜索、分页、空状态、失败提示和操作结果；覆盖审核弹窗、下载及其取消/关闭，转换设置和令牌一次性显示，版本弹窗焦点及狭窄屏幕布局。
- 版本附件上传使用 `application/octet-stream`、准确的 `Content-Length`；验证超过普通接口限制的上传、平台/文件名不匹配、重复平台、跨版本附件绑定、无效令牌、断连与中途取消，确认失败不会留下正式附件或发布记录。保持 `server/deploy/nginx-release-assets.conf` 中 1 GiB 上限、流式请求、超时与下载 Range 行为。
- 若设计把大文件流经 PHP，必须用与正式 MSIX 量级相当的受控文件测试代理全链路的内存、请求体限制、超时、断连清理以及服务端字节数和摘要；单纯的小文件成功不足以证明该路径可靠。若沿用现有精确路由，仍需核对新页面实际请求路径、认证令牌及断连行为。
- 避免隐式复用旧版构建清单：构建记录必须绑定实际使用的框架源码、项目覆盖文件和最终产物；遍历入口引用资源并核对摘要，检查产物不包含凭据、测试数据或不必要的默认管理功能。
- 回归公网公开的各平台更新查询和已发布附件的 HEAD、首尾 Range；Web `/office/`、匿名分享 `/share/` 和客户端 `/api/` 路由必须保持可用且不被新管理站点的路由覆盖。

## 部署与回滚门槛

1. 只读记录当前管理后台目录及入口摘要、后端服务指针、PHP 发布路径、站点及扩展配置的文件内容摘要和所有权；检查磁盘空间、PHP 8.2 扩展及候选路由冲突。
2. 以唯一目录上传候选前后端并在独立地址或本机隔离端口验证；对原始配置分别做私有备份，记录原文件不存在的情况。实际使用的服务器数据和应用密钥不能进入公开仓库或测试日志。
3. 上线按准备好的切换顺序设置 PHP 路径、Nginx 规则和后台静态目录；每一步失败都应有明确恢复动作，保持原 Node 服务、业务数据及客户端路由不变。Nginx 配置先执行语法检查，再重载。
4. 对正式地址验证首页及全部入口资源摘要、实际登录和只读页面、未授权访问、旧版更新查询及附件分段下载。不要在正式环境生成用于测试的发布记录或修改存量业务数据。
5. 至少在隔离环境演练静态目录、PHP 路径和 Nginx 配置任一阶段失败时的恢复，并确认恢复后旧管理后台、原公开 Web 与客户端接口均可访问。原 `scripts/deploy-server.cjs --rollback` 仅切回 Node 后端，不能视作这三部分的完整回滚方案。
