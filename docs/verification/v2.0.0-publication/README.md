# 2.0.0 仓库发行验收

本记录补充用户于 2026-10-19 提供的真实 Android APK 与 HarmonyOS 签名 App Pack，不改写第五轮及此前验收历史。

- [原生包验收](native-packages.json)：Android SDK、华为 SDK 验签、全部编辑器资源对照、原始字节和 AppGallery 发行范围。
- [应用源码冻结清单](source-inputs.json)：第五轮 1514 文件，本次逐项重算 SHA-256，一致。
- [微软商店包验收](msix.json)：2.0.0.0、既有商店身份与显示名、CRC、逐块 SHA-256 和已验收 Windows 构建一致性。
- [发行说明](../../v2.0.0-发布与移动成品.md)：下载、构建信息差异和未执行的真机验收。

鸿蒙 APP 的内层 HAP 没有独立签名，不能作为直接安装包发布。APP 内唯一差异是描述性 `build-info.json` 的 Android 平台标签；27 个实际运行资源完全匹配 Harmony 快照，原生外壳在运行时注入鸿蒙平台。已签名 APP 保持原始字节，仅外加 ZIP 方便仓库分发。

1514 个冻结输入含 1127 个仓库源码及发行脚本 / 配置文件、387 个按既有规则忽略的后台上游依赖和构建输出。后台源码按 [来源记录](../../../server/admin/PROVENANCE.md)固定上游提交构建，原始依赖目录和 `dist` 不强行加入 Git；全部 1514 个本机输入均复核哈希。源码发行 ZIP 补入两平台云打包快照及实际 Android 内置资源，生成物与 Git 源码分别标明。
