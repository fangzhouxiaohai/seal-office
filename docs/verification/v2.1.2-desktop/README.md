# 2.1.2 桌面修复与发行验收

本次按本地升级记录及用户提供的 BIFF XLS 样本修复桌面编辑问题，保留原 UI、账号与应用身份。版本仍为 2.1.2。原始升级文档及用户工作簿不随仓库或发行附件公开。

## 修复内容

| 问题 | 最终行为 | 验证方式 |
| --- | --- | --- |
| 表格内容被窄列遮挡 | 「开始 → 编辑 → 自适应列宽」按当前工作表的显示文本、字体、富文本分段和换行测量；空列保留，跨列合并标题不撑宽数据列；支持撤销、保存、快捷键自定义和英文界面 | 单元测试、真实 Chromium 点击功能区、XLSX 保存重开 |
| 文字正文无法直接粘贴、拖入图片 | 在正文插入 PNG/JPEG/GIF/BMP 文件图片，验证实际图片字节并按正文宽度缩放；支持多图、撤销重做和 SLDOC 保存重开 | 组件集成测试与真实浏览器图片解码、粘贴、拖入 |
| 桌面助手入口需要可移动圆球 | 使用海豹图标圆形悬浮球；鼠标拖动、方向键移动、位置记忆、窗口边界限制；保留现有助手抽屉 | 组件测试和 Chromium 实际鼠标输入 |
| 合法 XLS 文件出现五条兼容警告 | 导入/导出保留富文本、字体元数据、自定义六项页边距；识别默认对齐与无操作对齐属性，避免误报 | 原始 XLS → 随包转换引擎 → XLSX → 实际编辑模型 → 编辑 → XLS 保存 → 重开 |

XLS 样本中的两个工作表（含空表）、中文内容、合并区域、可见字体和页边距均经过断言。旧 BIFF 字符集提示在转换时可能被引擎规范化；测试验证 Unicode 文字和可见字体属性，另用 XLSX 合成样本验证字符集元数据的精确保留。没有据此宣称所有第三方 Office 对象均可无损往返；未支持的对象继续明确提示。

## 证据

最终全量回归为前端 283 个文件、2,619 项通过，主进程 111 个文件、1,089 项通过，服务端 46 项、移动公共逻辑 36 项、打包逻辑 11 项通过，共 3,801 项常规测试通过。需要私有本机路径的 XLS 测试在通用全量运行中条件跳过，另设置 `SEAL_XLS_SAMPLE` 后执行该文件，2 项测试全部通过（其中 1 项为重复验证的合成样本）。最终全量运行没有失败或未处理错误。

Windows unpacked 与便携版各三轮、共 128 项成品检查通过；Ubuntu 22.04、24.04 的实际安装包各通过 77 项检查；生产浏览器 6 组、41 项通过。TypeScript 检查和移动源码检查也通过。

- `verification.json`：最终回归、构建与成品验收汇总；初次失败及修复记录保留在汇总中。
- `unit-regression.json`：全量测试结果和本机原始日志 SHA-256。
- `desktop-ui.json`、四张 PNG：真实 Chromium 图片插入、列宽和悬浮球交互。
- `xls-user-sample.json`：用户样本校验值、编辑保存路径与数据范围；不包含原文件内容。
- `packaged-codecs.json`：最终 Windows app.asar 内的文字、表格、演示、PDF 及四种专属格式往返。
- `windows-asar.json`：139 项内部完整性记录与最终工作区构建逐字节一致，测试样本和 WPS 二进制未混入程序。
- `windows-runtime.json`：隔离用户目录与隔离注册表分支中的启动、重复启动、确认阶段；不覆盖用户文件关联。
- `windows-nsis.json`：提取 EXE 内部载荷并逐文件对照运行验收的 Windows 目录；未执行安装器。
- `msix.json`：商店身份、版本、关联后缀、CRC、分块哈希及 app.asar 与 Windows 成品一致性；未安装未签名 MSIX。
- `linux-deb.json`、`ubuntu-22.04.json`、`ubuntu-24.04.json`：GitHub CI 原生构建及两套 Ubuntu 的实际安装运行，发行 DEB 与两份报告的 SHA-256 一致。
- `web-browser.json`：生产 Web 构建中的 41 项分组检查；本次没有部署替换线上网页。
- `promo.json`：本版 PC 横版和 Android 竖版介绍视频的构建来源、画幅、解码、音轨、字幕与画面核验。
- `source-inputs.json`：参与本次构建的已提交源码指纹。
- `mobile-snapshots-preserved.json`：此前分别冻结的 Android/Harmony 云源码 ZIP 保持原校验值。
- `ci-environment.json`：首次 Ubuntu 24.04 软件源下载超时及 CI 下载源修复记录。

## 发行范围与限制

桌面交付 Windows x64 EXE 安装版、便携版、Microsoft Store MSIX，以及 Ubuntu amd64 DEB，均位于 `release/v2.1.2/`，文件名统一为英文 `seal-office` 前缀。MSIX 保留商店身份和名称 `seal-office`，版本为 `2.1.2.0`，作为 Partner Center 上传包；Windows EXE 未添加发行证书签名。

Android/Harmony 的 2.1.2 云打包源码保持此前独立冻结的资源，不把本次桌面产物当作新的 APK/HAP。Android 视频使用此前已冻结的 Android 生产资源，以手机尺寸在隔离浏览器中展示，不宣称是 APK 真机录像。PC 视频使用本次生产 Web 构建展示实际 UI。两条视频为界面画面加配音的介绍片。

便携版包含离线兼容引擎，首次解压体积较大。验收允许最多 600 秒准备调试入口、120 秒清理退出临时载荷；功能断言与 UI 操作时限保持不变。这些等待上限属于测试包装器，不表示日常编辑操作需要相同时长。
