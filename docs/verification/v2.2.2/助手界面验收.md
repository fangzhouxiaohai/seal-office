## 设计调整

- 标题栏只保留品牌标识、名称和图标操作：新对话、模型设置、收起。去除重复的“文件对话”副标题和文字按钮。
- 会话正文不再套用带“TXT”“Markdown”标题的卡片；纯文本和 Markdown 直接按正文排版，仅代码块保留带复制操作的独立面板。复制入口保留为图标，默认降低不透明度，悬停或键盘聚焦时增强。
- 输入区合并为单一圆角卡片，聚焦时使用品牌色描边和浅色光晕；输入框无边框，底部左侧显示“自动应用/修改需确认/只读问答”状态和快捷键提示，右侧只保留停止和发送图标。
- 当前范围压缩为一行文件信息；移动端继续保留目标文件选择，对话/工作模式和模式说明改为图标按钮并保留中文可访问名称。
- 所有助手操作按钮只保留图标，包括发送、加入队列、停止生成、应用修改、放弃修改、分页、复制、执行计划、队列返回/引导/移除/重试/暂停、设置保存/清除/高级设置。每个按钮都提供 `aria-label` 和中文 `title`，不留下无名称的图标。
- 助手设置新增“自动确认修改”开关，默认开启；关闭后恢复先预览再应用。“回车键发送消息”开关默认关闭，关闭时 Enter 换行、Ctrl+Enter 发送；开启后 Enter 发送、Shift+Enter 换行。两个选择写入本机存储，随时可改。
- 品牌色统一为产品蓝，移除原来的紫色悬浮球渐变和紫色头像。发送按钮禁用时改为中性底色和可读文字，避免低对比度。
- 深色主题同步修正输入占位文字对比度；浅色与深色均使用现有设计令牌。

参考图来自用户提供的对话面板截图，仅借鉴信息层级、圆角卡片、图标操作和输入区结构，不复制其品牌、文案或配色。

`npx electron scripts/verify-assistant-flow.cjs` 使用真实组件和隔离桥接，依次验证文字、表格、演示、PDF 在浅色和深色下共 8 组场景，全部通过。覆盖标题栏操作、首次配置、计划折叠、工具执行行、任务队列、补充引导、完成后清理和抽屉宽度。本次仅更新该脚本的假桥接，使其提供已完成身份核验的合成账号；没有放宽产品侧身份校验。移动端生产构建的 7 组浏览器回归另行记录在 Web 验收中。

## 限制

- 以上为浏览器内核渲染，不是 APK、HAP 或真机截图；移动端系统字体、输入法和安全区仍需在目标设备复验。
- 自动确认默认开启，AI 修改会直接写入当前文件；仅在目标文件仍是当前文件时生效，切换文件后自动退回预览。关闭开关后与旧版一致，先预览再应用。该行为不代表模型建议必然正确，编辑器的撤销和保存前检查仍然适用。
- 图标按钮只保留图形，中文名称通过 `aria-label`、`title` 和可访问名称提供；触屏用户需依赖图标含义或长按提示，未额外放置无响应的文字占位。
- 参考图中的附件回形针、光标位置标签等入口本次没有实现，因为没有对应的产品能力；界面未放置无响应的占位按钮。
- 审计覆盖当前合成会话；超长回复、代码块、表格和任务队列继续使用原有组件，未改变其功能语义。
- 未调用真实模型，不代表模型输出质量或网络错误处理通过；相关行为由现有单元测试和真实服务验收单独覆盖。
