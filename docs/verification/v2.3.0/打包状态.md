## 打印链路对比

用同一份 3 页 PDF 在 Electron 隐藏窗口里分别走旧、新两种打印方式，并用 `printToPDF` 捕获 Chromium 打印管线的实际输出：

| 方式 | 输出 | 结论 |
| --- | --- | --- |
| 旧：隐藏窗口加载 PDF 后直接打印 | 1 页、1,013 字节，只有查看器的深色背景，没有任何文档内容 | 复现“打印出来是空白” |
| 新：逐页渲染为图片 HTML 后打印 | 3 页、与源 PDF 页数一致，文字、表格、底色完整 | 修复 |

首次实测新方案时每页后多出一张空白页（3 页变 6 页），原因是打印块与纸张恰好等高，被 Chromium 分页取整推到下一页；已改为比纸张矮 1pt 并加上禁止页内分割，复测为 3 页。
