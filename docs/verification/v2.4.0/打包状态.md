## Android 体积

首次归档 Android 源码为 60,103,972 字节，超出上限。原因是桌面专用的视频预览渲染器在编译期被剔除后，Vite 仍输出了未被引用的 `mp4v-decoder-*.wasm`（111,379 字节）。`mobile/scripts/build.mjs` 改为在原生平台构建后删除脚本、页面和样式都不引用的 `assets/` 文件，重新构建后为 59,992,409 字节（余量 7,591 字节），后续新增移动资源时需要优先关注。
