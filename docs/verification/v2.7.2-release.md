## Android 保存与恢复

使用本轮新建模拟器副本，没有覆盖用户日常模拟器。2.7.1 同签名覆盖至最终 2.7.2 后，原测试文件字节、已编辑正文和语言设置均保留。

一次测试在普通保存后仅等待 500 至 800 毫秒便强停，恢复后触发文件指纹冲突保护。工作区备份延迟为 1,500 毫秒，该时序与陈旧恢复指纹吻合；未直接读取冲突发生时的内部指纹，不将推断写成直接取证。应用明确阻止覆盖并保留正文。另存新测试文件后解包核对正文，再次普通保存提示成功，充分等待落盘后强停重开，新增正文完整保留。

普通保存写入应用文档空间，系统另存生成外部副本。正式包手工验证与同资源调试包的原生自动验证分别记录，不声称完成手机真机验收。
