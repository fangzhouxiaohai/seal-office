# 2.7.2 更新交互调整与验收

普通更新在右下角提供更新入口。桌面下载可切换后台，下载完成后由用户选择安装；强制更新自动开始下载并尝试启动安装。安卓普通更新支持后台服务和通知，前台下载完成后尝试启动系统安装程序；应用处于系统后台时，由于 Android 对后台启动界面的限制，需点击完成通知继续安装。强制更新不可取消，失败时保留重试入口。

鸿蒙通过应用市场接口检查并打开系统更新界面。市场未提供应用内真实下载进度与安装完成回调，不能把显示市场界面当作安装完成。工作源码与鸿蒙交付源码的市场桥接已同步，仍需以新构建 HAP 和设备上的实测为准。

安卓隔离模拟器已验证前台服务、通知权限、后台存活、待授权取消、伪造发布拒绝及失败状态重启恢复；原生单元测试和调试构建通过。调试构建跳过网页资源同步，真实同签名 APK 的下载、安装器与覆盖安装尚未验收，不能作为正式成品。

华为开发者中心当前待提交版本为 2.7.1，已关联的隐私政策正文包含拍照用途，但设备权限调用模块缺少“添加权限及使用说明”入口，尚不能完成相机权限结构化声明及审核提交。华为[配置指南](https://developer.huawei.com/consumer/cn/doc/App/agc-help-privacy-policy-app-0000002282162168/)要求声明的权限与软件包一致。

已安装 2.7.2 的旧客户端不会因同版本修订自动发现更新，需手动安装本轮经过验收的修订包；正式发布状态以实际发布记录为准。
