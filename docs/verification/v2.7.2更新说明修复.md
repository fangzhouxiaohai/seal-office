# 2.7.2 更新说明修复记录

## 问题与处理

旧客户端将服务器提供的更新说明直接作为普通文本显示，Markdown 标题和列表标记会原样出现在更新卡片中。新版客户端使用 Markdown 解析显示标题、列表、强调和普通文本，保留标点及单换行；不渲染原始 HTML，也不将更新说明内的链接作为可点击入口。

已经安装的旧客户端在下载安装新版之前仍使用原显示逻辑，因此后台本轮创建的六条 2.7.2 稳定版记录的说明已由同一份 Markdown 生成可读纯文本，并经匿名更新查询逐平台验证；除说明外，版本号、附件、摘要和上下架状态未变。原记录已保存在本机私有备份中。发行页的 Markdown 原文不因兼容处理改变。

本次应用版本仍为 2.7.2。更新查询比较版本号，已经安装 2.7.2 的客户端不会因为同版本修复包重新提示更新，需要手动下载安装修复包；不得将这一情况描述为自动升级成功。
