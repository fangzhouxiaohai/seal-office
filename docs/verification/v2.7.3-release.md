## 三、PDF 清晰度实测

方法：用正式导出链路 `main/pdfExport.js` 的 `createPdfFromHtml` 在 Electron 25.9.8 中生成 PDF，再解析文件结构。

| 项 | 实测值 |
| --- | --- |
| 页面 | 1 页，MediaBox 594.96 × 841.92pt（A4） |
| 位图 | 0 个 `/Subtype /Image` |
| 字体 | 内嵌 `MicrosoftYaHei`、`MicrosoftYaHei-Bold` 子集（CIDFontType2 / Type0，2 个 FontFile2） |
| 正文版心 | 174 × 257mm（A4 减 18mm 左右、20mm 上下边距） |
| 文字 | 矢量文字（内容流为 Tj/TJ 文本操作，字号 22 / 14） |

结论：导出 PDF 为矢量文字并内嵌字体，不存在整页位图；此前“模糊”来自导出 HTML 缺少基础样式（浏览器默认 16px 衬线体、无行距与段距）以及字体未就绪就打印。
