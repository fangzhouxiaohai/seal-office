## 三、超大 PDF 实测

样本：`新疆聚百果ERP管理系统.pdf`，2,354,623 字节，单页 3117×38572 点，页面由一张 3117×38572 的 Flate RGB 位图（另有灰度透明蒙版）构成。

| 项 | 结果 |
| --- | --- |
| 失败原因 | Chromium 位图单边上限 32767 像素，原图高 38572 无法解码，页面只剩白底 |
| 优化耗时 | 约 1.9 秒（渲染进程内） |
| 位图变化 | 3117×38572 → 623×7714（整数因子 5 的盒式平均） |
| 文件大小 | 2.35 MB → 0.39 MB |
| 优化后 Chromium 渲染 | 约 1.4 秒完成，抽样区域非白像素 128,074，画面有内容 |
| 未优化原文渲染 | 默认参数下超过 120 秒未完成，画面空白；兼容参数下需约 35 秒 |
| 常规 PDF | 不触发优化，原样返回，页面尺寸与内容不变 |
