## 三、修复说明

- 更新入口原先浮动在 `bottom: 8px`，按钮高 32px，而底部状态栏仅 28px，按钮上沿超出 12px 压住版本号。现按钮高度 22px、`bottom: 3px`、圆角 11px，完全落在状态栏内；移动端入口不变。
- 更新检查原先用 Node `fetch`，不读取系统代理与系统证书库；开启系统代理或企业根证书的电脑上云同步正常但更新检查失败。现改用 Electron `net.fetch`（Chromium 网络栈），并在首次失败后等待 600ms 重试一次，用户取消时不重试。
