## 三、超大 PDF 清晰度实测

样本：`新疆聚百果ERP管理系统.pdf`，2,354,623 字节，单页 3117×38572 点，整页为一张 3117×38572 的 Flate RGB 位图（含灰度透明蒙版）。

| 项 | 2.7.5 | 2.7.6 |
| --- | --- | --- |
| 优化后位图 | 623×7714 | 1558×19286 |
| 优化耗时 | 约 1.9 秒 | 约 3.1 秒（之后命中缓存） |
| 优化后文件 | 0.39 MB | 约 1.33 MB |
| 175% 缩放画布 | 约 1135 宽（被 1600 万上限压缩后拉伸） | 1575×19491（按 3200 万上限 1:1 渲染） |
| 画面 | 文字模糊难辨 | 裁切图核对“日期查询、关键词查询、单据号查询、状态查询”等清晰可辨 |

验证方法：用 esbuild 把渲染层优化模块打包为 Node 脚本处理真实文件，再用 Electron（Chromium 114）按 1575 像素宽渲染整页，裁切 1575×560 画面人工核对。

## 四、桌面端更新入口

| 场景 | 结果 |
| --- | --- |
| 点击“更新” | 不弹窗口，入口立即变为进度环，后台下载 |
| 下载中 | 进度环显示百分比；总大小未知显示不确定动画；点击可打开进度窗口 |
| 下载完成 | 同一位置变为“安装”，点击启动安装程序 |
| 未点安装就退出 | 下次启动按 `恢复下载状态` 的原有逻辑自动安装已下载版本 |
| 运行期每 4 小时检查 | 已下载版本与最新一致时保持“安装”；发现更高版本时回到“更新”，可下载新版本 |
| 下载失败 | 显示“重试更新”，无需重新检查更新 |
| 下载前二次核对网络失败 | 继续下载，完成后仍按 sha256 与字节数校验 |
