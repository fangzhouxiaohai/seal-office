# 海豹办公 2.7.8 发行验收

## 发布与部署

- GitHub 和 GitCode 均已接收 `main` 和 `v2.7.8`。发行附件包括 Windows NSIS、微软商店 MSIX、Ubuntu DEB、Apple 芯片与 Intel 两款 DMG、Android APK、HarmonyOS HAP、Web ZIP 和 `SHA256SUMS.txt`。九个附件的 GitHub 摘要与本机一致，GitCode 匿名下载的全部字节也通过 SHA-256 校验。 [GitHub](https://github.com/fangzhouxiaohai/seal-office/releases/tag/v2.7.8) · [GitCode](https://gitcode.com/gcw_pGfMiWVg/seal-office/releases/v2.7.8)
- 云服务 2.7.8 已部署。公网能力接口返回 `keyRecovery: 1` 和 `sms: true`。迁移、自动解锁及短信恢复使用隔离账号验证。已迁移账号恢复后可读取历史密文。未迁移的旧账号仍需旧密钥或已解锁设备。 [能力接口](https://seal.xingmasoft.com/api/v1/capabilities)
- Web 公网核对 528 个发行文件的摘要，文稿、模板、项目三组浏览器检查通过。手机宽度 390px 与桌面宽度 1280px 的本地构建另行验证了登录、自动解锁及 DOCX、XLSX、PPTX 导入、导出和重开。 [在线办公](https://seal.xingmasoft.com/office/)
- 官网已更新 Windows、Ubuntu、macOS、Android 与 HarmonyOS 的下载链接。两款 Mac 下载入口通过公网检查，官网标注了临时签名及公证状态。 [官网下载](https://seal.xingmasoft.com/#downloads)
- 客户端内的 2.7.8 更新记录待发布。本机发布脚本的预检已通过，线上 2.7.7 更新查询仍返回无新版本。发布需要在本机 `.upgrade-private/admin-access.json` 配置拥有版本管理发布权限的账号。
