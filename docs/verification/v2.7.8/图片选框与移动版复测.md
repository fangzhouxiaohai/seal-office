# 2.7.8 同版本修复验收

Mac 上用含 16 张图片的用户 DOCX 验证。Retina 显示倍率为 2，页面缩放为 100% 时首张图片实际宽 514 CSS 像素，修复前选框为 1028，修复后为 514。滚动至前两张图片，在 75%、100%、150% 页面缩放下分别选中并测量；对应选框宽度为 385.5、514、771。图片编辑测试共 18 项通过。

ARM64 应用在 Apple 芯片上运行，Intel 应用在 Rosetta 下运行。两个架构及后台通用应用均通过签名校验、启动、原生图形加载、DOCX 打开和转换成 PDF 的检查。Mac 使用本机临时签名，未进行 Apple Developer ID 签名与公证。

HarmonyOS 使用正式 SDK 构建，分别验签 App Pack 与 HAP，内嵌 HAP 与独立 HAP 字节一致。Mate 90 Pro 鸿蒙模拟器覆盖安装最终 HAP，使用系统文件选择器导入测试 PNG，扫描页显示图像及一页审阅结果；导入合成 WAV 后转写页显示文件名与服务设置，授予麦克风权限后开始并结束录音，得到 M4A 文件。实际外部模型返回识别文字仍未验收。

安卓 Java 工程通过 Gradle 单元测试、Release APK 构建、包身份和原证书指纹校验。本轮按用户要求以鸿蒙模拟器的结果作为移动功能验收依据。原生文件选择、扫描、音频通道共 10 项测试通过，包括在系统选择器中等待四分钟再返回文件。

官网四个入口均按匿名下载的完整文件比对 SHA-256。后台三个平台分别检查了匿名下载、2.7.7 的可用更新和 2.7.8 的已是最新响应。旧的 2.7.8 安装需要从官网重新下载覆盖安装。AppGallery 上架用 App Pack 保存在本机发行目录。
