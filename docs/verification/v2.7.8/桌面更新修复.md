# 2.7.8 桌面更新修复验收

2026 年 11 月 22 日，在本机已安装的 Windows 2.7.7 和首次发布的 Windows 2.7.8 安装包中均复现了 `path is not defined`。2.7.7 查询稳定通道时能查到 2.7.8；点击后，主进程在初始化更新暂存目录时访问了未导入的 `path` 模块，下载请求数为零。

本机安装的 2.7.7 对应 11 月 19 日重发的 Windows 包。其更新通道与首发 2.7.8 的代码按相同换行符计算，SHA-256 均为 `7447e75653ca36a51f15e720063d7da9c2743acb6550c98e98abb6f54f54f705`。首发 2.7.8 的 Ubuntu 与 macOS 安装包也包含同一缺陷。

## 修复与升级方式

桌面更新通道显式加载路径模块。下载前的版本复查使用内置 Electron 25.9.8、Node 18.15.0 支持的请求取消与超时机制。安装包继续按后台登记的字节数和 SHA-256 校验，校验成功后才能安装。

遇到此弹窗的用户，请保存文件、退出程序，从官网按原平台下载 2.7.8 并覆盖安装一次。Windows 使用普通安装版，Ubuntu 使用 amd64 DEB，Mac 按“关于本机”显示的芯片选择安装包。已安装首发 2.7.8 的用户也可用这一步换成修订包；两者使用相同版本号，后台对 2.7.8 返回已是最新。[官网下载](https://seal.xingmasoft.com/#downloads)
