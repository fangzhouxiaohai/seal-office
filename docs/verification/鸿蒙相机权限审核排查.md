# 鸿蒙相机权限审核排查

## 提示含义

用户提供的开发者中心截图显示：待提交版本为 2.7.1，系统提示“只在软件包中的权限：[CAMERA]”。这表示平台检测到软件包包含用户授权类型的相机权限，但当前关联的隐私声明中未检测到对应的权限声明。截图中增加的是“我们如何收集和使用您的个人信息”正文；仅增加该正文并不能证明“设备权限调用”模块已声明相机。

华为官方对同一提示的排查要求，是核对软件包权限与隐私政策“设备权限调用”模块；需要该权限时在该模块补充对应权限和用途，并检查提交审核页面实际关联的协议。参见[华为审核问题说明](https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/appgallery-kit-faq-0013/)及[华为隐私政策配置指南](https://developer.huawei.com/consumer/cn/doc/App/agc-help-privacy-policy-app-0000002282162168/)。

## 已核对的实际用途与版本

- 2.7.1 标签的 `mobile/harmony-configs/entry/src/main/module.json5` 声明 `ohos.permission.CAMERA`；权限用途资源为“用于拍摄文档与单据，生成扫描件或识别为表格；拒绝后仍可从相册或文件导入”。截图也显示待审软件包含 CAMERA。本次未取得开发者中心当前上传的 2.7.1 包字节，不能将源码检查等同于对该包实物验包。
- 已读取本机 `release/v2.7.2/seal-office-2.7.2-harmony.hap` 和 App Pack 内的 HAP 实物 `module.json`：两者包名均为 `com.sealoffice.mobile`、版本均为 2.7.2，均声明 INTERNET、PRINT 和 CAMERA；相机用途引用 `seal_camera_reason`。这只证明本机 2.7.2 成品，不证明截图所示 2.7.1 已在开发者中心替换为 2.7.2。
- `mobile/pages/workspace/workspace.uvue` 的拍照流程在用户使用对应功能时申请相机权限，授权后调起相机读取拍摄图片；拒绝时提示可改用相册或文件导入。因此不能为了消除提示直接删除相机权限而保留原拍照功能。
- 用户补充截图显示 2.7.1 版本页“应用隐私说明”已识别相机并自动显示使用理由，页面提示默认存在理由时无需填写；这证明平台已识别待审包中的相机权限及理由，不等于所选隐私政策的权限列表已匹配。
- 按用户提供的[华为声明权限文档](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/declare-permissions-V5)，代码已声明 `name`、字符串资源形式的 `reason` 和 `usedScene`。当前理由未以句号结尾，不符合该文档的文案规范，但未取得证据证明它是此次“权限与隐私政策不一致”提示的原因；更改资源需重新构建、签名和提交安装包，不能改变已上传包。

## 在开发者中心修正

1. 确认当前选择的应用是 `com.sealoffice.mobile`，并明确本次提交的是截图中的 2.7.1 还是另行上传的 2.7.2；查看版本页面选中的“隐私政策”名称。
2. 打开左侧“协议服务”，编辑该版本实际选用的隐私政策。华为手册显示“设备权限调用”模块正常应有“添加权限及使用说明”，选择相机并填写用途。但用户补充截图显示该模块已展开且为空，实际没有该按钮，当前无法照手册操作。可以先确认编辑的是版本选中的同一协议，保存未完成的文字后重新进入该协议，并尝试另一浏览器排除页面加载问题；若仍无入口，向华为开发者支持提交截图和应用、版本信息排查，不把页面缺陷当作已解决。若按钮恢复，可填写与实际代码一致的表述：

   > 用于拍摄文档与单据，生成扫描件或识别为表格；拒绝后仍可从相册或文件导入。

3. 预览协议，确认“设备权限调用”中出现相机及用途，并对照当前待审软件包列出的其他用户授权权限，保持两边一致。不要把正文中“图片或视频”这一数据项误当作相机权限的结构化声明。
4. 按页面要求保存并生成或提交协议。华为说明：与在架版本关联的隐私政策修改需审核，通过后修改才生效；未关联在架版本的协议按页面生成。返回待审版本页面，确认选择的是更新后已生效的政策，重新查看权限列表后再提交版本审核。
5. 若仍提示不一致，按官方指引核对当前应用、包名、待审版本、软件包和已生效协议；再查看版本页面列举的权限，以及其他模块或第三方包引入的权限，必要时向华为提交工单。不要先删权限或重新打包来掩盖不一致。

截图中“是否涉及个人信息收集”选择了“否”，而协议正文写有收集图片或视频。该选项及正文还应由应用实际数据处理情况决定：拍摄图片可能包含个人信息，是否发生传输、保存或其他处理取决于用户使用的具体功能。当前排查不足以认定全部场景均不收集、均不上传或均只保存在本地，应核实后如实填写。

本排查未修改开发者中心协议，未提交协议或应用审核。
