# 海豹办公下一版云端与知识库升级计划

拟作为 1.9.0 的产品范围。现有本地文字、表格、演示和 PDF 编辑继续允许免登录使用；本次增加账号、云空间、云文档自动保存、PPT 市场和知识库。桌面端通过 HTTPS 调用服务端 API。私有云空间和云文档自动保存分别由用户主动开启；公开分享和 AI 对话分别取得相应授权。以下阶段以验收门槛推进，不把尚未接入的在线功能做成可点击的空入口。

## 三、账号、服务端与空间设计

1. **两种连接方式。** 默认连接海豹办公运营的服务；管理员可在设置中填写自己的 HTTPS 服务地址，完成服务版本与能力检查后切换。自建服务使用同一 API 协议和部署说明。服务端地址会被网络连接和安装包分析看到，因此不能承诺“客户端内置服务器信息完全不可见”；真正需要保密的是 SSH 凭据、短信密钥、数据库密码和 AI 密钥，它们只保存在服务端。用户提供的主机凭据不得写入仓库、安装包、日志或升级文档。
2. **手机号登录。** 服务端接入可配置短信供应商，验证码短时有效、一次使用，并限制发送频率、验证次数及同一设备和 IP 的异常请求；会话可主动退出和撤销。管理员与普通用户分权。短信登录的高风险操作增加二次确认，并预留更强的验证方式。设计依据：[OWASP 身份验证建议](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html)、[OWASP 多因素验证建议](https://cheatsheetseries.owasp.org/cheatsheets/Multifactor_Authentication_Cheat_Sheet.html)。
3. **300 MB 是实际存储配额。** 每个账号默认上限为 300 MB（300,000,000 字节），由服务端按实际占用的密文字节数执行硬限制。当前文件、历史版本、回收站对象、用户发布的公开副本和加密索引都计入该账号用量；目录记录及其他必要元数据由服务端另行预留。客户端上传前展示预计占用，服务端在接收与提交时核算并原子限制并发上传，超额时拒绝新数据但保留本地编辑，用户可以删除文件或清空回收站释放配额。服务端不能验证客户端申报的明文大小，因此不以它作为计费依据。加密文件不承诺跨账号明文哈希去重；真实磁盘仍须另外容纳数据库、临时上传、备份和运行冗余，按活跃用户数与增长量规划。普通删除进入有期限的回收站，未彻底清除前继续占用配额。
4. **服务组成。** Electron 客户端只持有短期用户会话；API 服务处理认证、最小化元数据、权限和配额；数据库保存账号与加密对象记录；对象存储保存私有文件密文、加密后的文件名／目录名与密钥封装结果。公开内容、模板预览、文档解析、索引和 AI 生成使用与私有云空间隔离的授权流程，不让后台任务默认读取私有云盘。自建部署支持兼容的对象存储或本地磁盘，但必须提供备份、容量告警和恢复演练。所有下载使用有时效的授权链接，不暴露存储管理凭据。
5. **服务部署。** 先完成域名、TLS、非 root 服务进程、最小权限账号、防火墙、备份和监控，再部署生产数据。当前分享过的高权限登录口令应更换，并改用受控的部署凭据；SSH 只用于运维，不作为应用 API。密钥管理参考 [OWASP Secrets Management](https://cheatsheetseries.owasp.org/cheatsheets/Secrets_Management_Cheat_Sheet.html)。

### 云空间开通、设置开关与停用

- 设置中提供两个独立开关：**云空间**和**云文档自动保存**，两者出厂及旧版本升级后均为关闭。登录不等于开通云空间，开通云空间也不等于开启自动保存；仅查看或打开已有本地文件不触发上传。
- 首次开通云空间须登录，展示专门的云服务协议与隐私说明，由用户主动勾选未预选的同意框。说明加密上传的范围、仍可见的最小元数据、300 MB 实际存储配额及计费范围、跨设备密钥恢复、删除及备份保留期限，以及公开发布和 AI 使用文档需要另外授权。未勾选时不能开启，也不能在后台创建用户云盘或上传本地内容。
- 自动保存开关仅在云空间已开通时可操作，仍须用户手动开启。云空间停用后自动保存立即关闭且不可操作；再次开通云空间时保持关闭，不自行恢复。关闭自动保存只停止后续自动同步，不删除已存云文件，本地保存功能继续可用。
- 关闭云空间的入口命名为**“清空并停用云空间”**。点击后先列出待删除文件、目录、历史版本、回收站内容、知识库私有内容、本人发布的公开副本及公开链接数量，提示本地文件不受影响、云端数据及跨设备访问会消失；提供下载／导出机会。用户再次确认并完成短信或等效二次验证后才停止新上传和分享并执行删除，显示任务进度与最终结果。清空包含活动对象、回收站、版本、本人发布的公开副本和分享授权；备份副本按事先公示的最长保留期到期清除，不能承诺点击后立即抹除所有物理备份，已经被他人下载的文件也无法收回。再次开通从空空间开始，不静默恢复旧数据。
- 手机号验证码只证明账号身份，不能充当文档解密密钥。客户端为用户生成独立加密根密钥，每个文件使用独立密钥和带完整性校验的加密方式；服务端不持有明文密钥。跨设备须由已登录且已授权的旧设备批准，或输入用户自己保存的恢复密钥。明确提示：如果所有已授权设备和恢复密钥都丢失，运营人员无法找回私有文件。更换手机号、重置登录状态不应暗中重置解密密钥。
- 对文件内容、文件名、目录名及可识别的预览缓存执行客户端加密；服务端仍可能知道账号、密文大小、对象数量、上传时间和访问记录，这些应写进协议。客户端本地缓存受操作系统账户保护并可清理。采用经审查的认证加密和密钥轮换方案，验收时用服务器管理员权限核对对象存储、数据库、日志、备份和管理后台，均不能直接还原私有云文档。此保证针对服务器已存储数据；客户端被控制、恶意更新或用户主动授权在线处理仍可能泄露明文，因此客户端发布签名、更新完整性和授权提示也须纳入安全评审。设计参考 [OWASP 加密存储建议](https://cheatsheetseries.owasp.org/cheatsheets/Cryptographic_Storage_Cheat_Sheet.html)和 [OWASP 密钥管理建议](https://cheatsheetseries.owasp.org/cheatsheets/Key_Management_Cheat_Sheet.html)。

### 云盘操作与实时保存

- 云空间提供新建目录、上传、下载、重命名、移动、复制、删除、回收站恢复、排序／搜索、用量显示及历史版本。文件名搜索在有密钥的客户端解密后进行；服务器不建立私有文档的明文全文索引，也不生成明文缩略图。大文件支持分块续传与失败重试，按版本检查避免覆盖其他设备的新修改。
- 对应用实际支持编辑和重新保存的文字、表格、演示、PDF、TXT、MD 等格式，开启自动保存后只要内容发生变动，就先保存本地工作状态，再在短暂防抖后生成加密快照上传；关闭标签、切换文档或退出时尽力刷新待上传队列。只读文件、未实际改变的打开动作及不支持写回的格式不上传，并在界面说明原因。不得因网络失败或空间已满丢失本地改动，也不得未经用户选择覆盖原始本地文件。
- 编辑器顶部使用统一、可关闭的横条提示：自动保存未开通且用户开始编辑时出现；云空间未开通则引导完成协议和开通流程，已开通则引导开启自动保存。同一文档会话关闭提示后不因每次敲字反复弹出，新文档或下次会话可再次提醒，提示不遮挡编辑区。
- 状态区分别显示“本地已保存”“加密上传中”“云端已保存”“离线待同步”“上传失败／空间不足”“版本冲突”；只有服务端确认对应版本后才显示“云端已保存”。离线时将待同步数据加密保存在本机并在联网后重试；多设备同时修改时保留冲突副本和历史版本，由用户选择合并或保留，不能静默覆盖。退出账号和停用云空间时清理或隔离本地待同步队列，不再继续自动上传。

### 运营管理后台与宝塔部署

- **后台地址。** 规划使用 `https://seal.xingmasoft.com` 作为海豹办公运营管理后台地址。正式部署时先完成域名解析，再按宝塔面板的站点／项目管理方式创建独立项目，通过[反向代理](https://docs.bt.cn/user-guide/site/php/site-config/reverse-proxy)接入后台服务。桌面端可调用的业务 API 需单独定义路径、鉴权和版本，不把管理页面当成客户端接口，也不在桌面端放入后台管理员凭据。
- **后台选型。** 以 [aizuda/panshi 官方仓库](https://gitee.com/aizuda/panshi)为管理后台基础框架；实施前固定经过验证的版本，核对项目许可证、运行环境、依赖及升级方式。海豹办公的账号与配额、模板审核、知识库公开内容审核、存储监控、短信配置、AI 任务与审计日志作为独立业务模块开发，不能假定框架已提供这些业务能力。后台界面换成海豹办公自己的名称、图标和文案。
- **HTTPS。** 在宝塔站点中申请可用的[免费 SSL 证书](https://docs.bt.cn/user-guide/site/php/site-config/ssl)，启用 HTTP 到 HTTPS 跳转、到期自动续签和续签失败告警；上线前检查域名解析、证书链与有效期，并做一次续签验证。证书类型及签发方式以部署时宝塔和证书服务的实际可用选项为准。
- **隔离与运维。** 管理后台仅允许管理员角色登录，配置独立的权限、审计与登录保护；数据库、对象存储和任务服务不直接暴露到公网。部署文档记录宝塔中的项目目录、反向代理、环境变量、备份、回滚和健康检查，但不记录服务器口令、短信密钥或其他生产凭据。

## 四、PPT 市场与三个工具的实现顺序

**市场资源。** 先建立模板元数据和对象格式：名称、分类、标签、封面、多页预览、作者、版权或授权说明、版本、公开状态及审核状态。首批 300 套分批上架，需取得明确授权或自制，不能直接抓取截图中的第三方市场。应用内置少量离线精选；在线目录分页加载和缓存缩略图，避免安装包随模板数量大幅增长。用户上传限定 PPTX 和封面格式，扫描、解析、预览成功后才可发布；支持下架、举报和版本替换。

**文档生成 PPT。** 复用现有 DOCX、XLSX、PPTX、PDF 读取与演示模型；旧式 DOC、XLS、PPT 的在线隔离转换须在用户明确选择在线处理后执行。流程为“选择资料并确认在线处理范围 → 抽取结构和引用 → 生成可编辑提纲 → 选模板与页数 → 生成演示模型 → 本地编辑与保存”。AI 调用由服务端代理并计量，模型结果经结构校验后才写入演示对象，不能用单张图片冒充可编辑页面；临时处理材料与私有云盘密文分开存放，按公示期限删除。

**美化 PPT。** 从当前文稿复制工作版本，执行字体、色板、间距、图文布局与封面建议；每页显示前后对比和对象保留情况。确认后应用到副本，并检查导出 PPTX 的可编辑性和重新导入结果。

**图片转 PPT。** 对输入图片做文字识别、版面分区与元素重建；文字框、简单形状和背景分别生成原生对象，识别置信度低时保留原图并标出待校对区域。给用户逐页预览与修改入口，不能承诺所有复杂设计都能无损转换。

## 五、知识库、公开分享与 AI 问答

- 每个用户可创建多个知识库。上传支持 DOC/DOCX、PPT/PPTX、XLS/XLSX、PDF、TXT、MD，单文件上限 10 MiB；上传时设置名称、封面，公开开关默认关闭。私有知识文件沿用云空间的客户端加密与密钥规则；如果用户尚未开通云空间，先完成其独立开通流程。客户端先检查格式、大小及解压后的体积，服务端对公开上传执行隔离解析与安全扫描；私有密文无法让服务器做明文扫描，下载／打开时仍须在客户端安全解析并限制资源消耗。参考 [OWASP 文件上传建议](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html)。
- 内置知识内容使用可追溯、可更新、授权明确的材料，标明来源与更新日期。私有文档的解析文本、页码或工作表位置及检索索引由有密钥的客户端产生并加密同步；服务端不默认持有其明文索引。扫描版 PDF 可在客户端 OCR，或由用户单次授权发送指定文件给在线 OCR，并说明处理方可在处理期间读取该内容。公开资料可由服务端建索引和处理缩略图，识别结果提示用户校对。
- 私有云文件与公开发布是两条明确区分的路径。用户主动打开公开开关时，单独提示公开内容会供其他用户及管理员浏览、下载和一键引用，并在确认后生成公开副本及公开索引；不能把原有私有密文直接当作可公开访问的对象。关闭公开开关后立即撤销下载授权并清理公开索引与缓存，同时在所有查询接口重新校验权限；已被他人下载的副本无法远程收回，这点在发布前说明。上传者可删除自己的内容，管理员只能审核与下架公开内容，不能借审核入口查看私有文件。
- AI 对话先按当前用户权限检索相关片段，再生成带出处的回答。支持限定“当前文档／某知识库／公开库”范围，允许打开来源位置、复制回答或把授权内容用于 PPT 生成。公开内容可由在线服务检索；私有内容优先在客户端检索，并在每次调用在线 AI 前明确告知将发送哪些选定片段给模型服务，取得单独同意，不把解密结果长期保存在服务器或日志中。若用户要求连处理期间也不向服务端披露内容，只能使用本地推理或关闭私有文档在线问答；不能同时承诺在线 AI 阅读私有文档和服务端在任何时刻都无法接触明文。无可信资料时明确表示未找到依据；不把私有内容用于其他用户的检索或模型上下文。
