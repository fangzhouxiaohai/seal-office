# 海豹办公下一版升级计划

## 手机版扫描取景

**目标**：用户点进“拍照转 Word”等扫描功能后，截图红框处直接显示后置摄像头的实时画面。已有权限时，进入页面后零次点击即可取景；首次使用且系统允许申请时，用户只需在系统弹窗点一次“允许”。画面出现后，第一次按快门就能拍下当前文档。

适用于 Android 和 HarmonyOS 手机版共用取景页的九种模式：文件扫描、照片转 PDF、拍照转 Word、拍照转 Excel、提取文字、图片翻译、证件扫描、去除手写、拍书籍。自动启动以进入取景页为触发点。从相册直接选图无需申请相机权限。

## 取景区的状态

| 进入时的情况 | 用户看到的界面与操作 |
| --- | --- |
| 已有相机权限 | 自动启动镜头。首帧到达前取景区使用纯深色底，随后直接显示实时画面。 |
| 首次申请权限 | 进入取景页即发起系统相机权限申请。点“允许”后在原页自动显示画面，无需再点快门、确认或播放。 |
| 拒绝或取消授权 | 底部显示一行“未获得相机权限，可从相册导入”。本次停留期间不反复弹窗。系统已禁止再次询问时，在底部提供“去设置”；从设置授权返回后自动取景。 |
| 摄像头被占用或不可用 | 底部显示具体原因。被占用时可点“重试”，缺少摄像头时可直接使用现有“相册”入口。 |

取景区移除截图中的图片图标、“开启相机取景”标题、权限说明和“开启相机”按钮。进入页面、等待授权、启动镜头及恢复预览时，都要隐藏视频组件的默认封面、中央播放图标和播放控件。保留四角取景框、辅助线和底部快门，快门在真实画面就绪后可用。

## 实施安排

1. **把启动时机移到进入取景页。** 在共用组件 `MobileScanCamera` 中，将目前绑定在按钮和首次快门上的相机启动流程移到页面可见时。复用 `useMobileViewfinder` 和宿主授权流程，只请求摄像头权限，合并同一次进入触发的重复请求。
2. **按真实首帧显示预览。** 在取景框内静音、内联播放相机流，用可显示的首帧作为揭开深色底和启用快门的条件。在 Android 与 HarmonyOS 的实际 WebView 中分别核对默认播放图标，覆盖启动瞬间和授权弹窗关闭瞬间。
3. **处理切换与返回。** 同页切换扫描模式时复用当前镜头。进入审阅页、退出扫描或切到后台时释放摄像头；返回仍处于前台的取景页时，根据当前权限恢复。若用户在等待授权时离开，迟到的授权结果不得在其他页面启动镜头。

## 真机验收

| 场景 | 通过条件 |
| --- | --- |
| 首次从“拍照转 Word”进入 | 自动弹出系统授权。点“允许”后不再触屏，移动纸张即可看到红框内画面随之变化；按一次快门，审阅页显示刚拍的纸张。 |
| 已授权，再从首页或服务页进入 | 自动显示实时画面。逐一打开九种扫描模式，检查从进入到首帧的全过程，中央无说明、启动按钮或一闪而过的播放图标。 |
| 拒绝权限，再去设置允许 | 拒绝后能从相册导入，停留期间不会再次弹窗。从设置允许后返回取景页，无需退出重进即可看到实时画面。 |
| 切换模式、连拍和返回取景 | 从转 Word 切到转 Excel 时画面连续。连拍两页后进入审阅，页数正确；返回取景后可继续拍摄。 |
| 中途离开或切到后台 | 离开取景页后摄像头释放；已授权时切回取景页自动恢复。申请权限过程中离开页面，也不会在后台占用相机。 |

以上为开发后的验收项，Android 与 HarmonyOS 分别用真机记录结果。

## Windows 与 macOS 打开兑换码表格

**用户反馈**：两个平台打开下列两份文件时，都在“读取并解析文件”阶段提示“文本编码无效或文件已截断，请先转换为 UTF-8 后打开”。只读检查确认，两份文件都使用 `.csv` 后缀，内部均为 XLSX 工作簿，压缩包内各项 CRC 校验通过。现有桌面读取流程按扩展名将它们送入文本解码器，因而出现编码报错。

| 原文件名 | 工作表数 | 样本行数（含首行） | 有数据的列范围 |
| --- | ---: | ---: | --- |
| `兑换码_2026-11-15 (1).csv` | 1 | 501 | A 至 I |
| `兑换码_2026-11-15 (2).csv` | 1 | 101 | A 至 K |

**修复安排**：在桌面共用的文件读取入口，对带 `.csv` 后缀的压缩文件核实工作簿内容类型和工作簿部件。确认是 XLSX 后，将实际格式传给表格编辑器并使用现有 XLSX 读取器；普通文本 CSV 继续按文本编码和 CSV 引号规则读取。对损坏的工作簿或普通 ZIP 给出对应的格式错误。打开样本时保留原文件；编辑后默认另存为 `.xlsx`，避免把工作簿误写成文本。

**双平台验收**：分别在 Windows 与 macOS 上，用原文件名从应用内“打开”和系统“打开方式 → 海豹办公”打开两份样本，全程无需改名或转码。逐份核对上表的行列范围，并与工作簿原值核对兑换码、中文和空单元格；兑换码应逐字符一致。另存为 XLSX 后重新打开并核对，同时确认原样本的文件校验值一致。另用带中文、引号及字段内逗号的文本 CSV 验证原有打开流程。这些应用内验收均安排在修复后执行。

## Windows 与 macOS 直接编辑网页型 XLS 审核报表

`审核报表_20261105034103.xls` 是以 UTF-8 编码的 HTML 表格。原件有 1 张表、1 行表头和 1,120 行数据，每行 11 列。12,320 个数据格均指定为文本格式。文件包含表头底色、加粗和表格边框，没有脚本、图片或嵌入对象。当前打开流程已经识别并解析了表格，但会给每份网页型 XLS 固定附上两条警告，从而弹出截图中的“仅查看／另存副本并编辑”对话框；现有导入器也会丢掉表头等显示样式。

**预期操作**：双击这份报表，直接进入可编辑的工作表。用户可以立即查看、查找和修改数据。首次保存编辑时，默认使用同名的标准 XLSX 文件，只在这时选择保存位置；此后正常保存到该 XLSX。取消首次保存可回到当前编辑位置，保留未保存的修改。

**同类文件的处理规则**：Windows 与 macOS 的应用内打开、系统打开和最近文件入口共用同一套识别逻辑。根据文件结构选择文本 CSV、XLSX、传统二进制 XLS 或 HTML 表格读取器。网页表格使用静态解析，保留单元格文字、文本类型、空格位置和可映射的表头与边框样式。成功导入后直接展示工作表；遇到确实无法保留的对象，列出实际发现的内容，在保存可能造成损失时说明影响。脚本不执行。

**验收安排**

1. 在 Windows 与 macOS 用审核报表原文件名直接打开，首屏可编辑，无截图中的通用弹窗，进度提示在表格可用时消失。检查表头底色、粗体和边框，定位并编辑最后一行。
2. 保存为 XLSX 后关闭重开，逐格与原表对照。除有意修改的单元格外，1,121 行、11 列的值、文本类型和空单元格位置一致。另测取消保存后继续编辑，核对源文件校验值。
3. 两端均将本报表和前述两份兑换码表作为同一组验收样本。再用标准 CSV、XLSX、传统二进制 XLS 和一份带无法导入对象的网页表格做回归，核对格式识别、实际损失提示以及保存后的内容。

## Windows、macOS、Android 和 HarmonyOS 表格工具栏

在表格“开始”工具栏中并排放置字体和字号，旁边保留独立的“字体颜色”和“填充颜色”入口。现有简洁模式会隐藏字体名称，表格工具栏缺少字号控件，两处颜色菜单各只有三种预设。桌面普通模式、简洁模式和手机竖屏都要能直接读到字体和字号，展开菜单后仍保有原选区。

### 字体与字号

| 操作或选区状态 | 工具栏显示和行为 |
| --- | --- |
| 打开空白表格、未选中内容，或只定位在空白单元格 | 字体框显示本机字体库按菜单顺序排列的第一个可选字体，紧邻的字号框显示 **10**（单位为磅）。字体目录加载期间先显示当前可用列表的首项，目录就绪后同步。查看默认值不会改写工作簿格式。 |
| 选中有内容的单元格，或在格内选中一段文字 | 两个框分别显示该选区实际生效的字体和字号，包括从工作簿样式继承的值。切换单元格、工作表或文字选区时立即更新。 |
| 多个单元格或文字片段格式不同 | 按属性判断。字体一致、字号不同时，字体框显示共同字体，字号框显示“混合”。字体不同时，字体框显示“混合”。两个框都可以直接为选区统一相应格式。 |

字号支持选择常用值，也支持直接输入磅值。选好字体或确认字号后，只对原选区应用该项格式。字体菜单的搜索词仅过滤候选列表。收起菜单时，当前字体名称和字号均可见。

### 字体颜色与填充颜色

两个入口共用同一套调色板。展开即显示常用色、灰阶以及各色系的深浅色块。“自定义颜色”提供色相、饱和度和明度选择，也支持直接输入 `#RRGGBB`，可精确设置全部 16,777,216 种 24 位 RGB 颜色。字体颜色作用于选中文字或单元格文字，填充颜色作用于选中单元格的背景。各入口分别显示当前颜色，手机上可以触控选色或输入色值。

### 四端验收

1. 在 Windows、macOS、Android 和 HarmonyOS 上分别打开空表，对照未搜索时字体菜单的第一项，确认工具栏显示其名称和字号 10。分别在桌面简洁模式和手机竖屏检查，两个值均可直接读到。
2. 选中设为 12 磅和 18 磅的两个单元格，逐个切换、再一起框选，核对共同值和“混合”。将整组选区设为 14 磅，再单独修改格内一段文字的字体，核对作用范围和撤销后的显示。
3. 给同一个单元格设置自定义字体色 `#24578A` 和填充色 `#E8D6AC`，核对前景与背景能独立修改。保存为 XLSX，在另一端重开，复核字体名、字号和两个精确色值。手机端同时检查调色板和色值输入框在竖屏下可操作。

## 单据转表格与扫描识别

### 导入 PDF

桌面和手机的“单据转表格”“扫描与识别”都增加“导入图片或 PDF”。手机通过系统文件选择器选 PDF，拍照、相册和桌面粘贴截图仍可作为输入。两处共用按页导入流程。

1. 选择单页或多页 PDF 后，先显示文件名、页数和缩略图，可导入全部或指定页，也可与图片一起导入。每页保留来源文件和原始页码。按页分批处理大文件，超出单次处理额度时可分段继续。
2. 可用的文字层在本机按位置提取，保留行列关系。扫描页及混合页中缺少文字层的区域按需 OCR，合并时去除重复文字。沿用现有识别授权流程，发送到识别服务前由用户确认。遇到加密 PDF 可输入打开密码，损坏文件或个别失败页单独提示，已导入页可继续处理。
3. “单据转表格”将表头、明细和异常项与 PDF 原页并排核对，核对后生成工作表或导出 XLSX。“扫描与识别”按选定页序预览、提取文字，支持导出可搜索 PDF 和 Word。

**验收**用一份含电子文字页、扫描页和图文混排页的 PDF 从两个入口分别导入，再测试只选部分页并追加一张图片。在工作表中回查单号、数量和金额的原页，在导出 PDF 中搜索原文，在 Word 中核对页序与文字。重试失败页后，导出结果不得增加重复行。

## 本机日历

### 节日、放假和调休

月视图在日期格内显示节日名称。中国大陆的放假日标“休”，调休上班日标“班”。同日有多个节日时，点击日期可查看全部名称、适用地区、放假安排和当天的个人日程。

| 日历内容 | 日期依据和验收要点 |
| --- | --- |
| 中国大陆节日 | 支持元旦、劳动节、国庆节等公历节日，春节、元宵、端午、中秋等农历节日，以及按节气确定的清明。按北京时间核对公历日期，覆盖跨年、闰月和节日重合。 |
| 世界著名节日 | 收录圣诞节、国际妇女节、世界地球日等固定日期节日，以及西方复活节、美国感恩节等逐年变化的节日。按适用国家、地区或历法核对来源，名称中区分不同地区的日期规则。国际节日仅在对应的大陆年度安排规定放假时显示“休”。 |
| 中国大陆每年放假安排 | 逐年核对国务院办公厅通知，录入完整放假区间和调休上班日，记录公告链接和更新日期。公布或修订后更新年度数据，已核验的年份可离线查看。尚未公布的年份仍显示可确定的节日，年度安排标记为“待公布”。 |

2026 年的核对样例为 1 月 1 日至 3 日标“休”，1 月 4 日虽是星期日，仍须标“班”。跨月切换及在不同时区的设备上查看时，中国大陆的全天日期标记均应落在同一公历日。[国务院办公厅关于2026年部分节假日安排的通知](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)

### 月份切换

将月份标题两侧的“上个月”“下个月”文字按钮替换为海豹办公现有图标库的左右箭头，沿用工具栏的线宽、颜色和悬停、聚焦样式。年月标题居中。左箭头向前翻一个月，右箭头向后翻一个月。按钮保留“上个月”“下个月”的读屏名称和悬停提示。桌面键盘和手机触控均应能连续翻月，验收包括从 12 月进入次年 1 月再返回。

### 日程到点提醒与内置提示音

- **新增日程**默认在开始时间提醒。表单提供三种内置短音供选择和试听，暂定为“轻铃”“木琴”“双音”。选定后随日程保存，也可为单项日程关闭提醒。声音随安装包提供，可离线试听、播放。
- **到点提醒**显示日程标题和开始时间，并播放所选声音一次。切到其他页面或最小化后仍可提醒。桌面和手机优先使用系统本地通知调度，覆盖系统允许的后台、锁屏和应用退出状态。按系统通知权限、静音和勿扰设置投递，界面显示实际可用的提醒状态。
- **修改和删除**按日程标识更新或撤销原提醒。重启后恢复待提醒日程，前后台切换或重复打开窗口时，同一日程只响一次。历史日程保留原记录，可在编辑时开启提醒。

**验收**在 Windows、macOS、Android 和 HarmonyOS 上分别新建两分钟后开始的日程，试听并选择一种声音，保存后切离日历。核对通知标题、触发时间、实际听到的声音和响铃次数。分别验证最小化或锁屏、重启、改期、删除以及拒绝通知权限的情况。改期后只在新时间触发，删除后取消待发通知，实际支持的后台及退出提醒状态按平台记录。

## 大文件异步打开与进度显示

桌面、手机和网页版从各自已有的“打开”、最近文件或系统文件入口打开文档时，先读取文件大小。原文件**大于 5 MB（5,000,000 字节）**即启用后台加载，在开始读取前显示文件名、转圈动画和当前进度。加载期间仍可操作主界面，例如切换到另一份已打开的文档。

| 阶段 | 用户看到的进度 |
| --- | --- |
| 读取文件 | 分块读取，按实际已读字节更新进度条，例如“已读取 8 / 20 MB（40%）”。百分比标明属于读取阶段。 |
| 解析内容 | 随格式显示能实际计数的工作量，例如“已解析 3 / 8 张工作表”或“已处理 12 / 30 页”。转换器无法提供总量时，继续转圈并显示正在执行的操作，例如“正在转换旧版表格”。 |
| 准备首屏 | 显示“正在准备首屏”。首屏已呈现并可滚动、选择或编辑时，才将本次打开标为完成并收起提示。 |

文件读取采用异步 I/O，解压、解码和格式转换等耗时计算交给后台线程或进程，编辑器按需分批呈现。进度按文件分别记录。取消或打开失败时结束对应任务并收起动画，失败信息指出文件名与处理阶段，用户可重新打开。

**验收**分别打开 4,999,999、5,000,000 和 5,000,001 字节的有效文件，核对阈值。再用大于阈值的多工作表 XLSX 和多页 PDF，对照文件大小、工作表数或页数核对进度，并在解析期间实际切换文档、滚动和点击。最后覆盖取消、损坏文件和重新打开，确认进度能正常结束，已打开的其他文档仍可操作。
