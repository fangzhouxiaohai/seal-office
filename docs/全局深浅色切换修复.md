# 全局深浅色切换修复

## 原因与修复

顶栏原先在首页分支中渲染主题按钮，文档、设置和其他页面使用的顶栏分支没有该入口。主题状态及回调已经由应用外壳统一提供，并不需要先进入设置切换。

主题按钮改为由公共顶栏直接渲染，固定在右侧操作区的最右端。首页、文字、表格、演示、PDF、设置和本地工具共用同一入口，不依赖页面类型或之前是否切换过主题。按钮的图标、操作提示和可访问状态随全局主题更新，继续沿用现有本机主题记忆。

## 设计令牌

- 配色：沿用 `--text-2`、`--brand`、`--bg-hover` 和 `--brand-soft`，深浅主题使用现有令牌。
- 控件：沿用 30 像素按钮、18 像素线性图标、6 像素圆角和 8 像素间距。
- 字体与层级：沿用全局字体，操作说明使用既有悬停提示，图标保持辅助操作的视觉权重。
- 响应式：沿用现有顶栏布局与小屏操作区，主题按钮始终在最右端。

## 界面自检评审

1. 非首页页面缺少主题按钮，需要离开当前工作页面才能切换。将主题入口移到公共顶栏，所有页面均直接可用。
2. 首页与其他页面的操作入口不同，主题按钮的位置容易随页面变化。固定在操作区的最右端，形成一致的位置。
3. 主题按钮缺少表示当前深色状态的可访问属性。补充切换状态，图标与操作提示继续跟随同一个全局主题更新。

## 回归范围

覆盖非首页首次展示、首次进入设置、返回首页、主题切换、本机主题记忆及应用重新挂载。修复前，非首页与设置用例均因找不到主题按钮而失败。

Windows 1.6.8 解包版和便携版分别完成首次首页、首次设置、设置切换、返回首页、文字编辑器切换与页面重新加载核验。每一步均只有一个可见按钮，固定距右侧 16 像素，深色状态和本机主题记录一致。成品完整性清单 35 个文件全部通过，两个成品均正常退出。
