# 公共弹窗设计令牌与界面自检

关于窗口、模板库、最近文档和页面异常提示延续现有工作台样式。模板预览以内容为视觉重点，分类和操作位于上方；关于窗口以应用信息为重点；错误弹窗突出原因和下一步操作。

## 设计令牌

颜色采用 `renderer/src/styles.css` 的 `--bg-app`、`--bg-card`、`--bg-hover`、`--text-1`、`--text-2`、`--brand` 和 `--border`。间距使用 `--space-1` 至 `--space-6` 的 4 像素刻度，圆角使用 `--radius-control` 和 `--radius-card`，字体使用 `--font-body` 与 `--font-heading`。模板纸张单独保留白底深色文字，以便预览文档原有排版。

## 界面自检评审

1. 关于窗口原先写死浅色背景和灰色文字，切换深色主题后信息层级失效。现使用全局颜色令牌，长链接允许换行，窄屏收紧标签列宽。
2. 模板列表原先用文件类型颜色画整张卡片边框，多个卡片同时抢占注意力。现统一边框与文字颜色，只在悬停和选中分类时使用主色，并将模板内容放在单个抽屉内预览。
3. 模板预览原先叠加第二层抽屉，窄屏会遮挡返回入口。现使用同一抽屉在列表与详情之间切换，预览按钮可以通过键盘访问。
4. 页面渲染出错时原先只在内容区显示错误，用户可能误以为页面无响应。现先显示错误弹窗，关闭后保留错误详情和重试入口。
5. 最近文档卡片与列表缺少完整的键盘打开方式，定位原文件失败也无可见反馈。现加入可见焦点、键盘操作和错误弹窗。
6. 演示模板原先预览为彩色封面，点击使用时却把网页内容传给演示编辑器，无法生成幻灯片。现让每个演示模板生成对应的可编辑文本框与背景色，预览与创建后的首页封面保持一致。

相关代码位于 `renderer/src/components/AboutDialog.tsx`、`TemplateLibrary.tsx`、`ErrorBoundary.tsx`、`DocCard.tsx`、`DocRow.tsx` 及其样式文件。弹窗宽度依视口收缩，交互控件有悬停、焦点和禁用状态。
