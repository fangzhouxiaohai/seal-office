# 海豹办公云端后端重构：客户端接口契约（一比一不可变）

> 本契约以 `server/*.cjs`（Node 实现）为基准提炼，Spring Boot 重构版必须逐字保持路径、方法、请求/响应字段、状态码与错误文案。客户端（桌面 Electron、Android、HarmonyOS、Web）只认这些行为，任何偏差都视为缺陷。
> 加密模型：文件内容、名称、标签、团队信息、分享信封均为客户端 AES-256-GCM 加密后的不透明密文，服务器只存储与转发，不接触明文。重构不得改变任何加密与密钥交换流程。

## 全局约定

- 反向代理：nginx 把 `/api/` 前缀剥掉转发到后端（`location ^~ /api/ { proxy_pass http://127.0.0.1:8096/; }`），后端控制器直接映射 `/v1/**`。
- 响应头：`Cache-Control: no-store`、`X-Content-Type-Options: nosniff`、`Content-Security-Policy: default-src 'none'`（API）。
- 错误形态：`{status}` HTTP 状态码 + JSON `{"error":"中文文案"}`。
- 方法覆盖：移动端的 `POST + X-Seal-Method-Override: PATCH` 还原为 PATCH，仅放行 PATCH。
- 用户鉴权：`Authorization: Bearer <32字节base64url>`，`sessions.hash = sha256(token)`，30 天有效；`session_devices` 记录设备；会话被删（撤销设备）立即 401。
- 管理员鉴权：`/v1/admin/login` 返回 `{token}`（base64url 32 字节，8 小时），`admin:` 前缀权限校验；revision 变化即失效。
- 配额：每用户 300000000 字节；分块上传块大小 1048576。
- 手机号脱敏：`138****0000`（3+4+4）。
- `/v1/capabilities` 返回：`{"version":1,"collaboration":1,"realtime":1,"diagramRealtime":1,"accountConversion":1,"passwordAuth":1,"accountDeletion":1,"aiIdentity":1,"shareLink":1,"methodOverride":1,"keyRecovery":1,"quota":300000000,"chunkSize":1048576,"sms":true,"encryption":"AES-256-GCM","agreementVersion":"2026-11-21"}`（agreementVersion 取自 spaceKeys.cjs 的 agreementVersion）。

## 一、认证与账号（index.cjs / passwords.cjs / accountErasure.cjs / accountConversion.cjs）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | /v1/auth/code | 发送短信验证码 `{phone,purpose}`，同号同用途 60 秒间隔、每 IP/手机号限流；返回 `{sent:true}`；开发联调可配 mock |
| POST | /v1/auth/login | 验证码登录/注册 `{phone,code,deviceId,deviceName}`，校验 HMAC 验证码（5 次尝试上限），签发会话 `{token,account}` |
| POST | /v1/auth/logout | 删除当前会话 `{loggedOut:true}` |
| POST | /v1/auth/password | 设置/修改密码（验证码校验 + 旧密码校验分支），scrypt 存储 |
| POST | /v1/auth/password-login | 密码登录 `{phone,password,...}`，仅已验证账号，错误计数锁定 |
| POST | /v1/auth/delete-account | 验证码校验后登记注销（进入 erasure 流程） |
| GET | /v1/auth/deletion-status | 查询注销进度 |
| POST | /v1/account-conversion/* | 账号转换流程（见 accountConversion.cjs，状态机 + 文档转换联动） |
| GET | /v1/me | 当前账号：`{id,phone(脱敏),identityVerified,identityMethod,hasPassword,enabled,autosave,envelope,keyRecovery,keyRevision,used,quota,agreementVersion}` |
| GET | /v1/devices | 设备列表 |
| POST | /v1/devices | 登记设备 |
| PATCH/DELETE | /v1/devices/{id} | 改名 / 撤销（撤销即删会话） |
| POST | /v1/space/enable | 开通云空间 `{envelope,consent}`，记录协议版本 |
| POST | /v1/space/autosave | 自动保存开关 |
| GET/POST | /v1/space/key、/v1/space/key/reset、/v1/space/purge | 空间密钥 envelope 存取与轮换（spaceKeys.cjs，otp.secret 派生校验） |

## 二、云空间对象（index.cjs 主体）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET/POST | /v1/nodes | 列表（含回收站过滤）/ 新建节点（folder、library、file），`{id,parent,kind,meta}` 密文 meta |
| GET/PATCH/DELETE | /v1/nodes/{id} | 详情 / 重命名移动（meta 更新+版本递增）/ 回收站（递归子树，publications 联动下架） |

| PUT | /v1/uploads/{id}/{seq} | 写块（幂等，received 累计） |
| POST | /v1/uploads/{id}/complete | 合并为 objects/<uuid>，写 versions 行（node_id,version,blob,bytes） |
| GET | /v1/nodes/{id}/download | 最新版本流式下载，`X-Seal-Version` 头；`x-seal-version` 请求头可指定版本 |
| GET | /v1/nodes/{id}/versions | 版本列表 |

## 三、协作（collaboration.cjs）

- 共享：`GET/POST /v1/shares`、`GET/DELETE /v1/shares/{id}`、`GET/PUT /v1/shares/{id}/blob`（`x-seal-access` 头校验访问摘要，PUT 即被共享方回写）
- 标签：`GET/POST /v1/tags`、`GET/PATCH/DELETE /v1/tags/{id}`、`GET /v1/tags/{id}/nodes`、`PUT /v1/tags/nodes/{id} {tagIds}`（上限 200 标签/50 关联）
- 团队：`GET/POST /v1/teams`、`DELETE /v1/teams/{id}`、成员 `GET/PATCH/DELETE /v1/teams/{id}/members[/{uid}]`、邀请 `POST /v1/teams/{id}/invites`、`GET/POST /v1/teams/invites/{id}`（接受）、团队节点与团队版本走 team-objects 目录
- 我的分享：`/v1/my-shares`、`/v1/my-shares/query`、`/v1/my-shares/batch`、`/v1/my-shares/cleanup-preview`（myShares.cjs）

## 五、公开内容（publications，index.cjs + publicValidation.cjs）

- 用户发布：`GET/POST /v1/publications`、`PATCH/DELETE /v1/publications/{id}`，kind ∈ template/knowledge/skin，状态 pending→published/rejected/withdrawn
- 公开浏览：`/v1/public/*` 免登录列表与详情（仅 published）
- 管理审核：`/v1/admin/publications/{id}` PATCH（review 权限）、下载

## 六、实时协作（realtime.cjs，WebSocket）

- HTTP：`/v1/realtime/...` 房间创建、更新提交（seq 严格递增、operation_id 幂等）、回执、检查点
- WS：`/v1/realtime/ws`（或既有路径，以 realtime.cjs 为准）握手后广播更新与 presence；checkpoint_seq/head 语义保持
- 用量计费公式（realtimeUsage/collaborationUsage/usage）必须与 index.cjs 第 67-69 行一致

## 七、发布与附件（releases.cjs / releaseAssets.cjs）

- 匿名：`GET /v1/updates/latest?platform&version&channel`（IP 令牌桶 30/分），`{hasUpdate,version,mandatory,notes,url,sha256,bytes,publishedAt}`
- 下载：`GET/HEAD /v1/release-assets/{id}/{filename}`，未上架 404，支持 Range/206、ETag=sha256
- 管理：`GET/POST /v1/admin/releases`、`PATCH/DELETE /v1/admin/releases/{id}`、`POST /v1/admin/releases/batch`、`POST /v1/admin/releases/delete-version`、`POST /v1/admin/release-assets`（octet-stream，1GiB 上限，平台格式校验）
- 语义化版本比较规则见 releases.cjs compareVersions

## 八、管理后台（index.cjs / adminAccess.cjs / converterAdmin.cjs）

- 登录：`POST /v1/admin/login`（IP+账号 15 分钟 5 次锁定），`POST /v1/admin/logout`，`GET /v1/admin/session`（profile 结构见 adminAccess.profile）
- RBAC：`GET/POST/PATCH/DELETE /v1/admin/access/(admins|roles|menus)`、`GET /v1/admin/access/menu-candidates`，19 个权限点与 11 个菜单键固定（adminAccess.cjs PERMISSIONS/MENUS）
- 概览：`GET /v1/admin/overview`（按权限裁剪 users/publications/audit/overviewCounts/runtime/sms 段）
- 转换器：`GET/PATCH /v1/admin/converter`、`POST /v1/admin/converter/token`、`POST /v1/admin/converter/test`（经 8298 控制令牌）
- 账号注销擦除：`seal-cloud-erasure` systemd path 触发 erase-worker（备份目录清理），数据表 erase_records/erase_backups

## 十一、加密参数（逐字锁定，偏差即数据不可读）

- 用户登录密码（passwords.cjs）：scrypt **N=32768, r=8, p=3, maxmem=64MiB**，salt 16 字节 hex，digest **64 字节** hex；并行 KDF 上限 2，超限 429「登录服务繁忙，请稍后重试」。
- 管理员口令（adminAccess.cjs）：scrypt **默认 N=16384, r=8, p=1**，digest **32 字节** hex；超管用 SEAL_ADMIN_SALT + SEAL_ADMIN_PASSWORD_HASH 校验。
- 分享访问码（shareLinks.cjs）：scrypt 默认参数，digest 32 字节；15 分钟 8 次尝试上限（内存计数）。
- 云空间密钥（spaceKeys.cjs）：`HKDF-SHA256(otp.secret, salt='seal-cloud', info='server-space-key-v1')` 得包裹密钥；AES-256-GCM（nonce 12 + tag 16，AAD=`seal-space-key:{uid}:{revision}`）包裹 32 字节根密钥存 users.vault_key；agreementVersion=2026-11-21，legacy=2026-10-08。
- 验证码：HMAC-SHA256(otp.secret, `{phone}:{purpose}:{code}`)，5 分钟有效、5 次尝试。
- 会话令牌：base64url(32 字节随机)，sessions.hash=sha256(token)，30 天；管理员令牌同形，8 小时。
