# 海豹办公后端重构：数据迁移与无感切换方案

> 目标：Node 版（SQLite + 文件）→ Spring Boot 版（MySQL + 同一文件目录），客户端零感知、已登录会话与云空间数据全部保留。

## 一、部署形态

- 新服务 `seal-server.jar` 监听 `127.0.0.1:8097`，与现行 Node（8096）并行运行，互不干扰。
- 数据目录沿用 `/www/wwwroot/seal.xingmasoft.com/data`（objects/incoming/team-objects/release-assets 不动）。
- 环境文件沿用 `/etc/seal-cloud/service.env`（新增 SEAL_JDBC_USER/SEAL_JDBC_PASSWORD 已写入）。
- Java 项目按宝塔规范在面板「Java 项目」中登记（jdk-17.0.8），systemd 单元 `seal-cloud-java.service` 托管进程。
- 切换时仅修改 nginx 扩展配置中 `/api/` 与 `/api/v1/admin/release-assets` 等上游端口 8096→8097，reload 即生效；回滚把端口改回 8096。

## 二、数据迁移（一次性，切换前执行）

工具：`seal-server/migrate/migrate.mjs`（Node 编写，直接读 sql.js 打开 seal.sqlite 与 admin-rbac.sqlite，经 mysql2 写入 seal_cloud 库）。

1. 全量导出 seal.sqlite 23 张表 + admin-rbac.sqlite 5 张表，逐表 INSERT 到 MySQL（idempotent：先清空目标表再写入，仅在迁移窗口执行）。
2. 校验：逐表行数比对 + 抽样字段比对（sessions、releases、users、admin_roles 全量比对哈希）。
3. 文件系统不动：objects/team-objects/release-assets 继续被两个后端引用。
4. 迁移窗口：暂停 Node 写流量不是必需——先在 Java 侧回放迁移，再于切换瞬间做一次增量校验（sessions/audit 等高频表行数差在秒级窗口内允许，切换后旧库只读封存）。

## 三、契约验收（切换前置门）

1. `node seal-server/contract-test.mjs --base http://127.0.0.1:8097` 全部通过（公共端点、认证、管理端、错误形态）。
2. 与 Node 版对拍：同一请求同时打 8096/8097，响应体逐字段一致（时间戳类字段豁免）。
3. 管理后台 UI（seal-admin-web）浏览器验收通过。
4. 真实管理员会话操作：发布列表、版本删除、审核流转、转换器状态读取。

## 四、切换与回滚

1. `nginx -t && systemctl reload nginx` 切换 /api/ 上游到 8097。
2. 观察 30 分钟：错误率、/v1/capabilities、客户端 /v1/me、分享下载、实时协作长轮询。
3. 异常时把端口改回 8096 即回滚（Node 服务保持热备 7 天，每日确认后可停）。
4. 旧 Node 代码下架：确认稳定一周后停止 seal-cloud.service，归档 server/ 目录标记为历史（用户要求最终删除旧服务端与代码，确认后执行删除）。

## 五、定时任务调整

- seal-cloud-backup/health 脚本请求 `http://127.0.0.1:8096/v1/capabilities` → 切换到 8097。
- seal-cloud-erasure 相关由 Java 版 accountErasure 接管后调整单元 ExecStart。
- seal-admin-php（PHP 桥）下线：新后台直连 `/api/v1/admin/*`，nginx 中 30-tpadmin.conf 的 `/seal-admin/` 段在 UI 切换后删除。

## 六、风险与对策

- **scrypt 参数一致性**：Node scryptSync(password, salt, 32) 默认 N=16384,r=8,p=1；Java 端 password4j 同参数验证，测试用旧库真实 digest 校验。
- **会话兼容**：token 为不透明字符串、sha256 落库，Java 直接查 sessions 表即可让已登录客户端免重登。
- **用量公式**：usage/realtimeUsage/collaborationUsage 的 SQL 已逐字移植（index.cjs:67-69），切换前对拍若干真实账号的 /v1/me.used。
- **时钟语义**：所有时间为毫秒时间戳（BIGINT），与 Node clock() 一致。
