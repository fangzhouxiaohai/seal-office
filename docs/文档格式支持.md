# 文档格式支持（2.2.0）

PC 和移动/Web 共用以下 50 种办公扩展名清单：`main/documentFormats.json`。Windows 的打开对话框、拖入、系统关联、最近文件和保存格式，以及手机的格式选择与读取均从这份清单获取。本轮不登记 WPS 专属格式，也不包括图片、压缩包、CAD 和思维导图。

2.2.0 增加跨平台系统字体读取、自定义字体导入和 `.sldoc` / `.slxls` / `.slppt` 字体资源嵌入；DOCX / XLSX / PPTX 保留来源字体名并使用本地回退链。完整方案、授权边界和平台差异见[字体读取、自定义导入与专属格式嵌入](字体与跨平台兼容.md)。2.0.0 追加公式、1900/1904 日期、数字格式、跨表结构引用、动态溢出与 WPS/Excel 兼容模式，以及 DOCX 修订历史、复杂来源包保留和原生 PDF 预览/导出。格式扩展名数量不代表每种对象都可无损往返；本轮功能与边界见 [第三轮记录](v2.0.0-三轮功能与回归.md)，历史样本见 [二轮记录](v2.0.0-二轮升级与Web发布.md)。

## Windows 功能范围

| 类别 | 扩展名 | 打开与编辑 | 保存 |
| --- | --- | --- | --- |
| 文字 | DOCX、DOC、DOT、DOTX、RTF、ODT、OTT、FODT | 导入正文、现有编辑器支持的排版与图片 | 可保存相应格式；转换后应重开核对 |
| 文字宏格式 | DOCM、DOTM | 导入正文，不运行宏 | 编辑后另存 DOCX 等普通格式，保护来源 |
| 纯文本与网页 | TXT、MD、JSON、HTML、HTM、MHT、MHTML | 文本编辑；网页导入正文和可导入图片 | 文本、HTML 或单文件 MIME 网页；不能完整导入的网页保护来源 |
| XML | XML（含 Word 2003 XML、Excel 2003 XML） | 普通 XML 按文本；Office XML 按文档正文导入 | 普通 XML 要通过语法校验；Office XML 编辑后另存 DOCX/XLSX，保留来源 |
| 工作簿 | XLSX、XLS、XLT、XLTX、ODS、OTS、FODS | 导入现有表格编辑器支持的数据、公式和样式 | 可保存相应格式 |
| 表格宏、二进制与加载项 | XLSM、XLTM、XLSB、XLA、XLAM | 导入表格内容，不运行宏或加载项 | 编辑后另存 XLSX 等普通格式，保护来源 |
| 分隔文本 | CSV、TSV | 保留文字、前导零、空字段、字段内引号与换行 | 原格式保存，保留来源换行、BOM 和编码；只能保存一张表 |
| 数据交换 | DBF、PRN、DIF、SLK | 导入单张数据表；PRN 按连续空格或制表符识别字段，需核对边界 | 一张表；公式按显示结果输出，转换损失先确认；DBF 字段名、长度受格式约束 |
| 演示 | PPTX、PPT、POT、POTX、PPS、PPSX、ODP、OTP、FODP | 导入现有演示编辑器支持的页面、文本与对象 | 可保存相应格式；放映格式保留文件类型，不自动播放 |
| 演示宏格式 | PPTM、POTM、PPSM | 导入演示内容，不运行宏 | 编辑后另存 PPTX 等普通格式，保护来源 |
| PDF | PDF（包含 PDF/A 输入） | 阅读、页面处理和现有批注编辑工具 | 普通 PDF；编辑后的文件不保证继续满足 PDF/A 归档标准 |
| OFD | OFD | 版式阅读、缩放、打印 | 原字节副本或 PDF 导出；不提供 OFD 原生编辑或证书有效性认证 |

“能够关联”表示 Windows 可把文件交给海豹办公。它不表示编辑器可以无损处理该格式的全部对象。导入器发现未支持对象时列出警告，禁止直接覆盖来源；编辑后的副本仍需核对。密码保护、损坏文件会报错，不用空白内容代替。宏和加载项正文能够导入，不代表提供宏执行、加载项安装或专有二进制结构回写。

CSV/TSV 来源支持 UTF-8、带 BOM 的 UTF-16 LE/BE，以及可无损解码的 GBK/GB18030 中文数据。新增字符无法以来源编码保存时拒绝写入，避免替换成问号。没有 BOM 的不明编码不能保证自动识别。其他非 UTF-8 文本导入后要求另存 UTF-8 副本。

PRN 没有统一自描述的列边界。本版导入连续空格/制表符分隔的常见打印文本并保护来源；输出按字段长度补空格，不截断字段。字段中含连续空格、换行或制表符时拒绝 PRN 输出，建议 CSV/XLSX。无间隔拼接的固定字段文件仍需先指定字段边界或在原软件转换。

Windows 的旧版和开放格式转换使用随安装包提供的离线引擎，无需安装 Microsoft Office 或联网转换。每次转换使用独立临时配置，关闭宏执行，超时只停止该转换的进程树。最终写盘继续执行文件指纹校验和原子替换，外部修改的文件不能被旧内容覆盖。

## 移动端与 H5

共享编辑器同步获得 CSV/TSV 原格式保存与编码处理、OOXML 模板及宏正文导入、MHTML 和 OFD 阅读。移动端 OFD 导出为图像型 PDF，保留纸张尺寸用于阅读与批注；Windows 通过原生打印保留可打印的 SVG 页面。

按用户确认的方案，手机使用“常用格式离线处理、少数旧格式连接自建转换服务”。全部 50 种格式均提供对应入口，具体路径如下：

| 处理路径 | 打开 | 保存 |
| --- | --- | --- |
| 本机常用编辑 | DOCX、XLSX、PPTX；TXT/MD/JSON/HTML/HTM/MHT/MHTML；CSV/TSV；PDF/OFD | 与 Windows 常用编辑器相同的保存范围；OFD 原样副本或图像型 PDF |
| 本机 OOXML 变体 | DOTX/DOCM/DOTM、XLTX/XLSM/XLTM/XLAM、POTX/PPTM/POTM/PPSX/PPSM | 普通模板 DOTX/XLTX/POTX 和放映 PPSX 可本机写入；宏来源保留，另存普通文档 |
| 本机表格兼容 | XLS/XLT/XLSB/XLA、ODS/OTS/FODS、DBF/PRN/DIF/SLK、Excel 2003 XML | XLS/ODS/FODS/DBF/PRN/DIF/SLK 可离线输出；主要保留数据和公式，高级对象可能缺失，先确认并建议保存副本。XLT/OTS 输出使用转换服务 |
| 自建服务转换 | DOC/DOT、RTF、ODT/OTT/FODT、Word 2003 XML；PPT/POT/PPS、ODP/OTP/FODP | 可输出对应非宏格式，生成后回到手机保存；每次发送前确认服务地址与正文上传 |

2.0.0 默认可使用普通云账号的会话访问同域格式转换网关，服务能力会实际探测；每次上传前均需确认。转换服务需要读取本次上传的正文，完成后删除临时文件，因此使用前应确认文件可发送给该服务。联网转换单文件最多 20 MiB，执行、连接和客户端均有独立超时与取消处理；大文件可在 Windows 离线处理。共享与团队文件的端到端加密不会让转换引擎直接读取云端密文。

显式自建服务配置继续优先：设置中心提供服务地址、加密访问令牌、测试连接和清除配置；更换地址不能自动复用旧令牌。没有有效会话或服务配置、网络失败、拒绝上传、文件加密或转换失败都会明确提示，不写入空白文件或替换来源。服务代码、Docker 配置和 HTTPS 反向代理示例见[自建转换服务](../server/converter/README.md)。现有手动令牌服务 `https://seal.xingmasoft.com/api/office-converter` 保留，可从后台“文档转换”生成令牌后使用。2.0.0 普通账号网关与隔离引擎验收见 [协作后端部署](v2.0.0-协作后端部署验收.md)；此前手动令牌路径的历史样例结果见 [后台转换验收](verification/backend-converter/mobile-production.json)。

新版 Android 资源已构建，APK 仍由用户通过 HBuilderX 云打包提供；本机只有 Android 14 模拟器，没有完成 iOS、鸿蒙或各厂商真机验收。浏览器生产页面的格式往返验证也不等于上述全部真机验收。

## 默认程序设置

安装版和设置中心注册全部 50 种处理程序、打开命令及四类文件图标。现代 Windows 的受保护默认选择需在“设置 → 应用 → 默认应用 → 海豹办公”确认。注册不会删除受保护的用户选择。资源管理器“新建”继续提供 DOC、DOCX、PPT、PPTX、PDF、XLS、XLSX 七种真实模板。

## 第三方引擎与许可证

离线引擎采用 LibreOffice 26.8.1 官方 Windows x64 分发包。`scripts/prepare-office-runtime.py` 校验固定 SHA-256 后在项目私有目录解包，不执行系统安装；安装包包含未修改的引擎、随附许可证及源代码获取说明。源代码见 [LibreOffice 26.8.1 官方源码目录](https://download.documentfoundation.org/libreoffice/src/26.8.1/)，过滤器说明见 [官方转换格式列表](https://help.libreoffice.org/latest/en-US/text/shared/guide/convertfilters.html)。

OFD 渲染采用 [@ycsx/ofdjs](https://github.com/ycsx/ofd.js) 1.0.6（Apache-2.0）；编码转换采用 [iconv-lite](https://github.com/pillarjs/iconv-lite) 0.6.3（MIT）；手机离线表格兼容采用 [SheetJS CE](https://docs.sheetjs.com/docs/getting-started/installation/nodejs/) 0.20.3 官方发行（Apache-2.0）。相关依赖与许可证随程序提供。签章图形展示不等同于数字证书验证。

公式扩展使用 Formula.js 4.6.1，数字格式使用 SSF 0.11.3，并在独立安全分析器中显式适配；它们及其 bessel、jstat、frac 依赖的许可证随桌面和 Web/移动静态资源提供。
