# 智能助手设计令牌与界面自检

## 设计令牌

智能助手延续当前项目的浅色工作台与蓝色主色，样式统一引用 `renderer/src/styles.css` 中的变量：

| 用途 | 令牌 |
| --- | --- |
| 主色与强调 | `--brand`、`--brand-soft` |
| 背景与面板 | `--bg-app`、`--bg-card` |
| 主要与次要文字 | `--text-1`、`--text-2` |
| 边框与层级 | `--border`、`--shadow-card` |
| 间距与圆角 | `--space-1` 至 `--space-4`、`--radius-control`、`--radius-card` |

主视觉是文件对话区；配置表单和修改预览按使用阶段展开。界面沿用现有正文字体与字号，不添加独立配色或装饰图标。

## 界面自检评审

1. 原定抽屉宽度固定为 430 像素，小于该宽度的窗口会截断内容。已改为不超过视口宽度，并在 480 像素内缩小水平留白。
2. 展开完整模型配置后，表单可能把对话和发送栏挤出较矮的窗口。已限制配置区最大高度并允许其独立滚动，发送栏始终可见。
3. 浏览器预览没有主进程桥接，直接读取配置会弹出无操作错误。已改为展示桌面版使用说明并禁用配置控件；桌面版真实读取错误仍通过弹窗说明。
4. 修改预览若只展示汇总数量，用户无法判断将修改哪些位置。已逐项展示位置、原文和修改后内容，应用与放弃按钮保持同一层级。

修复后的完整界面源码位于 `renderer/src/assistant/AiAssistant.tsx`、`renderer/src/assistant/AiSettingsCard.tsx` 和 `renderer/src/assistant/assistant.css`。
