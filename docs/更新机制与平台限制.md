# 更新机制与平台限制

自 2.8.0 起各平台的更新方式如下。应用内不支持的方式均有明确原因与替代路径，不作为缺陷登记。

| 平台 | 检查更新 | 应用内下载 | 安装方式 | 系统机制 |
| --- | --- | --- | --- | --- |
| Windows 安装版 | 支持 | 支持，校验大小与 SHA-256 | 启动可交互的安装向导 | NSIS 辅助安装器 |
| Windows 商店版 | 支持 | 不适用 | 跳转微软商店 | 微软商店 |
| macOS | 支持 | 支持，校验后打开 DMG | 用户拖入“应用程序” | 磁盘映像 |
| Linux | 支持 | **不支持** | 确认后在浏览器下载 DEB，用户自行安装 | DEB 需 root 与包管理器 |
| Android | 支持 | 支持 | 系统安装器确认 | `REQUEST_INSTALL_PACKAGES` |
| HarmonyOS | 支持 | **不支持** | 华为应用市场更新窗口；失败回退官网下载页 | AppGallery 更新接口 |

## Windows 安装版

1. 下载到用户数据目录 `verified-updates/`，核对后台登记的字节数与 SHA-256，不一致拒绝安装。
2. 点击“安装”后，主程序以 Electron 自带 Node 启动一个分离的交接进程（`main/update/installerHandoff.js`），随即退出。
3. 交接进程等待主程序退出（最长 2 分钟），再**不带任何参数**启动安装程序。安装程序与手动双击一致：安装模式、安装目录、进度与完成页由用户逐步确认。
   - 2.7.x 曾带 `--updated` 启动，electron-builder 的辅助安装器会据此跳过安装模式与目录页并在完成后自动拉起新版本，表现为“一闪而过”。2.8.0 已取消该参数，源码守卫测试禁止其回归。
4. 交接进程无法启动时，打开安装包所在文件夹并提示手动运行；用户取消或安装失败后，已下载的安装包保留，可再次点击安装。
5. 交接与启动结果写入 `%APPDATA%/海豹办公/verified-updates/install-log.jsonl`（交接开始、主程序退出超时、安装包缺失、安装向导已启动及进程号）。

## Linux

DEB 安装需要 root 权限与包管理器，项目未维护 APT 软件源，应用内静默或自动安装不可行。2.8.0 起：

- 发现新版本后弹窗说明更新内容；用户点“立即更新”后，在默认浏览器中打开后台登记的当前版本 DEB 地址（必须是 HTTPS 且以 `.deb` 结尾）。
- 应用内不再下载 DEB，也不再调用系统默认程序打开，避免被归档管理器接管造成误解。
- 下载完成后用系统软件中心打开安装，或在终端执行：

  ```bash
  sudo apt install ./seal-office-<版本>-amd64.deb
  ```

后续如需自动更新，另行评估软件源或 AppImage 方案。

## HarmonyOS

应用内安装 HAP 受系统限制，正式渠道是华为应用市场；直接侧载需要含设备 UDID 的调试证书。

- 通过 `updateManager.checkAppUpdate` 与 `showUpdateDialog` 显示应用市场更新窗口。
- 应用市场不可用、尚未上架新版本或未显示窗口时，如实说明原因并在浏览器打开官网下载区 `https://seal.xingmasoft.com/#downloads`，提示需通过华为应用市场安装。
- **发版核对**：后台登记鸿蒙新版本前，先确认 AppGallery 已上架同一版本号，否则用户会反复看到“市场暂未发现可更新版本”。

## Android 与 macOS

保持 2.7.x 行为：Android 下载后由系统安装器确认安装；macOS 下载校验后打开 DMG。
