# 本地工作台设计令牌与界面自检

日历、脑图、流程图、应用汇总和本机文件页延续现有首页的浅色办公界面。页面的核心内容分别为日历日期网格、图形画布、工具入口或文件列表；操作按钮位于标题右侧，次要说明使用较弱文字颜色。

## 设计令牌

所有新页面共用 `renderer/src/styles.css` 中已有的 CSS 变量：`--brand`、`--brand-soft`、`--bg-app`、`--bg-card`、`--bg-hover`、`--text-1`、`--text-2`、`--border`、`--border-subtle`；间距使用 `--space-1` 至 `--space-8` 的 4 像素刻度；控件和面板分别使用 `--radius-control` 与 `--radius-card`；字体使用 `--font-body` 与 `--font-heading`。新增样式不引入独立配色。

## 界面自检评审

1. 初版应用页把所有入口铺成相同卡片，主次不清。现按编辑文件、本地工具和应用设置分组，让文件编辑入口优先展示。
2. 初版本机文件列表在空目录时缺少内边距，提示紧贴边界。现为空状态加入与列表行一致的留白。
3. 初版左侧栏目用“可用”状态当作“选中”状态，多个入口同时高亮。现依当前导航键只高亮正在查看的栏目。

本机工作台按内容区实际宽度变列：900 像素以内日历与画布改为单列；620 像素以内文件列表保留名称和打开操作；480 像素以内收紧日历单元，并让不足 350 像素的日历横向滚动。自定义按钮提供悬停、键盘焦点和禁用反馈。

## 本轮界面自检评审

1. 本地页叠加首页容器和页面自身内边距，使日历与画布在同一窗口里比最近文档区窄。移除页面的重复内边距，并将标题字号与首页标题统一为 20 像素。
2. 原断点按整个窗口判断。侧栏和推荐栏同时占宽时，日历和画布会在狭窄的实际内容区仍保持双列。改为依据 `wps-main` 内容区的容器查询，并为极窄日历保留可滚动的最小网格宽度。
3. 本机文件页标题中的长目录路径可挤压刷新按钮。标题文本允许换行，标题组可缩小；文件列表按内容区宽度收起次要列。
4. 删除日程、删除图形节点及覆盖画布原用普通确认按钮，不易识别操作后果。统一使用危险操作按钮；图形数据导出失败时展示明确的错误弹窗。
