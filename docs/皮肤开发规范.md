# 海豹办公皮肤开发规范

适用版本：2.4.0 起。皮肤只改变界面颜色、圆角与可选背景图，不改变功能，也不能携带脚本或样式代码。

## 文件格式

皮肤文件扩展名 `.sealskin`，内容为 UTF-8 编码的 JSON，整体不超过 512 KiB。在“皮肤市场 → 开发规则”中点击“下载模板皮肤”可得到可直接修改的模板；内置皮肤也可“导出”作为起点。

```json
{
  "format": "seal-skin",
  "schema": 1,
  "id": "your-name.my-skin",
  "name": "我的皮肤",
  "author": "你的名字",
  "version": "1.0.0",
  "description": "一句话介绍这套皮肤",
  "light": { "bg": "#F4F5FB", "sidebar": "#FFFFFF", "card": "#FFFFFF", "toolbar": "#FBFBFE",
             "text": "#1B1D2B", "text2": "#5A6075", "text3": "#6B7186", "border": "#E7E8F2",
             "brand": "#6A5CF5", "brandHover": "#5848E8", "brandSoft": "#EFEDFF",
             "hover": "#F3F2FF", "selected": "#ECEAFF", "gradientFrom": "#7B6BFF", "gradientTo": "#5B7CFA" },
  "dark": { "...": "与 light 相同的 15 个键" },
  "radius": { "card": 12, "control": 8 },
  "background": { "image": "data:image/webp;base64,...", "opacity": 0.18 }
}
```

## 字段规则

| 字段 | 要求 |
| --- | --- |
| `format` / `schema` | 固定为 `"seal-skin"` / `1` |
| `id` | 必填，3–64 位小写字母、数字、点或连字符，以字母或数字开头，建议“作者.名称”；不能与内置皮肤重复 |
| `name` | 必填，1–24 个字符 |
| `version` | 必填，语义化版本，如 `1.0.0`；同一 `id` 再次导入会替换旧版本 |
| `author` / `description` | 可选，分别不超过 32 / 120 个字符；所有文本不能包含尖括号或控制字符 |
| `light` / `dark` | 必填，各包含下表 15 个键，值必须是 `#RRGGBB`；出现未知键即拒绝 |
| `radius` | 可选，`card` 为 0–24 的整数，`control` 为 0–16 的整数 |
| `background` | 可选，`image` 仅限 PNG / JPEG / WebP 的 base64 data URL，解码后不超过 300 KiB，文件头须与声明类型一致；`opacity` 为 0–0.4 |

顶层出现未列出的字段即拒绝，不接受自定义 CSS、脚本或外部链接。

### 颜色键

| 键 | 用途 |
| --- | --- |
| `bg` | 页面背景 |
| `sidebar` | 侧栏与图标栏 |
| `card` | 卡片、弹窗、菜单 |
| `toolbar` | 编辑器功能区 |
| `text` / `text2` / `text3` | 正文 / 次要文字 / 辅助文字 |
| `border` | 边框与分隔线 |
| `brand` / `brandHover` / `brandSoft` | 主色 / 主色悬停 / 主色浅底 |
| `hover` / `selected` | 列表悬停 / 选中底色 |
| `gradientFrom` / `gradientTo` | 主按钮渐变起止色 |

## 可读性要求

两种模式分别检查（WCAG 对比度）：

- `text` 与 `card`、`text` 与 `bg` 不低于 4.5:1；
- `text2` 与 `card` 不低于 3:1；
- 白色文字与 `brand` 不低于 3:1，保证主按钮可读。

不满足时导入和公开申请都会被拒绝，并提示具体的模式、颜色与实际对比度。

## 导入与公开

- **本机导入**：皮肤市场“导入皮肤”，校验通过立即应用，只对本机生效，无需审核。可随时卸载，卸载正在使用的皮肤会回到默认“海豹紫”。
- **公开给所有人**：须登录并开通云空间。在“我的皮肤”中点击“上传公开”，皮肤先加密保存到云空间，再提交公开副本给管理员审核；封面由客户端根据颜色自动生成色板。审核通过后出现在“公开皮肤”，任何用户都可安装；作者可随时撤回。
- 只上传自己创作的皮肤。服务端使用与客户端相同的校验模块（`main/skins/skinFormat.js` / `server/skinFormat.cjs`）重新检查，管理员在后台“皮肤审核”中确认配色可读、无侵权后公开。
