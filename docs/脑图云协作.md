# 脑图、流程图的云同步与共同编辑（2.0）

脑图和流程图保留原来的本机项目列表、画布与编辑工具，新增“云端与协作”页签。云项目使用与文字、表格和演示相同的账号、加密空间、共享授权及团队角色体系。

## 创建和打开

1. 本机项目卡片上的“同步到云端”可以把当前图保存到“我的云空间”或有编辑权限的团队。原本机项目保留，后续云修改与本机副本独立。
2. “云端与协作”中可以新建多个云项目、按来源筛选、搜索、重命名、另存本机或另存到其他云位置。
3. 个人云、共享页、团队空间、标签中的图形文件均打开同一个云图形编辑器。脑图使用 `.sealmind`，流程图使用 `.sealflow`，下载会合并当前加密协作日志并生成最新图形文件。
4. 同一账号在其他设备登录并解锁空间后，可以读取个人云项目。共享和团队继续遵循原有凭证接收流程；新设备没有凭证密钥时需要重新接收原凭证。

## 共享与团队

- 个人云项目可在云项目卡片点击“共享”，指定接收账号、只读或共同编辑权限及有效期。接收者从“共享”页面接受凭证后打开。
- 团队图形沿用团队的所有者、管理员、编辑者和查看者角色。查看者实时接收修改，编辑控件禁用；服务端每次同步重新检查权限。
- 共享撤销、到期、团队降权或移除会停止相应写入。撤销个人共享不会影响所有者继续同步自己的项目。
- 可将已下载内容另存为独立本机项目。团队删除不可通过个人回收站恢复，删除前应保存需要的副本；个人云项目可从原云回收站恢复，协作日志也保留到永久删除。

## 实时编辑与离线恢复

节点文字、备注、坐标、形状、配色和连线通过加密增量合并；枚举值、颜色和连线端点按完整字段处理，避免字符合并产生无效值。撤销/重做针对当前设备自己的编辑，远端编辑保留。

状态栏显示连接状态、在线设备和待同步操作。已经打开的项目在断网后可继续编辑，操作与目录缓存在当前账号的加密本机存储中。恢复网络或点击“立即同步”后重新授权并合并；安全队列未完成落盘时离开页面会触发保护。

中文合成输入和节点拖动使用操作开始时的画布基线。若其他成员删除了正在编辑的节点，未合并的输入会加密保留并提示“另存恢复项目”，不会把已删除节点直接复活。恢复副本保存失败时，原恢复记录继续保留。

移动端保留项目列表、触摸拖动、双指缩放与缩放按钮，页面适配手机、平板和桌面宽度。Android/HarmonyOS 使用相同的图形逻辑与原生网络桥接。

## 当前边界和验收

单图沿用最多 100 个节点、300 条连线及 2 MiB 图形数据的限制。离线读取限于当前设备已缓存的项目；切换账号不会读取上一个账号的加密协作缓存。服务器需提供 `diagramRealtime: 1` 能力，旧服务器会明确提示升级。

本次验证包含真实本机 HTTP 服务、加密磁盘/IndexedDB、独立生产窗口和 WebView 宿主协议。最终报告位于 `docs/verification/v2.0.0-fifth-pass/`。Android/HarmonyOS 交付的是可云打包源码快照，实际签名 APK/HAP 和真机安装仍由云打包及设备验收确认。
