# 海豹办公隐私声明

上次更新时间：2026 年 10 月 7 日

适用产品：海豹办公（Seal Office）Windows 桌面版，适用于 1.8.3 及后续版本。

本声明说明海豹办公会处理哪些数据、为什么处理、数据存放在哪里，以及你可以如何访问、控制和删除这些数据。为便于对照阅读，本声明沿用通行的隐私声明结构（数据类别、使用目的、共享情形、访问与控制、存储与保留、儿童数据、声明变更、联系方式），并按本程序的实际实现逐项说明。

海豹办公是一款安装在你电脑上的本地办公软件，**没有面向用户的账号体系，也没有用于收集数据的服务端**。你的文档、设置和对话都保存在你自己的电脑上。

## 要点

- **开发者不收集你的个人数据**：程序内没有使用统计（埋点）、没有遥测上报、没有崩溃转储上传、没有广告组件、没有自动更新检查。开发者无法看到你在软件里的任何操作。
- **文件始终在本机读写**：打开、编辑、保存、打印、导出全部在你的电脑上完成，文档内容不会上传到开发者或任何中间服务器。
- **只有你主动使用联网功能时才会外发数据**：AI 助手、翻译、语义校对、语音合成、演示生成等功能，会把完成该次请求所需的片段发送到**你自己配置的服务地址**（如 DeepSeek、豆包/火山方舟、智谱、Kimi 或自定义兼容接口）。是否使用、发给谁、发什么，都由你在这一步决定。
- **密钥与对话记录加密保存**：模型密钥、对话与记忆使用 Windows 系统提供的数据保护能力加密后存放在本机；系统加密不可用时，程序会拒绝保存而不是退回明文。
- **工作区自动备份不加密**：为在崩溃或误关闭后恢复，未保存的工作区会以明文 JSON 保存在本机用户数据目录中，请注意共享电脑上的可见性（见[其他重要隐私信息](#其他重要隐私信息)）。
- **屏幕录制由你主动开始**：演示文稿的“屏幕录制”可以录制你选择的屏幕或窗口，并可选择同时录制麦克风；录制内容只保存在你指定的本机路径，不上传。程序不使用摄像头，也不收集位置与通讯录。
- **不要求注册、不收集身份信息**：程序不索取姓名、手机号、邮箱、支付信息，也没有账号与云端同步。

## 我们收集的个人数据

### 结论：开发者不收集

海豹办公不向开发者或其服务器发送任何个人数据。程序中没有账号注册、没有云端同步（界面中的“云端同步暂未开放”为占位说明）、没有数据回传通道。因此开发者既无法访问你的文档，也无法获取你的使用行为。

### 由你提供并保存在本机的数据

以下数据由你在使用过程中产生，保存在本机，不会自动外发：

| 数据 | 内容 | 存放位置（Windows 用户数据目录） | 是否加密 |
| --- | --- | --- | --- |
| 模型服务设置 | 接口地址、密钥、模型名称、思考强度、上下文令牌等 | `assistant-config.secure` | 加密（系统安全存储） |
| 对话与记忆 | 按文件隔离的对话记录、目标与进度摘要、长期记忆条目 | `assistant-sessions/` | 加密（系统安全存储） |
| 演示服务设置 | 演示生成、语音合成等服务的接口地址与密钥 | `presentation-services.secure` | 加密（系统安全存储） |
| 语音缓存 | 已合成语音的音频文件 | `presentation-speech-cache/` | 否 |
| 本地素材库 | 你导入的图片与分类信息 | `presentation-assets/` | 否 |
| 最近文档记录 | 文件名、本机路径、类型、大小、修改时间、星标状态 | `recent.json` | 否 |
| 工作区自动备份 | 未保存文档的正文与编辑状态，用于关闭或异常后恢复 | `backup/autosave.json` | 否（明文 JSON） |
| 首次提醒记录 | 是否已提示过设置默认程序、临时安装标识 | `default-app-validation/default-app-prompt.json` | 否 |
| 文件关联图标 | 便携版在持久目录中生成的图标文件 | `file-icons/` | 否 |
| 你的文档 | 你打开与保存的 DOCX、XLSX、PPTX、PDF 等文件 | 你自己选择的位置 | 由你的系统与文件本身决定；程序不额外复制到其他位置 |

“用户数据目录”的默认位置为 `%APPDATA%\SealOffice`（便携版可能位于其解压目录的数据文件夹）。该目录同时包含 Electron/Chromium 的标准运行数据（缓存、`Local Storage`、`Preferences`、GPU 缓存等），这是所有桌面应用运行时的通用行为；程序未启用崩溃上报，因此这些数据不会自动上传，Windows 也可能在本机系统中保留崩溃转储供你自行排查。

### 使用联网功能时发送给第三方服务的数据

只有在你使用下列功能时，程序才会向网络发起请求，且请求目标是**你在设置中填写的服务地址**：

- **AI 助手与文档改写**：系统指令、你输入的提示词、当前文件的相关片段（正文段落、单元格内容、幻灯片文本、备注等）、该文件的对话历史；当你附加图片时，还会发送该图片的 Base64 数据（用于具备图像理解能力的模型）。
- **翻译、语义校对、讲稿生成、智能美化、演示文稿生成**：待处理的文本片段或结构，以及你设置的术语表、目标语言等参数。
- **语音合成**：需要朗读的文本稿。
- **模型记忆摘要**：接近上下文预算时，程序调用同一个已配置服务对历史对话做压缩。

请求直接发往你的服务商（HTTPS，本机地址除外；`Authorization: Bearer <你的密钥>`，`redirect: error`，不携带 Cookie，不附带本程序的设备标识或使用统计）。服务商能够看到的内容包括你发送的上述片段、请求时间，以及网络层必然可见的 IP 地址。

### 我们不收集的数据

姓名、邮箱、电话、通讯录、账户凭据；支付与订阅信息；设备唯一标识与广告标识；精确或不精确的位置；按键记录、剪贴板历史；使用统计、崩溃转储、性能遥测；与你无关的其他文件。程序不申请摄像头、通讯录、位置权限，也不读取 Windows 账号名或计算机名，保存的文档中不写入这些信息。

程序会请求两类系统能力，都只在你主动触发时发生，且内容留在本机：**屏幕/窗口捕获**与**麦克风**（演示文稿的“屏幕录制”，见下文[屏幕录制与麦克风](#屏幕录制与麦克风)）；此外会写入当前用户的注册表以注册右键新建与默认程序。

## 我们如何使用个人数据

由于数据都在你的设备上，这里的“使用”指本机处理，目的包括：

- **提供产品功能**：打开与解析文件、编辑、排版、打印、导出，以及你请求的联网功能。
- **保持工作状态**：写入最近文档记录与工作区自动备份，用于重新打开、崩溃恢复与退出前提醒。
- **安全与完整性**：校验安装目录完整性清单、校验链接协议白名单、校验导入文件结构，避免损坏或越权访问。
- **故障排查**：把错误信息显示在界面或写入本机控制台，便于你自行定位或反馈。

我们**不会**把你的数据用于广告投放、用户画像、信用评估，也不会用它训练任何模型——本程序不提供模型服务端，模型能力由你选择的服务商提供。

## 我们共享个人数据的原因

- **不向开发者共享**：程序没有回传通道。
- **只在你发起时直连服务商**：数据由你的设备直接发送给你配置的第三方服务（模型、翻译、语音、素材服务）。这些服务商按其自身隐私政策处理数据，可能位于境内或境外，请你按需自行评估合规要求（涉密信息、个人信息、未成年人信息、行业监管要求）。
- **系统集成**：设置默认程序、注册右键新建菜单时，程序会按 Windows 规范写入当前用户注册表项；这属于本机系统配置，不涉及数据外发。
- **法律要求**：若司法机关或行政机关依法提出要求，开发者仅能提供其实际持有的数据——即仓库源码与发布包，不包含你本机上的任何数据。

## 如何访问和控制你的个人数据

你不必联系开发者即可完全控制这些数据：

- **查看与更正**：设置中心可查看模型服务配置（密钥不回显，只显示是否已配置）；最近文档可在首页查看、重命名、加星标。
- **删除**：
  - 对话与记忆：在智能助手中按文件删除对话，或直接删除 `assistant-sessions/` 目录。
  - 最近记录：单条移除，或使用首页“批量管理”一次移除多条（只删记录，不删磁盘文件）。
  - 语音缓存与素材库：在演示相关面板中清理，或删除对应目录。
  - 工作区自动备份：退出前保存全部文档，或删除 `backup/autosave.json`。
  - 全部数据：关闭程序后删除整个用户数据目录，或卸载软件；卸载不会删除你自己保存的文档。
- **撤回同意**：删除模型服务配置中的地址与密钥，即不再发生任何外发；程序也不要求你同意任何数据收集。
- **可携带**：对话、设置等以标准 JSON 保存在本机，可直接复制；文档为标准 Office 格式，可在其他办公软件中打开。
- **我们无法代为操作**：由于开发者不持有你的数据，无法为你检索、导出或删除本机文件；如需协助，请通过下方联系方式说明情况。

## Cookie 和类似技术

本程序不使用 Cookie、Web 信标、像素标签或广告标识符，也不做跨应用追踪。界面中的本地存储（`Local Storage`）仅用于记住窗口布局、主题、面板开关等本机偏好，不用于识别你的身份，可通过删除用户数据目录清除并重置。

## 账户

本程序不提供账户注册与登录，不存在用户资料、密码或订阅授权数据。演示文稿中的超链接、默认程序设置等能力均在本机完成。

## 收集儿童数据

本程序面向一般办公场景，不针对儿童设计，也不收集任何年龄信息。由于程序不收集个人数据、不提供社交或内容分发功能，儿童使用时的数据处理方式与成人一致。请监护人注意：**联网功能会把内容发送给你配置的第三方服务**，其中可能包含个人信息，建议在监护下使用并避免输入敏感内容。

## 个人数据的存储和处理

- **全部在本机**：本程序处理的所有数据都保存在你的设备上，开发者不进行跨境传输，也不设置任何云端副本。
- **你配置的第三方服务**：当你使用联网功能时，数据由该服务商在其数据中心处理，处理地点、保留期限与安全措施适用其隐私政策与所在地法律。
- **保留期限**：本机数据没有自动过期时间，保留到你删除对应文件、清除记录或卸载程序。对话记忆按文件标识保存，直到你在应用内删除；最近记录由你管理。
- **系统加密的边界**：加密使用 Windows 系统接口（数据保护 API，与当前 Windows 用户账户绑定）。因此在同一台电脑上，登录同一账户的其他程序或用户可能具备解密能力；多人共用同一 Windows 账户时，请把用户数据目录视作需要保护的目录。系统加密不可用时，程序拒绝保存密钥与对话记忆，不会退回明文。

## 广告

本程序不包含广告，也不使用广告标识符或个性化推荐系统。界面中的“精选推荐”“快捷开始”“工具与编辑”等为固定的本机功能入口，不基于你的行为数据。

## 其他重要隐私信息

### 人工智能与联网功能（产品特定）

- **需要你自行配置**：程序不附带模型权重、密钥或调用额度。未配置服务地址与密钥时，联网功能不可用，其余功能完全在本地工作。
- **服务商预设**：内置 DeepSeek、豆包（火山方舟）、智谱、Kimi 四家接口地址预设与文档链接，也支持任意 OpenAI 兼容接口。预设仅代表“地址与参数格式”，不代表开发者与该服务商存在数据合作或代理关系。
- **发送范围以完成该次请求为限**：助手默认只发送当前文件的相关片段与你输入的提示；长篇文档会按上下文预算分批读取，超出部分不发送。
- **服务商侧的行为**：内容是否被留存、是否用于模型训练、如何计费，由你与该服务商之间的条款决定。请在使用前阅读其隐私政策；对涉密或受监管内容，建议改用本机部署的兼容接口（将地址指向 `localhost` 等本机服务时，程序不会外发数据）。
- **地址规则**：模型、翻译、语音等服务地址必须是 `https`，只有本机地址（`localhost`、`127.0.0.1`、`::1`）允许使用 `http`，用于连接你在本机部署的兼容服务；接口地址不得内嵌账号、密码或片段标识。
- **不会自动改写你的文件**：助手提出的修改先以候选形式展示（含定位与原文），只有你逐条确认后才应用到当前文档，并且仍需你主动保存才会写入磁盘；模型返回的内容在界面上明确区分“思考”与“正文”。

### 文档属性与元数据

保存的 DOCX 会按 Office 格式写入标准文档属性：当前版本写入固定的创建者/修改者占位值 `Un-named`，并写入创建与修改时间。程序不写入 Windows 账号名、计算机名或软件授权信息。你导出 PDF、图片时，相应文件也会带有格式本身的时间等元数据。若你不希望保留这些信息，可在其他办公软件中清除文档属性后再分发。

### 系统集成

- 安装版会在**当前用户**注册表下注册 DOC、DOCX、PPT、PPTX、PDF、XLS、XLSX 七种右键新建模板与四类默认程序关联；卸载会恢复仍属于本软件的菜单项，保留其他程序后来做的更改。
- 程序仅在安装后首次启动检查默认程序，读取系统关联状态以判断是否需要提示，不会读取其他程序的私有数据。
- 首页的“桌面”“文档”“下载”“浏览”等入口，只在你打开该入口时列出对应目录的文件名与状态，不会在后台扫描你的磁盘。
- 打印时，内容会交给 Windows 打印子系统与你在打印对话框中选择的打印机驱动处理。如果该打印机是网络打印机、打印服务器或虚拟打印服务，内容会按该打印配置发送到对应设备或服务。

### 屏幕录制与麦克风

演示文稿编辑器的“屏幕录制”是本程序唯一能够捕获应用之外内容的功能，使用规则如下：

- **由你选择捕获对象**：先在“刷新捕获源”得到的列表中选定某个屏幕或某个窗口（列表由系统桌面捕获接口返回，缩略图仅在本机界面显示）；未选择时无法开始。
- **麦克风需要单独勾选**：默认只录制画面；“同时录制麦克风”由你显式勾选后才请求系统麦克风授权，拒绝授权时会提示并改为仅录制画面。
- **内容只留在本机**：录制的片段保存在内存中供预览，只有你点击“保存录制”并选择路径后才以 WebM 文件写入磁盘；程序不上传录制内容，也不做后台录制。
- **请自行确认授权与合规**：录屏可能拍到他人信息、受保密约束或受版权保护的内容，麦克风可能录入他人语音。请在录制前取得必要授权，并遵守你所在组织与所在地的规定。
- **随时可停止**：录制过程中可暂停或停止，停止后关闭面板或退出程序会释放屏幕与麦克风设备。

### 网络请求与安全

- 只允许 `http`、`https`、`mailto` 协议交给系统打开，且渲染层与主进程各校验一次；应用内页面禁止导航到外部地址，也不允许弹出新的程序窗口。
- 模型请求使用 HTTPS 且禁止跟随重定向，避免密钥被转发到非预期地址；密钥不回显到界面，也不写入日志。
- 安装包当前未做代码签名，Windows 可能显示未知发布者提示；程序内提供安装完整性清单校验，可检测已打包文件被替换。

### 演示与媒体

- 语音合成的音频缓存在本机，便于重复播放；本地素材库仅索引你导入的图片。
- 演示文稿中的超链接、打开网页等动作，在放映时经协议白名单交给系统默认浏览器处理。

### 共享或受管电脑

如果多人共用一个 Windows 账户，或电脑由单位统一管理：本机数据目录对所有能登录该账户的人可见，工作区自动备份与最近记录为明文；集中管控软件（如终端审计、端点防护、备份代理）可能读取到这些文件。建议在受管设备上避免在联网功能中输入敏感内容。

附：彻底清除本机残留数据的步骤

1. 关闭海豹办公，确认没有标签处于未保存状态。
2. 删除用户数据目录（默认 `%APPDATA%\SealOffice`）：其中包含模型密钥、对话记忆、最近记录、工作区备份、语音缓存与素材库。
3. 便携版另需删除其数据文件夹与在 `file-icons/` 生成的图标（若使用安装版注册过关联，建议先卸载以恢复右键新建菜单）。
4. 如需重新开始，卸载后删除上述目录即可；你自己保存的文档不受影响，需要单独处理。
