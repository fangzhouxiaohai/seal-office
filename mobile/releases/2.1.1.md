# 海豹办公移动端 2.1.1 / 20101

本版沿用原 AppID、包名、Harmony bundleName 和签名配置。四种短后缀 `.sldoc/.slxls/.slppt/.spdf` 同时支持 Android、Harmony、Web 和桌面，旧三种后缀继续兼容。移动全屏阅读默认收起操作栏，双击唤出并在三秒无操作后收起；文档编辑、云存储和未失焦草稿保护共用本版编辑器。

Harmony 修复了 SDK 普通对象消息被误当成 UTSJSONObject 而导致打开、保存和网络请求无响应的问题，并加入启动握手、失败反馈和超时。详情见[修复说明](../../docs/HARMONY_BRIDGE_FIX_2.1.1.md)。

生成式 AI 使用前核验当前服务端会话和已验证手机号账号。首次使用短信验证登录，已有已验证账号也可密码登录；取消登录保留输入，登录成功后由用户主动重试。AI 核验不要求开通云空间，本地文档阅读、编辑和保存仍可使用。法规依据与调用边界见 [AI 身份核验](../../docs/AI身份核验.md)。

## 分平台云打包

分别使用 `mobile/unpackage/cloud-ready/2.1.1/android/` 和 `mobile/unpackage/cloud-ready/2.1.1/harmony/` 冻结目录，或解压对应的 `seal-office-2.1.1-*-cloud-source.zip`。每个平台包含自己的 `build-info.json` 和 `snapshot-info.json`，不要混用静态资源。

用 HBuilderX 打开对应目录，沿用本项目身份和原签名，确认版本 `2.1.1`、构建号 `20101` 后提交该平台云打包。源码包和 UTS 编译检查产物都不等于 APK、HAP 或签名 App Pack。

原仓库也可分别执行 `npm --prefix mobile run build:android` 或 `build:harmony` 后构建。`static/office/` 是共享输出目录，切换平台会覆盖它；正式交付使用上面的独立冻结目录。

## 成品与设备复验

- Android 下载原始 APK 后，运行 `npm --prefix mobile run check:apk -- <路径> --require-current --archive release/v2.1.1`，再用 Android SDK 验证签名。归档为 `seal-office-2.1.1-android.apk`，保持原字节。
- Harmony 已签名 App Pack 归档为 `seal-office-2.1.1-harmony.app`，发行外层 ZIP 名为 `seal-office-2.1.1-harmony.app.zip`。外层 App Pack 和内层 HAP 签名分别校验；内层未签名 HAP 不能冒充直接安装包。
- 如果得到独立签名 HAP，运行 `npm --prefix mobile run check:hap -- <路径> --archive release/v2.1.1`，再使用华为官方工具独立验签。
- 包内须包含 Noto Sans SC、Noto Serif CJK SC 和两份许可证；验包会记录四个资源的大小与 SHA-256。
- 在真实目标设备核验：冷启动握手、系统选择器选择四种新格式、编辑后保存、另存为选择系统目录、取消不误报成功、退出应用后重新打开实际目标文件、阅读双击与三秒隐藏、输入法草稿切页保护、短信实际到达及密码登录。
- AI 助手核验：匿名发送时先显示登录原因；取消保留原输入；已验证手机号账号短信或密码登录后主动重试；会话过期或撤销时重新核验。匿名、核验失败和取消时不应向模型发送请求。

当前没有连接 HarmonyOS 6.1 审核设备。SDK 形状契约、UTS 编译、生产 IIFE 浏览器测试与真实系统选择器/短信投递的验收范围分别记录，不互相替代。
