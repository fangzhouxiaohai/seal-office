# 海豹办公 2.1.2 移动/Web 同步修复

应用版本 **2.1.2**，移动构建号 **20102**。本次把桌面富文本、字符集、自定义页边距、列宽自适应及正文图片粘贴/拖入修复同步到 Android、HarmonyOS 和网页版。共用编辑器，继续采用两个独立平台构建、原生编译检查、生产交互测试和冻结快照。

最新交付目录为 `release/v2.1.2/mobile-web/`：

- `seal-office-2.1.2-android-cloud-source.zip`
- `seal-office-2.1.2-harmony-cloud-source.zip`
- `seal-office-2.1.2-web.zip`
- `SHA256SUMS.txt` 与逐包 `.verification.json`

云源码 ZIP 的根目录直接包含 `App.uvue`、`manifest.json` 等 HBuilderX 项目文件。分别打开解包后的 `android-cloud-source/`、`harmony-cloud-source/`，提交对应平台云打包；包内编辑器已就绪，不要用仓库里最后一次构建的 `mobile/static/office/` 覆盖任何快照。应用身份、显示名与原签名配置沿用。

Android 归档同时校验压缩包与解压文件总量均不超过 **60,000,000 字节**。字库保持完整，配图沿用已验证的移动派生资源；逐文件 SHA-256、ZIP CRC、资源版本、平台和原生编译资源指纹均须一致。

传统 XLS 在已开通云空间或配置自建转换服务时，读取/保存经确认后使用完整转换引擎；取消或失败直接停止，不能悄悄降级成离线输出。没有可用服务时保留已有离线读取与保存入口，并如实说明高级格式限制。XLSX 和四种专属格式使用共用编辑模型与资源保存。来源文件保持，未支持的对象仍明确提示。

重现顺序（仓库根目录）：

```powershell
npm --prefix mobile run build:android
npm --prefix mobile run check:android
npm --prefix mobile run test:browser -- --file
node mobile/scripts/snapshot.mjs android sync
node mobile/scripts/archive-source.mjs android --snapshot-label sync --output-label mobile-web
# 完成 Android 冻结后，再对 harmony 执行相同流程。
npm --prefix mobile run build:harmony
npm --prefix mobile run check:harmony
npm --prefix mobile run test:browser -- --file
node mobile/scripts/snapshot.mjs harmony sync
node mobile/scripts/archive-source.mjs harmony --snapshot-label sync --output-label mobile-web
# Web 使用独立输出目录，验收后通过 deploy-web.py 分阶段部署。
npm --prefix mobile run build:web
npm --prefix mobile run test:browser -- --web
```

上述快照和归档使用排他创建；重现时选择新的安全英文修订标签，不覆盖已经冻结或发布的同名文件。首次 2.1.2 移动快照和桌面发行保留，新补充发行标签为 `v2.1.2-mobile-web`，原 `v2.1.2` 标签不移动。

线上入口为 [海豹办公网页版](https://seal.xingmasoft.com/office/)。部署先验收独立静态目录，再切换前端指针；保留后台、账号数据及旧页面需要的哈希资源。发布后再次核对线上资源、匿名权限和实际浏览器操作。

详细结果见 [移动/Web 验收记录](../../docs/verification/v2.1.2-mobile-web/README.md)。源码与模拟宿主测试不代表已生成或验收新的签名 APK / Harmony App Pack；原生安装包由用户云打包后另行验签和设备验收。

云打包返回安装包后，可在仓库运行 `npm --prefix mobile run check:apk -- <APK路径> --source release/v2.1.2/mobile-web/android-cloud-source --require-current`，HAP 对应使用 `check:hap -- <HAP路径> --source release/v2.1.2/mobile-web/harmony-cloud-source`。检查器验证所选源码的平台、版本及应用身份，避免误拿上一次构建或此前同版本旧快照作比较。签名 App Pack 仍需分别核验外层签名与内层 HAP 签名。
