# 海豹办公 2.1.2 移动云打包

版本名称 **2.1.2**，构建号 **20102**。此次交付为源码包，Android APK、HarmonyOS 已签名 App Pack 由用户提交云打包后生成。应用名、DCloud AppID、Android 包名、HarmonyOS bundleName 和既有签名身份保持不变。

两份最终交付文件均在仓库 `release/v2.1.2/verified/`：

- `seal-office-2.1.2-android-cloud-source.zip`
- `seal-office-2.1.2-harmony-cloud-source.zip`

分别解压到两个独立文件夹，在 HBuilderX 中打开对应文件夹（根目录直接有 `manifest.json`、`App.uvue`），选择对应平台云打包。包内已经包含经过平台构建的办公编辑器，不要从另一个源码文件夹复制 `static/office`。Android 和 HarmonyOS 共用界面代码，但原生文件选择、保存、分享、WebView 消息等存在平台分支，因此继续独立交付。

本地旧目录清理遇到 EPERM，本次未发布试包删除也被自动审批拒绝，因此保留原文件，最终交付另存于 `verified/`，以该目录的 SHA256SUMS.txt 和验收记录为准。`release/v2.1.2/` 顶层的 Android 试包不用于云打包。Android 最终快照在 `mobile/unpackage/cloud-ready/2.1.2/android-verified/`，鸿蒙快照在同级 `harmony/`；历史发布快照没有改写。

本次包含可拖动的圆形 AI 悬浮球、大弹窗、已打开文件选择，以及对话 / 工作模式。默认目标为当前文件；没有打开文件时强制对话模式，不能开启工作模式。对话模式不修改文件。工作模式沿用已有修改预览和确认流程；PDF 当前提供引用内容问答，不宣称具备 AI PDF 编辑功能。AI 使用仍需通过已有登录和身份校验。

Android 源码 ZIP **及解压后的全部文件合计**均按 60,000,000 字节限制校验。移动模板照片使用 1280 像素 JPEG，透明插画使用 PNG 派生资源，完整中文字库不裁字，桌面模板原图不变。派生图的类型、尺寸和内容指纹同步生成，已测试 PPTX 导出重开后的图片字节。

复现流程：分别执行平台 `build`、`check`，通过生产资源回归后执行 `node mobile/scripts/snapshot.mjs android|harmony`，再执行 `node mobile/scripts/archive-source.mjs android|harmony`。快照和归档拒绝覆盖同版文件，发布后不得修改已归档的资源字节。

本次保留试包后的交付命令：Android 快照使用 `node mobile/scripts/snapshot.mjs android verified`，归档使用 `node mobile/scripts/archive-source.mjs android --snapshot-label verified --output-label verified`；鸿蒙仍使用标准 `harmony` 快照，归档加 `--output-label verified`。修订标签只允许安全英文名称；不会删除或覆盖之前的文件。

云打包返回的 Android APK 请运行 `npm --prefix mobile run check:apk -- <APK路径> --require-current --archive release/v2.1.2` 校验，文件名归档为 `seal-office-2.1.2-android.apk`。鸿蒙 App Pack 使用 `seal-office-2.1.2-harmony.app`，外层 ZIP 使用 `.app.zip`，外层签名与内层 HAP 签名分别验证；内层未独立签名时不能作为独立可安装 HAP。浏览器交互回归和原生源码编译不等于最终签名安装包真机验收。
