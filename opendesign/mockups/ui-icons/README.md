# 海豹办公界面图标效果稿

状态：**两版效果稿已获用户确认，PC / 移动端图标已接入 1.9.10。**

参考用户提供的 WPS PC 插入功能区、移动端首页与新建面板截图。PC 使用细线条、小面积颜色点缀；移动端使用彩色分层文件图标与圆润功能入口。应用品牌、功能名称沿用海豹办公。

打开 `index.html` 或通过 OpenDesign 预览。页面可切换 PC / 移动端，并展开完整图标目录。`assets/pc` 与 `assets/mobile` 各有 127 个已确认的 SVG 主资源。移动端尚无独立入口的功能，只在样式稿中展示已有编辑器能力，不作为新功能发布声明。

从项目根目录运行 `node opendesign/mockups/ui-icons/generate-preview.cjs`，根据保留的主资源刷新图标目录，不改动主资源或产品源码。运行 `node build/import-ui-icons.cjs` 将这两套 SVG 转成产品共用的类型化图形数据。程序组件根据桌面或移动布局选择对应图标，导航可使用单色轮廓，并为重复出现的裁切图形分配独立 ID。

PC 实际界面采用白底、细边框、小圆角与轻阴影；独立验收和真实程序截图见 [1.9.10 图标与扁平界面验收](../../../docs/v1.9.10-图标与扁平界面验收.json)。本目录仍保留确认前的效果稿，实际功能和导航以程序为准。
