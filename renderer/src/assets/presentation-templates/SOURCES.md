# 演示模板摄影资产

这些摄影由内建 `image_gen__imagegen` 于 2026-10-18 按海豹办公模板用途原创生成，未使用外部照片、素材库、商标、真实人物照片或真实产品图作为输入。画面中的人物、建筑和产品为生成场景。用途是离线演示模板的主题配图，不表达对具体机构、地点或人物的事实陈述。

- `city.png`：城市滨水商务建筑，适用于经营复盘、季度总结、路演和项目背景。
- `workshop.png`：团队围绕实体模型展开协作，适用于培训、项目和跨团队行动。
- `product.png`：无品牌产品与工作台静物，适用于产品介绍、创新和方案讨论。
- `research.png`：虚构材料研究实验台与光学原型，适用于科技方案和学术答辩。
- `finance.png`：无品牌财务规划工作台，适用于年度计划和财务经营。
- `event.png`：虚构创意展览场景，适用于市场营销和品牌活动。

完整生成指令保存在同目录 `prompts.json` 与 `prompts-expanded.json`；原始尺寸、字节数与 SHA-256 存在 `metadata.json`。项目内图片是生成 PNG 原始字节的副本，没有把示意色块作为照片，也没有把图表文字烘焙进图片。

配图经 `?seal-image` 内联到应用资源，选择模板时写入演示资源库。预览和实际模型使用相同资源指纹、坐标与裁切参数；PPTX 导出打包 PNG 字节。幻灯片的正文、图表、表格、流程节点和页码均为可编辑原生对象。
