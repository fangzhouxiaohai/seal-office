# 海豹办公云服务 1.9.0

客户端默认连接 `https://seal.xingmasoft.com/api`，也可在账号设置中连接兼容的 HTTPS 服务。Node.js 20 及以上运行 `npm ci --omit=dev && npm start`。服务监听回环地址；通过宝塔站点 Nginx 反向代理提供 HTTPS。管理页面使用固定版本 Panshi 前端基础，构建方法见 [来源与许可证](admin/PROVENANCE.md)。

## 服务配置

通过系统服务的 `SEAL_ENV_FILE` 指定仅运维账号可写的环境文件。生产配置不入库；不要将文件复制到客户端。变量：

| 变量 | 用途 |
| --- | --- |
| `PORT` | 回环监听端口，默认 8096 |
| `SEAL_DATA_DIR` | 数据目录，服务账号需读写，其他用户不可读取 |
| `ALIYUN_ACCESS_KEY_ID` / `ALIYUN_ACCESS_KEY_SECRET` | 阿里云短信访问凭据，仅服务端 |
| `SMS_SIGN_NAME` / `SMS_TEMPLATE_CODE` | 审核完成的签名和验证码模板 |
| `SEAL_ADMIN_SALT` / `SEAL_ADMIN_PASSWORD_HASH` | 管理员密码盐及 scrypt 派生的 32 字节十六进制哈希 |

每账号上限 300,000,000 字节。文件密文、版本、回收站、加密元数据、公开副本与公开索引计入用量；并发上传通过预留用量控制。上传块 1 MiB，24 小时未提交的上传会清理；回收站保留 30 天。接收新数据前检查磁盘余量，预留 2 GiB 运维空间。此部署使用 sql.js 持久化 SQLite，适用于初始部署；须监控进程内存和数据库体积，在扩大用户规模前迁移到独立持久化数据库并进行负载验收。

## 隐私和公开资料

私有文件、名称、索引在客户端以 AES-256-GCM 加密；每文件独立密钥由用户根密钥封装。恢复密钥不上传服务器。服务器仍可知道手机号、密文大小、时间与对象数量。桌面设备的密钥和会话由操作系统安全存储保护；系统安全存储不可用时拒绝保存密钥。

云空间与自动保存默认关闭，需要各自主动开启。公开发布须另行授权，生成供管理员审核的明文公开副本；这是私有加密存储以外的一条路径。公开文件最多 10 MiB。后台采用隔离工作线程验证格式、签名、宏、路径、XML 实体和解压大小，不能等同于通用杀毒引擎。撤回或删除后立即拒绝公开访问并清除公开原文件和索引。已经被他人下载的副本无法收回。

AI 沿用用户当前配置的服务。私有检索在客户端进行，选定片段或扫描页仅在单次授权后发送给该 AI 服务，云端管理后台不持有用户的 AI 凭据和资料明文。

## 部署、备份和回滚

`deploy/` 提供独立的 Nginx 站点、非 root API 服务、每日备份、每小时健康检查和只针对本域名的证书续签任务。按实际项目目录调整配置再安装；勿覆盖已有其他站点。站点目录结构：

```text
/www/wwwroot/seal.xingmasoft.com/
  releases/<发布版本>/    服务代码及 admin/dist
  current -> releases/<发布版本>
  admin -> current/admin/dist
  data/                  持久化数据，权限 0700
```

备份保存到 `/www/backup/seal-cloud`，权限 0600，保留最长 7 天。备份脚本暂停本服务取得一致副本，恢复后检查就绪；仅操作海豹办公服务。恢复演练须在独立目录和端口进行，先核对 SQLite 和对象文件，再用用户恢复密钥验证下载解密。不得将备份直接覆盖生产数据。回滚切换 `current` 至前一发布目录并重启本服务，保留 `data` 和环境文件。

证书由免费证书服务签发，安装到宝塔站点证书目录。`seal-cloud-cert.timer` 每日检查本域名续签，健康检查在剩余有效期不足 14 天时失败。通过 `systemctl status`、系统日志和站点错误日志排查；服务日志不打印短信凭据、验证码或私有内容。

## 验证

运行 `npm test`。集成用例使用临时目录和隔离的短信替身，覆盖真实加密客户端、双设备冲突、并发上传、断网、重启、过期、撤权、配额、停用和备份恢复。真实短信收取需要业务提供测试手机号，测试替身不会部署到生产入口。旧式 DOC/XLS/PPT 在线转换要求独立、受维护的转换环境；当前生产主机未配置该引擎，客户端只承诺现代 Office、PDF、TXT 和 MD 的解析功能。
